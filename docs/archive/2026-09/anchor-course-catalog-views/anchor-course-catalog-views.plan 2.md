# 16개 교육과정 카드·리스트 안내

2026-09-21 · anchor-course-catalog-views

첨부 현황표의 라이프케어 6개, 로컬창업 6개, 팝업 4개 과정을 원문 순서로 공개 안내한다. 관련 자격증은 세 번째 이미지의 행 대응을 따른다. 2026년 현황표를 일정·정원·시수의 최신 근거로, 기존 운영계획 자료를 교육 소개·교육내용의 근거로 사용한다.

- `/courses` 기본 화면: 넓은 데스크톱 4열×4행, 태블릿 2열, 모바일 1열.
- 카드형/리스트형 전환과 검색·운영방식 필터 유지. 관련 자격증 검색 및 표시.
- 모든 과정 상세에 기간·요일/시간·장소·정원·시수·관련 자격증·교육내용 제공.
- 공개 안내 자료를 DB에 저장한다. 기존 3개 운영 과정과 연결해 중복 카드를 방지한다. 기존 접수 상태·교육기록·내부 예산/인력 자료는 유지한다.
- 표의 빈 자격증을 자격증 없음으로 단정하지 않는다. 12월 예정처럼 확정 날짜가 없는 일정은 날짜를 만들어 넣지 않는다.
- 검증: 16개/6·6·4 분포, 자격증 12개와 빈값4개, 수정·2차 일정, 공개 읽기/쓰기 거부, 검색·보기 전환·상세, 모바일, lint/build. Preview→Production 적용 후 main push.
