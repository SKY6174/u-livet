## 원문 수치 차이
첨부표 하단232명/511시간과 달리 16개 세부 행은244명/541시간이다. 골프피팅 행12명/30시간 차이에 해당한다. 개별 안내는 세부 행을 보존하며 별도 합계 수치를 화면에 만들지 않는다. 과목별 변경된 날짜와 요일은 원문 기재를 보존한다.

## 구현 검토
React 서버 컴포넌트와 병렬 조회를 사용하며 추가 클라이언트 상태/라이브러리가 없다. 카탈로그만 읽는 명시적 SELECT, FK unique 인덱스, 공개행 전용 RLS로 조회 범위를 제한한다. 홈의 추천·기존 신청/운영 자료의 접근 계약은 유지한다.
