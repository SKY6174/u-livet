# 운영 권한별 전체 페이지 검증 결과

검사일: 2026-11-08 (Asia/Seoul). 운영: https://u-livet.org.

## 결과

108개 페이지 모듈을 학습자·강사·관리자·비로그인으로 검사했다. 학습자 110, 강사 114, 관리자 113, 비로그인 110건으로 총 **447/447건 통과**했다. 정상 화면, 권한 거부, 로그인 이동과 레코드 누락을 구분했으며 모바일 메뉴의 실제 상태 변경·데스크톱 렌더링·브라우저 예외를 확인했다.

비공개 임시 기수로 수강 신청·수강·학습자료와 강사 강의실 상세를 확인했다. 담당 강사 지정 전의 공식 문서 접근 거부와 지정 후 계획/결과 상세·인쇄 네 화면도 확인했다. 관리자 회원 디렉터리 세 그룹과 강사 상세·이력을 포함한다.

## 수정한 오류

강사 서류함의 문서 세션 요청이 HTTP 403으로 실패했다. 운영 Edge Function 허용 origin에 `https://u-livet.org`가 누락돼 있었다. 기존 두 도메인을 유지하고 해당 origin만 추가해 운영에서 즉시 복구했다. 수정 후 강사 session/context가 200이고 파일 입력 화면이 표시됨을 확인했다. 외부 origin은 계속 거부한다.

배포된 함수와 main bundle의 SHA-256이 같아 앱·함수 소스 수정이나 함수 재배포는 필요하지 않았다. 이 변경에는 CORS 회귀 검사, 전체 페이지 검사기, 임시 데이터 생성/정리 도구와 운영 가이드를 담았다.

## 검증과 정리

- CORS 검사기 회귀 15건과 운영 OPTIONS 4건 통과.
- 기존 배포 준비 회귀 111건, 고정 Supabase CLI 검사와 lint 통과. 격리된 검토 설정으로 Next.js production 모드 빌드 검증.
- 운영 검사 revision: `8f6c5bf18e314fb8785795de162f4c97519dd686`. 최신 운영 오류/fatal 로그 조회 결과 없음.
- 임시 Auth 계정 2개, 권한 6개와 비공개 기수 관련 8행 정리 완료. Auth·문서 세션 및 해당 계정/권한/기수 잔여 0 확인.
- 원래 검증 계정 manifest 복구 및 복사한 비밀번호 폐기. 실제 직원 권한과 지정 운영자 유지.
- 출석·성적·수료·공식 문서 제출·증명 발급·메일·AI 실행 없음.

운영에 증명·배지·제안·성과보고 레코드가 없어 그 상세는 누락/차단 상태만 확인했다. 정상 발급 상세나 지정자 전용 회원 등록·재설정 메일의 실행까지 통과했다는 의미는 아니다.
