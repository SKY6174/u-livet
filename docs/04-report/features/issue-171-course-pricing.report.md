# Issue 171: 과정 등록 아카데미 및 수강료 구현 보고

2026-10-13 · 이슈: https://github.com/SKY6174/u-livet/issues/171

## 변경 결과

과정 등록의 아카데미·분야를 기존 네 아카데미 선택 목록으로 바꿨다. 등록 시 무료·유료를 선택하고 1인 수강료를 입력할 수 있다. 무료는 0원, 유료는 1~100,000,000원의 정수로 저장한다. 유료 금액 미입력·0원·소수·범위 초과는 실제 등록 시 차단한다.

아카데미와 가격은 임시저장 및 복원에 포함하며, 이전 가격 필드 없는 임시저장은 무료로 복원한다. 기존 항목 밖의 아카데미 값도 복원할 수 있다. 새 원자적 RPC가 일반 등록과 원문에서의 등록 모두에 수강료를 반영하고 감사 기록을 남긴다. 이전 RPC와 기존 유료 공개·납부 검증은 유지한다.

## 검증

설계 기준 9/9(100%) 충족. 모델·액션·SSR, 기존 임시저장 10개, 기존 prefill 7개 검증을 통과했다. 로컬 DB에서 무료·유료·원문 연결·기관/익명 권한·실패 롤백·유료 공개 보호·임시저장 저장/복원을 확인하고 테스트 변경은 모두 롤백했다. 실제 클라이언트 UI에서 가격 전환, 잘못된 금액 차단, 150,000원 복원 및 360px 배치를 확인했다. lint·TypeScript·프로덕션 build도 통과했다.
