# 초대 메일 새 창 열기 결과

2026-09-19

초대 메일 버튼을 새 창으로 열도록 보완하고, 메일 내부 미리보기에서 연결 거부가 표시될 때 새 탭을 여는 방법을 안내했다. 운영·Preview의 저장된 메일 템플릿이 소스와 일치하며, 실제 운영 페이지는 새 탭에서 정상 표시됐다.

프레임 차단과 기존 인증·가입 보안 설정은 유지한다. 변경 사항은 메일 템플릿이며 승인 개인정보 문안이나 동의 범위, 예정된 SYSTEM_ADMIN 단일 권한은 바뀌지 않았다.

처음 보고된 메일 클라이언트를 직접 재현한 것은 아니므로, 수신자가 새 메일에서 비밀번호 설정을 완료했는지는 후속 확인이 필요하다. 발송·계정 상태의 실행 증거는 비공개 운영 기록에 보관한다.
