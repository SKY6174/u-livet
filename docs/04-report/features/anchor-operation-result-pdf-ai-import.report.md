# 완료 결과보고서 PDF·AI 가져오기

2026-09-22 · `anchor-operation-result-pdf-ai-import`

관리자는 완료된 과정의 원본 결과보고서 PDF를 업로드하거나 보관된 원본을 다시 선택해 본문과 사진을 읽을 수 있다. AI 제안은 `gpt-5.6-terra`를 우선 사용하며, 필드와 회차별 강의표에 원문 쪽수·인용을 표시한다. 서버에서 확인되지 않은 인용은 자동 선택되지 않는다. 선택한 내용만 초안에 반영하며 예산·장학금·서명·최종 제출은 기존 담당자 절차를 따른다.

샘플 PDF 3개에서 사진 10/26/8장을 추출했고, 첫 샘플의 업로드·저장·재조회·인쇄 및 중복 방지를 브라우저에서 확인했다. 관리자 권한과 책임강사 차단, 예산 우선 입력, 서명·최종 제출 회귀 검사를 통과했다. 이번 보강은 원문 인용 검증 5개 사례, Deno 타입 검사, 린트, TypeScript 검사, Next.js 빌드와 Preview·운영 Edge Function 배포를 확인했다.

실제 Terra 응답은 아직 확인하지 못했다. Preview에는 `OPENAI_API_KEY`가 없고, 운영에 등록된 키는 앞선 실제 요청에서 `401 token_invalidated`로 거절됐다. 유효한 키를 두 환경의 Supabase Edge Function secret으로 설정한 뒤 관리자 화면에서 샘플 원본의 AI 제안·근거·강의표를 확인해야 한다.
