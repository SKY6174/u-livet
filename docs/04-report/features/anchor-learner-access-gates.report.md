# 수강생 로그인·후속 서류 자격 - Completion Report

> Date: 2026-09-23 | Feature: `anchor-learner-access-gates`

## 결과

수강생 로그인은 카카오·네이버·구글을 중심으로 유지하고 이메일 로그인은 개인정보 처리 안내 반대편의 하단 보조 버튼으로 이동했다. 이메일 버튼을 누르면 기존 로그인 폼이 같은 카드 안에서 열린다.

수강생 서류는 과정별 행정 상태와 학사 상태를 연결했다. 수강신청원서가 승인되기 전에는 환불·장학금 탭이 잠기며, 환불은 승인 직후, 장학금은 해당 과정의 유효한 수료 승인까지 완료된 뒤 열린다. 자격 있는 과정만 각 신청서 목록에 표시된다.

## DB·보안

- 승인 원서 조회용 부분 인덱스를 추가했다.
- UI와 제출이 같은 DB 자격 함수를 사용한다.
- 직접 RPC 호출에서도 승인 원서가 없으면 `APPLICATION_APPROVAL_REQUIRED`로 거부한다.
- 장학금은 현재 academic revision, sealed 학사, ACTIVE 등록, `READY` 결과, 승인된 현재 수료 정책을 모두 확인한다.
- 다른 사용자의 승인 원서와 수료 결과는 자격에 영향을 주지 않는다.

## 검증

- DB 통합: 승인 전 환불·장학금 거부, 승인 후 환불 성공, 수료 승인 후 장학금 성공
- PDF 회귀: 수강신청·장학금·환불 PDF 1.7 생성과 원본 양식 검증 통과
- UI: 자격 보유 계정은 세 탭 활성, 미보유 계정은 수강신청원서만 활성
- 정적 검사와 Next.js production build 통과

Supabase DB lint에는 기존 함수에서 발생한 경고와 `course_budget_overview`의 기존 참조 오류가 남아 있으며, 이번에 추가한 함수에서는 새 경고가 발생하지 않았다.
