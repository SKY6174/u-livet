# 성인학습자 화면 글자·아이콘 개선 결과

2026-10-10 · 설계 일치율 100% (8/8)

공통 본문과 작은 글씨를 2px 확대하고, 주요 제목 크기와 바닥글 문의처를 함께 조정했다. 공개 홈의 검색·과정 탐색·신청 안내와 모집 과정 카드에 의미 있는 아이콘을 추가했다. 링크·권한·데이터 흐름은 유지했다.

검증: lint, TypeScript, 프로덕션 빌드 통과. 360/720/1440px 홈·과정 목록 모두 HTTP 200, 본문 20px, 작은 글씨 18px, 수평 넘침 없음. 로컬 DB 미연결로 모집 과정 카드의 실제 데이터 화면은 확인하지 못했다.
