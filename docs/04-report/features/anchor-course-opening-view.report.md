# 2026 운영계획서 개설 준비 화면 완료 보고

> 2026-09-19 · Feature: anchor-course-opening-view

## 변경 결과

관리자 메뉴의 **2026 개설 준비**에서 16개 운영계획서를 검토할 수 있다.
경로는 `/admin/course-plan/opening`이며 COURSE_MANAGER 접근 권한을 사용한다.

- 스마트테크·라이프케어·로컬창업·팝업 현황과 총 244명·541시간을 표시한다.
- 교육내용·대상·기관·일정·담당교수·교내/교외 강사·보조강사·보조인력을 확인할 수 있다.
- 수강료 산식·자격 원문·확인 사항·PDF 쪽수를 상세에서 함께 보여준다.
- 아카데미·강사 구분·추가/기존 자료·과정 및 인력 검색을 제공한다.
- 기존 현황표 대응 13개, 추가 자료 3개, 계획서 미제공 1개를 구분하고 기존 카드와 연결한다.
- 모집 조건·최종 비용은 미확정으로 유지하고, 알려진 원문 날짜·금액 불일치도 보존한다.

## 검증

새 검사 9개, 기존 현황 회귀 검사 14개, lint와 앱 전체 빌드가 통과했다.
브라우저에서 미인증 접근 제한을 확인했고, 읽기 전용 렌더링 환경에서 데스크톱·모바일 화면과 검색 폼을 확인했다.
원천 JSON은 클라이언트 정적 번들에 포함되지 않는다.
자세한 실행 결과와 검증 한계는 [설계 대조](../../03-analysis/anchor-course-opening-view.analysis.md)를 참조한다.

## 다음 단계

`preview` 브랜치에 반영한다. 실제 개설은 최종 일정·모집기간·자격·선발·비용·수료 기준·정책을 확정한 뒤 진행한다.
원래 운영 개방 feature는 Do를 유지한다. 별도 담당자 권한 연결은 연기된 상태다.
