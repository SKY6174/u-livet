# 과정별 운영 결과보고서 완료 기록

2026-09-19 · anchor-course-reports

## 사용 방법
사업단 관리 → 과정의 **결과보고서 · 출력**에서 내용을 작성·저장한다. 여섯 서식을 개별 또는 전체 미리보기 후 브라우저 인쇄의 PDF 저장으로 출력한다. 사진과 기존 PDF는 같은 페이지 하단에서 보관한다.

강사는 기존 **강의 운영 → 출결·시험 관리**에서 인정시간을 기록하고 **실제 강의실적**에서 강의시간을 제출한다. 운영진은 보고서 페이지에서 강의실적을 승인하고 장학금·강사료를 입력한다. 모바일 웹을 지원하며 별도 앱 설치는 필요하지 않다.

이연향 연구원을 기본 운영 담당자로 표시한다. 나중에 계정을 생성하고 해당 기관의 COURSE_MANAGER 역할을 부여하면 동일한 페이지를 사용할 수 있다. 계정은 이번 작업에서 생성하지 않았다.

## 검증
- `node scripts/verify-course-reports.mjs`: 역할·기관 경계, 직접 테이블 접근 차단, 입력 범위, 동시 수정, 출결/강의실적 연동, 파일 형식/용량/교체/삭제, 금액 계산·마스킹·수료 상태.
- `node scripts/verify-learning.mjs`: 기존 학습·출결·시험·수료 회귀 검사 33건 통과.
- 타입 검사·린트 및 깨끗한 별도 디렉터리의 전체 Next.js 빌드 통과. 기존 작업 디렉터리에는 중복된 `.next/types/cache-life.d 2.ts` 캐시가 있어 별도 빌드로 분리했다.
- 실제 브라우저 저장, PDF·사진 업로드, 390px 관리자/강사 화면, A4 출력과 많은 학습자 명단 확인.
- 로컬/Preview DB 보안 Advisor 경고·오류 없음. 새 테이블 RLS, 익명 조회 및 직접 쓰기 차단, 공개 RPC의 invoker/익명 실행 회수를 확인했다.

## 반영 범위
Preview DB `bfqwntulxabfrimcypvx`에 `20260919043637_anchor_course_reports.sql` 적용. Production DB와 이연향 연구원의 계정 생성은 이번 반영에 포함하지 않는다. `preview` 브랜치로 코드를 푸시하며 운영 반영 시 같은 migration을 먼저 적용해야 한다.

파일 본문은 현재 비공개 DB 테이블에 제한된 크기로 보관한다. 향후 파일 규모가 커지면 동일 권한 경계를 유지한 object storage 이관을 검토한다. 수기 서명을 자동 생성하지 않으며 날인부는 강사 제출·운영진 승인 상태와 인쇄 후 서명 칸을 제공한다.
