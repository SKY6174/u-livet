# 운영 환경 수료 판정·승인 검증 기수 결과

> 2026-09-25 | Feature: anchor-completion-live-test

두 원 과정의 기록과 분리된 `[검증용]` 기수를 운영 환경에 만들고, 수강생별 판정·승인 화면을 실제 저장 데이터로 검증했다.

| 검증 기수 | 화면 | 수강생 | 출석 기준 충족 | 확정 수료 | 환불 신청서 표시 |
|---|---|---:|---:|---:|---:|
| 건강식생활지도사 | `/completion/e81e85df-4cc8-408f-b284-64954298fa78` | 6명 | 3명 | 2명 | 1명 |
| 실버푸드전문가과정 | `/completion/17ec60a5-a00e-4989-9a47-3dcfb29f099e` | 6명 | 3명 | 2명 | 1명 |

각 기수에서 85% 사례의 실제 후보 산출과 90% 사례의 실제 승인을 UI로 수행했다. 70% 미달, 철회, 출결 누락, 사전 승인 완료도 확인했다. 처리 버튼은 최근 추가 인증 후 동작했으며 자기 산출 결과의 직접 승인은 차단됐다. 원 기수 두 곳은 수강등록·수료 판정 0건을 유지한다.

검증 데이터는 `[검증용]` 조직과 `DRAFT` 기수에 한정된다. 생성·제거 절차는 `scripts/seed-completion-live-test.sql`과 `scripts/cleanup-completion-live-test.sql`에 있다. 관리자에게 부여한 검증 조직 역할의 만료일은 2026-10-31이다. 화면 검토가 끝나면 제거 스크립트를 실행한다.
