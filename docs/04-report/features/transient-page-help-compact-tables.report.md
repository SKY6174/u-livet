# 화면 설명 말풍선·표 가독성 개선 결과

2026-10-10 · 설계 일치율 100% (8/8)

공통 화면 제목 설명을 진입 시 한 번 나타나는 말풍선으로 바꿨다. 정보 버튼으로 다시 열 수 있다. 접수 문서의 긴 안내는 하나의 말풍선에 묶고 표 내부 글씨를 1.5px 낮췄다. 버튼형 링크와 공통 주요 버튼의 한 줄 표시를 우선했다. 중요한 상태·오류·인증 안내는 계속 화면에 보인다.

검증: lint, TypeScript, 프로덕션 빌드 통과. 360/720/1440px에서 말풍선 동작·표 계산 크기·가로 넘침 없음 확인.
