# 과정별 수료기준·자동 수료율·중도 환불 표시 결과

> 2026-09-25 | Feature: anchor-completion-attendance-refunds

운영계획서에 과정별 출석률 기준(기본 80%, 조정 범위 80~100%)을 추가했다. 책임교수의 입력값을 사업단이 최종 제출하면 해당 스냅샷과 승인 수료 정책 중 높은 출석 기준을 판정에 적용한다. 재제출은 기존 수료 판정을 무효화한다.

수료 검토 화면은 실시간 출석부에서 종료된 정상 수업의 출석률을 계산하고, 모든 회차·출결이 완료된 활성 등록자 중 기준 충족 인원으로 잠정 수료율을 계산한다. 별도 승인된 수료 인원으로 확정 수료율을 표시한다. 분모는 철회자를 포함한 전체 등록자다. 중도 환불 신청서와 실제 금융 환불 이력은 상태를 구분해 수강생별로 표시한다.

검증: lint, TypeScript, production build, 운영계획서 사전 채움 검사 통과. 로컬 DB에서 migration과 함수·기존 문서 호환성·80% 경계·90% 재제출·수료 보드·판정을 트랜잭션으로 검증한 뒤 롤백했다. 배포 DB에는 아직 적용하지 않았다.
