## 결과

결과보고서의 모든 운영사진을 같은 크기의 16:9 비율로 표시한다. 가로·세로·4:3 사진은 가운데를 기준으로 불필요한 좌우 또는 상하 영역을 자동으로 잘라 사진이 찌그러지지 않는다.

## 적용 범위

- 관리자가 직접 첨부하는 JPG·PNG 사진
- 완료된 원본 결과보고서 PDF에서 추출한 사진
- 과거에 저장된 기존 운영사진의 미리보기와 인쇄 출력
- PDF 가져오기 단계의 추출 사진 썸네일

새 직접 첨부 사진은 최대 960×540, PDF 추출 사진은 최대 672×378의 JPEG로 저장한다. 원본 업로드 파일과 원본 PDF는 변경하지 않는다.

## 출력 규칙

- 2열 배치
- 첫 운영성과 페이지 최대 4장
- 계속 페이지 한 장당 최대 8장(2열 × 4줄)
- 촬영일과 사진 설명 유지
- 사진 5장 이상이면 누락 없이 계속 페이지 생성
