# 기존 운영 결과보고서 등록 및 검토

2026-09-19 · anchor-report-import

사업단 관리의 과정별 **결과보고서 · 출력**에서 원본 PDF, 원본 집계와 전사한 내용을 검토한다. 송경영 관리자의 기존 시범 COURSE_MANAGER 권한을 사용한다.

| 등록 완료 과정 | 원본 교육기간 | 모집 / 수료 | 시수 | 집행예산 |
| --- | --- | ---: | ---: | ---: |
| 반려동물수제간식 만들기 | 2026-08-05~08-21 | 11 / 11명 | 30시간 | 4,877,500원 |
| 파크골프지도사 양성(자격증)과정 | 2026-07-14~07-21 | 16 / 16명 | 35시간 | 6,441,120원 |
| 달콤한 도약: 로컬 쿠키 창업 마스터클래스 | 2026-07-20~07-31 | 14 / 14명 | 30시간 | 6,818,480원 |

모집 일정·수강료·선발방식은 원본에 없어 미기재 상태다. 보관 과정은 일반 수강생에게 공개하지 않는다. 원본 사진·강의표는 PDF에서 보존하며, 개인별 출결·수료·장학금 지급·강사료 지급 기록을 추정하지 않는다.

반려동물의 표지/상세표 연도와 일일 시간대, 파크골프 10·11회차 시수, 쿠키 7/29 시간대 등 원본 내부 불일치를 관리자 확인 사항으로 표시한다. 쿠키의 취창업 7명은 원본 집계이며 신규 취창업으로 확정하지 않는다.

`scripts/import-archived-reports.mjs`는 원본 지문·운영자·기관 확인, 중복 방지와 파일 단위 원자적 등록을 수행한다. 대용량 원본은 비공개 임시 객체에 분할 전송하고 전체 지문을 확인한 뒤 연결한다. 실행 증거와 원본·manifest는 Git 제외 `ops/evidence/report-import`에서 관리한다. 운영 등록 3건의 감사기록·보고서·파일과 원본 지문 일치를 확인했다.

송경영 관리자 계정으로 로그인하고 MFA 확인 후 다음 화면에서 원본 PDF, 보고서 수정 및 6종 출력 구성을 검토할 수 있다.

- [반려동물수제간식 만들기](https://uc-life.org/admin/offerings/361eda75-8153-4b2b-86dc-3724a5105f17/reports)
- [파크골프지도사 양성(자격증)과정](https://uc-life.org/admin/offerings/6f436e94-61df-4822-bea3-eccbf25b4c5b/reports)
- [달콤한 도약: 로컬 쿠키 창업 마스터클래스](https://uc-life.org/admin/offerings/1e1e0bb6-f2b2-4b2a-b99f-127e462db915/reports)

화면과 DB 변경은 PR #4를 통해 운영 배포 `688d2e14248f2de73983bada1f45334a01902418`에 반영했다. 이후 실제 원본 3건을 등록했다. 다음 단계는 운영진이 원본 확인 사항과 출력 구성을 검토하는 것이다.
