# 신청내역 관리 리스트 결과

2026-10-10 · feature: `application-management-list`

## 변경 결과

신청 한 건마다 큰 카드가 나오던 목록을 다섯 열의 표로 바꿨다. 신청자 이름을 누르면 기존 신청 상세 화면으로 이동한다. 삭제된 계정, 신청 및 수강 상태, 한국 시각을 유지했다. 같은 renderer를 사용하는 수강생 상세의 신청·수강 이력도 표로 표시한다.

검색·결과 수·페이지 이동·빈 결과 안내는 기존 흐름을 사용한다. 표는 좁은 화면에서 내부에 가로 스크롤을 제공하고, 접근성 이름·caption·열 및 행 머리글을 갖춘다.

## 검증 결과

설계 대조 5/5 충족. 실제 컴포넌트 서버 렌더링 6개 항목, 1440px/360px 브라우저 검증, lint·타입 검사·production build·매뉴얼 검사·diff 검사 통과. 테스트에는 합성 자료를 사용했고 운영 신청 데이터를 변경하지 않았다.

## 릴리스 확인

사용자가 push·PR·병합·운영 배포를 요청했다. 위 검증 결과를 근거로 PR을 생성하고 일반 병합 후 운영 READY, 정확한 병합 revision 및 상태 API를 확인한다. 최종 PR·배포 식별자와 운영 확인 결과는 PR 본문 및 완료 응답에 기록한다.
