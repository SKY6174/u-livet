# 운영대상별 매뉴얼 v1.3.0 발행 보고

> 2026-09-25 · 상태: Preview·Production 배포 완료 / 기관별 업무 검수 전

v1.2.0 전체 발행본을 현재 브랜치에 복구한 뒤 수강생, 교내 강사, 교외·보조강사, 과정 운영, 수료·증명, 수납·환불, 성과·평가, 사업단·시스템 관리자 매뉴얼을 v1.3.0 전체 스냅샷으로 발행했다. 현재 웹 주소는 `/manuals`이며 각 대상의 버전 고정 웹 주소와 PDF·Markdown 배포본을 제공한다. v1.0.0~v1.2.0은 그대로 남아 있다.

이번 판은 수업 질문과 공개 범위, QR 시작·종료 확인, 원본 운영계획의 과정 초안 등록, 과정 모니터링과 2026–2027 PDCA, 수료 출석 기준·환불 상태, 구성원 엑셀 등록·다운로드를 설명한다. 정본은 `src/content/manuals/1.3.0.json`, 발행 폴더는 `public/manuals/1.3.0`과 `output/pdf/manuals/1.3.0`이다. PDF 9개, Markdown 8개, 무결성 manifest 1개를 만들었다.

네 버전 무결성 검사, 88개 매뉴얼 테스트, lint, 프로덕션 빌드, 로컬 HTTP 경로 확인, PDF 43쪽 및 합본 44쪽 시각·텍스트 검사를 통과했다. 상세 설계 대비 결과는 `docs/03-analysis/anchor-operation-manuals-1-3-0.analysis.md`에 기록했다. Preview와 Production에 배포했으며, Production의 대상별 웹 문서 8종·PDF 8종·통합 PDF가 정상 응답하는 것을 확인했다. 기관별 업무 검수는 별도 절차다.
