# 16개 과정 연간 일정·PDCA 신호등 결과

> Date: 2026-09-25 | Feature: `anchor-course-monitoring-pdca`

기존 과정 모니터링 첫 화면에 2026년 16개 과정의 12개월 일정표와 정상·지연·애로·계획전 신호등을 추가했다. 과정별 P/D/C/A 목표·완료일, 애로 사유와 조치 내용을 저장하고, 실제 개설·수업·운영 문서 상태와 비교할 수 있다. 안내 일정과 실제 일정은 구분해 표시한다.

검증은 빌드·린트·타입 검사, 기존 모니터링 회귀, 신호등 규칙, 16개 표 렌더링, 로컬 DB 적용·권한 차단·수정 충돌 방지를 통과했다. 운영 반영 시에는 DB 마이그레이션을 앱 배포보다 먼저 적용한다. 초기 P/C/A 기한은 담당자가 확정해야 한다.
