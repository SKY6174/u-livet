# 2026~2027 과정별 연간 PDCA 및 완성도 구현 보고

> 2026-09-25 | 설계: `docs/02-design/features/anchor-course-monitoring-extended-pdca.design.md`

## 결과

- 16개 과정의 연간 일정을 2026년 1월부터 2027년 2월까지 14개월로 표시한다. 과정준비·운영계획서 제출·수강생모집, 운영, 평가, 차년도 반영 목표를 월별로 구분한다.
- 과정 행과 상세 화면에 P 0/50/100%, D 0~100%, C 0/75/100%, A 0/100% 완성도와 산출 근거를 표시한다. P는 운영계획서 최종 제출/모집 종료, D는 전체 예정 수강생별 출결 건수, C는 결과보고서와 목표 1~2회 평가회, A는 사업단 또는 자체평가회 수행을 근거로 한다.
- 목표일 대비 신호등 판정에는 실제 증빙을 반영한다. A 성과평가 수행과 차년도 운영 판단·반영 내용은 별도로 기록한다.
- 두 신규 DB migration은 기존 P 날짜를 이관하고 평가회 수행일 및 목표 횟수, 차년도 결정을 저장한다. 기존 관리자 역할·최근 MFA·revision 및 감사 경계를 유지한다.

## 확인

- 로컬 DB에 신규 migration 2개를 적용하고 v2/v3 저장, 날짜·평가 횟수·미래 날짜·revision 충돌을 롤백 방식으로 확인했다. 익명 역할에는 새 저장 함수 실행 권한이 없다.
- 16개 과정 렌더링, 14개월 연도 경계, 완성도·신호등 계산, 기존 모니터링 회귀 검사를 통과했다.
- ESLint, TypeScript, Next production build를 통과했다.
