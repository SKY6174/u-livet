# 개설 준비 임시저장 현황 완료 보고

2026-09-21 · anchor-opening-draft-overview

`사업단 관리 → 과정 운영 관리 → 2026 개설 준비`에서 본인이 임시저장한 과정 개수와 최근 저장 시각을 바로 확인할 수 있다. 저장 카드의 `이어서 준비하기`로 기존 입력을 복원하고, `내 임시저장 모두 보기` 또는 `내 준비 내용 → 내 임시저장만`으로 모아 볼 수 있다. 기존 검색 조건과 함께 사용할 수 있다.

요약은 같은 관리 조직·작성자에 한해 단일 RPC로 조회한다. 전체 편집 내용이나 다른 담당자의 저장 자료는 노출하지 않는다. 실제 기수 등록·모집 공개 여부는 별도이며, 저장 성공 후 목록을 갱신한다. 연결 실패는 미저장으로 오인하지 않도록 오류와 재시도 안내를 표시한다.

- Migration `20260920230000_anchor_opening_draft_overview.sql`: Local → Preview → Production 적용. 읽기 함수만 추가.
- 양쪽 hosted DB 기존 기수 3개 및 임시저장 수 불변, 익명 RPC HTTP401/42501, authenticated 전용 실행 권한 확인.
- 59개 자동 검증, production build, 390px 모바일 UI 검증 통과.
- 로컬 16건 요약: 1회 요청, JSON 1,295bytes, 5회 재조회 중앙값 5.8ms. 운영 환경의 페이지 응답시간과 구분한다.
- 상세: `docs/03-analysis/anchor-opening-draft-overview.analysis.md`.

다음 사용 단계는 저장 현황에서 준비 중인 과정을 선택해 확정된 항목을 이어서 작성하는 것이다. 모집기간·최종 일정·실제 강사 배정 및 수강생 등록은 사용자 확정 자료에 따라 진행한다.
