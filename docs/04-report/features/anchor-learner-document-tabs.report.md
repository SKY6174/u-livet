# 수강생 서식 단일 창 전환 완료

2026-09-22 · anchor-learner-document-tabs

수강생 작성 서류를 `/mypage/documents` 한 화면으로 통합했다. 상단의 수강신청원서 / 장학금 지급신청서 두 버튼을 누르면 새 창 없이 입력 폼과 PDF 미리보기가 바뀐다. 각 서식에서 작성한 정보·동의·서명은 전환 후에도 유지된다.

나의 학습에는 통합 작성 창을 여는 버튼 하나를 두었다. 기존 서식별 URL도 통합 창으로 연결한다. 원본 양식과 PDF 1.7 출력은 유지한다.

검증: 타입·ESLint·프로덕션 빌드 통과. 브라우저에서 전환, 상태 유지, 숨겨진 서식의 미다운로드 변경 경고, 서식별 PDF 내용, 모바일, 키보드, 기존 URL 연결을 확인했다. 기존 PDF 생성 검사도 통과했다.

다음 확인 위치: 나의 학습 → 수강생 서류 작성.
