# 가입 준비 안내와 개인정보 동의 가독성 개선

2026-09-19 · anchor-consent-readability · 구현·로컬 검증 완료

개인정보 문안이 없는 상태에서도 이름·이메일·비밀번호 입력란이 보이던 화면을 개선했다. 가입에 필요한 문안 또는 인증 메일이 준비되지 않으면 이유와 가능한 다음 행동을 먼저 안내한다. 승인 문안이 준비된 화면에서는 내용을 펼쳐 놓고 16px 본문으로 표시해 성인학습자가 동의 전에 읽을 수 있게 했다.

## 반영 내용

- 가입 준비 안내와 공개 과정·기존 계정 로그인 링크.
- 기본 펼침 동의 본문, 큰 글자·넉넉한 줄간격.
- 미리 선택하지 않은 필수 동의 체크와 기존 서버 검증 유지.
- [개인정보 검토 틀](../../operations/privacy-review-template.md)의 화면 설명 갱신.
- 초기 관리자 역할에 대한 사용자 결정은 비공개 운영 기록에 반영. 실제 역할 부여는 수행하지 않음.

## 확인 결과

5개 화면 상태의 합성 렌더링 검사, 수정 파일 lint, 격리 빌드와 타입 검사를 통과했다. [설계 대조](../../03-analysis/anchor-consent-readability.analysis.md)는 기능 항목 7개 모두 대응한다. 배포 대상은 Preview와 운영의 같은 Git 커밋이며 최종 버전·사이트 상태·준비 안내 검증은 Git 제외 운영 증거 `ops/evidence/signup-opening/consent-readability-release.json`에 기록한다.

운영 문안·동의·권한·계정·메일 데이터를 새로 생성하지 않았다. Supabase 가입 설정을 변경하지 않았고 실제 가입은 아직 개방되지 않았다. 다음 운영 단계는 기관 문안 확정과 최초 담당자의 해당 문안 동의·초대 절차다.
