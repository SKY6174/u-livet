# 전체 회차 출석부와 QR 종료 기록 완료 보고

> 2026-09-25 · 상태: Preview·Production 배포 및 자동 검증 완료

회차별 시작·종료 QR을 분리하고 종료 후 15분까지 종료 확인을 허용했다. 기존 시작 시각은 보존하며 종료 시각을 별도 기록한다. 강사 화면은 회차별 시작·종료 QR을 발급·출력하고, 수강생 확인 화면과 출석부는 두 시각을 구분해 표시한다. 출석부는 전체 회차를 한 표에 담아 A4~A0 가로 용지로 출력할 수 있다.

[설계 대조 결과](../../03-analysis/anchor-qr-session-grid.analysis.md)는 10개 항목 모두 구현·검증한 100%다. 로컬 합성 계정의 QR DB 통합검사 9개, QR 액션·화면 검사, lint와 프로덕션 빌드가 통과했다. Preview·Production DB에서 종료 시각 컬럼과 종료 QR 발급 RPC를 확인했고, 두 앱 배포가 완료됐다.

자동 검증은 실제 수업의 휴대전화 카메라 스캔을 대신하지 않는다. 기관의 현장 운영 검수에서 시작·종료 QR을 각각 스캔해 확인한다.
