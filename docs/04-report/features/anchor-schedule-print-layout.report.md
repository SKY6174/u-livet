# 강의 일정 출력 표 조정 완료 보고

2026-09-23 · anchor-schedule-print-layout

## 결과

운영계획서와 운영결과보고서의 강의 일정 표를 읽기 쉬운 8열/10열 구조로 조정했다. 일자와 시간은 한 셀 안에서 두 줄로 표시하고, 주제·강사·장소는 내용 특성에 맞는 열 폭과 줄바꿈 규칙을 사용한다.

## 적용 내용

- `일자 / (시간)` 두 줄 머리글과 본문 형식
- 한 줄 날짜와 괄호 시간
- 한국어 어절 중심의 강의주제 줄바꿈
- 네 글자 기준 강사명 열과 `교육 / 시간` 머리글
- 장소명 한 줄과 괄호 호실 다음 줄
- 결과보고서 8열, 운영계획서 10열 및 합계 행 정렬

## 검증

- `npm run lint`
- `npm run build`
- `node scripts/verify-operation-documents.mjs`
- 브라우저 DOM·오버플로·오류 검사
- 실제 A4 미리보기 육안 확인

모든 검사를 통과했으며 데이터베이스 변경은 없다.
