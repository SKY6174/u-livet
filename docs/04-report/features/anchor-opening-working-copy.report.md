# 개설 준비 임시저장 완료 보고

2026-09-21 · anchor-opening-working-copy

모집기간과 최종 교육일정이 미정인 상태에서도 16개 운영계획서의 개설 준비 내용을 계정별로 저장하고 이어서 편집할 수 있게 했다.

## 사용 경로
1. 사업단 관리 → 과정 운영 관리 → 운영계획서 개설 준비.
2. 해당 계획서의 `등록 양식에 불러오기` 선택.
3. 확정한 항목만 편집하고 `개설 준비 임시저장` 선택.
4. 다시 방문하면 본인이 저장한 내용을 복원한다. `저장본 다시 불러오기`는 현재 미저장 편집 내용을 버리고 서버 저장값을 불러온다.
5. 모든 필수값을 갖춘 뒤 `실제 기수 초안 등록`으로 기존 등록 절차를 진행한다. 임시저장본은 별도로 유지된다.

작성자 개인 준비 자료로 다른 담당자에게 공유되지 않으며, 모집 공개나 기존 보관 과정 변경을 수행하지 않는다. 역할 회수 시 접근이 차단되고 저장에는 최근 추가 인증이 필요하다. 다른 창의 변경과 충돌하면 기존 저장본을 덮어쓰지 않는다.

## 반영·검증
- migration `20260920224000_anchor_opening_working_copy.sql`: Local, Preview, Production 적용. 양쪽 hosted DB에서 기존 보관 기수 3개, 새 임시저장 0개 확인.
- RLS·직접 접근 차단·최근 MFA trigger·migration history 검증. 익명 RPC HTTP401/42501 확인.
- 52개 자동 검증 + production build + 브라우저 동작·390px 모바일 검증 통과.
- 상세 근거: `docs/03-analysis/anchor-opening-working-copy.analysis.md`.

모집기간은 계속 미정이며 실제 기수·차시·강사·수강생을 임의로 생성하지 않았다. 다음 운영 작업은 담당자가 계획서를 선택해 확정된 항목부터 임시저장하는 것이다. 담당자 권한 연결은 기존 요청대로 추후 진행한다.
