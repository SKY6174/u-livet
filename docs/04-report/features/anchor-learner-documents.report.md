# 수강생 원본 서식 작성 완료

2026-09-22 · anchor-learner-documents

## 구현
나의 학습에 수강생 작성 서류 영역을 추가했다. 수강신청원서와 학습활동 우수 장학금 지급신청서를 각각 별도 창에서 작성한다. 데스크톱은 왼쪽 입력·오른쪽 PDF, 모바일은 세로 배치로 제공한다.

원본 PDF의 페이지를 사용하므로 표, 여백, 배경색과 강조색, 문구 및 기존 글꼴을 보존한다. 입력·동의 선택·자필 또는 이미지 서명이 실제 PDF에 반영된다. 최신 미리보기와 같은 PDF 1.7 파일을 내려받는다. 예시 과정명과 날짜는 사용자가 입력한 값으로 대체한다.

## 검증
- `npm run build`: 컴파일, ESLint, TypeScript, 경로 생성 통과.
- `node scripts/verify-learner-documents.mjs`: 두 서식 및 입력 검증 통과.
- 원본 대조: 과정명·날짜 제거 영역 외 변경 픽셀 0개.
- 브라우저 실제 입력, 서명 그리기·업로드·지우기, 별도 창, 다운로드, 모바일 가로 넘침 검사 통과.
- 실제 다운로드 파일 2개: PDF 1.7, A4 595 × 842 pt, 1페이지, 한글 글꼴 내장. 재렌더링 후 육안 확인.

## 운영 안내
위치: 나의 학습 → 수강생 작성 서류.
입력값은 서버에 자동 저장되지 않는다. 작성한 PDF를 내려받아 담당자의 안내에 따라 제출한다. 다운로드만으로 수강신청이나 장학금 접수가 완료되는 것은 아니다.

추후 서버 제출·보관을 연결한다면 주민번호·계좌·서명에 대한 접근권한과 보관 정책을 별도로 설계한다. 이번 요청의 작성·미리보기·다운로드 범위에는 누락 항목이 없다.
