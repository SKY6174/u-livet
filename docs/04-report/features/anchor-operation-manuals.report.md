# 운영대상별 매뉴얼 제작 완료 보고

2026-09-22 · anchor-operation-manuals · 문서 버전 1.0.0

## 제작 결과
웹 매뉴얼과 배포용 PDF를 함께 제작했다. 수강생, 교내 강사, 교외·보조강사, 과정 운영 담당자, 수료·증명 담당자, 수납·환불 담당자, 성과·평가 담당자, 사업단·시스템 관리자 8종이며 총 44개 업무 절차를 포함한다.

각 문서는 권한 전제, 메뉴 경로, 준비사항, 수행 순서, 완료 확인, 주의사항, 일상 점검표와 문제 해결을 담는다. 실제 구현을 근거로 PDF 다운로드와 접수, 입실 확인과 출석 확정, 저장과 최종 제출, 입금 신고와 확인 입금, 지급 기록과 실제 송금을 구분했다.

## 이용 경로
- 웹 `/manuals`: 검색·대상 선택·합본 다운로드.
- 문서 `/manuals/{audience}/1.0.0`: 고정 주소, 목차, 인쇄, 개별 PDF/Markdown.
- 이력 `/manuals/history`: 버전별 변경 내역과 보존 문서.
- footer의 이용 매뉴얼 링크.
- `public/manuals/1.0.0`: 개별 PDF 8개, 38쪽 합본, Markdown 8개, manifest.
- `output/pdf/manuals/1.0.0`: 전달용 PDF 복사본.
- `docs/manuals/README.md`: 문서 대장과 개정·검토·발행·복원 절차.

## 버전관리
JSON 원문과 전체 공통 안내를 버전별로 고정한다. 현재 버전 목록과 실제 로더의 일치를 검사하고 구판 등록 제거를 거부한다. 발행본의 원문·파일 SHA-256을 기록하여 같은 번호의 덮어쓰기를 차단한다. 새로운 버전 번호로만 개정한다.

`manuals:build`는 검토용 생성, `manuals:release`는 로컬 발행 확정, `manuals:check`는 모든 발행본 검사다. 일반 빌드와 Vercel 빌드에 검사를 연결했다. 초판은 로컬 Git 변경과 `manuals-v1.0.0` 태그로 관리한다.

## 검증
25개 검사, lint, production build 및 타입 검사 통과. 웹 검색·목차·이력·모바일·인쇄, 8종 페이지와 PDF 다운로드, 잘못된 주소/버전 거부를 확인했다. 38쪽 합본과 8종 개별 PDF의 모든 절차를 텍스트 추출로 확인하고 최종 렌더링을 검토했다. 자세한 근거는 `docs/03-analysis/anchor-operation-manuals.analysis.md`에 기록했다.

## 운영 적용 상태
현재 문서에는 **소스 기준 제작본 · 운영 검수 전**을 표시했다. 원격 사이트에는 배포하지 않았고 기관 정책·승인자·권한을 변경하지 않았다. 다음 단계는 업무별 운영 담당자가 실제 운영 환경과 정책·위임 조건을 확인하는 검수다. 이후 수정은 새 버전으로 발행한다.
