# 로그인 인증 코드 자동 확인 보고서

2026-09-22 · anchor-mfa-auto-submit

이메일 로그인 후 추가 인증 화면이 열리면 코드 입력칸에 자동 포커스한다. 숫자 6자리 입력·붙여넣기가 완료되면 기존 서버 검증을 자동 요청하고, 성공 응답 후 원래 작업 화면으로 이동한다. 잘못되거나 만료된 코드·연결 실패 시 입력을 비우고 다시 입력할 수 있도록 포커스를 복구한다.

검증 진행 중 중복 요청을 차단한다. 확인 버튼과 Enter 제출은 유지하며, 새 인증 앱 등록 및 직접 연 계정 보안 관리에는 수동 확인을 적용한다. 기존 서버 인증·세션·권한 정책은 변경하지 않았다.

## 검증

- MFA 입력·서버·이동 회귀 50개 통과.
- 전체 lint 및 production build 통과.
- 실제 React 브라우저에서 자동 포커스, 5자리 비제출, 6자리 자동 성공 이동, 잘못된 코드 재입력, 공백 포함 붙여넣기, 직접 관리의 수동 확인 검증.
- 설계 대비 8개 항목 충족. 브라우저 인증 응답은 합성이며 실제 회원 인증 정보는 사용하지 않았다.
