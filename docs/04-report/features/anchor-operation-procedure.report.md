# 평생직업교육 운영절차 안내 구현 보고

## 변경 내용
- 첨부 자료 6장의 내부·외부 교육과정 운영 내용을 `/operation-procedure`에 정리했다.
- 운영 비교, 두 유형의 각 5단계 흐름, 최대 3회 모집 조율과 폐강, 결과보고·정산을 모두 포함한다.
- 공통 메뉴의 앵커사업 소개와 수강안내 사이에 운영절차를 추가했다.
- 기존 브랜드 색상·공통 레이아웃을 사용하며 모바일에서는 단계가 세로로 표시된다.
- 역할별 내비게이션 검증에 새 공개 메뉴의 이름·위치·경로를 반영했다.

## 검증
- production build 및 포함된 lint·타입 검사 통과.
- 데스크톱·모바일 화면, 메뉴 순서·활성 표시, 섹션 이동, 가로 넘침 없음 확인.
- 설계·첨부 자료 대조 10/10 항목 충족.
- 기존 역할 검증 21개 항목 통과. 뒤이어 수행하는 운영 문서 목록 fixture 실패는 변경 전 HEAD에서도 동일하게 재현됨.
- 상세 결과: `docs/03-analysis/anchor-operation-procedure.analysis.md`.
