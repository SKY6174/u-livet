# PDF 1.7 적용 보고

2026-09-22 · feature `anchor-pdf-17`

## 변경
- 새 강사 서류 PDF, 이수증·강의경력증명서, 결과보고서 6종 및 출석부를 PDF 1.7로 생성한다.
- 보고서·출석부에 **PDF 1.7 다운로드**를 제공하며 종이 출력용 **인쇄** 버튼을 유지한다.
- 기존 보관 보고서, 증명서, 강사 서류에는 **PDF 1.7 변환본** 버튼을 제공한다. 파일을 열 수 있는 기존 권한과 만료 URL을 그대로 사용한다.
- 변환본은 페이지 이미지로 된 사본이다. 원본과 검증 해시는 보존하며 검색·전자서명 검증에는 원본을 사용한다.
- 한국어 구형 PDF의 문자맵·글꼴 및 이미지 코덱은 같은 사이트에서 제공한다. 변환 파일은 브라우저에서 만들어 다운로드하고 서버에 재저장하지 않는다.
- Supabase `instructor-documents` 함수는 새로 생성하여 저장하는 PDF의 1.7 헤더·Catalog·파서 구조를 검증한다. 사용자 분석용 원본에는 이 제한을 적용하지 않는다.

## 검증과 배포
- PDF 회귀검사 6개, 로컬 강사 서류/권한 검사 15개, TypeScript·ESLint·Deno 검사·프로덕션 빌드 통과.
- 가로·세로 혼합 보고서, 긴 문단, 출석부, 구형 한국어 원본과 PDF 2.0 변환을 브라우저 다운로드 및 Poppler로 확인했다.
- 상세 설계 대조 및 테스트 한계: `docs/03-analysis/anchor-pdf-17.analysis.md`.
- Supabase 운영 프로젝트 `uoebygejgglgiivzgyks`에 Edge Function version 5 배포, ACTIVE 확인. 프런트엔드는 main push에 연결된 Vercel 자동 배포로 반영한다.

기존 업로드 원본을 일괄 변경하지 않는다. PDF/A 인증, 브라우저 인쇄 대화상자의 자체 PDF 출력 버전 통제는 이 기능의 범위가 아니다.
