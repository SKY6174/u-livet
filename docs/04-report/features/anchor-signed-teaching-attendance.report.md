# 강사 강의날인부·QR 확정 출석부 완료 기록

2026-09-22

강사는 종료 수업의 실제 강의 구간을 제출하고 자신의 강의날인부에 서명한다. 관리자는 최신 승인 기록을 강의 순서·오전/점심/오후 구분으로 취합해 출력한다. 관리자용 현재 운영결과보고서 출력에는 이 날인부가 부록으로 연결된다. 출석부는 QR 입실과 강사 확정 출결을 구분하며, 전체 회차 4회 이하 세로·5회 이상 가로 A4로 출력한다. 두 양식의 사방 여백은 20mm이고 사업단 로고는 왼쪽 하단이다.

Preview와 운영 Supabase DB에 `20260922102545_anchor_signed_teaching_attendance.sql` 한 건을 적용했다. 두 환경에서 migration/서명 열/함수 실행권한을 확인했고 Security Advisor 경고는 0건이다. 로컬 DB에서는 구간 검증, 서명 저장, 관리자 QR·출결 조회를 rollback 거래로 확인했다. 브라우저 인쇄와 PDF 1.7 출력에서 A4 방향, 여백, 로고, 빈 페이지 부재를 확인했다. 빌드·린트·diff 검사는 통과했다.

전체 `test:core` 스크립트는 기존 로컬 MFA 시험 계정의 fixture secret이 없어 계정 준비 단계에서 멈췄다. 이번 기능의 새 DB 및 인쇄 경로는 위의 별도 검증을 마쳤다.
