# 휴대폰 번호 자동 하이픈 적용

- 이메일 가입 및 카카오 가입 완료 화면의 공통 입력란에서 휴대폰 번호를 `010-1234-5678` 형태로 표시한다.
- 중간 수정, 하이픈 경계에서의 삭제, 국제 형식 붙여넣기, 폼 초기화를 브라우저에서 확인했다. 390px 화면에서 가로 넘침이 없다.
- 표시 형식과 기존 서버 저장 형식의 일치, 과도한 길이·문자 입력 거부를 확인했다. 카카오 가입 검사 37개, 공개 가입 검사 13개와 프로덕션 빌드가 통과했다.
- 번호 입력은 필수지만 휴대폰 소유 확인은 수행하지 않는다. 운영·스테이징의 Supabase 전화번호 인증은 꺼져 있고, DB의 `phone_verified_at`은 null로 저장된다. 기존 정책과 서버 검증은 유지했다.
