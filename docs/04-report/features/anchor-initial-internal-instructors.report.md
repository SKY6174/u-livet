# 2026 과정 초기 책임강사 편성 결과

2026-09-22. 운영계획서 16개를 원본 순서로 대조해 첫 교내 강사 9명을 10개 과정에 우선 승인했다. 나머지 교외 강사만 있는 6개 과정의 초기 책임강사는 사용자 지정에 따라 현용환 센터장으로 기록했다. 이름만으로 기존 로그인 계정과 병합하지 않았다.

기수에 연결된 3개 과정(파크골프, 로컬 쿠키, 반려동물 수제간식)은 첫 교내 강사를 기수에 배정하고 미지정 책임강사로 초기 등록했다. 다른 13개 과정은 아직 기수가 없으므로 과정 목록에 초기 책임강사만 표시한다. 제출된 문서는 수정하지 않았다.

검증: 원본 JSON과 마이그레이션의 10개 교내 강사 대응 확인; 로컬 SQL 적용; Preview·운영 DB에서 10개 교내/6개 센터장, 9명 강사 Pool, 계정 연결 0개 및 3개 기수 배정 확인; Next 빌드·TypeScript·ESLint 통과.
