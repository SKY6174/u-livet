# 간편 로그인 가입 여부 자동 분기 보고

2026-09-21

카카오·Google·네이버 인증 뒤 별도 선택 화면 없이 서버가 가입 여부를 판별한다. 신규 사용자는 바로 가입 양식을 보고, 기존 가입자는 원래 목적지로 로그인한다. MFA 설정 계정은 보안 확인을 유지한다.

기존 이메일 가입도 Auth가 같은 사용자로 연결한 경우 가입 완료로 인정한다. 이전에는 EMAIL 출처가 빠져 기존 가입자가 재가입 양식을 거칠 수 있었다. DB 가입 상태와 접근 상태의 조건을 함께 수정해 분기와 권한 판정이 일치하도록 했다. 다른 계정의 이름·전화번호를 근거로 자동 병합하지 않는다.

## 검증
- JS 165개, DB 114개: 총 279개 검사 통과.
- 세 제공자별 신규·기존·EMAIL 연결·MFA·계정 제한 경로 확인.
- lint, 타입 검사 포함 build, diff 공백 검사 통과.
- 실제 서버 컴포넌트의 합성 브라우저 화면에서 선택 화면 없이 가입 양식 표시 확인.
- [설계 대조 및 검증 한계](../../03-analysis/anchor-social-auto-routing.analysis.md).

## 릴리스
`20260921141157_anchor_social_auto_routing.sql`은 기존 함수 두 개의 가입 출처 조건만 확장한다. 회원 데이터·동의 기록·권한 설정을 일괄 변경하지 않는다. DB를 먼저 적용한 뒤 앱을 배포할 수 있다.

검증한 소스는 `codex/social-auto-routing`에서 Git으로 전달한다. 실제 Git/배포 식별자는 해당 PR과 후속 배포 증거에 기록한다. 네이버 제공자 활성화는 기존 설정을 따르며, 로그인 경로 변경 자체가 제공자 연결 설정을 생성하지는 않는다. 실제 계정으로 세 제공자의 전체 가입 제출을 수행한 결과는 아니다.
