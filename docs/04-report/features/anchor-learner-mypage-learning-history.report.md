# 수강생 마이페이지 학습이력 흐름 개선 결과

2026-09-27

온국민평생배움터의 학습이력 등록, 연계동의, 학습이력증명서, 학습이력철 흐름을 수강생 마이페이지에 안내했다. UC Life 수강·수료 이력과 사업단 이수증 경로를 가까이 배치하되 국가 포털의 기능과 구별했다. 수강이력 화면에는 전체, 수료 확정, 미확정 건수와 빈 결과·오류 상태를 추가했다.

외부 학습이력 데이터 연동이나 국가 증명 발급은 구현하지 않았다. 해당 단계는 온국민평생배움터에서 로그인 후 진행하도록 안내한다. 빌드 검증 중 발견한 기존 보고서 JSX 오류 한 줄도 수정했다.
