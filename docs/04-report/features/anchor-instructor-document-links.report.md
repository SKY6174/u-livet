# 강사 서류 직접 입력·공유 완료

사업단 관리 → 전문가 관리 → 강사 마스터에서 문서 입력과 관리 작업을 연결했다.

- 신분증·통장사본 / 이력서 열을 분리하고 입력 버튼을 별도 창으로 연결. 로그인 권한으로 문서 세션을 자동 발급하므로 중간 ‘서류함 열기’ 단계가 없다.
- 관리 열의 링크·수정·삭제 아이콘 제공. 링크 아이콘은 강사별 입력 주소와 6자리 PIN을 각각 표시/복사한다. 재발급 시 이전 자격과 초대 세션은 무효화한다.
- 외부 강사는 계정 없이 성명·PIN으로 해당 강사의 서류만 입력. 링크 유효기간 7일, 입력 세션 30분, 5회 실패 시 15분 잠금.
- 삭제는 대장에서 제외하며 계정·기존 서류·지급 이력을 보존한다. 이전 링크와 입력 세션은 해제한다.
- 회귀·보안 검증 48개 및 타입/린트/빌드 통과. 실제 브라우저에서 새 창, 직접 탭 진입, 외부 PIN 입력과 암호화 초안 저장, 모바일·로그아웃 확인.
- Supabase 운영 마이그레이션과 인증 핸들러 반영 완료. 앱은 main push의 Vercel 배포로 반영한다.

입력 링크와 PIN은 발급 시에만 원문이 제공된다. 분실하거나 새로 공유할 때 관리 화면에서 재발급한다. 메시지는 자동 전송하지 않는다.
