# 계정 구분 관리 리스트 수정

2026-09-21 · anchor-account-list-layout

- 첨부 첫 이미지의 교내·교외 로그인/미등록 직책 안내 박스를 삭제했다.
- 두 열 계정 카드를 하나의 리스트로 변경했다. 웹에서는 이름·이메일 / 직책·강사 구분 / 저장 버튼을 한 행에 표시하고 모바일에서는 행 내부에 세로로 배치한다.
- 계정별 저장, person_id, 기본값, 필수 선택, 복수 역할 선택 항목, SYSTEM_ADMIN 권한 검사와 기존 RPC를 유지했다. 실제 계정 구분이나 DB 스키마는 변경하지 않았다.
- 공통 ActionForm은 optional className만 추가했으며 미지정 화면의 기존 배치를 유지한다.

검증: 타입 검사·린트 통과, 역할별 메뉴/권한 기존 검증 18개 통과. 실제 페이지와 ActionForm에 합성 계정·저장 액션을 연결하여 1280px 웹 행 정렬, 안내 삭제, 개별 저장 후 선택 유지, 상태 메시지, 390px 모바일 및 긴 이메일 줄바꿈을 확인했다. 가로 넘침 없음. 설계 대비 누락 없음.
