# 과정 운영과 결과보고서 통합 관리

2026-09-20 · anchor-course-workspace

과정 목록에서 검색·상태 필터·원본/보고서 요약을 확인하고 **과정 운영**으로 진입한다. 과정 내 공통 메뉴는 **운영 개요 / 운영 설정·신청 / 결과보고서**다.

운영 개요에는 다음 할 일, 인원·교육시간·예산·원본 보관 현황, 출결과 정산 상태를 표시한다. 보고서의 6종 준비 현황에서 입력 담당을 확인하고 보완할 항목 또는 출력 화면으로 이동한다. 긴 원본 확인사항은 펼쳐볼 수 있으며 보고서 입력 항목 간 이동과 저장 버튼을 추가했다.

Supabase의 기존 자료를 읽는 집계 RPC를 추가했다. 상태를 별도로 복제하지 않고 과정/등록/출결/수료 승인/강의실적/보고서/첨부를 연결한다. 원본 집계와 개인별 자료는 구분하고 강사 출결 입력·운영진 지급 입력 역할을 유지한다. 인증된 운영진의 기관 범위와 MFA를 검사하며 목록에 개인정보나 파일 본문을 포함하지 않는다.

기존 3개 보관 과정은 그대로 유지했다. [과정 관리](https://uc-life.org/admin)에서 송경영 관리자의 운영진 권한으로 검토할 수 있다.
