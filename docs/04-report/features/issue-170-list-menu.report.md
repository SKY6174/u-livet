# Issue 170: 과정 리스트 관리 메뉴 결과

2026-10-13 · feature: `issue-170-list-menu`

과정 운영 관리의 리스트형에서 표 밖으로 밀리던 상태/관리 열을 오른쪽에 고정했다. 작은 화면에서는 240px, 넓은 화면에서는 320px 너비로 모든 버튼을 표시한다. 모바일에서는 메뉴 위에 과정 이름도 표시한다. 카드형과 관리 권한별 목적지는 기존 컴포넌트를 유지한다.

수정 전 실제 버튼 클리핑을 재현했고, 수정 후 360/768/1440px 좌우 스크롤에서 링크 및 문구 클리핑 0건을 확인했다. 설계 대조 5/5, 실제 컴포넌트 회귀 6개 항목, lint·타입·production build·매뉴얼·diff 검사 통과.

사용자가 PR·push·병합·운영 배포를 요청했다. 검증 결과로 PR을 생성하고 검사 통과 후 일반 병합 및 운영 READY, 정확한 revision·health를 확인한다. 최종 릴리스 식별자와 검증 결과는 PR 본문 및 완료 응답에 기록한다.
