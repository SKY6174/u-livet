# 과정 운영·예산 관리

2026-09-21 · anchor-course-budget

`/admin/courses`에서 2026년 16개 과정과 3개 기존 운영 자료를 함께 조회한다. 카드/리스트 전환 및 프로그램 ID/강사 검색을 제공한다. 세부 프로그램 앞에 프로그램 ID를 배치했다.

예산 현황은 여섯 항목을 수정해 저장하며 아카데미 소계와 총계가 재계산된다. 관리자 및 과정 담당자의 기관 권한·최근 추가 인증을 확인하고 동시 수정과 변경 이력을 보호한다.

예산 집행현황에서는 XLSX 시트와 제목행을 선택해 내용을 검색·확인하고 저장한 내역을 공유한다. 양식 확정 전이므로 임의 항목 매핑 대신 원본 열과 값을 보존한다. 원본 파일 자체를 보관하는 기능은 이번 범위가 아니다.

첨부 예산의 항목 합계와 총계의 100원 차이는 원문 금액을 보존하고 화면에 표시했다.

검증: 모델12 / 로컬DB21 / 역할18 / 카탈로그14 검사, 타입·린트·빌드, 데스크톱/모바일 컴포넌트 브라우저 검증. Preview와 Production DB에 적용. 배포 상태와 원격 브랜치 동기화는 push 후 확인한다.
