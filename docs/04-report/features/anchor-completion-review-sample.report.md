# 수료 판정·승인 예시 화면 결과

> 2026-09-25 | Feature: anchor-completion-review-sample

수강등록자가 없는 과정의 수료 검토 화면에 읽기 전용 예시 보기 기능을 추가했다. 수료 확정, 승인 대기, 기준 미달, 중도 환불, 출결 입력 중, 자료 변경 후 재산출의 여섯 사례가 기존 수료율·판정 근거·승인 UI에 표시된다. 예시 모드의 처리 버튼은 모두 비활성화되고, 합성 수강생은 운영 DB에 저장되지 않는다.

운영 환경의 건강식생활지도사와 실버푸드전문가과정은 현재 전산 수강등록자 0명이며, 로그인된 관리자 계정에서 두 수료 검토 화면에 접근할 수 있음을 확인했다. 코드와 계획·설계·점검 문서를 PR #81에 푸시했다. ESLint, TypeScript, Next.js production build와 PR 전용 Supabase·Vercel 배포 검사가 통과했다.

운영 사이트의 현재 revision은 `248ebdb`로, 이 기능이 담긴 `3fbe99f`는 아직 반영되지 않았다. 운영 반영 후 두 과정에서 예시 링크·배너·여섯 사례·비활성 버튼을 실제 브라우저로 확인해야 한다. PR에는 이 기능 외에 이전 요청의 PDCA 및 수료 기준 변경과 SQL migration 3개가 함께 포함된다.

운영 반영 준비 과정에서 미적용 migration 3개를 확인하고, `ops/evidence/managed-cloud-backup/20260925T062909Z/`에 운영 public 데이터와 전체 스키마를 권한 제한 파일로 백업했다. 데이터 덤프는 순환 외래키가 있어 복원 시 제약·트리거 처리에 주의해야 한다.
