# 페이지 안내 및 과정 카드 표시 변경

2026-10-10 · 기능: `page-help-right-center`

공통 페이지 안내문은 i 버튼 오른쪽에서 수직 중심을 맞추어 나타난다. 작은 화면에서는 안내 버튼을 제목 다음 줄에 두어 오른쪽 공간을 확보한다.

과정 운영 카드와 리스트의 “우선 승인 교내 강사” 표시 영역을 제거했다. 문서 카드의 기관·차년도는 프로그램 ID 오른쪽에 “앵커사업단∙2차년도”로 표시한다. 로컬창업 아카데미 배지는 “C1-LOCAL-BUSINESS-00”으로 표시하며 해당 코드로도 검색할 수 있다.

## 완료한 검증

- 설계 대조 10/10 항목, 일치율 100%.
- 360/720/1440px 안내문 위치·중심·가로 넘침·닫기 검증.
- 실제 카드·리스트 렌더링과 책임강사 유지, 코드 검색 검증 5건.
- lint·TypeScript·운영 빌드·매뉴얼 검사·원문 16과정 검증.
- 통합 검증 스크립트의 기존 mock/로컬 DB 환경 제한은 분석 문서에 기록했다.

## 릴리스 추적

검증한 커밋을 PR로 push하고 Vercel preview 검사 후 main에 병합한다. 운영 배포의 READY 및 merge commit 일치, 버전·health 응답과 실제 공개 페이지 안내문을 확인한다. 배포 결과는 이 변경에 연결된 GitHub PR과 최종 작업 응답에 기록한다.
