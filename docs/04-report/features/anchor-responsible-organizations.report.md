# 담당 기관 추가 결과

- 담당 기관: 울산과학대학교 산학협력단(`uc-sanhak`), 울산과학대학교 앵커사업단(`uc-anchor`). 강사 관리 선택 목록은 한국어 이름순으로 표시한다.
- 기존 총괄 관리자에게 산학협력단 COURSE_MANAGER만 연결했다. 기존 기관 자료와 정책·동의 기록은 이동하거나 복제하지 않았다.
- `20260922043317_anchor_responsible_organizations.sql`을 스테이징과 운영에 적용하고 양쪽 마이그레이션 이력에 같은 버전으로 기록했다.
- 양쪽 DB에서 기관 2개와 기관별 관리자 1명을 확인했다. 운영의 산학협력단에는 다른 역할이 추가되지 않았으며 감사 이벤트 1건을 확인했다.
- 스테이징에서 authenticated 역할과 트랜잭션 내 임시 MFA 세션으로 관리자 RPC 옵션 2개 및 각 기관 대장 조회를 확인했다. 기존 앵커사업단 강사 1명, 신규 산학협력단 0명으로 자료가 분리된다. 일반 회원은 관리 옵션이 없으며 양쪽 대장 모두 FORBIDDEN이다. 임시 인증 자료는 전체 ROLLBACK했다.
- 마이그레이션 재실행을 ROLLBACK 트랜잭션으로 확인하여 기관·역할·감사 이벤트의 중복 생성이 없음을 확인했다.
- `npm run lint`, `git diff --check` 통과. 로그인된 브라우저 탭이 없어 실제 로그인 UI 조작은 수행하지 않았다.
