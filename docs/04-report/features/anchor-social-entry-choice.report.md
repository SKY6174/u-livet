# 간편 인증 후 회원가입·로그인 선택 완료 보고

2026-09-21

카카오 또는 Google 인증 뒤 U-LIFE 가입 확인이 필요한 경우 곧바로 개인정보 입력을 요구하던 화면을 선택 화면으로 바꿨다. 새 회원가입을 선택해야 기존 가입 양식이 나타나며, 기존 계정으로 로그인을 선택하면 현재 브라우저의 U-LIFE 세션을 종료하고 원래 복귀 주소를 유지한 로그인 화면으로 이동한다.

이미 간편가입을 완료한 회원의 자동 이동과 MFA는 유지한다. 문구는 ‘간편 인증이 완료되었습니다’로 수정했다. 실패한 인증 종료는 화면에서 안내하며 다른 기기의 세션은 종료하지 않는다.

## 검증
- 상태·로그인·가입 회귀 검사 총 115개 통과.
- lint, 타입 검사를 포함한 프로덕션 빌드, diff 공백 검사 통과.
- 합성 상태의 브라우저 경로와 데스크톱/360px 모바일 표시 확인.
- 설계 요구사항 10/10 구현. [상세 검증 및 한계](../../03-analysis/anchor-social-entry-choice.analysis.md).
