# 초대 우선 계정 개방 결과

2026-09-19

초기 관리자용 개인정보 문안을 등록하더라도 공개 가입 폼이 자동으로 열리지 않도록 서버 설정을 분리했다. 화면과 가입 액션이 같은 설정을 사용하며 기본은 닫힘이다. 기존 로그인·복구·초대 수락 절차는 유지한다.

기능 검사 13개, 폼 렌더 검사 3개, 실제 로컬 HTTP GET/Server Action POST, 변경 파일 lint와 운영 빌드가 통과했다. Preview에서 구현 커밋 e08b1db의 가입 차단 및 기존 인증 화면을 확인했다. 최종 Production/Preview 배포 증거는 비공개 `ops/evidence/signup-opening/invite-only-release.json`으로 남긴다.

회원정보 보유기간과 해외 처리 기관 검토 완료라는 사용자 답변을 비공개 검토안에 반영했다. 공개할 계정 문안은 버전·본문 해시로 식별하며 개인 휴대전화는 포함하지 않는다. 개인정보가 포함된 초대 검토 자료는 Git에 올리지 않는다.

실제 계정·권한 생성과 사람에게 보내는 초대 메일은 아직 실행하지 않았다. 다음 단계는 정확한 문안의 승인·본인 동의·초대 발송 요청을 받은 뒤 운영 계정을 준비하는 것이다. 비밀번호와 인증 앱은 본인이 설정하고, 확인된 이후 SYSTEM_ADMIN만 부여한다. 과정 운영 역할은 추가하지 않는다.

세부 설계 대조 및 검증: `docs/03-analysis/anchor-invite-only-opening.analysis.md`.
