# 접수 문서 리스트 및 버튼형 서류 선택

## 변경 내용
- 큰 카드 목록을 요청한 8개 열의 접수 문서 표로 변경했다.
- 다음 처리 단계와 새 수강생 안내를 각 행에서 입력하고 상태를 저장한다.
- 비고에는 현재 상태와 펼쳐 보는 처리 이력을 배치했다. 기존 최신 안내·환불액·원본 PDF 열람은 유지한다.
- 종류 드롭다운은 전체, 수강신청, 장학금신청, 환불신청의 버튼형 단일 선택으로 바꿨다.
- 종류·처리 상태·검색어를 선택한 뒤 기존 조회 버튼이나 검색창 Enter로 적용한다.
- 좁은 화면에서는 표 내부를 가로로 스크롤한다.

## 검증
- `npm run build` 및 `git diff --check`: 통과.
- `node scripts/verify-learner-document-list.mjs`: 8열·행별 폼·상태 전환 선택지·종결 문서·4개 종류 선택·조회 조건·권한 검사 통과.
- 합성 자료의 실제 HTML을 브라우저에 렌더링해 행별 native FormData 격리, 필수값, 필터 조합, Enter 조회를 검증했다.
- 데스크톱·모바일 화면 확인 및 모바일 가로 넘침 수정 완료.
- 기존 서버 액션, 권한/MFA, DB 및 실제 접수 데이터는 변경하지 않는다.
- 설계 대조: `docs/03-analysis/anchor-learner-document-list.analysis.md`.
