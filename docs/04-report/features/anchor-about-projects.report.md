# 앵커사업 소개 개편 검증

## 반영

- 공식 메인 자료를 바탕으로 Dynamic TALENT / BRIDGE / JUMP / CARE를 순서대로 구성했다.
- 각 프로젝트의 원본 사진과 CSS 강조색을 유지했다. 일반 본문은 밝은 색으로 표시하고 프로젝트별 색상은 제목·번호·구분선에 적용했다.
- RCC센터의 공식 소개 사진 및 네 가지 주요역할을 반영했다.
- 내부 바로가기, U-LIFE 교육과정·수강안내 연결, 공식 자료·사진 출처를 제공한다.
- 원본 사진 5장은 변경 없이 저장했고 인증·권한·DB 설정은 변경하지 않았다.

## 설계 대조 및 확인

- 공식 HTML의 프로젝트별 사진·과제 및 CSS 색상을 구현과 대조했다. RCC 주요역할 4개 항목이 모두 포함된다.
- 1440px에서는 프로젝트 2열, 390px/320px에서는 1열. 3개 폭 모두 가로 넘침 없음.
- Next Image로 제공되는 사진 5장 모두 로딩 확인. 원본 종횡비 유지.
- RCC / JUMP 내부 링크 이동 시 대상 상단 약 160px, 고정 헤더 하단 129px로 제목이 가려지지 않는다.
- 320px에서 한국어 줄바꿈을 단어 단위로 보완하고 프로젝트 영역 제목/부제는 세로 배치했다.
- 공식 4색과 카드 배경 #0b162b의 대비는 각각 14.09 / 11.74 / 8.10 / 4.52:1.
- ESLint, git diff --check, 격리된 Next production build와 타입 검사 통과. 빌드 이후 반응형 클래스 2곳 보완에 대해 lint와 브라우저 재검증을 완료했다.
