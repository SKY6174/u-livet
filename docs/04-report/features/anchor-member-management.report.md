# 구성원 관리 완료 보고

2026-09-21 · anchor-member-management

`/admin/accounts`를 사업단/강사/수강생 분류, 검색·페이지, 상세 수정·삭제·강의 및 수강이력 조회가 가능한 구성원 관리 화면으로 확장했다. 요청한 컬럼을 각 분류에 배치하고 강사의 Q&A 문의 연락처는 개인 핸드폰과 별도로 저장한다. 이메일은 로그인 아이디로 조회 전용이다.

수정·삭제는 관리자·기관 범위·최근 MFA·revision을 확인한다. 삭제는 active=false로 서비스 이용을 중지하며 강의·수강·증명 이력을 남긴다. 목록 RPC는 20명 제한, 상세 필드는 선택된 페이지에만 join, 이력은 별도 조회하고 관련 인덱스를 추가했다.

입력/액션/화면 23개, 실제 DB 37개, 기존 회귀 64개와 타입·린트·프로덕션 빌드가 통과했다. 브라우저에서 세 분류, 수정·삭제·이력, 390px 반응형 화면을 확인했다. 운영 쓰기 테스트는 하지 않았다.

Preview 및 운영 DB에 새 migration 적용을 완료하고 기존 데이터 계수를 대조했다. Security Advisor 경고 없음. 기존 legacy 모델의 성능 경고는 별도 과제이며 새 구성원 모델의 경고는 없다.

상세 범위와 검증 한계: [검증 기록](../../03-analysis/anchor-member-management.analysis.md).


## 2026-09-23 최고관리자 누락 수정

기존 최고관리자 송경영을 소속 사업단 명부에 포함하고 성명 옆에 최고 관리자 배지를 표시한다. 다른 기관의 과정 운영 역할로 인한 누락을 읽기 범위에서 해결했으며, 기존 계정/직책을 사용하고 수정·삭제 권한은 확대하지 않았다.

총 96개 회귀 검증과 lint·타입·production build 통과. 새 migration은 Preview 및 운영에 적용했다. 로그인된 운영 브라우저 세션이 없어 실제 관리자 화면 시각 검증은 제한되었다. 세부 설계 비교와 검증 기록은 분석 문서에 남겼다.
