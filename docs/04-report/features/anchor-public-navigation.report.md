# 공개 메뉴 구성 결과

- 공통 Header에서 앵커사업 소개 → 수강안내 → 교육과정 소개로 이름·순서를 통일했다.
- 비로그인 공개 화면의 나의 공간을 제외하고 로그인 버튼은 유지했다. 로그인 시작화면에는 중복 로그인 버튼을 표시하지 않는다.
- 로그인 화면에서 실제 메뉴를 눌러 사업소개·수강안내·교육과정 이동과 각 화면의 동일한 메뉴 및 로그인 버튼 표시를 확인했다.
- 모바일 390px에서 같은 메뉴 순서·로그인 링크·가로 넘침 없음 확인. 임시 viewport 설정은 해제했다.
- 설계와 구현 직접 대조, lint·diff check 및 독립 production build 통과. main·preview push 후 배포 확인.
