# Preview 통합 검증 결과: 통과

2026-09-19 · `anchor-preview-integration-verification` · Production 전환 2단계 완료

`https://staging.uc-life.org`의 Preview revision `3670705`에서 실제 웹 로그인부터
DB 저장, 첨부파일 처리, 6종 출력까지 확인했다. 설계한 7개 검증 경로를 모두 통과했다.

## 확인한 동작

- 운영진·강사의 비밀번호 로그인과 TOTP 추가 인증, 학습자 로그인과 본인 강의실 접근.
- 역할에 맞는 화면 제공과 관리자 보고서/첨부에 대한 강사·학습자 접근 차단.
- PDF 기반 14개 과정, 강사명 검색, 스마트테크·라이프케어·로컬창업·팝업 필터.
- 보고서 폼과 가상 강사료 저장, 재조회 및 DB revision/입력값 대조.
- PDF·사진 업로드와 원본 해시가 일치하는 다운로드, 삭제 및 삭제 후 접근 차단.
- 전체/개별 6종 인쇄 화면, 인쇄 버튼, 10쪽 QA PDF의 내용·페이지 표시 및 계좌 마스킹.
- 검증 시간대의 해당 Preview Vercel 로그에서 5xx가 조회되지 않음.

## 이전 차단 해소

초기 시험 도구의 별도 정책 ID와 누락된 휴대전화 값이 새 가입 규칙과 맞지 않았다.
카카오 가입 변경이 Preview 코드에 반영된 뒤 현재 승인 정책과 합성 휴대전화 입력으로
시험 계정을 준비하니 메일 발송 없는 초대 링크 생성 및 후속 로그인·MFA가 정상 동작했다.
이번 검증을 위해 제품 코드나 실제 가입 설정을 변경하지 않았다.

## 정리와 검증 범위

- 시험 계정 3개와 생성한 모든 시험 자료를 삭제했다. DB는 Auth 3명·과정 0개·조직 1개로 복원됐고 시험 인물은 0명이다.
- 기존 계정의 비밀번호/MFA를 변경하지 않았고, 로컬 시험 비밀번호·MFA 비밀도 제거했다.
- 실제 메일 발송, 외부 카카오 계정 OAuth 전체, 실제 프린터의 A4 출력은 이번 검증 대상이 아니다.
- QA PDF는 자동화 도구의 기본 Letter 출력이며, 총 10쪽을 렌더링하여 내용과 잘림 여부를 확인했다.
- 이번 작업에서 Production DB 적용이나 main 병합, Production 배포는 수행하지 않았다.
