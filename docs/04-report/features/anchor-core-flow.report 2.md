# 앵커사업 홈페이지 1차 구현·검증 보고

2026-09-19 KST · 작업단위 `anchor-core-flow` · 전체 플랫폼은 계속 구현 중

## 구현 결과

수강생의 실제 로그인·가입 동의·과정 조회·무료 신청·강의실과, 강사의 자료·과제·채점, 사업단의 개설·공개·강사 배정·신청 심사를 DB에 연결했다. 사용자 선택에 따라 LMS는 홈페이지 내부에 둔다.

| 대상 | 사용 가능한 기능 |
|---|---|
| 방문자 | 공개 과정 검색·상세, 수강안내, 승인된 개인정보 안내, 가입·로그인 |
| 수강생 | 필수 동의, 신청/심사/대기/수강 확정 상태, 시작 전 취소, 등록된 강의실의 자료 열람, 텍스트 과제 제출·재제출, 점수·피드백 조회 |
| 강사 | 담당 기수 조회, 최소 수강 명단, 텍스트 자료·과제 등록, 제출 버전별 채점·피드백 |
| 과정담당 | 과정·버전·기수 초안 생성, 승인된 정책을 연결한 모집 공개, 승인 강사 배정·해제, 신청 승인·미선정·대기자 승급 |

새 모델은 19개 `life_` 테이블과 RLS, 사용자 세션 기반 업무 RPC로 구성했다. 모든 등록·취소는 기수 잠금으로 정원을 확인한다. 학습자의 제출내용과 강사 점수는 별도 테이블에 저장한다. Auth 계정을 삭제해도 새 학습·신청 기록은 자동 삭제되지 않는다.

종전 역할 체험 로그인, localStorage/user_metadata 권한 판정, 가상 신청 성공, 임의 ID 가짜 수료증·배지와 고정 실적 화면은 제거했다. 실제 기록이나 승인 기준이 없는 서비스는 준비 상태로 표시한다.

이 33개는 이번 작업단위의 테스트 수다. 전체 설계 문서의 T01~T30 전체가 통과했다는 의미가 아니다. 영상 부정진도·금전거래·증명 원장·복구 등 미구현 영역은 검사하지 않았다. 보안 점검 도구의 0건 결과도 모든 운영 위험이 제거되었다는 뜻은 아니다.

기존 Next.js 14의 보안 취약점을 실제 패키지 감사에서 발견해 15.5.25 / React 19.3으로 전환했다. 공식 codemod와 비동기 쿠키/호출부 수정을 적용했고 PostCSS·개발 도구의 간접 의존성도 수정했다. 근거: [공식 보안 공지](https://nextjs.org/blog/august-2026-security-release), [v15 전환 가이드](https://nextjs.org/docs/app/guides/upgrading/version-15).

## 남은 구축 범위

1. 영상 학습·공식 출결·시험·파일 제출·Q&A, 수료 산출과 승인.
2. 이수증·디지털배지·진위검증, 강사 이력·경력증명과 발급권한.
3. 유료 청구·입금·환불·정산, 문자/이메일 안내와 전송 이력.
4. 상담·지원·만족도·연차별 과정 평가·성과 집계와 공식 보고.
5. 정책 승인·권한 관리 UI, 관리자 MFA/재인증, 보유·파기·접근 로그·속도제한, 백업/복구·모니터링·운영 배포.

이번 무료 신청은 취소 후 동일 기수 재신청을 지원하지 않는다. 선착순 대기 승급은 담당자가 확인한다. 과정 재사용·버전 심의와 대규모 목록의 페이지 처리도 확장 대상이다. 기존 교육·재무·증명 원자료 이관은 기관 검토와 대조가 별도로 필요하다.

다음 작업은 내부 LMS의 공식 출결·시험·수료판정 연결이다. 미확정된 수료기준, 수납/환불 규정, 개인정보 보유기간, 발급 명의·위임은 기관 확정 후 활성화한다.

PDCA: `anchor-core-flow` 구현·검증 완료. 상위 `anchor-lifelong-education-platform`은 Do 진행 중이며, 이번 완료를 전체 플랫폼 완료로 기록하지 않는다.
