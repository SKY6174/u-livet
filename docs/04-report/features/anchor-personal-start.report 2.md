# 개인 시작화면 검증

2026-09-20

## 반영 내용
- 비로그인 `/`는 사업단·강사(교내)·강사(교외)·수강생 로그인 선택으로 연결된다.
- 일반 이메일·소셜 로그인과 가입 완료의 기본 목적지는 개인 홈(`/`)이다. 로그인된 이용자가 로그인 화면에 다시 방문해도 개인 홈으로 돌아간다.
- 개인 홈은 기존 남색 배너와 교육과정 목록을 유지하면서 이름과 실제 역할별 업무 바로가기를 표시한다.
- 명시적 업무 복귀 주소, 신규 가입 동의, 필수 MFA, 공개 교육과정 열람을 유지한다. 로그아웃 후에는 다시 로그인 선택 화면을 표시한다.

## 검증 결과
- 개인 홈 접근·역할별 렌더링 12개, 로그인 대상·제공자 46개, 소셜 가입·복귀 40개, MFA 이동 24개: 총 122개 통과.
- ESLint, diff 공백 검사 통과. 기존 개발 서버와 분리한 깨끗한 복사본에서 Next.js 프로덕션 빌드·타입 검사 통과.
- 로컬 브라우저에서 `/` → 로그인 선택, 데스크톱 네 칸/390px 모바일 두 칸 배치, 수강생 선택과 모바일 가로 넘침 없음을 확인했다.
- 서버 응답에서 이메일·소셜 로그인 form의 복귀 주소가 `/`임을 확인했다. 브라우저 런타임 오류 없음.
- 설계 대조: 인증 전 회원정보 접근 차단, 이름·실제 역할 표시, 기본 홈 복귀, 명시적 업무 링크 유지, 가입·MFA 단계 및 로그아웃 경로 모두 구현·회귀 검증했다.

자동화 검증은 합성 회원으로 수행했으며 실제 계정 생성·동의 대행·권한 변경·인증 메일 발송은 없다. 로그인 제공자의 실제 인증은 기존 설정을 유지한다.
