# 운영계획서·결과보고서 메뉴 분리 — 완료 보고

> 2026-09-22 · [설계](../../02-design/features/anchor-operation-document-menus.design.md) · [검증](../../03-analysis/anchor-operation-document-menus.analysis.md)

관리자 업무 홈의 묶인 운영 문서 메뉴를 운영계획서와 결과보고서로 나눴다. 결과보고서에는 공식 문서 작성과 기존 결과 보고·6종 증빙을 바로 전환하는 탭을 두었다. 기존 보고 목록의 검색·상태 필터·과정별 작성·6종 출력, 기존 PDF 및 지급자료 경로는 유지된다. 증빙 탭은 기존 COURSE_MANAGER 권한으로 제한한다. 이전 목록 URL은 적절한 새 탭으로 이동한다.

검증: 역할별 탐색 20개 검사, 문서 RPC 통합 검사, lint/build 통과. 브라우저에서 관리자 공식/증빙 탭과 강사 공식 목록을 확인했고, 강사의 증빙 직접 접근은 404, 모바일 가로 넘침은 없음. 새 DB 마이그레이션은 필요하지 않다.
