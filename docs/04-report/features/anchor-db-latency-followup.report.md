# DB 연동·조회 최적화 검증

2026-09-23 · anchor-db-latency-followup

운영 DB 연결과 공개 조회는 정상이다. 운영문서 RPC의 비로그인 접근은 401로 차단된다.

## 변경 결과

- 과정 목록에서 상세 교육내용·일정 이력·시간·장소 필드를 제외했다. 목록·검색·정렬은 유지하고 상세 페이지에서는 계속 전체 정보를 읽는다.
- 운영문서 편집 화면은 인증·입력 검증 후 문서와 과정 목록을 동시에 읽는다. 기존 권한·오류 처리와 인쇄 화면의 단일 조회를 유지한다.
- 편집기의 과정 선택 항목에는 id·과정명·시작일만 전달한다.

운영 공개 REST 비교에서 동일한 16개 과정의 JSON 본문이 **13,070 → 7,318바이트(44.0% 감소)**로 줄었다. HTTP 중앙값은 160 → 173ms로, 이번 소표본에서는 응답시간 단축이 입증되지 않았다. 편집 화면은 동시 조회 실행을 검증했으며 실제 로그인 후 전체 화면의 개선율은 측정하지 않았다.

## 검증과 적용 대상

관련 회귀 **51개**, 설명서 확인, 프로덕션 빌드에 포함된 lint·TypeScript 검사, diff 검사 통과. 설계 구현 항목 8/8 확인. 운영 데이터·스키마·RLS·계정 설정 변경은 없다.

적용 대상은 현재 `main`과 연결된 `uc-life.org` 운영 배포다. 배포 후 revision과 DB health를 확인한다. `preview`/staging은 이번 변경의 push 대상이 아니다.
