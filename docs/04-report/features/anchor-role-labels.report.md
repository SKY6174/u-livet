# 역할 표시 검증 결과

2026-09-19. [상세설계](../../02-design/features/anchor-role-labels.design.md)의 표시 규칙을 Header에 적용했다.

- 시스템 관리자 → 관리자, 과정·수납·증명·성과 담당 → 운영자, 강사 → 강사, 일반 계정 → 수강생.
- 데스크톱과 모바일 메뉴에 동일한 텍스트 배지·이름을 표시한다. 실제 권한 및 메뉴 조건은 유지한다.
- 실제 Header 및 RoleProvider, 빌드된 Tailwind CSS를 Chromium에서 합성 신원으로 검증했다. 실제 로그인 자격 증명은 사용하지 않았다.
- 17개 확인 항목 통과: 데스크톱 11개(네 표시, 업무별 운영 권한, 동명 계정, 복수 역할), 모바일 4개, 비로그인 2개. 모바일 가로 넘침과 브라우저 런타임 오류도 없었다.
- main 기준과 preview 기준 각각 lint 및 Next.js 프로덕션 빌드 통과. 양쪽 Header 소스 동일함을 확인했다.
- Production·Preview의 대상 인물 조회 결과, 현용환·이연향·이현섭은 아직 등록되어 있지 않다. 신규 계정·권한 변경 없이 기존 송경영 계정의 실제 역할을 표시한다.

Git 반영 후 자동 배포 결과와 도메인의 버전·상태는 별도로 확인한다. 서버 데이터베이스 변경은 없다.
