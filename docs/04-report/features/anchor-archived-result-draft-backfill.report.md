# 보관 결과보고서의 검토용 초안 반영

2026-09-22 · `anchor-archived-result-draft-backfill`

운영 DB에 보관된 3개 결과보고서 PDF를 기존 집계와 대조해 새 운영결과보고서의 저장된 `DRAFT`로 연결했다. 반려동물 수제간식 10장, 파크골프 26장, 로컬 쿠키 8장의 운영사진을 압축해 포함했다. 강의 시간·연도 충돌이 있는 표는 채우지 않았고, 원본 확인사항을 검토 메모에 남겼다. 예산과 서명은 비워 두어 담당자 예산 입력 후 책임강사 검토·서명·제출 순서를 유지한다.

적용 전 SHA-256과 DB 양식·예산 검증을 통과했다. 적용 후 세 과정 모두 revision 1의 `DRAFT`, 본문과 보관 PDF 원본 일치, 사진 수 일치를 확인했다. 원본 PDF 3건과 기존 집계는 변경하지 않았고, 감사기록 3건을 남겼다. 재실행 시 기존 결과 문서를 덮어쓰지 않는 관리 스크립트 `scripts/backfill-archived-result-drafts.py`를 추가했다.

담당자 화면에서 사진 순서·설명·강의표·예산을 최종 확인해야 한다. 실제 Terra 제안은 Preview·운영의 유효한 `OPENAI_API_KEY` 설정 후 테스트가 필요하다.
