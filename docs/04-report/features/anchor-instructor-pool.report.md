# 평생직업교육 강사 Pool 관리 개선

2026-09-22

사업단 관리 → 전문가 관리(`/admin/instructors`)에서 교내·교외 강사 대장, 비공개 서류, 강의·활동 이력, 수당 지급 기록과 이력 심사를 운영한다.

- 인원·서류 준비·지급 대기·누적 지급 요약과 대장 중심 화면 구성.
- 신규 강사 등록, 검색·필터, 엑셀 일괄등록/다운로드 및 기존 강사 연계.
- 소속·구분 변경 이력, 과정 배정/확정 강의시간, 당시 소속을 보존하는 활동·수당 기록.
- 지급일/거래 참조/근거/필수 서류 확인 후 지급 완료, 원기록을 보존하는 취소.
- 기존 비공개 문서 및 PDF 1.7 경로 유지. 실제 송금은 외부 처리 후 기록한다.

검증: Pool RPC 18개, 기존 문서 15개 회귀 검증, 실제 XLSX 입출력, 브라우저 등록/수정/검색/지급 완료, 모바일 너비, TypeScript/ESLint/production build 통과. 가상 운영 자료는 로컬에서만 사용하고 정리했다.

운영 Supabase 마이그레이션: `20260922035605_anchor_instructor_pool_history.sql`. 원본 적용 이력은 변경하지 않고 후속 마이그레이션으로 반영했다. 사업단 COURSE_MANAGER 기관 범위, RLS 및 테이블 직접 조회 차단 확인. 상세 검증과 범위는 `docs/03-analysis/anchor-instructor-pool.analysis.md` 참고.
