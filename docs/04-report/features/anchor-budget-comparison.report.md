# 예산 및 집행현황 통합 구현 보고

2026-09-21

과정 운영 관리의 예산 현황과 예산 집행현황을 한 화면으로 합쳤다. 프로그램 ID와 과정명을 병합하고 각 과정에 예산/집행 두 행을 표시한다. ‘단위: 원’은 오른쪽 상단으로 옮겼으며 기존 상단 안내 문구는 제거했다.

기존 예산 편집과 엑셀 파일 선택·저장·원본 조회 기능은 통합 화면 안에서 제공한다. 최신 저장 파일을 자동 조회하며 정확히 연결된 과정의 집행 금액만 비교한다. 미등록 값과 0원은 구분하고, 중복 자료나 식별 불가능한 열은 확인 안내를 표시한다.

모델/비교 검증 26건, lint, TypeScript, production build를 통과했다. 데스크톱/모바일 및 합성 XLSX 흐름은 로컬 컴포넌트 검증을 완료했다. 상세 범위와 결과는 `docs/03-analysis/anchor-budget-comparison.analysis.md`에 기록했다.
