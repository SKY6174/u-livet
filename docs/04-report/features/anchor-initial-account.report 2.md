# 최초 계정 비밀번호 설정 준비 완료

2026-09-19 · anchor-initial-account · 기술적 준비 완료 / 실제 초대 대기

초대 메일에서 처음 비밀번호를 설정하고 새 비밀번호로 로그인하는 흐름을 운영과 Preview에 반영했다. 기존 복구 화면을 재사용하되 서버에서 초대·복구 목적을 구분한다. 메일 링크 조회만으로 인증을 소비하지 않으며 완료 시 임시 세션을 종료한다. 관리자 업무는 본인의 인증 앱 연결과 별도 권한 승인 후 이용하도록 안내한다.

## 적용 내용

- [처음 비밀번호 설정](https://uc-life.org/auth/accept-invitation): 이메일 링크가 없으면 초대 메일 이용 안내를 표시한다.
- [설정 후 안내](https://uc-life.org/auth/invitation-accepted): 새 비밀번호 로그인과 계정 보안 확인을 안내한다.
- [한국어 초대 템플릿](../../../supabase/templates/invite.html): 운영·Preview 각 SiteURL로 연결, 15분·1회 사용 안내.
- 비밀번호 보이기·숨기기와 실시간 조건 체크를 재사용하고 이전 대소문자 안내 문구를 현재 Supabase 정책에 맞췄다.
- [운영 절차](../../operations/signup-opening.md), [설계 대조](../../03-analysis/anchor-initial-account.analysis.md), [개인정보 기관 검토 틀](../../operations/privacy-review-template.md).

인수 검증한 애플리케이션 변경은 `eefe2e67af4c934cb02e9e5aac587b1368c5598b`이다. 이 보고서의 후속 커밋은 문서만 변경한다. 양 브랜치와 최종 배포 SHA·상태는 Git 제외 운영 증거 `ops/evidence/signup-opening/initial-account-release.json`에 기록한다.

시험은 메일을 보내지 않는 Supabase generateLink와 합성 계정을 이용했다. 실제 담당자 수신함·실제 초대 메일 배달·관리자 권한 부여는 이번 검증에 포함하지 않는다. 신규 DB 마이그레이션이나 유료 서비스 추가는 없다.

## 남은 개방 조건

기관 개인정보 문안의 보유기간·위탁/국외이전 근거를 확정하고 승인본을 등록해야 한다. 이후 최초 담당자에게 해당 문안을 제시해 동의 및 초기 설정 메일 요청을 확보하고, 지정된 업무 역할에 따라 계정·MFA·권한을 설정한다. 공개 가입은 이 절차와 실제 메일 수신 검증 뒤 개방한다.

연락처 제공을 본인 동의나 기관 승인으로 대신하지 않았다. 현재 실제 관리자 계정은 생성되지 않았고 공개 가입도 계속 닫혀 있다.
