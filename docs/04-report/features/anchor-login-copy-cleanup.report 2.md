# 로그인 안내 간소화 확인

- 사업단 직책 안내, 가입 이메일 입력 도움말, 비밀번호 보이기 도움말, 로그인 후 역할 안내를 제거했다.
- 로그인 입력의 삭제된 설명 참조도 제거했다. 회원가입·비밀번호 재설정의 조건 안내와 교내 강사 암호 설정 안내는 유지했다.
- 데스크톱 사업단·교내/교외 강사·수강생 화면 확인. 교외 강사·수강생 이메일 옵션 펼침, 비밀번호 보기/숨기기 키보드 조작 정상.
- 모바일 390px 확인: 가로 넘침 없음. 삭제한 문구와 빈 공간 없이 필드·복구 링크·로그인 버튼 표시.
- lint, diff check, 임시 디렉터리의 깨끗한 production build(컴파일·타입 검사 포함) 통과.
- 로컬은 기존 봇 인증 설정 부재로 실제 로그인 제출이 비활성이다. 인증 제출 코드는 변경하지 않았으며 이번 검증은 문구·레이아웃·보기 토글과 빌드에 한정했다.
- 로컬 설계 문서와 변경 diff를 직접 대조했다. main·preview를 동일 커밋으로 push한다.
