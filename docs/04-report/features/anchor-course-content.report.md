# 2026년 평생직업교육과정 현황 반영 보고

2026-09-19 · anchor-course-content

## 제공한 화면

**사업단 관리 → 2026 과정 현황** (`/admin/course-plan`). 과정담당 계정으로 접근한다.

사용자가 제공한 「2026 지역혁신중심 대학지원체계(RISE)사업 평생직업교육과정 현황.pdf」 1쪽의 14개 세부 과정을 반영했다. 4개 아카데미 분류, 강사·보조강사·보조인력, 학부·거버넌스, 교육일정, 정원·시수, 모집·수료, 관련 자격증, 비고, 예산을 조회할 수 있다. 과정명·사람 이름·기관·자격증 검색과 아카데미·강사 구분 필터를 제공한다.

## 주요 수치

| 항목 | PDF 원문 총계 | 세부 과정 합산 |
|---|---:|---:|
| 모집정원 | 267명 | 212명 |
| 시수 | 543시간 | 523시간 |
| 예산 | 109,608,320원 | 109,608,320원 |

라이프케어 7개, 로컬창업 4개, 팝업 3개다. 스마트테크는 원문 소계 15명·20시간만 있어 세부 미기재로 표시했다. 로컬창업·팝업 소계와 세부 정원의 각 20명 차이를 보존했다.

## 운영 시 참고

- 교내·교외 분류 체계를 마련했으며 원문에 근거가 없는 소속은 **확인 필요**다.
- 보조강사와 보조인력은 별도 표시한다. 원문 ‘미정’, ‘-’, 공란, A/B를 구분한다.
- 모집인원·수료인원의 공란은 0명으로 바꾸지 않았다.
- 이 화면은 제공 PDF 기준의 읽기 전용 연간 계획이다. 실제 모집 기수·신청·출결·수료를 생성하지 않는다.
- 세부 교육일정과 승인된 수료기준, 강사 소속 명단을 확정하면 후속 운영자료로 연결할 수 있다.
