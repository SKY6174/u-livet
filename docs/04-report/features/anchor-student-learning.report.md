# 수강생 학습 허브 개편 보고

2026-09-21 · anchor-student-learning

`/mypage`를 평생학습자의 학습 여정에 맞춘 네이비·민트 대시보드로 개편했다. 제목은 `OOO님의 학습`이다. 내 수업과 다음 일정, 신청·납부 대기, 출석·주차별 학습자료, 이수 기준, 이력·수료·배지, 만족도 조사, 장학금, 추천 과정을 연결했다. 수강 신청이 없는 계정에도 과정 탐색과 과목 제안을 제공한다.

희망 과목은 DB에 저장되며 사업단 `/admin/course-requests`에서 기관별로 검토·답변한다. 본인 기록만 조회하도록 보호하고 잘못된 입력, 중복 제출, 하루 5건 초과, 타 기관 검토를 차단했다. 장학금은 운영 보고서의 본인 금액·지급일 기록이며 계좌와 타인 정보는 반환하지 않는다. 추천은 동일 분야 기반이고 실제 선수과정 관계를 의미하지 않는다.

검증: UI/모델/서버경계 5 시나리오, 실제 로컬 DB/RLS 6 시나리오, lint/TypeScript/production build, 데스크톱·모바일 브라우저 및 제출 후 새로고침 확인. 설계 14/14 구현. 세부 근거는 `docs/03-analysis/anchor-student-learning.analysis.md` 참조.

새 기능은 `20260921123756_anchor_student_learning.sql`에 정의했다. 배포 환경의 기존 데이터 수정·가상 학습/송금 기록 생성 없이 새 테이블과 제한된 조회·제출·검토 함수만 추가한다.

Preview와 Production에 이번 migration 1개를 적용했다. 각 환경에서 함수 설치, RLS 활성화, 익명 조회/실행 차단, 직접 INSERT 권한 차단을 확인했다. 기존 이력과 데이터는 유지했다. Git push 후 배포 상태는 작업 응답에서 보고한다.
