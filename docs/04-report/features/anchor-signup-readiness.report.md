# 공개 가입 준비 점검 보고

2026-09-19 · anchor-signup-readiness · 준비 산출물 완료 / 가입 개방 대기

메일 설정 이후 남은 가입 요건을 실제 운영·Preview에서 읽기 전용으로 확인했다. 두 환경 모두 계정·유효 개인정보 정책·관리자가 없고 가입 차단은 유지된다.

사용자가 제공한 초기 관리자 후보와 개인정보 문의 부서를 비공개 검토본에 반영했다. 게시 연락처 초안에는 사무실 번호를 사용했다. 관리자 계정 생성·권한 부여·본인 동의·기관 문안 승인은 아직 수행하지 않았다.

## 검증

읽기 전용 SQL을 양 DB에서 실행했고 가입/정책 동결 트리거 활성과 미충족 상태를 확인했다. 배포된 양 사이트의 가입 버튼 비활성 및 개인정보 안내 준비 상태를 HTTP 응답에서 확인했다. 설계 요구 8개에 대한 준비 산출물이 모두 대응한다. 점검에 메일 발송·사용자 생성·권한 부여는 없었다.

기존 메일 검증은 공급자 진단 전달과 Preview 복구 흐름까지이며, 실제 담당자 수신함과 최초 관리자 설정은 후속 범위다. 기존 운영 코드는 이번 작업에서 수정하지 않았다.

## 다음 실행 조건

1. 기관 보유기간·처리기관·위탁/국외이전 근거와 최종 문안 승인.
2. 지정된 최초 담당자의 해당 문안 동의와 초기 설정 메일 발송 요청, 필요한 업무 역할 확정.
3. Preview에서 최초 계정 설정·이메일 확인·MFA·역할 접근을 검증하고 운영 적용.
4. 가입 인증·동의 기록 검증 후 공개 가입 개방.

담당자 정보를 제공했다는 이유만으로 동의 기록이나 관리자 권한을 생성하지 않는다. 전체 프로젝트의 운영 개방 완료를 선언하는 보고서가 아니다.
