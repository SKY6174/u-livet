# 운영계획서 등록 준비 연결 완료

> 2026-09-19 · Feature: anchor-course-opening-prefill

## 사용자 결정

개설 준비 대상은 운영계획서 **16개 전체**, 모집 시작·마감 일시는 **미정**이다.
별도 담당자 권한 연결은 사용자가 연기한 상태를 유지한다.

## 변경 결과

관리자 **2026 개설 준비 → 등록 양식에 불러오기**로 해당 과정의 입력 준비를 시작할 수 있다.
과정명·아카데미·정원·장소·소개·교육내용을 편집 가능한 기본값으로 제공한다.
사업연도·모집기간·최종 교육기간·운영방식·선발방식은 관리자가 확인해 입력한다.

원문 일정·교육방식·수강료 산식과 불일치는 폼 위 참고 영역에서 확인한다.
계획서의 날짜나 예산 금액을 확정값으로 자동 저장하지 않는다. 기존 무료 초안·유료 정책 설정 절차를 유지한다.
직접 입력으로 돌아가거나 전체 계획서로 돌아갈 수 있고, 다른 과정으로 이동하면 이전 폼 상태가 남지 않도록 원문 ID로 구분한다.

## 검증

신규 7개와 기존 23개 검사가 통과했다. lint·앱 전체 빌드·클라이언트 번들 검사를 완료했다.
브라우저에서 링크 이동, 입력값·필수 항목, 편집, 직접 입력 복귀, 데스크톱·모바일 표시를 확인했다.
자세한 근거와 실제 운영 검증 범위는 [설계 대조](../../03-analysis/anchor-course-opening-prefill.analysis.md)에 기록했다.

## 운영 상태

이 변경은 `preview` 반영 대상이다. 실제 운영 DB의 과정·기수·정책은 변경하지 않았다.
`anchor-course-opening-prefill`은 완료이며 `anchor-production-opening`은 Do 상태를 유지한다.
모집기간 및 나머지 운영 조건이 확정되면 실제 등록과 정책 연결을 진행한다.
