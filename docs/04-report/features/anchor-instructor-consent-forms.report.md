# 강사 필요서류 3종 및 보조강사

사업단 관리 → 전문가 관리 → 강사 마스터에서 교외 보조강사를 등록하고 문서별 입력 버튼으로 새 창을 연다. 교외 강사와 보조강사는 이력서 및 개인정보동의·성범죄 조회동의·청렴서약 3종을 제출해야 지급 완료 처리할 수 있다.

성범죄 조회동의서는 제공된 원본 PDF의 빈칸을 채운다. 개인정보동의서는 uc-anchor의 항목별 안내·동의·서명 구성을 참고하고 첨부 양식의 보유기간·세무서 제공 내용을 반영했다. 청렴서약서는 KoPub Dotum으로 인적사항·서약·이해관계 확인을 구성했다. 입력 왼쪽/실제 PDF 미리보기 오른쪽, 모바일에서는 세로로 배치한다.

초안과 인적사항·서명은 암호화하여 저장하고 최종 PDF는 비공개 보관한다. 거부 동의는 별도 상태로 보관하며 필수 완료에 포함하지 않는다. 재제출 시 과거 버전은 유지하고 서명·동의는 재입력한다. 모두 A4/PDF 1.7.

검증: 기능·회귀 78개 통과, PDF 시각/글꼴 검사, 실제 Edge/Storage 저장·다운로드, PIN 및 사업단 브라우저 흐름, 모바일 확인. 상세 근거는 분석 문서 참조.
