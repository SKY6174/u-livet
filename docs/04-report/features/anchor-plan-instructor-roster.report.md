## 결과

- 실명이 기재된 강의·보조강사 43건을 39명으로 정리해 강사 pool에 반영했다. 교내 9명, 교외 30명이며 미정 인원·보조인력은 제외했다. 센터장 1명을 더해 강사 pool은 두 환경 모두 40명이다.
- 첫 교내 강사가 있는 10개 과정은 그 사람을 대표강사로, 교외 강사만 있는 6개 과정은 현용환 센터장을 대표강사로 지정했다. Production의 센터장은 실제 `CENTER_HEAD` 구성원과 연결했다.
- Production의 개설 기수 16개에 실제 운영 책임이 연결됐다. Preview에서는 현재 개설된 3개에만 실제 운영 책임이 있고 나머지 13개는 계획상 지정으로 남아 있다.
- 관리자 구성원 강사 목록에 계정 미연결 pool 인물이 표시되고 강사 마스터 정보로 이동할 수 있다. 새 외부 강사에 로그인이나 강사 권한을 자동 부여하지 않았다.
- 기존 Production 운영 문서 3건과 이미 승인된 교외 강사 2명의 역할을 유지했다.
