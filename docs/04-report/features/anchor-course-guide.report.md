# 수강안내 구성 개선 확인

## 변경
- 신청 전 확인할 다섯 항목, 번호·아이콘을 붙인 네 단계, 관련 화면 바로가기로 `/terms`를 재구성했다.
- 심사·대기, 취소·환불, 수료·증명은 키보드로 열고 닫을 수 있는 native details로 정리했다.
- 기존 정책과 이수증·디지털배지 발급 준비 중 안내를 보존했다. 기존 안내문에 확인된 사업단 전화 링크를 제공한다.
- 서버 컴포넌트를 유지하며 별도 클라이언트 상태나 데이터 호출은 추가하지 않았다.

## 확인
- `npm run lint`, `git diff --check` 통과.
- 별도 임시 디렉터리의 깨끗한 production build에서 컴파일·타입 검사·페이지 생성 통과.
- 브라우저: 데스크톱 네 열, 모바일 390px 세로 단계와 FAQ 확인. document width와 viewport width 모두 390px.
- 취소·환불 FAQ Enter 펼침/접힘, 모바일 수료 안내 펼침 확인.
- 교육과정 바로가기는 `/courses`, 비로그인 신청 현황은 `/auth/login?next=%2Fmypage`로 정상 이동. 브라우저 console error 없음.
- 로컬 설계 문서와 구현을 직접 대조해 체크리스트·네 단계·FAQ·연락처·기존 정책 보존을 확인했다. bkit 서버는 로컬 설계 파일을 찾지 못해 자동 일치율은 산출하지 않았다.

## 반영
- main과 preview를 동일 커밋으로 push하고 자동 배포 상태를 확인한다.
