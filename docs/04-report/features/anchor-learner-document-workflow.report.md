## 결과

수강신청원서, 장학금 지급신청서, 수강료환불신청서를 다운로드 전용 작성 도구에서 DB 기반 접수·검토·승인·반려·완료 시스템으로 확장했다. 수강생은 같은 화면에서 제출과 처리 이력을 확인하고, 담당자는 관리자 문서함에서 원본 PDF와 이력을 검토해 상태와 공개 안내를 기록한다.

## 주요 구현

- 수강신청원서 `입력완료`, 장학금·환불 신청서 `신청처리` 버튼
- PDF 다운로드와 제출 시점 PDF 1.7 원본의 분리 제공
- 요청 메타데이터·처리 사건·private PDF 원본의 독립 테이블
- 수강생별 내 처리 현황, 상세 타임라인, 원본 열람, 검토 전 취소
- 관리자 유형·상태·검색 필터, 원본 PDF, 상태 변경, 공개 안내 메모
- 조직 역할, MFA, 소유권, 멱등 키, revision, 감사 로그 보안 경계
- 과정 수강료를 이용한 환불액·공제액 자동 계산과 직접 입력 차단
- 최신 국내 주요 금융기관 은행명 드롭다운
- 환불 PDF 중복 신청날짜 영역과 `음영처리된 곳만 표기` 문구 제거
- 관리자 업무 홈의 `수강생 서류` 메뉴

## 환불 계산

| 발생시점 | 300,000원 과정 예시 |
|---|---:|
| 수업 시작 전 | 반환 300,000원 / 공제 0원 |
| 수업 시작 ~ 총 수업시간 1/6 전 | 반환 250,000원 / 공제 50,000원 |
| 총 수업시간 1/6 이상 ~ 1/3 미만 | 반환 200,000원 / 공제 100,000원 |
| 총 수업시간 1/3 이상 ~ 1/2 미만 | 반환 150,000원 / 공제 150,000원 |
| 총 수업시간 1/2 이상 | 반환 0원 / 공제 300,000원 |

수강료가 null인 과정은 세 금액을 공란으로 두고 제출을 차단한다. 등록된 무료 과정의 0원은 유효한 수강료로 처리한다.
