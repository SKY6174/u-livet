# 관리자 출석부 준비 상태 연결 완료

2026-09-21 · anchor-attendance-readiness

**사업단 관리 → 과정 운영 관리 → 과정 운영 개요 → 수업·출석부 운영**에서 배정 강사·수강 확정 명단·수업 일정의 등록 상태를 각각 확인한다. 부족한 항목과 관리자가 할 작업을 표시한다. 일정·출결 입력은 담당 강사의 업무로 구분한다.

기존에는 강사만 배정되고 수강생이나 일정이 없어도 다음 작업이 결과보고서 작성으로 넘어갈 수 있었다. 이제 빠진 명단·일정 준비를 먼저 안내하며, 수업이 남았을 때는 수업 진행·출결 확인으로 연결한다. 수료 검토는 등록된 정상 수업이 모두 종료되고 교육기간이 지난 뒤 안내한다.

보관 과정은 원본 출석부 첨부 확인 흐름을 유지한다. 원본 모집·수료 인원을 실제 전산 명단처럼 취급하지 않는다. 강사 일정 입력에는 점심·휴게시간을 제외한 교육 구간별 등록 안내를 추가했다.

기존 집계를 사용하므로 추가 DB 요청과 migration이 없다. 사용자 권한과 실제 과정·명단·시간표는 변경하지 않았다. 자동 검사 47개, 빌드, 웹/모바일 확인과 [설계 대조](../../03-analysis/anchor-attendance-readiness.analysis.md)를 완료했다.

실제 운영 입력 조건은 [출석부 등록 준비표](../../operations/2026-attendance-rollout-readiness.md)에 유지한다. 최종 시간표·수강 확정 명단·담당 강사 계정 연결 정보가 아직 필요하다.
