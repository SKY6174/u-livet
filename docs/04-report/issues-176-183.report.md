# Issues 176–183 변경 보고

2026-10-17 · branch `codex/issues-176-183`

운영계획서의 중복 항목을 정리하고 목적 다중 체크, 통합 모집 표·자동 비율, 선택적 발급기관 양식, 시간 안내와 예산 재계산을 반영했다. 기존 JSON 키·제출 PDF·결과보고서 형식은 보존한다.

원서 신규 접수는 실제 모집 기간과 상태를 확인하고 동일 본인·과정의 중복 원서를 차단한다. 일반 신청과 원서, 원서만 접수한 수강생도 관리 화면에서 함께 찾을 수 있다. 서류 승인과 수강 등록 상태를 구분하고, 기존 동의·납부·정원 근거를 우회하지 않는다.

활성 강사 대장의 외부강사를 배정·책임강사 후보에 포함하고 비활성·타 기관을 차단한다. 수강료·환불 규정의 진입점, 변경 제한 안내, 승인 규정 새 버전·계산 조항 편집 경로와 관리자 메뉴 자동완성을 제공한다.

설계 대비 18/18 항목을 확인했다. UI→로컬 HTTP→실제 DB RPC→저장·복원, 390px 너비, PDF 1.7 출력, 중복·기간·역할·기관 범위·revision·환불 조항 불변성 검사를 통과했다. 타입·lint·운영 빌드와 기존 입력 문서 회귀도 통과했다. 테스트 자료는 모두 로컬이며 ROLLBACK했다.

운영 적용은 두 migration으로 분리한다. 운영 권한·schema advisor 확인 후 적용하고, PR 검사·push·merge·운영 READY와 실서비스 version·health의 정확한 결과는 PR 본문에 기록한다. 완료 후 PDCA 문서를 archive할 수 있다.
