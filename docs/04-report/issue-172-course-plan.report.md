# Issue 172 운영계획서 개선 보고

2026-10-13 · 이슈: https://github.com/SKY6174/u-livet/issues/172

## 반영 내용

- 강의 기본정보를 입력하거나 기존 회차에서 불러온 후 새 회차에 재사용한다. 기존 회차와 날짜·보강 정보는 독립적으로 관리한다.
- 표지의 성인학습자·지역주민을 하나 또는 둘 모두 선택할 수 있다.
- 담당교수 서명은 검토 요청·최종 제출에 필수이며 임시저장은 허용한다. 표지와 PDF의 서명을 확대하고 이름·문구와의 겹침을 제거한다.
- 예산 산출식 변경 시 계산 가능한 금액을 자동 입력한다. 직접 금액 조정과 기존 수동 금액을 보존한다.
- 재료비 산출내역은 여러 줄로 입력하고 합산하며 저장·PDF 출력에서 줄바꿈을 유지한다.

## 검증

설계 대비 11/11 항목을 확인했다. 계산 경계값·불명확한 수식, 복사된 회차의 독립성, 대상 문자열 호환, 실제 DB의 서명·권한·revision·스냅샷, UI 입력·저장·복원, 360px 너비, A4 PDF 1.7 렌더링을 검증했다. 타입 검사·lint·빌드와 사전 입력 문서 회귀 검사도 통과했다.

운영 DB migration `20261013012440_plan_signature_required`를 적용했으며 advisor 종류·건수 증가가 없다. 기존 제출본 읽기와 결과보고서 흐름은 유지한다. 기본정보는 새 회차 입력을 돕는 편집 상태이며 다시 열면 첫 저장 회차에서 복원된다.
