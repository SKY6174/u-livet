# 가입 준비 안내와 동의 화면 설계

2026-09-19 · [계획](../../01-plan/features/anchor-consent-readability.plan.md)

## 준비 상태

`AuthForm`의 signup 경로에서 승인 문안이 없거나 인증 메일이 미준비이면 개인정보 입력 폼을 렌더링하지 않는다. 안내 영역에 준비 이유, 공개 교육과정 보기, 기존 계정 로그인 링크를 제공한다. reviewOnly일 때에도 이 안내를 사용한다. 로그인 경로의 폼·복구 링크는 그대로 둔다.

이는 화면의 준비 조건이며 Supabase의 실제 가입 허용 설정을 대신하지 않는다. 기존 서버 액션의 승인 문안·동의·메일 준비 검증과 Auth의 가입 제한은 유지한다. 승인 정책을 만들거나 공개 가입을 켜는 변경은 없다.

## 동의 표시

준비 조건을 충족하면 기존 정책 ID·본문·버전과 필수 동의 값을 그대로 사용한다. 접힌 details를 항상 표시되는 section으로 바꾸고, 제목은 16px 이상, 본문은 16px·넉넉한 줄간격·줄바꿈으로 표시한다. 사용자에게 목적·항목·보유기간·거부 시 제한을 읽고 선택하도록 안내한다.

체크박스는 미리 선택하지 않고 기존 required/name을 유지한다. 광고 등 다른 동의를 추가하거나 개인정보 문안의 의미를 자동 요약하지 않는다. DB 본문은 React 텍스트로 렌더링하고 HTML 삽입을 사용하지 않는다.

## 검증

실제 컴포넌트의 미준비/승인 문안/메일 미준비/로그인 상태 렌더링을 확인한다. 임시 합성 문안은 메모리에만 사용하며 DB에 등록하지 않는다. 수정 파일 lint, 기존 빌드 환경에 대한 Next.js 빌드, 배포된 가입 준비 안내와 입력란 부재를 확인한다. 저위험 표시 변경에 대한 별도 영구 테스트 파일은 추가하지 않는다.

같은 코드를 Preview·운영에 배포하고 버전·상태를 확인한다. 기관 문안과 실제 관리자 설정의 미완료 상태는 유지한다.
