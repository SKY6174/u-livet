# 운영사진 8장 출력 설계

2026-09-23 · anchor-operation-photo-eight-grid

결과보고서의 운영성과 본문은 사진 1~4를 유지한다. 사진이 7장보다 많으면 사진 5부터 별도 페이지로 보내고 `groups(..., 8)`로 나눠 각 페이지에 최대 8장을 렌더링한다. `op-photos`의 2열 그리드와 사진 셀 높이 43mm를 재사용하므로 한 페이지에 4줄이 구성된다. 사진이 5~6장인 기존 문서는 남은 1~2장을 첫 강의표 페이지 위에 배치한다.

검증은 4·6·7·8·12·20장 경계에서 첫 페이지/사진 전용 페이지/강의표 앞 사진 수를 계산하고, 빌드와 PDF 미리보기 구조를 확인한다.
