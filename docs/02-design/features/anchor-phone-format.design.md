# 휴대폰 입력 표시 설계

- `registration.ts`에 순수 표시 함수 `formatMobilePhone`을 추가한다. 010 번호는 3-4-4로 점진 표시하며 기존 011/016/017/018/019 번호도 길이에 맞게 표시한다.
- +82, 공백, 하이픈, 괄호로 입력된 번호는 국내 표시로 정리한다. 너무 긴 번호나 그 밖의 문자 입력을 임의 절삭해 유효한 다른 번호로 바꾸지 않는다.
- 공통 `PhoneField`를 Client Component로 전환하고 uncontrolled 입력을 유지한다. 입력 변경 시 숫자 기준 커서 위치를 보존하여 중간 수정 및 폼 초기화가 자연스럽게 동작한다.
- 하이픈 경계의 Backspace/Delete는 인접 숫자를 함께 삭제하도록 선택 영역을 조정하여 삭제가 막히지 않게 한다.
- 기존 required, tel, autocomplete, 미인증 안내와 서버 `normalizeMobilePhone` 검증은 유지한다.
- 검증: 입력·붙여넣기·중간 삭제의 브라우저 확인, 서버 정규화 일치/과도한 길이 거부 확인, 기존 가입 회귀 검사 및 빌드.
