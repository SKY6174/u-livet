# 수강생 홈의 내 수업 중심 상세설계

2026-09-23 · [계획](../../01-plan/features/anchor-learner-home-focus.plan.md)

## 데이터와 권한
- `/`에서 `workspaceKind(me) === "learner"`일 때만 `life_my_learning()`과 공개 과정 카탈로그를 병렬 조회한다. 다른 역할은 현재 관리·강사 데이터 경로를 그대로 사용한다. `life_my_learning()`의 인증·본인 확인을 재사용한다.
- 활성 수강이고 종료일이 아직 지나지 않은 과정만 홈의 “내 수업”에 표시한다. 신청 단계와 지난 수업은 별도 안내·`/mypage`에서 확인한다. 조회 실패는 빈 수업으로 오인하지 않는다.
- 기존 `nextClass`, `courseAttendance`, `recommendCourses` 모델을 재사용한다. 출석률은 종료된 정상 회차의 기록이 모두 입력됐을 때만 수치로 표시하고, 미입력은 확인 중으로 표시한다.
- 추천은 카탈로그에서 본인 신청·수강 과정의 기수 ID, 연결된 기수 ID, 이름 중복을 제외하고 동일 교육분야를 우선한다. 홈은 최대 8개를 표시하며 `/mypage`의 기본 3개 추천은 유지한다. 카탈로그 오류와 추천 결과 없음은 별도 상태로 표현한다.

## 화면
- 수강생 히어로는 “내 수업을 이어가세요”와 자기 수업 바로가기. 오른쪽에는 다음 수업의 날짜·시각·과정과 강의실 링크를 둔다. 수업이 없는 경우 신청 현황 또는 과정 찾기 안내를 표시한다.
- 첫 본문은 “내 수업” 카드: 과정명·강사·기간·다음 수업·출석 상태, 강의실·출석 확인·강사에게 질문 링크. 카드는 활성 수강 과정에만 표시한다. 신청만 한 경우 신청 현황으로 안내한다.
- 그 아래 “다른 과정 추천”은 작은 고정 너비 카드의 가로 스크롤 레일이다. 스크롤 스냅, 터치/트랙패드, 명시적 이전·다음 버튼을 제공한다. 카드에는 분야·과정명·짧은 소개·운영 방식·과정 정보 링크를 표시한다. 추천 이유는 같은 분야일 때만 설명한다.
- 모바일에서도 본문 폭을 넘기지 않고 레일 내부만 가로로 이동한다. 버튼·링크는 키보드로 접근할 수 있고 각 이동 버튼은 명확한 접근성 이름을 가진다.

## 검증
- 합성 신원으로 역할별 조회 분리, 활성/신청만/빈/실패 상태, 내 강의실·질문·출석 링크를 검증한다. 추천 중복 제외와 동일 분야 우선, 수평 레일의 카드 수와 내비게이션을 확인한다.
- TypeScript·ESLint·production build 후 Preview 배포 검사, PR 병합, main/preview 동기화와 두 배포의 revision·health를 확인한다.
