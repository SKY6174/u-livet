- 대상: `src/components/common/Footer.tsx` 공통 Footer.
- 배경과 상단 테두리: 첨부 아이콘의 주 색상 `#105e59`.

- 기존 폭·간격·모바일 줄바꿈·링크 목적지·인쇄 시 숨김 동작은 유지한다.
- 확인: 실제 브라우저의 계산된 배경색과 글자 대비, 390px/1440px 레이아웃, ESLint 및 빌드.
