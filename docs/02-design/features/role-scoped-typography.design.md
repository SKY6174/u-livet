# 역할별 화면 글자 크기 설계

계획: `docs/01-plan/features/role-scoped-typography.plan.md`

- 루트 레이아웃에서 기존 `workspaceKind`와 강사 구성원 구분으로 계정을 사업단·강사·수강생으로 판정한다. 비로그인은 수강생용 크기를 적용한다. 다중 역할은 기존 탐색 메뉴와 같이 사업단 우선, 다음 강사, 마지막 수강생으로 판정한다.
- 본문과 Tailwind `text-xs`~`text-6xl`, 공통 제목과 문의처에 공통 `--type-adjust`를 사용한다. 사업단·강사는 0px이며 확대 이전의 본문 18px, `text-sm` 16px, `text-base` 18px을 복원한다. 수강생·비로그인은 1.25px을 더한다.
- 공통 표는 각 역할의 글자 토큰보다 1.5px 작게 유지한다. 고정된 로고·인쇄 양식은 확대하지 않는다.
- 로그인 뒤 역할이 바뀌면 레이아웃이 새 세션 신원을 받아 동일한 규칙을 적용한다. 서버 권한 검사나 데이터 흐름은 변경하지 않는다.
