# 사업단 메뉴·업무 홈 개선 설계

> Date: 2026-09-21 | Status: Approved by user request

이번 변경의 상세 설계는 [사업단 메뉴 설계 v2.0.0](./anchor-business-menu.design.md)을 따른다.

- 공통 헤더에서 직접 이동 링크와 펼침 버튼을 분리한다.
- 이름 목록과 오른쪽 설명 패널은 호버·키보드 포커스로 연동한다.
- `OfficeNav`와 해당 layout 참조를 제거하고 인증/권한 gate는 보존한다.
- `/admin`은 안내 문구 없는 제목, 전체 너비의 과정 운영 강조 카드, 1/2/3열 업무 카드로 구성한다.
- 역할별 링크와 legacy redirect는 기존 회귀 검증을 유지한다.
- 인증 없는 로컬 브라우저 검증은 실제 컴포넌트와 합성 identity를 묶은 별도 fixture에서 수행한다. 배포 경로에 인증 우회 코드를 추가하지 않는다.

## 2026-09-22 포커스 경고 수정

- 하위 링크 선택 시 포커스가 패널 내부에 남아 있다면 펼침 버튼으로 먼저 옮기고 패널을 닫는다. Escape도 펼침 버튼으로 돌아간다.
- 닫힌 패널은 `aria-hidden` 대신 `inert`와 기존 시각적 숨김을 함께 사용해 포커스와 접근성 트리에서 제외한다.
- Tab으로 이미 외부에 옮겨진 포커스는 되돌리지 않는다. 링크의 기본 이동과 대상 MFA 입력의 자동 포커스를 유지한다.
- 실제 React 브라우저에서 링크 선택·Escape·Tab 이탈·재열기와 MFA 자동 포커스, 콘솔 경고 재발 여부를 확인한다.
