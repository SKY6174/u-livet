# 강사 My Room 상세설계

2026-09-22 · [계획](../../01-plan/features/anchor-instructor-my-room.plan.md)

## 화면과 업무 경로
- 기존 page-shell/panel/badge/btn 스타일과 청록색 카드 디자인을 사용한다. `/instructor`는 계정 정보와 강사 업무의 단일 홈이다.
- 실제 INSTRUCTOR 권한은 상단 My Room 하나로 연결한다. `/mypage`의 강사·관리자 겸직 계정도 My Room으로 이동하되 사업단 메뉴는 유지한다. 하위 강사 이력·연락처·보안·개발·경력증명에서도 My Room 활성 표시를 유지한다.
- 개발 → RCC 연간 점검·배정 → 운영 준비 → 공동 홍보·개설 확인 → 수업·출결 → 이수 확인·만족도 → 강의이력·증명 순서를 안내한다. 각 단계에 기존 기능 링크를 연결한다.
- 교외 강사에게 매년 심사·이력 갱신을 안내한다. 현재 심사 시스템의 승인·유효기간은 유지하며 안내만으로 자격 승인·연간 점검 완료를 부여하지 않는다.
- 담당 강좌 카드의 상태는 DRAFT/PUBLISHED/CLOSED/ARCHIVED 및 한국 날짜 기반으로 표시한다. 수강 확정 명단에서 인원을 확인하고 최종 개설은 사업단 확인을 받도록 안내한다.
- 수료 확인은 담당 강사 전용 읽기 화면으로 현재 수료 결과·승인·재검토 여부만 제공한다. 최종 수료 승인 권한은 사업단에 유지한다.
- 만족도는 기존 승인된 조사·집계 화면으로 연결하고 강사는 수강생 설문 경로를 안내한다. 조사 개설·공식 결과 확정은 기존 담당 권한을 유지한다.
- 강의이력은 기존 실적 제출·승인 원장, 경력증명은 기존 TEACHING 신청·공식 발급 경로를 사용한다.

## QR 출석 데이터와 권한
- `life_private.qr_attendance_tokens`: 차시, SHA-256 토큰 해시, 발급 강사, 생성·만료 시각. 원문은 응답에서만 반환한다. 암호학적 난수 32바이트, 유효기간 최대 120초와 수업 종료까지, 화면은 60초마다 갱신한다.
- `life_private.qr_attendance_checkins`: 차시+본인 유일, 최초 확인 시각. QR은 입실 증빙으로 저장하고 `life_attendance.credited_minutes`를 자동 부여하지 않는다.
- 공개 RPC는 security invoker, 비공개 함수는 고정 search_path와 인증·기관·현재 배정·현재 수강 검증을 사용한다. 테이블은 RLS 및 직접 접근 권한 회수.
- 발급/중지는 담당 강사만 가능하다. 차시는 SCHEDULED이고 현재 진행 중이며 학사자료가 마감되지 않아야 한다. 수강생 확인 시 토큰의 차시/강좌/만료/발급자 현재 배정도 다시 확인한다.
- 반복 확인은 최초 시각을 반환하고 기존 확정 출결을 덮어쓰지 않는다. 교사 자신의 수강 출석은 거부한다.
- 강사는 명시적 시작 버튼으로 QR을 발급하고, 중지 버튼으로 해당 차시 QR을 폐기한다. 네트워크 실패·만료 시 QR을 숨기고 실패 안내를 표시한다.
- 로그인 복귀 URL은 강좌·차시·토큰을 보존한다. GET 렌더링에는 쓰기가 없으며 본인 확인 버튼의 Server Action POST로만 기록한다. 오류가 있거나 응답 형태가 잘못되면 성공하지 않는다.
- 전용 읽기 RPC는 담당 강사에게 해당 강좌의 증빙만, 수강생에게 본인 증빙만 제공한다. 기존 출석부에서 입실 시각을 함께 표시하여 종료 후 실제 인정시간을 입력·확정한다. DB 미배포 시 준비 안내로 안전하게 실패한다.

## 검증과 배포
- QR DB 검증: 비로그인·비배정·배정만료·비수강·탈퇴·본인강사·시간 외·휴강·위조·다른 강좌·만료·중지 거부, 중복 멱등, 읽기 범위, 실제 출석부 연결.
- Server Action 검증: 입력·인증·RPC 실패·예외·응답·캐시 갱신, GET 쓰기 없음. 기존 메뉴·출석·증명 회귀 및 lint/build.
- 데스크톱/모바일에서 QR·내 정보·운영 링크를 확인한다. 출석 토큰은 화면에만 표시하고 로그에 쓰지 않는다.
- 새 migration과 소스를 커밋하고 원격 브랜치에 push한다. 실제 적용한 환경과 미적용 환경을 결과에 명시한다.
- Supabase 2026-09-22 changelog 확인: 현 RPC/Postgres 사용에 해당하는 변경 없음. 콘솔 chext 확장 오류는 앱에서 억제하지 않는다.
