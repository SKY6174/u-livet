# 동의서 원본 여백 보존 설계

기존 `anchor-instructor-consent-forms` 설계의 공통 PDF 생성 경로를 유지한다.

- 세 원본은 595 × 842pt 페이지. 재작성하는 양식도 동일한 크기를 사용한다.
- 개인정보동의서: 본문 x=28.32pt, 폭=538.60pt. 원본 제목 상단 약 66.83pt, 수신처 하단 약 762.91pt에 맞춰 제목/하단 배치를 이동한다. 내용과 글자 비율을 유지하고 본문 폭을 조정한다.
- 청렴서약서: 원본 외곽선 (x=72.84, top=73.68, width=470.52, height=698.64)으로 기존 벡터 레이아웃을 사상한다. 외곽선, 내용, 입력과 서명에 동일 변환을 적용한다.
- 성범죄: 원본 페이지를 그대로 복사한다. public/Edge 템플릿의 단일 밑줄 path `m(586,4551) l(1466,4551) S`(0.12 배율)를 제거하고 PDF 1.7로 저장한다. 텍스트, 표, 페이지 좌표는 보존한다.
- 작성 중 안내는 종이 하단 여백 밖으로 출력하지 않고 각 양식의 기존 빈 본문 영역에 둔다.
- 서식 버전 2026-09-22.2. 기존 제출 기록의 PDF/버전은 수정하지 않는다.
- 검증: 원본/결과 PDF의 페이지 크기·벡터 경계·템플릿 텍스트 비교, Poppler 렌더링 육안 검사, 입력/서명 보존, TypeScript 및 production build. Edge와 Vercel 배포 후 commit 확인.
