# 강사 서류 직접 입력·공유 설계

## 화면
- `DocumentPortal`은 처음 마운트 시 로그인 문서 세션을 1회 자동 요청한다. 오류/만료/인증 해제 후에만 재시도 버튼을 표시한다.
- 강사 대장에 신분증·통장/이력서 별 제출 상태와 입력 버튼. 클릭 시 사용자 이벤트 안에서 window.open 팝업(1680×1000, 화면 크기 제한), 차단 시 같은 URL 새 탭 대안. 해당 탭으로 직접 시작한다.
- 관리 열은 이름이 붙은 접근 가능한 링크·수정·삭제 아이콘. 링크는 다이얼로그에서 무작위 주소와 6자리 PIN을 발급해 각각 표시/복사하며 만료일·이전 자격 무효화를 알린다. 실제 메시지는 자동 전송하지 않는다.
- `/instructor-documents/[code]`는 로그인 없이 성명/PIN만 요청한다. 인증 전 인물정보를 노출하지 않는다. 성공하면 기존 서류 입력 컴포넌트를 사용한다. PIN과 세션 토큰은 URL/저장소에 저장하지 않는다.
- 삭제 확인은 강사 이름과 보존 범위를 명시한다. 명단에서 제외하되 지급 기록, 기존 서류, 계정은 보존한다.

## 데이터·권한
- private `instructor_pool_removals`: 기관/인물 PK, 삭제자/시각. 대장 목록/인원은 제외, 수당 대장과 과거 상세·합계는 유지. 새 활동 등록은 중지.
- public `life_instructor_document_invites`: 기관/인물/발급자 FK, code SHA256, PIN bcrypt, 만료 7일, 철회, 실패 횟수, 15분 잠금. 직접 접근은 service_role만 허용하고 RLS 활성화.
- 기존 document_sessions에 nullable actor_user_id + invite_id 추가, 둘 중 정확히 하나 필수. 로그인 세션은 기존 JWT/현재 MFA/역할 검증을 유지하고 초대 세션은 매 요청마다 초대 만료·철회·발급자 권한·인물 활성·대장 삭제를 재검사한다.
- 발급/재발급 RPC는 로그인 COURSE_MANAGER 기관 범위와 document_access 검사. 이전 초대 철회, 원문 code/PIN은 생성 응답에만 반환. 감사 로그에는 비밀 미포함.
- PIN 검증 RPC는 service_role만 실행. 행 잠금으로 병렬 시도 집계, 5회 실패 시 15분 잠금. 실패는 예외 대신 결과 반환으로 집계를 커밋한다. 정상 PIN/이름 이후 30분 세션 발급.
- Edge `invite-auth`만 PIN 인증을 받는다. 기존 문서 동작은 session 유형에 따라 인증하며 세션에 묶인 인물만 접근한다. 클라이언트 supplied person/org로 대상 전환 불가. admin 세션/초대 관리를 guest에 허용하지 않는다.
- Edge gateway JWT 검증은 끄되 handler에서 로그인 JWT와 초대 세션을 각각 명시적으로 검증한다. 기존 익명 session action은 계속 거부된다. no-store/no-referrer 및 robots 비노출.

## 검증
기존 서류 15개/Pool 회귀 검증과 추가 초대 테스트: 기관 권한, PIN/성명 실패, 병렬 5회 잠금, 만료/재발급/발급자 권한 철회, 토큰 대상 고정, 로그아웃, 삭제 명단 제외 및 지급 보존. 실제 브라우저 팝업 자동 진입/탭/별도 링크·PIN/외부 입력/삭제 확인과 모바일 확인. 가상 로컬 자료만 사용하며 정리한다.
