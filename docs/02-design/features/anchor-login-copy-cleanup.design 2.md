# 로그인 안내 간소화 설계

- 기존 anchor-login-audiences·anchor-accessible-auth 설계의 로그인 도움말 표시를 사용자 최신 요청에 맞춰 변경한다.
- AuthForm: 사업단용 설명 패널을 삭제한다. 이메일 도움말과 역할 승인 안내는 회원가입에서만 표시한다.
- PasswordField: 로그인에서는 보기 도움말을 렌더링하지 않고 aria-describedby도 제거한다. 회원가입의 비밀번호 조건 안내와 규칙 참조는 유지한다.
- 삭제한 문구가 차지하던 여백은 빈 요소 없이 함께 제거한다. 입력 레이블, 보기/숨기기, 비밀번호 복구, 제출, 간편 로그인과 교내 강사 암호 설정 안내는 기존대로 동작한다.
- 서버 인증, 권한, 승인·동의 및 개인정보 정책은 변경하지 않는다.
- 화면 검증: 사업단·교내 강사 및 교외 강사·수강생 이메일 옵션에 네 문구가 없는지, 키보드 토글과 모바일 넘침을 확인한다. 회원가입의 보안 안내는 보존한다.
