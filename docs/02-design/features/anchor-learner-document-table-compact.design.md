# 접수 문서 표 밀도 조정 설계

## 안내 내용
- 현재 공개 안내는 한 줄에서 말줄임으로 표시한다. 전체 원문은 제목 툴팁과 접근성 텍스트로 유지한다.
- 새 안내는 한 줄 텍스트 입력칸으로 바꾼다. 기존 `form` 연결, `name="note"`, 필수값과 최대 1,000자 규칙을 유지한다.
- 저장 액션과 공개 안내 데이터 구조는 수정하지 않는다.

## 신청시각
- 원본 `submitted_at`을 한 개의 semantic `time` 요소에 둔다.
- 한국어·Asia/Seoul의 날짜와 시각을 별도 formatter로 표시하여 줄바꿈이 화면 폭과 무관하게 항상 한 번만 생기게 한다.
- 처리 이력의 기존 `documentDate` 표시는 유지한다.

## 비고
- 편집 가능한 행에는 현재 상태 표시와 ‘상태 저장’ 버튼을 2열 grid로 한 줄에 놓는다. 각 칸은 사용 가능한 너비의 절반 수준이다.
- 상태 표시는 비작동 상태 정보로 남기고, 저장 버튼만 기존 개별 행 `form`을 제출한다.
- 최소 표 너비에서도 두 4글자 레이블이 들어가도록 양쪽 패딩과 글꼴을 조정한다. 처리 이력은 다음 줄에 둔다.
- 종결된 행에는 저장 폼 없이 상태와 이력만 보인다.

## 검증
- 합성 자료에서 안내 input의 폼 소유·필수값, 날짜·시각 두 표시, 상태/저장 2열 배치를 확인한다.
- 실제 빌드 CSS로 데스크톱 및 최소 표 폭 화면을 확인하고 기존 폼 동작 회귀 검사를 수행한다.
