# 하단 ANCHOR 브랜드 설계

- 대상: `src/components/common/Footer.tsx`.
- 첨부 ANCHOR 원본의 상단 기관명은 제거한다. ANCHR 글자·하단 슬로건은 흰색이며, O를 구성하는 조타륜·닻 심벌만 약 10% 다른 색상으로 표시한다.
- 데스크톱: 왼쪽 로고, 그 오른쪽에 기관명/서비스 문구 두 줄, 맨 오른쪽에 기존 안내 링크를 배치한다.
- 로고는 약 240px 너비에서 원본 비율을 유지한다. 대체 텍스트는 `ANCHOR · 지역사회와 함께하는 든든한 버팀목`이다.
- 자산 배경은 검정, 일반 글자는 #FFFFFF, 심벌은 90% 흰색(#E6E6E6)으로 준비하고 화면에서 screen 합성을 적용한다. 청록 배경과 합성된 심벌은 약 #E7EFEE의 옅은 민트색으로 보인다. Footer의 isolate로 합성 범위를 제한한다.
- 기관명은 흰색 강조, 서비스 문구는 밝은 teal-50으로 표시한다. 하단 배경은 #105e59를 유지한다.
- 작은 화면에서는 브랜드 요소와 안내 링크를 세로로 배치해 넘침과 지나친 축소를 피한다.
- Next.js Image 사용, 로고의 상단 기관명을 중복 렌더링하지 않는다. 기존 안내 경로와 흰색 키보드 포커스 유지.
- 검증: 빌드·린트·타입, 이미지 실제 로딩, 1440px/390px/320px 표시, 문구 및 안내 링크 확인.
