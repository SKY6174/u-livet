# 결과보고서 PDF 재무·원본 서명 가져오기 설계

2026-09-22 · anchor-result-pdf-finance-signature-import

## 입력과 검증
- 브라우저 PDF.js 추출 텍스트에서 `5. 예산집행현황`의 행별 신청·집행 금액과 `8. 장학금 지원`의 인원·금액을 보수적으로 파싱한다. 원문 쪽수와 인용을 후보마다 표시한다. 불명확한 숫자는 제외한다.
- 담당자가 선택한 값만 `Budget.rows`와 장학금 필드에 적용한다. 기존 값은 자동 덮어쓰지 않고 작성 중(DRAFT)에서만 변경한다. AI 연결 상태와 관계없이 숫자 가져오기가 작동한다.
- PDF 페이지 미리보기에서 담당자가 직접 서명 영역을 지정하면 해당 크롭과 원본 쪽수·파일 ID를 `Content.sourceSignature`에 넣는다. 이를 현재 책임강사의 `Content.signature`와 명확히 구분한다. 원본 서명은 제출 게이트를 통과시키지 않는다.

## 데이터와 출력
- 결과 `Content`에 선택적 `sourceSignature: {image,page,fileId}`를 허용한다. 기존 4-key 저장본은 그대로 유효하며 신규 5-key 값도 클라이언트/DB에서 검증한다. PDF 인쇄에서 '원본 PDF 서명(참고)'로 별도 표시한다.
- 기존 3건은 원본 PDF 해시·과정·기존 초안 revision을 재검증하고, 예산/장학금만 관리 이력과 함께 덧입힌다. 실제 서명이 없는 원본에서 서명을 생성하지 않는다.
- DB의 현행 책임강사 서명/최종 제출 권한은 변경하지 않는다.
