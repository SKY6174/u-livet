# 화면 설명 말풍선·표 가독성 설계

계획: `docs/01-plan/features/transient-page-help-compact-tables.plan.md` · 2026-10-10

## 일시적 제목 안내

- `PageIntro`는 서버 컴포넌트로 두고, 설명 `children`이 있을 때 제목 오른쪽에 정보 버튼과 작은 클라이언트 컴포넌트 `PageDescriptionHint`를 배치한다. 제목 아래 설명 블록은 제거한다.
- 새 컴포넌트는 경로 진입 후 한 차례 말풍선을 열고 약 7초 후 닫는다. 경로가 바뀌면 다시 한 번 표시한다. 버튼으로 다시 열고 닫을 수 있으며 Escape로 닫는다. 마우스가 말풍선 위에 있거나 초점이 안에 있으면 자동 닫힘을 잠시 멈춘다.
- 버튼은 `aria-expanded`, `aria-controls`, 명시적 안내 이름을 갖는다. 말풍선은 텍스트가 길어도 스크롤 가능하며 좁은 화면에서는 뷰포트 너비 이내로 표시한다. 닫힌 뒤에는 레이아웃 공간을 차지하지 않는다.
- `/admin/learner-documents`의 `접수 문서` 아래 긴 설명은 `PageIntro`의 말풍선 내용에 합친다. 목록 접근성 설명은 시각적으로 숨긴 원문으로 유지한다. 처리 결과·오류·실제 업무 안내는 숨기지 않는다.
- 공통 제목을 쓰지 않던 과정 계획 현황·개설 준비·운영절차 화면의 비필수 제목 설명도 `PageIntro`로 전환한다. 로그인·가입·오류 페이지의 수행 지침은 사용자 행동에 필요하므로 계속 표시한다.

## 표와 버튼

- 인쇄물을 제외한 `#main table`의 기본 상속 글자 크기를 1.5px 낮춘다. Tailwind `text-xs`, `text-sm`, `text-base`, `text-lg`, `text-xl`, `text-2xl`, `text-3xl`이 테이블 및 후손에 지정된 경우 해당 기준 크기에서 1.5px 낮추는 공통 CSS를 추가한다. 특수 고정 크기·인쇄 서식은 유지한다.
- 표의 버튼형 링크·버튼은 한 줄로 표시한다. 일반 화면의 주요 버튼은 640px 이상에서 한 줄을 우선하고, 작은 화면에서는 필요한 줄바꿈을 허용한다. 기존 가로 스크롤 표의 스크롤 영역은 유지한다.
- 접수 문서 표의 `신청서` 링크에는 명시적으로 `whitespace-nowrap`를 적용한다. 기존 링크 문구·아이콘·접근성 이름은 보존한다.

## 검증

- 방문 직후 말풍선 노출 → 시간 경과 후 사라짐 → 정보 버튼으로 다시 열림 → Escape 닫힘을 브라우저에서 확인한다.
- 360/720/1440px에서 표 글자 계산 크기와 `신청서` 한 줄, 본문 가로 넘침을 확인한다. lint, 타입 검사, 빌드 및 운영 `/api/version` 확인.
