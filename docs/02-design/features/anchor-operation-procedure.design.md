# 평생직업교육 운영절차 화면 설계

## 경로와 내비게이션
- `/operation-procedure`에 공개 Server Component 페이지를 추가하고 제목·설명 metadata를 제공한다.
- `src/lib/auth/workspace-navigation.ts`의 `primaryLinks`에서 `/about`과 `/terms` 사이에 ‘운영절차’를 추가한다.
- 기존 Header의 데스크톱·모바일 표시와 `primaryActive`의 `aria-current`를 그대로 사용한다.
- 데이터 조회, 인증 요구, 새로운 API와 클라이언트 상태를 추가하지 않는다.

## 정보 구조와 원문 반영
1. 제목 ‘평생직업교육 운영절차’, 기획부터 결과보고·정산까지 안내하는 짧은 소개와 섹션 바로가기.
2. 운영 개요: 내부는 전 학과 공문·교수진 계획 회신·5월~12월 정기 운영, 외부는 공문 없이 필요에 따른 강사 섭외·협의·수시/상시 개설. 두 유형 모두 심의 후 확정.
3. 내부 5단계: 공문 안내 → 계획서 회신 → 심의위원회 → 홍보·운영 → 결과보고·정산. 과정 책임 교원의 유관기관·네트워크 연계 홍보 협조 문구 포함.
4. 외부 5단계: 수요 파악·섭외 → 계획서 작성 → 심의위원회 → 홍보·운영 → 결과보고·정산. 직업 동향·산업체 요구를 반영한 수요 기반 운영 안내.
5. 모집 미달: 1차 홍보·모집 후 적정 인원 충족 시 개강. 최소인원 미달 시 교수/강사와 일정 조율·재홍보. 최대 3회 조율 후에도 미달이면 최종 폐강. 행정력·예산·시설 운영 효율 설명.
6. 결과보고·정산: 종료·출결 확인 및 수료 기준에 따른 이수 처리 → 운영 성과·만족도 조사·총 지출 내역을 담은 결과보고서 제출 → 승인 후 강사료 및 수료생 대상 장학금 지급 수속. 내부·외부 모두 결과보고 완료 건에 한해 진행.
7. 관련 링크: 수강안내 및 교육과정 소개.

## 표현과 접근성
- 기존 page-shell, 남색·청록 브랜드, 흰색 패널과 16px 본문을 사용한다. 내부는 남색, 외부는 청록색과 명시적인 텍스트로 구분한다.
- 운영 비교는 두 개의 설명 목록, 절차는 의미 있는 ordered list로 표현한다.
- 넓은 화면에서 각 절차를 5열로 표시하고 모바일·태블릿에서는 세로로 순서대로 표시한다.
- 모집 기준은 3단계 세로 흐름, 정산은 3열(모바일 1열). 모든 콘텐츠는 접힘 없이 읽을 수 있다.
- 장식 아이콘은 aria-hidden, 섹션 제목은 aria-labelledby, 바로가기는 sticky header를 고려한 scroll margin을 제공한다.
- 사진과 외부 사진 URL은 게시하지 않고 원문 내용을 텍스트로 재구성한다. 미제공 인원·수료율·금액·지급일은 추정하지 않는다.
