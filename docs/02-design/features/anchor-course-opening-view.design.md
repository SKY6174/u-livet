# 운영계획서 기반 개설 준비 화면 설계

> Feature: anchor-course-opening-view · 2026-09-19
> [계획](../../01-plan/features/anchor-course-opening-view.plan.md)

## 경로와 자료 흐름

- `/admin/course-plan/opening`에 Server Component 페이지를 추가한다. 기존 현황표 경로는 유지한다.
- 관리자 메뉴와 기존 현황 화면에서 새 화면으로 이동한다. 대응 과정은 기존 현황 카드 앵커로 연결한다.
- `src/lib/course-opening/server.ts`만 `docs/operations/2026-course-opening-plans.json`을 값으로 import한다.
- loader는 `server-only`, `requireIdentity`와 COURSE_MANAGER를 확인한다. 기존 관리자 layout/세션의 MFA 경계를 이용한다.
- JSON의 타입은 type-only import로 추론하여 중복 데이터와 타입 단언을 줄인다. UI와 필터는 원천을 값으로 import하지 않는다.
- 원문 PDF/로컬 경로를 제공하는 공개 endpoint나 다운로드를 추가하지 않는다.

## 필터

GET 폼은 기존 `normalizeFilters`의 q(100자), academy(4개), affiliation allowlist를 재사용한다.
교내/교외는 강사와 보조강사만 대상으로 하며, 담당교수·보조인력은 소속 필터에 넣지 않는다.
검색은 과정명·교육내용·대상·기관·장소·담당교수·강사·보조인력·자격정보를 포함하고 한글 NFC로 정규화한다.
`coverage`는 빈 값/`additional`/`matched`만 허용한다. 배열이나 알 수 없는 값은 기본값으로 되돌린다.

## 화면

1. 계획서 기준 16개·244명·541시간 및 4개 아카데미 집계.
2. 기존 현황 대응 13개, 추가 자료 3개, 계획서 없는 재활운동지도사 1개를 구별한다. 합집합 17개를 개설 총계로 표시하지 않는다.
3. 공통 미확정 항목: 실제 개설 여부, 모집기간, 지원자격/증빙/우선순위, 선발, 최종 비용/납부/환불, 출석/성적, 정책 승인.
4. 각 카드에 아카데미·대응 여부·제목·요약·계획 기간·정원/시수·담당교수와 확인 사항 수를 표시한다.
5. native details에 교육내용, 계획상 대상/기관, 일정표의 원문 날짜/시수, 인력별 소속/시간, 수강료 산식과 불일치, 자격 원문, 확인 사항, 원본 파일명·물리 쪽수를 표시한다.
6. 미확정 수강료를 최종 비용처럼 강조하지 않으며 금액의 0/미정/예시를 혼동하지 않는다. 보조강사 묶음의 시수는 인시 합계임을 알린다.
7. 빈 검색 결과와 스마트테크 자료 미제공 상태를 안내한다. label/summary/제목 구조를 사용하고 모바일에서 긴 제목·원본 파일명이 줄바꿈되도록 한다.

## 검증과 범위

- 데이터 합계·자료 대응·원문 쪽수·강사 시수와 미확정 상태를 검사한다.
- P05 월 불일치, P08 원문 2025년, P10 2,225,000/2,250,000원, P11 42/48시간 차이를 그대로 렌더링하는지 검사한다.
- 결합 필터, 보조강사 소속 포함/담당교수·보조인력 제외, 악성/배열 입력, 검색 결과 없음, React 문자열 escape를 검사한다.
- loader를 미인증·MFA 미완료·권한 없음·COURSE_MANAGER 스텁으로 실행하여 경계 동작을 확인한다. 이는 실사용자의 인증 성공 검증을 대신하지 않는다.
- 기존 과정 현황 회귀 검사, lint, 앱 build, 모바일/데스크톱 렌더링을 확인한다.
- DB write, 공개 모집, 정책 승인, 담당자 권한 연결, Production 배포는 수행하지 않는다.
