# 앵커사업 홈페이지·기본 LMS 화면명세

버전 1.0 · 2026-09-18 · 상위 기준: [상세설계](/Users/thomas/Documents/uc-life/docs/02-design/features/anchor-lifelong-education-platform.design.md)

## 1. 공통 화면 규칙

- 영문 소제목·메뉴 라벨의 자간은 공통 디자인 토큰 `tracking-label`(0.05em)을 사용한다. 기존 넓은 자간 0.1em의 50%이며, 좁은 보조 라벨은 `tracking-label-compact`(0.025em)를 사용한다. 새 화면은 `PageIntro` 또는 `.eyebrow`로 구성해 이 규칙을 상속한다. 글꼴·크기·굵기를 유지하고 `tracking-widest` 등으로 개별 재정의하지 않는다. 인증번호 입력처럼 기능상 구분이 필요한 표시는 별도다.

- 공개영역 상단: 교육과정 / 수강안내 / 학습·경력지원 / 사업소개 / 소통마당 / 나의 공간.
- 로그인 후 실제 부여된 역할만 전환 가능. 현재 기관·역할을 명확히 표시하되 전환 자체로 새 권한을 부여하지 않음.
- PC는 좌측 업무 메뉴+본문, 모바일은 ‘홈·과정·강의실·내 이력·더보기’ 중심. 관리표는 핵심 컬럼 카드와 상세 펼침 제공.
- 모든 목록: 검색·필터 초기화, 페이지네이션, 건수, 데이터 기준시각, 빈 목록, 조회실패·재시도, 권한 없음 상태.
- 모든 작성: 필수/선택 구분, 저장 중/저장됨, 임시저장, 입력값 유지, 필드별 오류, 제출 전 요약, 완료번호. 서버 성공 확인 전에 완료를 표시하지 않음.
- 공동 편집·승인: 마지막 수정자·시각, revision 충돌 안내, 최신값 재조회. 강제 덮어쓰기는 제공하지 않음.
- 주요 변경: 대상·사유·영향·처리기한을 확인하고 완료 이력을 남김. 보류·실패·재처리 상태를 성공과 구분.
- 모바일 기본 본문 16px 이상을 제안하며 확대·키보드·화면낭독·자막·명확한 오류 초점을 검수. 색상만으로 상태를 구분하지 않음.
- 로그인 중단 후 원래 신청·과제로 복귀하며 입력 복원 여부를 안내. 공용 기기에서 개인정보를 지속 브라우저 저장하지 않음.

## 6. 핵심 화면 상세

### 6.1 L02 수강신청: 4단계

1. 과정 확인: 기수·일정·비용·이수·환불 조건과 현재 신청가능 상태.
2. 정보·자격: 본인 기본정보 확인, 해당 과정에 필요한 자격 답변·증빙만 입력.
3. 안내·동의: 처리 근거 안내, 필요한 동의, 별도 선택동의와 버전.
4. 최종 확인·제출: 금액·일정·동의 요약, 신청번호·대기/선발/납부기한 안내.

| 필드 | 필수 조건 | 검증·권한 |
|---|---|---|
| 성명·인증된 연락수단 | 기본 | 본인 프로필에서 읽기; 변경은 인증·정정 흐름 |
| 연령·거주구군·재직 상태 | 자격·보고에 필요한 과정만 | 목적·보유기간을 먼저 확정, 상세주소·전체 생년월일은 필요성 확인 |
| 자격증빙 | 증빙 요구 과정만 | 본인 소유 fileId, 허용 형식·크기·검사완료 |
| 지원동기 | 심사기준에 포함한 과정만 | 글자수 제한, 자유서술 개인정보 입력 최소화 안내 |
| 선택동의 | 항상 선택 | 기본 미선택, 거부로 기본 수강 제한 없음 |
| 비용·선발·수료·환불 정책 버전 | 시스템 필수 | 서버가 유효 버전을 고정; 제출 중 변경되면 요약 재확인 |

저장 중 중복 클릭, 모집 종료, 정책 변경, 정원 초과, 이미 신청, 인증 만료를 각각 구분한다. 정원 충돌이면 기존 내용을 유지한 채 대기 신청 결과 또는 다음 행동을 안내한다. 대리접수에는 접수자·경로·본인확인·동의 근거가 추가된다.

### 6.2 L04 강의실

상단은 과정·기간·수료조건·다음 일정, 좌측/모바일 탭은 차시, 중앙은 학습내용, 하단은 과제·질문이다. ‘진도 70%’와 ‘출석 미확정’을 동시에 표시할 수 있어야 한다. 학생에게 공개하는 성적은 강사가 공개 확정한 결과만 제공한다.

| 탭 | 주요 필드·행동 | 필요한 상태 |
|---|---|---|
| 차시·영상 | 차시명, 인정시간, 학습기간, 재생·이어보기, 자막, 다운로드 허용 여부 | 준비중·공개예정·학습중·완료·권한만료·동기화 대기 |
| 자료 | 파일명·크기·권리·수정일, 미리보기/다운로드 | 검사중·이용가능·회수 |
| 출석 | 일정·방법·인정분·상태·근거 요약, QR·정정요청 | 예정·미확인·출석·지각·공결·결석 |
| 과제 | 설명·마감·배점·rubric·제출형식, 파일/답변 저장·제출·재제출 | 미제출·임시저장·제출·지각·보완·채점중·공개성적 |
| 퀴즈 | 응시기간·시간제한·시도횟수·채점·공개방식, 시작·저장·제출 | 시작전·진행·서버마감·채점대기·결과공개 |
| 질문 | 공개/강사만 공개 선택, 제목·내용·첨부·답변 | 작성·답변대기·답변완료·신고 |
| 수료현황 | 출석·필수평가 충족, 누락·미채점, 수료확정 결과 | 충족·미충족·확인필요·확정·정정중 |

영상 재생 오류는 학습완료로 전환하지 않는다. 업로드·제출 실패 시 재시도 가능한 파일·입력을 유지하되 개인정보 파일의 임시보관 만료를 적용한다. 시간제한 퀴즈는 클라이언트 카운트다운 외에 서버 마감을 표시한다.

### 6.3 I03 과정 개발·개편

기본정보 → 수요·목표역량 → 모듈·차시 → 강사·시설·기자재 → 비용 → 수료·평가 → 제출 순서다. 새 과정과 기존 과정 개편을 구분하고 개편 사유·비교표를 제공한다. 필수: 소유기관·아카데미·과정명·대상·목표·시간·차시·수료기준. 평가 가중치는 해당 평가방식의 총합과 맞아야 하며 평가면제는 근거가 필요하다. 승인된 버전은 읽기 전용, 수정은 ‘개편안 만들기’로 시작한다.

### 6.4 A04 개설·모집

과정 버전, 사업연도, 기수명, 모집/교육 기간, 시간표, 정원, 최소개강인원, 교육방식, 교육장, 강사, 수강료·별도비용, 선발·환불정책을 입력한다. 모집기간·시간표 순서, 시설·강사 중복, 승인되지 않은 버전, 수료/환불정책 누락을 검증한다. 강사·시설 중복 예외에는 사유·승인을 요구한다. 공개 전 수강생 화면 미리보기를 제공한다.

### 6.5 A07 입금대사·환불

입금대사 화면은 미확인 거래와 청구를 나란히 보여준다. 계좌·입금자·금액·거래일·참조번호·배분잔액·수강생·기수로 확인하며 자동 추천은 담당자가 확정한다. 일괄업로드는 미리보기·오류행·중복거래를 먼저 확인한다.

환불 상세에는 요청자·사유·요청시각·적용정책·계산표·기환불·승인예약·환불가능액·계좌확인·승인/지급 이력을 표시한다. 버튼은 산출·보완요청·반려·승인·지급확인·대사로 분리한다. 지급 여부 불명 시 ‘다시 송금’ 대신 ‘거래 확인’을 제시한다. 계좌 열람에는 별도 권한과 기록이 필요하다.

### 6.6 A08 수료판정

행: 수강생. 열: 대상시간·인정시간·출석률·필수평가·최종점수·미채점·설문조건·판정·확정상태. 각 수치를 클릭하면 근거 자료를 본다. 일괄 산출은 batch ID와 기준 revision을 생성한다. 확정 전 변경된 행은 제외하고 재산출한다. 일괄 확정에는 대상·제외·실패 건수를 보여주며 실패행까지 성공으로 표시하지 않는다.

### 6.7 A09 증명·강의경력

문서종류, 대상, 근거 수료/강의실적, 발급기관·권자·직인, 발급일, 서식 버전을 보여준다. 경력증명은 기간별 실제 확정시간을 합산하고 공동강의의 중복시간을 검토한다. 미확정 실적은 제외 사유를 표시한다. PDF 미리보기 → 승인 → 생성 → 다운로드이며 서식만 미리본 단계는 발급완료가 아니다. 취소·정정 시 사유, 대체문서, 배지 영향, 본인 안내를 함께 기록한다.

### 6.8 A10 문자

운영/홍보 선택 → 담당범위 내 대상 조건 → 템플릿·예약시각 → 예상 건수·발송비·표본 → 발송 순서다. 예외 제외 대상과 이유를 집계하되 불필요한 개인정보를 노출하지 않는다. 기수안내, 입금·수강확정, 일정변경, 환불, 수료 등 운영 유형을 코드화한다. 홍보는 발송 직전에도 동의 상태를 확인한다.

### 6.9 A12 연차평가·공식 보고

사업연도·기관·아카데미·지표버전을 선택한다. 각 지표에 목표·현재값·분자·분모·기준일·자료원·미확인건·증빙완성도를 표시한다. 공식 지표와 운영 참고통계를 구분한다. 과정 개발건수와 기수 개설건수, 실인원과 수강건수를 서로 다른 항목으로 표시한다. 취업조사 미응답은 미취업으로 합산하지 않는다. D06 미확정 항목은 ‘집계 기준 확인 필요’로 표시하고 보고 확정에서 제외 또는 차단한다.

### 6.10 L08·A14 개인정보

수강생은 목적별 현재 동의와 당시 문안을 보고 선택동의를 철회한다. 탈퇴 전 진행 중 환불·발급 요청, 탈퇴 후 보존할 최소기록·근거·기간을 안내한다. 사업단은 요청종류·접수일·담당자·기한·본인확인·처리결과만 필요한 범위에서 관리한다. 파기 작업에는 원자료·파일·연계처·백업 순환 처리 결과를 기록한다. 보존기간이 비어 있는 정책은 실제 수집 화면에 게시하지 않는다.
