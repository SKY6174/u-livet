# 관리자 과정 등록·수정 설계

2026-10-08 · [계획](../../01-plan/features/admin-development-authoring.plan.md)

## 화면
- 관리자 개발·심의 목록에 신규 등록/기존 과정 수정 양식을 제공한다. 수정은 같은 기관의 기존 과정을 고른 `REVISION` 제안으로 시작한다.
- 관리자 개발·심의 목록에는 실제 운영 과정의 `+ 과정 등록`과 등록 과정 관리 진입도 제공한다. 심의안 초안 작성과 실제 과정 개설의 차이를 화면 문구로 구분한다.
- 운영 관리 카드의 과정 안내 수정 링크는 해당 가이드 편집 화면으로 연결한다.
- 사업연도와 담당 구분은 현재 필터를 기본값으로 사용한다. 초안 생성 직후 기존 상세 편집기로 이동한다.
- 관리자 목록에는 제출된 제안과 **본인 미제출 초안만** 보인다. 본인 초안 카드에는 수정 진입을 명시한다.
- 상세의 저장·심의 제출·후속 버전 작성은 기존 양식과 상태 전이를 재사용한다. 제출·승인본은 불변이며 작성자 본인 승인은 금지한다.
- 관리자 요약의 불필요한 회색 안내 상자는 제거한다.
- `/admin/courses`의 접힌 등록 양식 제목과 목록 상단 진입을 `+ 과정 등록`으로 통일하고 눈에 띄는 버튼 스타일을 적용한다.

## 데이터·권한
- `id_proposer`는 활성 사용자에게 해당 기관의 유효한 `COURSE_MANAGER` 역할이 있으면 제안 작성 자격을 부여한다. 역할은 대상 `person_id` 기준으로 확인하고, 화면 조건만 신뢰하지 않는다.
- 기존 시작/저장/제출 RPC의 본인·기관·역할·정책·revision 검사를 유지한다.
- 분류별 관리자 목록에서 본인 초안만 제출 전 표시한다. 타인의 초안은 상세 RPC에서도 계속 차단한다.
- 관리자 작성 제안도 심의 제출 후 다른 과정담당자가 승인해야 과정 버전으로 확정된다.
- 운영 현황의 `life_course_budget_overview`는 `life_course_guides.org_id = 요청 기관`인 가이드만 반환한다. 예산 저장도 해당 기관 소속 가이드로 제한한다. 기존 앵커사업단 가이드의 소속 데이터는 유지한다.

## 검증
- 관리자 전용 신규/개편 제안, 본인 초안 조회·저장, 타인 초안 비공개, 비관리자 및 다른 기관 거부, 자기 승인 거부를 확인한다.
- 기존 강사 작성과 심의 흐름을 회귀 확인한다.
