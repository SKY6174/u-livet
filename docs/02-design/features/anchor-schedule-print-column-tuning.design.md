# 강의 일정 출력 열 미세조정 설계

2026-09-23 · anchor-schedule-print-column-tuning

## 열 너비

- 결과보고서: `5 / 18 / 31 / 8 / 6 / 8 / 6 / 18`.
- 운영계획서: `5 / 15 / 24.5 / 8 / 6 / 8 / 6 / 11.5 / 7 / 9`.
- 회차 열은 1%p 확대하고 `white-space: nowrap`을 적용한다.
- 주제 열은 결과보고서 2%p, 운영계획서 1.5%p 확대한다.
- 확보 폭은 일자와 교육장소에서 줄인다.

## 괄호 설명

출력 전용 `splitScheduleTopic()`이 주제 끝의 `공백 + (괄호 설명)`을 본문과 분리한다. 괄호 설명은 새 줄의 별도 span으로 렌더링하고 한 줄 표시를 우선한다. 괄호가 주제명에 붙어 있거나 끝에 없으면 원문을 분리하지 않는다.

## 검증

- 공백 뒤 괄호, 붙어 있는 괄호, 괄호 없는 주제를 단위 검증한다.
- 브라우저에서 회차 머리글 한 줄, 주제 설명 줄 분리, 셀 오버플로 부재를 확인한다.
- 기존 운영문서 회귀 검사, 린트와 production build를 실행한다.
