# 강사 강의날인부·QR 확정 출석부 설계

2026-09-22 · [계획](../../01-plan/features/anchor-signed-teaching-attendance.plan.md)

## 데이터 및 권한
- `life_teaching_logs`에 `segments` JSON 배열(`starts_at`,`ends_at`), `signature` 이미지 data URL, `signed_at`, `signed_revision`을 추가한다. 각 구간은 수업 안에 있고 서로 겹치지 않으며 합계가 제출 강의분과 일치해야 한다. 기존 로그는 빈 구간/서명으로 남긴다.
- 강사의 새 `life_submit_teaching_detail` RPC는 기존 제출 검증·revision·감사를 재사용하고 구간을 저장한다. revision이 바뀌는 모든 경로에서 트리거가 이전 구간/서명을 지운다.
- `life_sign_teaching` RPC는 본인 로그, 최신 revision, 종료된 담당 수업만 서명할 수 있다. PNG/JPEG magic bytes와 크기를 확인하고 감사 이벤트를 남긴다. 재서명은 가능하지만 타인 서명은 불가하다.
- 관리자 결과보고서 RPC의 강의실적에는 위 필드가 포함되므로 최종 날인부는 승인된 최신 revision과 유효한 서명만 출력한다. 강사별 교육시간 표도 같은 레코드를 쓴다.
- 출석부 읽기 RPC는 유효한 담당 강사와 운영 담당자에게만 과정 전체 명단·출결을 반환한다. QR 확인 읽기도 같은 권한으로 확장한다. 출력 화면은 서버에서 역할을 다시 확인한다.

## 화면과 인쇄
- `/instructor/records`에서 강사는 실제 강의시간 구간을 입력·수정한 뒤 별도로 캔버스 서명을 제출한다. 구간 변경 시 다시 서명한다. 구간 시작·종료는 한국 시간으로 입력한다.
- 결과보고서 강의날인부: 실제 구간을 시작 순으로 정렬하고 한국시간 12:00에 걸친 구간은 오전/오후로 나눈다. 같은 날짜의 연속 두 강의 구간 사이 공백이 11:00~14:00에 걸치고 30분 이상이면 점심시간 행, 나머지는 휴식 행이다. 강의시간은 구간별 실제 시간이며 유효 승인·서명 이미지를 각 강의 행에 반복 표시한다. 과거 기록은 시간/서명 미등록으로 표기한다.
- 출석부: 원본의 과정 정보·회차별 표 구조를 유지하되 각 회차는 `QR 입실`과 `확정 출결` 2열을 둔다. QR 없는 출결 확정도 그대로 표시하고 QR만 있으면 미확정이라고 표시한다. 전체 회차가 4 이하일 때 세로, 5 이상일 때 가로. 긴 명단과 회차는 페이지별 분할한다.
- `@page` 지정과 PDF 1.7 다운로드 경로 모두 해당 두 양식에 20mm 여백을 적용한다. 원본에서 추출한 앵커사업단 로고를 매 페이지 왼쪽 하단에 둔다. 다른 4종 문서의 여백은 유지한다.
- 관리자 과정 결과보고서에서 두 양식으로 직접 이동하고 출력한다. 관리자용 현재 공식 결과보고서 출력에도 강의날인부를 부록으로 연결한다. 과거 제출본 재출력에는 현재 시점의 강의날인부를 섞지 않는다. 담당 강사는 출석 결과를 자신의 페이지에서 열람한다.

## 검증
- DB: 내 기록만 서명 가능, 타인/미배정/미종료/잘못된 revision 거부; 구간 겹침·범위·합계·이미지 검증; 정정 시 서명 무효화; 관리자 외 전체 QR 명단 거부.
- UI: 4/5회차 인쇄 방향 경계, 오전·점심·오후 정렬, 미확정 QR와 확정 출결 구분, 서명/로고 표시, 20mm 여백, 여러 페이지 분할.
- TypeScript/ESLint/build, 로컬 DB migration, 사용 가능한 Preview/Production 환경 반영 후 원격 브랜치 push.
