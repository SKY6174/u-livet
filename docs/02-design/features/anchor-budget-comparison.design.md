# 예산 및 집행현황 통합 설계

2026-09-21.

- OperationsDashboard의 예산/집행 탭을 BudgetPanel 하나로 합친다.
- 표의 프로그램 ID, 세부 프로그램, 수정 버튼은 rowSpan=2. 구분 열의 예산/집행 행을 다른 배경색으로 표시한다. 기존 예산 6항목과 집행 자료의 현수막, 총액을 함께 표시한다. 현수막 예산은 기존 편성 필드가 없으므로 빈값이다.
- 제목 우측 단위: 원. 이전 상단 설명 삭제. 예산 편집 폼 유지. 엑셀 자료 관리는 표 아래 접힌 details에 통합하고 ExecutionPanel을 재사용한다.
- 가장 최근 저장한 workbook을 자동 조회하며 새 파일/시트/제목행 선택 시 비교 표도 갱신한다. 저장 전 자료는 미리보기임을 표시한다. 로딩 실패/자료 미선택/미연결을 실제 0원과 구별한다.
- 양식 미확정이므로 정확히 식별 가능한 열만 읽는다: 세부 프로그램/과정명/교육과정 또는 과정 ID, 예산 6항목/현수막, 총액/합계. 프로그램 ID는 공유 코드이므로 단독 연결 금지. 과정명은 공백·구두점만 정규화하고 한 과정과 정확히 일치해야 한다. 구분 열이 있으면 집행 행만 읽고 예산/소계 행은 제외한다. 같은 과정 중복 행 또는 잘못된 금액은 확인 필요로 처리하며 임의 합산하지 않는다. 자료가 없는 값은 —. 집행 소계/총계는 연결된 과정 수를 표시한다.
- 기존 DB/RPC/권한 구조와 XLSX 저장 포맷은 유지한다.
- 검증: 16과정32행, rowSpan과 단위 위치, 탭/예산 편집/엑셀 변경 연동, 실제 0원과 빈값, 공유 ID·중복·잘못된 금액의 안전 처리, 데스크톱/모바일 스크롤, lint/typecheck/build. main/preview push 및 배포 확인.
