# 접수 문서 안내·처리이력 개선 설계

2026-10-08 · [계획](../../01-plan/features/learner-document-desk-clarity.plan.md)

## 안내 표시
- 원서의 현재 `current_note`와 연결 과정에서 계산한 `documentRegistrationMessage`를 관리자 ‘수강생 안내 내용’ 안에 순서대로 표시한다. 별도의 DB 저장이나 임의 동의·신청 생성은 하지 않는다.
- 수강생의 ‘내 서류 처리 현황’도 같은 두 문구를 한 안내 영역에서 보여준다. 신청 링크는 기존대로 유지한다.
- 과정 열에서는 원서의 과정명만 기본 표시한다. 중복된 ‘연결 과정’ 이름·기간은 삭제하고, 실제 연결과 관리 링크는 유지한다.

## 표와 이력
- 관리자 표의 ‘승인자’ 단독 열을 ‘처리 이력’으로 바꾼다. 접수 시간은 `submitted_at`, 승인 시간과 승인자는 시간순 이벤트 중 마지막 `APPROVED` 이벤트를 사용한다.
- 전체 상태 변경 이벤트는 같은 열의 접이식 상세에서 계속 열람할 수 있다. 승인 이벤트가 없으면 승인 내역을 임의 생성하지 않는다.
- 표의 최소 너비와 열 비율을 조절하여 비고·관리 열까지 한 화면에 보이게 한다. 삭제 버튼은 `whitespace-nowrap`로 아이콘·문구가 한 줄을 유지하게 한다.
- 기존 폼 ID와 필드, 원본 PDF·삭제 동작은 변경하지 않는다.
