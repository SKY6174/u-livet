# 수강생 서식 단일 창 설계

2026-09-22 · anchor-learner-document-tabs

이 설계는 기존 anchor-learner-documents의 서식별 독립 창 동작을 대체한다.

- 통합 경로 `/mypage/documents`에서 두 서식을 제공한다. `type` 검색값은 첫 선택에만 사용한다. 기존 `/application`, `/scholarship` 경로는 통합 경로로 리다이렉트한다.
- 나의 학습 진입은 하나의 `수강생 서류 작성` 버튼과 공통 창 이름 `learner-documents`를 사용한다.
- 편집기 상단에 수강신청원서 / 장학금 지급신청서 버튼을 두고 `aria-pressed`로 선택 상태를 제공한다. 클릭 시 React 상태만 전환한다.
- 입력 상태와 마지막 다운로드 상태를 서식 종류별로 보관한다. 창을 벗어날 때 어느 서식이든 다운로드 이후 변경되었다면 기존 이탈 경고를 유지한다.
- 전환 시 이전 PDF·검증 오류·안내를 지우고 선택한 서식의 PDF가 준비될 때까지 다운로드를 비활성화한다. 늦게 완료된 렌더링·서명 처리 결과를 다른 서식에 적용하지 않는다.
- 서명 패드는 서식별로 다시 마운트하되 기존 적용 서명은 해당 서식의 상태에서 표시한다. 동의나 서명은 다른 서식으로 자동 복사하지 않는다.
- PDF 템플릿과 생성기는 변경하지 않는다. 실제 전환 후 각각의 다운로드 PDF를 확인하고 모바일 및 빌드를 검사한다.
