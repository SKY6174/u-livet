# 연결 과정의 기본 정보와 복수 교육장소 — Design

2026-10-07 · linked-course-locations

## 출처 및 DB 동기화

`life_course_guides.offering_id`가 있으면 개설 과정(`life_offerings`)의 과정명·교육장소·운영방식·정원·시작/종료일을 공통 기본 정보의 기준으로 삼는다. 안내 전용 교육내용·교육시수·요일별 시간·자격증·이미지는 가이드에 남긴다. 기존 연결 행은 개설 과정 값으로 한 번 정합화한다. 개설 과정의 공통 값이 바뀌면 트리거가 연결 가이드 값을 같은 트랜잭션에서 갱신하고 가이드 revision을 높인다. 가이드의 공통 값 직접 수정은 DB에서 거부하며, 새 `offering_id` 연결 시 개설 값으로 맞춘다. 가이드 고유 값의 저장 RPC와 개설 과정의 revision/권한/마감 검사는 유지한다. 가이드 저장이 개설 과정 상태/정원/일정을 우회하지 않게 한다.

## 화면

- 관리 페이지에서 장소를 최대 3행으로 편집한다. 장소 1~3과 `+교육장소`/삭제를 제공한다. 기존 쉼표 구분 장소는 표시용 행으로 분리하되 변경 전 원문은 그대로 저장한다. 변경 후에는 줄바꿈 구분 문자열로 저장한다. 장소별 시기 설명은 각 행에 자유 입력한다. 모두 비면 저장할 수 없고, 결합 길이는 160자 이하로 제한한다.
- 안내 편집 페이지의 연결된 과정은 공통 필드를 읽기 전용으로 보여주고 `과정 기본 정보 수정` 링크를 표시한다. 개설 전 안내 과정은 기존과 같이 편집하며 같은 다중 장소 컴포넌트를 쓴다.
- 요일 버튼은 `+요일·시간`이고 기존보다 3px 작은 13px로 표시한다.
- 공개 상세 교육장소는 줄바꿈을 유지한다. 기존 단일 문자열도 그대로 표시한다.

## 구현과 검증

- 공용 `CourseLocationFields`와 문자열 정규화 helper. `OfferingEditForm`, `GuideEditForm`, 서버 액션 검증을 연결한다.
- 새 SQL migration: 초기 연결 행 정합화, 가이드 보호/연결 트리거, 개설→가이드 동기화 트리거. DB 권한을 넓히지 않는다.
- 파싱/직렬화와 저장 검증, 가이드-개설 변경 전파, 미연결 가이드 독립 저장, UI 360px 레이아웃, lint/tsc/build, Preview/운영 상태를 확인한다.
