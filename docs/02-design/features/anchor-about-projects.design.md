# 앵커사업 소개 개편 설계

## 페이지 구성

1. `앵커사업 소개` 제목과 지역의 인재·산업·일·삶을 연결한다는 짧은 소개.
2. 4개 프로젝트와 RCC센터로 이동하는 페이지 내부 링크. 고정 헤더에 가려지지 않도록 scroll margin 적용.
3. TALENT, BRIDGE, JUMP, CARE 순서의 사진 카드: 모바일 1열, 데스크톱 2열. 사진은 카드 전체 배경으로 배치하고 object-cover로 비율을 유지하며 채운다. 과도한 장식과 자동 재생은 사용하지 않는다.
4. 각 카드는 공식 사진 위에 프로젝트명, 목표 요약, 주요 과제를 겹쳐 제공한다. 설명 패널 배경은 #0b162b, 불투명도 70%로 하고 글자는 불투명하게 유지한다. 설명은 일반 문서 흐름으로 배치해 모바일에서 내용이 늘어나도 잘리지 않는다. 원본 색상은 제목·번호·강조선에 유지한다.
5. RCC센터 소개와 네 가지 역할: 지역 맞춤형 평생직업교육, 리빙랩·캡스톤 기반 지역문제 해결, 보건·복지 지원, 환경·문화와 시민참여. 공식 센터 소개 사진을 함께 표시한다.
6. U-LIFE 교육과정·수강안내 연결 및 공식 자료 출처 링크.

## 원본과 데이터

- `src/app/about/page.tsx`: 서버 컴포넌트, 정적 프로젝트/역할 배열, Next Image, lucide 아이콘 사용. 추가 클라이언트 상태·외부 스크립트·실시간 수집 없음.
- `public/images/anchor/`: 원본 JPEG 4장과 RCC PNG 1장을 변경 없이 보관. Next Image에서 반응형 최적화. 사진 출처·수집일·각 경로를 `docs/operations/anchor-about-sources.md`에 기록.
- 메인 CSS `/resources/_Templet/Main/main_rise/main_rise.css`의 `.txtBox.tp01..04 i` 기준 원본 색상: TALENT `#4DFFC2`, BRIDGE `#FFC938`, JUMP `#FF86C0`, CARE `#E5480E`.
- 프로젝트별 과제는 공식 메인 슬라이드 내용을 간결하게 정리한다. RCC는 `/rcc/CMS/Contents/Contents.do?mCode=MN021`의 주요역할 네 항목을 기준으로 한다.
- 원본 프로젝트 상세 MN027은 현재 자료 준비 중이므로 실제 내용이 확인된 메인 페이지를 출처 링크로 사용한다. 프로그램 실적·모집 상태처럼 시점에 따라 바뀌는 수치는 가져오지 않는다.
- 명시적인 이미지 대체텍스트, 제목 계층, 링크 포커스 및 키보드 탐색 유지. 비로그인 공개 페이지의 로그인 버튼 유지.
