# 동의서 입력 정렬 및 서명 설계

- 공통 renderer text helper에 글자 윤곽(Fontkit glyph bounds) 기반 centerTop 및 baselineTop 정렬을 추가한다. 글자가 폭에 맞게 축소되어도 세로 중앙을 유지한다.
- 성명 칸 y=162.48..228.96, 식별번호 228.96..283.44, 연락처 283.44..340.20pt의 중앙 사용. 외국인은 성명·영문 두 줄 전체를 같은 칸 중앙에 배치한다.
- ‘동의자’의 원본 기준선 top=499.44pt를 입력 이름에도 사용한다. 청렴서약 인적사항 칸도 글자 윤곽 기반 중앙 정렬한다.
- 서명 이미지는 기존 PNG를 보존한 채 PDF에서 0.24pt 이내 오프셋으로 Multiply 합성하여 선을 보강한다. 흰색 배경 이미지가 기존 글자를 지우지 않도록 한다. 신규 동의서 서명 패드는 4.8px 선, 기존 공용 패드 기본값 2.4px 유지.
- 여백은 한글 공식 도움말의 설명대로 위쪽 25mm + 내용 없는 머리말 10mm를 예약해 본문이 35mm에서 시작한다. 좌우/아래 10mm, 꼬리말/제본 0mm. 우선 세 동의서에 공통 적용한다.
- 개인정보/청렴 양식은 표·텍스트의 좌표와 칸 크기만 출력 영역에 맞추고 글꼴 및 서명 비율은 유지한다. 성범죄 원본 본문은 이미 해당 여백 안에 있어 기존 표 안쪽 여백과 좌표를 보존하고, 아래 여백을 침범하는 쪽번호만 위로 옮긴다. 기존 텍스트/표/밑줄 삭제 상태를 보존한다.
- 새 서식 버전 2026-09-22.3. 기존 제출본 수정 없음.
- 검증: 가상 한국인/외국인/긴 이름·서명 입력으로 PDF 생성. 셀 중심·동의자 기준선·여백 확인, Poppler 육안 검사, 서버 타입 검사 및 production build.
