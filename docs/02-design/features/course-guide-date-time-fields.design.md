# 과정 안내 날짜·요일·시간 설계

2026-10-07 · course-guide-date-time-fields

## 날짜 및 시간 변환

- course-guide/model.ts에 strict ISO 날짜 검증과 period parser/formatter를 둔다. 기존 점/대시/물결 표기와 월일 생략·연도 넘김을 지원한다. 날짜가 실제 달력에 존재하고 종료일이 시작일 이상이어야 한다.
- 같은 연도는 `2026. 10. 10. - 12. 5.`, 다른 연도는 `2026. 12. 20. - 2027. 1. 5.`로 출력한다. 하루 일정도 시작일·종료일로 입력한다.
- 요일 행은 day(월~일), startTime/endTime(HH:mm)로 구성한다. 기존 `월·수·금`, `월–목`을 각 행으로 확장한다. 여러 줄 저장 형식은 `토 14:00 - 18:00\n일 15:00 - 19:00`이다. DB의 160자 제한 안에서 최대 7행을 허용하며 시간 역전은 거부한다.
- 파싱에 실패한 기존 미확정 기간/시간은 자동으로 추정하지 않는다. 빈 새 입력칸과 기존 안내를 보여 주며 미수정 상태에서 다른 필드 저장 시 원문을 유지한다. 새 날짜/시간 입력 시 완전한 유효 값이 필요하다.

## 입력 및 공개 화면

- GuideEditForm: date 입력 2개, 요일 select와 time 입력 2개의 반복 행. 행마다 명확한 접근성 이름, 추가/삭제 버튼, 기간 미리보기를 제공한다. 모바일 360px에서 가로 넘침이 없어야 한다.
- 기존 13필드 저장 RPC, optimistic revision, 권한과 이미지 기능은 유지한다. 날짜/시간은 정규화한 period_label/time_label로 저장하므로 schema migration이 필요 없다.
- mergeCatalog와 guide 상세 조회에서 파싱 가능한 기존 기간을 새 형식으로 표시한다. guideEndDate는 동일 parser를 사용해 날짜별 노출 필터를 유지한다.
- 상세 시간은 개행을 유지해 한 요일당 한 줄로 표시한다. 원문의 미확정 안내와 일정 변경 이력은 그대로 표시한다.

## 검증

날짜/연도 넘김/윤년/역전/미확정 parser, 요일 그룹/다중 행/잘못된 시간, 기존 16개 안내 호환, 종료일 필터, 실제 Auth 편집→RPC→DB→재열기→상세 표시, 모바일 행 추가/삭제를 확인한다. 권한/revision은 기존 DB 검증을 활용한다. 카탈로그 회귀 및 lint/build 후 Preview와 main 운영 revision/health를 확인한다.
