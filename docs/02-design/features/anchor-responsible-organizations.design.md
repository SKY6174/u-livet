# 담당 기관 추가 설계

- `life_organizations`의 `uc-sanhak` 기관을 이름 `울산과학대학교 산학협력단`으로 등록한다. UUID는 DB 기본값으로 생성하고 slug 기준으로 중복을 방지한다. 기존 `uc-anchor`는 유지한다.
- 새 기관의 COURSE_MANAGER는 현재 `uc-anchor`에서 SYSTEM_ADMIN과 COURSE_MANAGER를 함께 가진 활성 회원에 한해 연결한다. 기존 두 역할의 유효기간 중 짧은 기간을 적용하고, 이미 유효한 산학협력단 관리 역할이 있으면 중복 생성하지 않는다.
- 권한 연결은 이번 등록 시점에만 수행한다. 이후 일반 관리자를 자동으로 다른 기관에 연결하지 않는다. SYSTEM_ADMIN/FINANCE/CERTIFIER/INSTRUCTOR 역할은 복제하지 않는다.
- 새 역할은 `life_audit_events`에 출처가 구분되는 이벤트로 남긴다.
- 강사 관리 페이지는 기존 `life_instructor_options`의 manager 필터를 유지하고 기관명을 한국어순 정렬하여 산학협력단, 앵커사업단 순서로 표시한다.
- 기존 옵션과 URL의 기관 ID를 그대로 사용한다. 강사·서류·지급 자료는 기관별 RPC 권한 검사를 유지한다.
- 신규 기관에 기존 강사, 개인정보 동의, 승인 정책, 과정, 지급 기록을 자동 복제하지 않는다.
- CLI로 생성한 단일 데이터 마이그레이션을 스테이징 검증 후 운영에 적용한다.
- 검증: 관리자 옵션에 정확한 두 기관, 기관별 대장 조회, 일반 회원의 관리 옵션 없음/대장 거부, 마이그레이션 재실행 시 중복 없음, lint.
