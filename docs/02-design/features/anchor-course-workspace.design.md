# 과정 통합 작업 공간 설계

2026-09-20 · anchor-course-workspace

## 화면
`/admin`은 검색·상태 필터, 과정/보고서 요약과 다음 작업을 보여준다. 신규 등록은 하단 접기 영역으로 옮기되 plan 사전 채움 진입은 펼쳐 둔다. 목록은 작업 공간으로 들어가는 하나의 기본 동선을 제공한다.

`/admin/offerings/[id]`는 운영 개요다. 같은 헤더와 현재 메뉴 표시를 운영 설정·신청(`/manage`)과 보고서(`/reports`)에서 사용한다. 교육기간·담당자·상태를 유지하고 목록으로 돌아갈 수 있다. 개요에서 신청/강사 → 출결 → 수료 → 보고서 단계를 연결한다. 관리자는 강사 입력 화면에 진입하지 않고 출결 집계를 확인한다. 수료 검토에는 과정으로 돌아가는 링크를 제공한다.

보고서는 중복 인원 카드를 제거하고 6종 자료 상태·입력 담당·보완 위치·출력을 함께 보여준다. 원본 확인사항은 접기 영역으로 정리한다. 기본정보/예산/총평/인적사항/장학금/강사료에는 고정 앵커를 부여하고 앵커 이동 시 해당 입력 영역을 펼친다. 저장된 보고서 기준 출력 안내와 편집/저장 상태를 유지한다.

## Supabase 읽기 계약
`public.life_course_workspace(f uuid default null)` → jsonb 배열. 기존 관례인 public invoker + private definer를 사용한다. private 함수는 auth.uid, 검증된 직원 MFA, 현재 활성 COURSE_MANAGER 기관을 검사한다. 특정 f가 권한 범위 밖이면 FORBIDDEN, 전체 조회는 허용된 기관만 반환한다. 고정 search_path, PUBLIC/anon/service_role 실행 회수, authenticated 최소 grant를 적용한다.

기관별 권한 검사를 CTE로 먼저 수행하고 해당 과정만 집계한다. 명시적 메타데이터와 합계만 반환한다: 상태·기간·정원·분야·사업연도, 현재 강사 수, 신청 대기 수, 활성 등록 수, 유효 수료 승인/검토 수, 예정/종료 회차·교육시간, 종료 회차의 미입력 출결, 강의실적/최신 승인 수, 보고서 revision/updated_at/담당자/기본정보 누락, 장학금/강사료 행 수·지급일 미입력 수, 업로드 문서 종류, 원본 집계 숫자. 파일 본문, 계좌, 주민번호, 개인별 명단과 판정 근거는 반환하지 않는다.

수료 유효성은 기존 completion_board와 동일하게 최신 산출, ACTIVE 등록, input_revision 및 승인 수료 정책 유효성을 확인한다. 휴강·미래 수업은 출결 미입력 경고에서 제외한다. ARCHIVED에만 원본 숫자를 사용한다. 비용 합계는 지급 확정이 아닌 저장된 기록으로 표시한다.

새 테이블이나 중복 상태 컬럼을 만들지 않는다. 기존 쓰기 RPC와 revision 충돌 검사를 재사용한다. 사용자 세션 SSR RPC를 요청마다 호출하며 모듈 전역/공유 캐시를 두지 않는다. React cache는 같은 요청의 권한 조회만 중복 제거한다. 저장·승인·업로드 후 기존 revalidatePath/router.refresh로 새 집계가 보인다. RPC 오류는 0건/완료가 아닌 조회 오류로 표시한다.

## 상태 규칙
6종 카드의 상태는 법적/행정적 제출 승인이 아니라 자료 준비 안내다. 원본 PDF 보관과 전산 입력 상태를 구분한다. 데이터 없음·미래 일정·지급 대상 없음은 추정해서 완료 처리하지 않는다. 지급은 해당 시 입력하도록 안내한다. 다음 작업은 준비 중 설정, 신청 대기, 강사 배정, 종료 수업 출결 확인, 수료 검토, 강의실적 승인, 보고서 보완 순이며 보관 과정은 원본·보고서 검토를 우선한다.

## 검증
합성 로컬 데이터로 집계 정확성, 미래/휴강 제외, 결석 0분과 미입력 구분, 유효/만료/오래된 수료 판정, 보고서·첨부 변경 반영을 검증한다. 관리자/일반 사용자/강사/타기관/익명/MFA 미완료 경계를 검사한다. 실제 브라우저에서 검색·필터·목록→개요→보고서→보완 앵커→저장→출력과 390px 화면을 확인한다. 기존 보고서 및 workspace 회귀, lint/build, 보안 Advisor를 실행한다. 로컬→Preview→운영 DB 순으로 추가 RPC만 적용하고 Git push를 수행한다.
