# 성인학습자 화면 글자·아이콘 개선 설계

계획: `docs/01-plan/features/adult-learner-typography-icons.plan.md` · 2026-10-10

## 글자 체계

- `html` 루트 16px 유지. `body` 18→20px. Tailwind `text-xs`/`text-sm` 16→18px, `text-base` 18→20px, `text-lg` 18→20px, `text-xl` 20→22px, `text-2xl` 24→26px, `text-3xl` 30→32px 등 화면용 표준 크기를 각각 2px 올린다. 줄높이는 읽기 쉽게 유지·조정한다.
- `.page-title` 모바일 30→32px·데스크톱 40→42px, `.section-title` 모바일 24→26px·데스크톱 28→30px. 인쇄용 `.report-*`와 픽셀 고정 로고 아트워크 크기는 조정하지 않는다.
- 확대에 따라 가로 공간이 부족하면 본문을 줄이는 대신 카드·버튼의 유연한 줄바꿈을 사용한다. 기존 48px 최소 조작 높이를 유지한다.
- 공통 바닥글의 별도 고정 크기 문의처 글씨도 12.5→14.5px, 제목 14.5→16.5px로 조정한다. 로고 이미지 위의 그림 속 문구는 건드리지 않는다.

## 아이콘 위치와 의미

- 공개 홈: 과정 검색 동작에는 돋보기, 모집 과정 제목에는 책, `수강신청 안내`에는 신청서, `나의 신청 확인`에는 확인 목록, `앵커사업 소개`에는 기관 아이콘을 사용한다.
- 공개 모집 과정 카드: 교육기간은 달력, 신청기간은 시계, 운영방식은 사람, 수강료는 지갑으로 나타낸다. 아이콘은 레이블 옆에 배치해 눈에 띄되 의미 전달은 텍스트에 의존한다.
- 기존 `lucide-react`를 이용하고 각 장식 아이콘은 `aria-hidden="true"`; 기존 링크 문구와 대상 경로는 유지한다.

## 검증

- 컴파일된 CSS 또는 브라우저 계산 스타일에서 16→18px, 18→20px 증가 확인.
- 360px와 1440px의 홈·과정 목록에서 가로 스크롤 및 잘림 확인. `npm run lint`, 타입 검사, `npm run build`.
- 사용자 인증·데이터 로직은 수정하지 않는다.
