# 교육장소 호실·호실명 설계

2026-10-07 · course-guide-room-fields

- GuideEditForm의 교육장소를 fieldset으로 묶고 `호실`, `호실명` text 입력을 두 열(모바일 한 열)로 표시한다. 호실 예시는 `2-418`, `G-110`이며 여러 호실은 쉼표로 구분한다. 외부 장소는 호실명만 입력한다.
- 기존 location에서 숫자를 포함한 영문/숫자/하이픈 호실 코드와 선택적 `호` 접미사를 앞에서 추출한다. `2-418, 비앤비네오필라테스센터`는 호실/호실명으로, `1-302, 331`은 복수 호실로, `청년스테이지ON`은 장소명으로 자동 채운다. 해석되지 않는 장소는 호실명에 원문을 유지한다.
- 모델의 split/format helper를 사용하며 호실 입력에는 동일 코드 형식을 검증한다. 문자열을 trim하고 한쪽이 비어 있으면 다른 쪽만, 둘 다 있으면 `호실, 호실명`으로 기존 location에 저장한다. 두 칸 모두 빈 값이나 합친 문자열 160자 초과는 차단한다. 기존 값이 미수정이면 원문을 보존한다.
- 공개 상세는 기존 `교육장소` 표시를 유지한다. DB columns/RPC 13필드, revision, 기관 권한 및 실제 개설 기수는 변경하지 않는다.
- 기존 16개 위치의 변환/보존을 검사한다. 이미 있는 전용 로컬 실제 편집 회귀에서 분리 값 자동 채움, 변경→RPC→DB→새로고침, 공개 장소 표시, 360px 가로 넘침, 빈 장소 저장 거부를 확인한다. 날짜/시간·카탈로그 회귀 및 lint/build를 거쳐 운영 배포를 검증한다.
