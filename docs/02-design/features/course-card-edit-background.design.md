# 과정 카드 편집·배경 이미지 설계

2026-10-01 · [계획](../../01-plan/features/course-card-edit-background.plan.md)

## 저장 및 권한

- `life_course_guides`에 `card_image_url`(nullable HTTPS URL), `revision`을 추가한다. 기존 16개 행은 이미지 없이 시작한다.
- 직접 UPDATE 권한은 열지 않는다. `life_save_course_guide` RPC가 해당 가이드의 소속 기관을 확인하고 활성 사업단 역할(`INSTRUCTOR` 제외), 수동 등록된 사업단 구성원, 지정 운영자 중 해당 기관에 속한 계정을 검사한다. 현재 가이드는 앵커사업단 소속이며 신규 기관 가이드를 위해 `org_id`를 명시한다.
- RPC는 편집 가능한 공개 소개 필드만 허용하고 길이·형식·배열 개수·URL 스킴을 검증한다. 예상 revision이 다르면 저장을 거부한다. 성공 시 감사 이벤트를 기록한다.

## 화면

- `/courses` 카드와 리스트는 수정 가능 계정에만 별도 `수정` 링크를 표시한다. 카드 전체 링크와 수정 링크를 중첩하지 않는다.
- `/admin/courses/guides/[id]`에서 과정명, 아카데미, 요약, 교육내용, 방식, 정원, 시수, 기간, 시간, 장소, 자격증, 카드 배경 이미지를 편집한다. JPEG·PNG·WebP(최대 5MB) 파일 업로드와 HTTPS 주소 입력, 미리보기와 이미지 제거를 제공한다. 업로드는 공개 `life-course-covers` 버킷에 과정별 고유 경로로 저장하며 유효한 사업단 역할만 INSERT 가능하다.
- 공개 카드 이미지는 상단 배경 영역에 표시하고 텍스트 본문은 흰 배경을 유지한다. 이미지가 없으면 기존 카드 형식을 유지한다.
- 공개 조회는 `published` 조건을 유지하며 기존 수강 신청·보고서 권한은 변경하지 않는다.

## 검증

- 익명·수강생·강사 전용 계정은 수정 링크와 저장 권한이 없다. 사업단 역할 계정, 수동 등록된 사업단 구성원, 지정 운영자는 자기 기관 가이드를 저장할 수 있다.
- URL과 revision 오류를 처리한다. 기존 16개 과정은 이미지 없이 정상 표시되고, 이미지 지정 과정은 카드·상세에서 안전하게 표시된다.
