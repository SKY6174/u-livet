## 판단 규칙

- 표지 체크 표시로 아카데미를 판독한다. 기관·직위·내부/외부 예산란이 근거가 될 때 강사 구분을 제시하고, 근거와 불일치를 함께 남긴다.
- 담당교수·강사·보조강사·보조인력을 구별한다. 일반인 대상 원칙과 세부 모집인원 합계도 따로 확인한다.
- 총시수·차시 합계·시각 차이를 대조하며, 현황표와 다른 경우 계획서 값을 무조건 최신 확정값으로 덮어쓰지 않는다.
- 수강료 예산표의 총액과 1인 산출액을 구분한다. ‘센터 작성 예정’ 등 단서와 원문 산식 오류가 있으면 그대로 확인 필요로 표시한다.
- 정원 80% 모집 지침·장학금 80% 산식을 출석률 또는 수료 기준으로 해석하지 않는다.
- 접수기간·선발 방식·수료 규정·승인 상태는 문서에 명시된 범위에서만 기록한다. 자격 관련 정보는 원문 기재값이며 현재 공식 시험일정·취득 보장을 의미하지 않는다.
