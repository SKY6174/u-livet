# U-LiVE 헤더 브랜드 교체 설계

2026-09-27 · [계획](../../01-plan/features/u-live-header-brand-refresh.plan.md)

## 표시

- 공통 `Header`의 기관 `uc` 이미지를 기존 `/images/u-live-favicon.png`로 바꾼다. 이 자산은 첨부 그림의 색상과 형태가 같은 투명 심볼이며 아래 워드마크가 없어 오른쪽 텍스트와 중복되지 않는다.
- 심볼 오른쪽에 `U-LiVE` 워드마크를 한 줄로 놓고, 아래 보조 문구를 `열린 배움, 더 넓은 내일`로 표시한다. 워드마크의 남색·청록 계열은 제공된 그림을 따른다.
- 상단 `울산과학대학교 앵커사업단 | 개방형 평생직업교육`과 링크 목적지, 메뉴·인증 처리는 변경하지 않는다.
- 로고 이미지는 장식 이미지로 처리하고 홈 링크에 서비스명과 새 문구를 접근성 이름으로 제공한다.

## 구현과 확인

- 변경 대상: `src/components/common/Header.tsx`; 이미 저장된 로고 파일을 재사용해 새 바이너리 파일을 추가하지 않는다.
- 모바일 좁은 폭에서 문구가 메뉴 버튼과 겹치지 않는지 확인한다.
- lint·TypeScript·빌드를 실행하고 공개/로그인 헤더를 브라우저에서 확인한다.
- 기존 `u-live-brand-transition.design.md`의 `uc` 로고 유지 결정은 이 새 사용자 요청에 한해 대체된다.

데이터 모델 및 API 변경은 없다.
