# 장학금 안내 운영 문안 설계

2026-10-17 · Feature `operational-scholarship-notices`
Plan: `docs/01-plan/features/operational-scholarship-notices.plan.md`

## 조사와 근거

22개 과정의 공식 운영 문서 8개·불변 제출본 1개, 결과보고 원본 요약 3개,
구 장학금 마스터 3개·지급 대장과 장학 신청 서류를 조사했다. 검증 문구·작성 요령은 없다.
운영 완료 3개의 원본 지급 합계, 실버푸드의 계획 예산과 검토 중 결과 합계는
공개된 개인별 지원 약정과 구분한다. 구 마스터는 현재 life_offerings와 연결되지 않으며
현재 공개 안내가 해당 금액을 조회하지 않는다. 기존 자료는 보존한다.

## 화면 변경

ScholarshipNotice의 공통 ‘아직 공개되지 않았습니다’ 문구를 실제 절차로 교체한다.
기존 공개 운영절차는 결과보고서 승인 후 지급 수속을 진행한다고 안내한다.
기존 learner_document_eligibility는 원서 승인·수료 인정 후 지급신청서 이용을 허용한다.
따라서 지원 대상으로 안내받은 경우의 서류 제출·결과보고 후 지급 수속을 설명하고,
수료·신청 접수 자체가 지급 확정을 뜻하지 않음을 표시한다. 대상·금액·일정은 사업단 확인으로 안내한다.

archived boolean을 두 공개 페이지의 기존 offering.status에서 전달한다.
운영 완료 과정에는 과거 지급 내역 조회·사업단 확인을 안내하며 신규 신청 절차는 표시하지 않는다.
내 장학금 확인 `/mypage#scholarships`와 사업단 문의 `/terms#help-title` 링크를 제공한다.
추가 DB 조회·공개 API·개인별 계좌나 지급 정보 노출·조건/금액/승인 데이터 변경은 없다.

## 검증

lint·TypeScript·diff·Preview 검사 후 공개 소개 16개와 실제 공개 과정 상세 5개를 확인한다.
운영 완료 6개 화면과 나머지 15개 화면의 안내를 구분하고 검증·작성 요령·구 미공개 문구를 검사한다.
운영 DB의 장학금·문서·제출본·수료 관련 자료 해시를 전후 비교한다.
실제 화면·링크 도착점·배포 SHA·health·최근 오류 로그를 확인하고 PR·push·병합·배포를 완료한다.
