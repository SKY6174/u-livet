# 수강안내 화면 설계

## 정보 구조
- 도입: ‘수강안내’ 제목과 과정 찾기·신청 현황 두 행동 링크를 표시한다. 제목 아래 보조 설명은 표시하지 않는다.
- 준비 체크: 교육대상·일정·장소·수강료·수료기준의 다섯 항목을 읽기 전용 체크리스트로 표시한다. ‘신청 전, 다섯 가지만 확인하세요’ 제목 아래 보조 설명은 표시하지 않는다.
- 네 단계: ordered list로 과정 찾기, 로그인·수강신청, 심사·수강 확정, 강의실 이용을 표시한다. 각 단계는 번호·아이콘·짧은 설명·실제 서비스 링크로 구성한다.
- 세부 안내: native details/summary로 심사·대기, 취소·환불, 수료·증명의 기존 설명을 보존한다. 발급 준비 중 표시를 유지한다.
- 문의: 공통 SupportContact에서 RCC센터·AID-X지원센터·ECC센터의 이름·전화·이메일을 안내한다. 상세값은 `anchor-multi-center.design.md`를 따른다. 과정별 모집 안내와 운영센터 확인 문구를 표시하며 운영시간이나 처리기한은 추정하지 않는다.

## 표현과 동작
- 기존 남색·청록 브랜드, 넉넉한 여백, 최소 16px 본문, 장식용 아이콘 aria-hidden, 명확한 링크 이름을 사용한다.
- 넓은 화면은 네 단계 가로 흐름, 모바일은 세로 순서. FAQ/문의는 데스크톱 두 열·모바일 한 열이다.
- JS 상태나 새로운 데이터 조회를 추가하지 않는다. 로그인 전에도 안내를 볼 수 있고 보호된 목적지는 기존 로그인 복귀 규칙을 따른다.
- 원래 업무 규칙을 변경하거나 신규 동의·비용·환불률·수료 보장을 만들지 않는다.

## 확인
- desktop/mobile 렌더링, 가로 넘침 없음, FAQ 펼침과 접힘, 과정·나의 공간 이동, 원문 핵심 안내 보존, lint와 배포 빌드를 확인한다.
