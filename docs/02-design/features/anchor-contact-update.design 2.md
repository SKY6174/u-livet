# 시스템 문의 담당자 변경 설계

## 표시
- SUPPORT_CONTACT 상수와 SupportContact 구성요소에서 담당자 이름·직위, 전화·이메일과 tel/mailto 주소를 통일한다.
- 모든 페이지의 Footer와 교내 로그인, 계정 복구·MFA, 강사 등록 준비, 개인정보 안내에 적용한다. 수강안내의 남색 문의 영역도 같은 상수를 사용한다.
- 사용자는 연락처만 지정했다. 계정 생성, 역할 부여, 이메일 발송, 개인정보 수집 목적·항목·기간은 변경하지 않는다.

## 버전과 기록
- 이번 사용자 요청을 문의 담당 변경의 승인 근거로 기록한다. ACCOUNT v3→v4, INSTRUCTOR PRIVACY/REVIEW v1→v2를 만들고 새 가입 안내 포인터를 바꾼다.
- 기존 승인 본문은 불변이며 기존 동의·이력 기록도 변경하지 않는다. 새 버전이 같은 기관에 존재하는 경우에만 명시된 이전 버전을 현재 안내 선택 목록에서 제외한다.
- 기존 제출에 적용한 원문은 제출 기록에 그대로 남긴다. 현재 문의는 공통 하단에서 확인할 수 있다.
- 운영과 Preview 각각 트랜잭션으로 실제 승인자 역할·원문 해시를 확인하고 새 문안만 등록한다. 감사기록은 사용자 요청을 근거로 한 관리 API 실행임을 명시한다.

## 검증
- 기존 등록 준비 검증에 새 전화/mailto와 새 안내 우선 표시 및 다른 기관 영향 없음 확인을 반영한다.
- lint/build, 모바일 링크 넘침, 실제 운영 개인정보 페이지와 가입 정책 버전·연락처를 확인한다.
