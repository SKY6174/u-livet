# 모집기간 날짜 한 줄 표시 설계

- `RecruitmentDates` 공통 컴포넌트에서 한국 시간대 날짜를 `YYYY.MM.DD ~ YYYY.MM.DD`로 표시한다.
- 범위 전체에 nowrap을 적용해 카드와 목록에서 시작일·종료일이 한 줄로 보이게 한다.
- `<time dateTime>`의 원래 타임스탬프, 미정 안내와 모집 상태 계산은 유지한다.
- 전역 `dateTime`과 교육 일정, 관리자 입력값은 변경하지 않는다. DB 변경 없음.
- 실제 CSS로 카드 390px·640px·1440px, 목록 표시와 한국 자정 경계 날짜를 확인한다.
