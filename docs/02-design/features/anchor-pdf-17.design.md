# PDF 1.7 공통 출력 설계

## 생성과 저장
- `src/lib/pdf/version.ts`: PDF_VERSION=1.7 및 생성 바이트의 엄격한 헤더 검증. 임의 PDF를 헤더 교체만으로 변환하지 않는다.
- `src/lib/pdf/browser.ts`: 고정 버전 jsPDF 생성기를 1.7로 설정하고 출력 시 다시 검증. Blob/data URI/다운로드 공통 처리.
- 강사 서류 기존 표준 유틸은 공통 생성·출력 유틸을 재사용한다. Supabase 생성 PDF 저장은 PDF 1.7 헤더와 실제 파서의 페이지·Catalog 검증을 통과해야 한다. 2.0 Catalog나 확장 사전도 거부한다. 외부 분석용 원본 입력에는 이 제한을 적용하지 않는다.
- 증명서 pdf-lib 출력은 이미 1.7이다. Catalog Version을 명시하고 출력 바이트를 검증해 라이브러리 기본값 변경을 방지한다. 발급 후 저장된 원본·해시는 재작성하지 않는다.

## 보고서·출석부
- 기존 직접 인쇄는 유지하고 별도 `PDF 1.7 다운로드` 버튼을 제공한다.
- `.report-sheet`를 순서대로 캡처하여 각 세로/가로 방향에 맞는 A4 페이지로 생성한다. 인쇄 대상 밖의 개인정보/화면 내 메뉴는 캡처하지 않는다.
- 폰트·그림 로딩이 완료된 후 2배율 캡처. 그림 실패 시 불완전한 파일을 다운로드하지 않는다.
- 한 장을 넘는 문서는 행·제목·그림·텍스트 줄 경계를 고려해 여러 페이지로 분할한다. Canvas와 DOM의 글자 기준선 차이로 인한 잘림을 막기 위해 실제 래스터의 빈 줄로 경계를 보정한다. 동시 생성 방지 및 완료/실패 안내.

## 검증
- jsPDF와 pdf-lib 실제 생성 파일을 PDF 파서로 열어 1.7, 페이지 수, A4 크기 확인.
- 1.4/2.0/가짜 헤더 입력을 1.7로 오인하지 않는지 검증.
- 문서/그림/표/긴 문단 및 가로·세로 혼합 다중 페이지를 가상 예시로 다운로드하고 렌더 확인.
- 타입/린트/빌드, 로컬 Supabase 저장 경계 검증, 변경 파일만 커밋/push.

## 기존 보관 PDF 변환본 (추가 요청)
- 원본 보고서·발급 증명서·강사 보관 PDF마다 권한이 확인된 기존 다운로드 경로를 사용하여 PDF 1.7 변환본을 제공한다.
- PDF.js로 모든 페이지를 읽어 2배율(최대 한 변 4096px)로 렌더하고 jsPDF로 새 PDF 1.7을 생성한다. 원본 버전이나 확장 기능을 헤더만 바꿔 위장하지 않는다. 페이지 크기·회전·순서를 보존한다.
- 구형 한글 PDF의 CMap, 표준 폰트 및 이미지 코덱은 고정 PDF.js 패키지에서 로컬 API로 제공하고 배포 산출물에 포함한다. 버전·디렉터리·확장자를 제한하며 임의 파일은 노출하지 않는다. PDF 파서 오류는 불완전한 사본 대신 실패로 알린다.
- 변환본은 페이지 이미지로 구성된 사본임을 안내한다. 원본·해시·전자서명·입력필드는 변경하지 않으며 텍스트 검색·서명 검증은 원본을 이용한다.
- 최대 원본 30MiB를 스트리밍으로 제한. 기존 인증/만료 URL을 그대로 적용하고 인증 실패·암호화 잠금·잘못된 PDF는 오류 안내한다. 변환본을 서버에 추가 저장하지 않는다.

외부 원본 PDF 보관/읽기와 기존 저장본은 보존한다. 이 변경은 PDF/A 인증을 제공하지 않는다.
