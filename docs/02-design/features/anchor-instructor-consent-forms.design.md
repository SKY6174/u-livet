# 필요서류 3종 및 보조강사 설계

## 강사 정책
- 교내외 kind를 보존하고 teaching_role=LECTURER/ASSISTANT를 추가. 보조강사는 EXTERNAL만 허용하며 교외 수에 포함하고 별도 배지/등록·수정·엑셀 값을 제공한다.
- 교외/보조 이력서는 필수. 세 동의서는 기본 교외/보조 필수(교내 적용 여부 사용자 응답 반영). DB 지급완료 검사와 대장 준비 합계/UI를 같은 기준으로 갱신한다.
- 역할을 소속 변경 이력과 수당 스냅샷에 보관한다. 기존 역할/로그인 권한은 추가하지 않는다.

## 문서 및 UI
- 기존 문서 창 탭에 개인정보동의, 성범죄 조회동의, 청렴서약 추가. 대장 각 문서 상태와 입력 링크는 해당 탭의 별도 창에 바로 연결한다.
- 왼쪽 성명/연락처/해당 문서 필드·동의 선택·직접 서명/서명 이미지. 오른쪽 동일 PDF bytes를 PDF.js canvas로 렌더링하고 다운로드한다. 모바일은 세로 배치.
- 성범죄: 첨부 PDF의 내용/표/주의사항을 복사한 템플릿에 이름, 국내 주민번호 또는 외국인 생년월일/등록번호, 연락처, 일자, 서명만 오버레이.
- 개인정보: uc-anchor의 표·안내·두 동의 항목·서명 구성, 첨부의 사업단/세무서 제공/5년 보유 내용 사용. 기본 미선택, 동의 거부 선택 가능. 거부 응답은 보관하되 제출 완료로 집계하지 않는다.
- 청렴: 첨부의 인적사항/위촉 프로그램·기간/서약/이해관계 예·아니오/해당 교직원 정보/서명. 미선택 금지, 예 선택 시 세부관계 필수. KoPub Dotum embedded fonts.
- 공통 PDF renderer는 브라우저와 Edge가 공유. 서버는 검증된 필드로 PDF를 직접 생성해 입력값과 보관 PDF의 일치 보장. PDF writer 1.7, A4 단일 페이지. 첨부 원본은 수정하지 않는다.

## 저장·보안
- org/person/type 단위 암호화 초안 테이블, final 버전별 레코드(불변 id, template version, encrypted JSON/IV, status, actor kind, submitted timestamp, private path/hash/size).
- 개인정보/고유번호/서명은 AES-GCM 암호문에만 저장. 기존 private 버킷에서 5분 signed URL. 브라우저 저장소/로그에 원문 보관 금지.
- 기존 JWT+MFA 또는 PIN 세션 권한·만료·철회 검사를 모든 요청에 유지. 타 org/person/type/id 접근 금지. final 저장 요청 UUID로 재시도 중복 방지. 서버가 필드/길이/타입/날짜/서명 파일 검증 후 PDF를 생성한다.
- 최종 제출 후 초안 정리, 과거 버전 유지. PDF 업로드 실패는 완료 상태를 만들지 않으며 메타데이터 실패 시 새 object 정리.
- direct table access는 service_role만, RLS 활성화, 필요한 FK 인덱스. public RPC는 기존 기관 권한 검사 패턴을 유지한다.
