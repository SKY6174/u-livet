# anchor-business-menu - Design Document

> Version: 2.0.0 | Date: 2026-09-21 | Status: Approved (user-requested revision)

## UI structure

- `Header`가 `officeSections(identity)`를 이용해 `업무 홈`과 권한별 하위 메뉴를 구성한다.
- `사업단 관리` 텍스트는 `/admin` 링크로 렌더링한다. 인접한 화살표 버튼은 메뉴 펼침만 담당한다.
- 데스크톱 패널은 왼쪽에 서브메뉴명만 나열하고, 오른쪽에 호버·포커스한 항목의 설명을 표시한다.
- 모바일에서도 상위 텍스트는 업무 홈으로 이동하며 독립된 펼침 버튼으로 서브메뉴명을 표시한다.
- 중복 가로 메뉴 `OfficeNav`는 사업단 관련 모든 layout에서 제거한다. 서버 권한 검사는 유지한다.
- 업무 홈의 이름·역할 안내 문구를 삭제한다.
- 업무 홈은 단정한 제목 영역과 업무 분류별 3열 카드로 구성한다. 과정 운영은 전체 너비의 강조 카드, 나머지는 아이콘·미세한 그라데이션·화살표·호버 효과로 구분한다. 업무 분류명과 기존 설명/경로는 유지한다.

## Interaction

- 데스크톱에서 상위 메뉴 호버 또는 링크 포커스로 패널을 연다.
- 서브메뉴 호버·포커스가 오른쪽 설명을 변경한다. 초기 설명은 현재 업무(또는 업무 홈)를 따른다.
- Escape는 패널을 닫고 상위 링크로 포커스를 돌린다. 메뉴 바깥 포커스 및 포인터 이탈도 닫힘을 처리한다.
- 하위 링크를 선택하면 패널과 모바일 메뉴를 닫는다.
- 모바일 메뉴는 화면 높이에 맞춰 내부 스크롤하며 가로 넘침 없이 단일 열로 표시한다.

## Accessibility and responsive behavior

- 펼침 버튼에 고유한 `aria-expanded`, `aria-controls`, 접근 가능한 이름을 제공한다.
- 현재 페이지와 상세 경로의 소속 메뉴는 `officeActiveHref`로 한 항목만 활성화한다.
- 닫힌 패널 링크는 포커스 순서에서 제외한다. 서브메뉴 설명은 스크린리더에도 제공한다.
- 데스크톱은 화면 내 제한 폭의 2열 패널, 모바일은 일반 흐름의 한 열 메뉴다.
- 카드 1/2/3열 반응형 배치와 `prefers-reduced-motion`을 지원한다.

## Data and security

- 데이터베이스·API 변경 없음. 존재하지 않는 업무 통계나 실시간 상태를 만들지 않는다.
- 기존 `isOfficeMember`, `officeSections`, 서버 라우트 접근 제어를 유지한다.

## Validation

- 타입 검사, ESLint, production build, 기존 역할별 메뉴/서버 권한 회귀 검사
- 브라우저에서 호버 설명, 직접 홈 이동, Escape/Tab, 모바일 펼침, 권한별 링크, 390/768/1024/1440px 가로 넘침 확인

## Revision 3 — 2026-09-24

- `전문가 관리`를 업무 메뉴 마지막의 `계정·권한` 그룹으로 옮겨 `구성원 관리` 바로 위에 표시한다.
- 기존 `COURSE_MANAGER` 접근 조건과 경로는 유지한다. 구성원 관리 접근 조건도 변경하지 않는다.
- 데스크톱·모바일이 공유하는 `officeSections` 순서 및 역할별 회귀 검사에 같은 순서를 적용한다.
