# 동의서 PDF 미리보기 안정화 설계

- `ConsentEditor`는 `form` 변경 시 `bytes`를 비우지 않는다. 최신 요청 완료 여부를 `previewPending`으로 추적한다.
- 300ms 입력 지연과 기존 비동기 완료 무효화(`active=false`)를 유지해 오래된 PDF가 최신 PDF를 덮지 않도록 한다.
- 새 PDF 생성이 완료되면 `bytes`를 교체하고 `previewPending`을 해제한다. 입력 직후부터 새 PDF가 준비되기 전까지 다운로드를 비활성화한다.
- `PdfPreview`는 이전 캔버스를 새 캔버스 렌더링이 끝날 때까지 유지하고 성공 시 원자적으로 교체한다. 생성 오류는 기존 캔버스 위에 알림으로 표시한다.
- `loading` 및 첫 미리보기 생성 전에는 기존 진행 문구를 유지한다.
- 확인: 연속 입력과 지연된 PDF 생성/렌더, 변경 중 다운로드 상태, 생성 오류, 정적 빌드와 Lint.
