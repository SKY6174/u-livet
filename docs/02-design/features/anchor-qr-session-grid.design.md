# 전체 회차 출석부와 QR 종료 기록 설계

2026-09-25 · [계획](../../01-plan/features/anchor-qr-session-grid.plan.md)

## 데이터와 권한
- 기존 `life_private.qr_attendance_checkins`에 nullable `checked_out_at`을 추가한다. 기존 `checked_in_at`은 변경하지 않는다.
- 토큰에 `phase` (`START`/`END`)를 저장한다. 기존 발급 RPC는 시작 전용으로 유지하고 종료 발급 RPC를 추가한다. 시작 QR은 수업 시간 중에만, 종료 QR은 종료 후 15분까지 유효하다. 학생 스캔 RPC는 토큰의 phase로 분기하며 종료는 시작 기록이 있을 때만 최초 시각을 저장한다. 재스캔은 각 최초 값을 유지한다.
- 기존 강사·수강생·회차·유효시간·발급 강사 검증을 그대로 적용하고, QR 조회 RPC에는 종료 시각을 추가한다. 기본 테이블 권한은 닫아둔다.

## 화면·문서
- 강사 QR 화면에서 시작/종료를 선택해 발급하며 QR 이미지의 안내문도 구분한다. 수강생 확인 페이지는 이름 아래 작은 일자·시각과 시작/종료 결과를 표시한다.
- 출석부는 회차를 분할하지 않고 전체 정규 회차를 한 표의 가로축에 배치한다. 회차 날짜·수업시간 아래 `시작`·`종료` 칸에 해당 QR 최초 확인 일자·시각을 표시한다. QR 기록은 출석 인정시간과 별도이다.
- 출석부는 A4 가로를 기본으로 하되 회차가 많을 때 A3·A2·A1·A0 가로까지 사용해 전체 회차 축을 유지한다. 명단만 세로 방향 페이지로 분할한다. 화면은 가로 스크롤 가능하다.
- `attachmentTitle`은 순수 문서명만 반환한다. 첨부 번호 함수로 출력물 문서 좌상단에 `[첨부 #1]`부터 `[첨부 #5]`를 표시하고 해당 표시 글꼴을 기존 제목보다 3px 작게 한다.

## 검증
- 시작 후 종료 QR만 허용, 종료 전 스캔·다른 강좌·만료·무권한 거부, 중복 멱등성, 예전 시작 기록 보존을 검사한다.
- 시작/종료 시각이 한국시간으로 개별 회차에 표시되고 전체 회차가 같은 표에 배치되는지, 첨부 1~5 제목/좌상단, PDF 페이지 크기와 1.7을 확인한다.
