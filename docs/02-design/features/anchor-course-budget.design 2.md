# 과정 운영·예산 설계

2026-09-21 · anchor-course-budget

## 화면과 연결

`/admin/courses`는 공개 guide 16개와 권한 내 workspace를 offering_id로 병합한다. 연결되지 않은 실제 개설 과정도 유지하며, 권한이 없는 운영 링크는 노출하지 않는다. 안내의 일정·정원·시수를 기준으로 표시하고 개설 계획의 교내/교외 강사·보조강사·보조인력을 연결한다. 미개설 과정은 개설 준비로 연결한다. 운영계획서만 존재하는 상태에서 모집을 자동 개시하지 않는다.

과정 목록(카드/표), 예산 현황(표와 개별 편집), 예산 집행현황(엑셀 보기)의 세 탭. 표는 프로그램 ID → 세부 프로그램 순서. 아카데미·상태·검색과 카드/리스트 선택 지원. 프로그램 ID는 첨부 근거의 라이프케어 C1-S3T4-2, 팝업 C1-S3T4-3, 로컬창업 강조 행 C1-S4T5-3을 초기값으로 쓰되 수정 가능. 동일 프로그램 ID를 여러 과정이 공유할 수 있다.

## DB 및 권한

life_course_budgets: 기관/guide 복합키, program_id, 재료비·인쇄비·강사료·운영비·보조인력·장학금(원, nullable), revision, 수정시각/작성자. 빈칸·원문 '-'는 null로 보존. 총액은 합산. seed는 첨부 이미지 2의 16행을 사용하며 source 표기. 기관 관리자 SYSTEM_ADMIN 또는 COURSE_MANAGER만 읽기/쓰기. RLS 활성화, 직접 테이블 권한 회수, 사용자 세션 RPC → private 권한 검사. 기존 최근 MFA 쓰기 가드 사용. 변경시 revision 비교 및 감사 이벤트 기록.

life_budget_workbooks: 기관/연도, 파일명·시트명·SHA256·제목행·문자열 행렬·생성자/시각. 저장은 append-only, 이전 파일 이력 유지. 조회/저장은 같은 역할과 MFA 범위. 다른 기관 접근 차단. 개인 수강료·환불 원장과 별개.

## 엑셀

read-excel-file을 지연 로드하여 .xlsx(최대5MB)를 브라우저에서 읽는다. 시트와 제목 행(첫 50행)을 선택하고 최대2000행/40열/셀500자/JSON1MB를 검증한다. 수식은 실행하지 않고 캐시된 결과만 텍스트 표시한다. 저장 전 미리보기, 검색, 파일명과 시트명 표시. 행렬 그대로 기관 DB에 저장해 다른 관리자도 확인 가능하다. 양식 미확정이므로 자동 금액 매핑·합산은 하지 않고, 저장된 조회 자료임을 명시한다. 새 파일 선택시 이전 미리보기와 저장 상태를 초기화하며 비동기 로딩 경쟁 방지.

## 검증

16행 연결/중복, 초기 합계, 금액·프로그램ID 경계, 엑셀 행/셀/용량 오류, 기관 및 역할 격리, 익명/수강생 차단, stale revision, MFA 차단, 감사, 실제 브라우저 카드/표/탭/엑셀 동작, lint/build/typecheck. DB 적용은 로컬 검증 후 preview와 production에 동일 migration 적용.
