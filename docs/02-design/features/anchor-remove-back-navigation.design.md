# 페이지 돌아가기 메뉴 제거 설계

## 화면 규칙
- `←`, `ArrowLeft`, ‘돌아가기’, ‘목록으로’로 표시되는 페이지 복귀 링크를 실제 JSX에서 제거한다. CSS로 감추지 않는다.
- 공통 CourseHeader와 강사 대장의 복귀 링크도 제거하여 모든 이용자에게 같은 규칙을 적용한다.
- 서류 입력 화면의 대장 복귀 버튼과 보고서·출석부 출력 도구의 복귀 버튼도 제거한다.
- 복귀 버튼에서만 사용하는 props, import, 변수, 여백은 함께 정리한다.
- 삭제 확인 대화상자의 ‘돌아가기’는 취소 동작이므로 ‘취소’로 명확히 표시하고 기능을 유지한다.
- 목록의 ‘이전’ 페이지 링크, 공통 메뉴, 업무 탭, 오류 안내와 재시도는 유지한다.
- 서버 인증/인가, returnTo 인증 처리, 데이터 조회·저장 및 자동 이동은 변경하지 않는다.

## 검증 기준
- 페이지 복귀 JSX가 남아 있지 않고, 남는 왼쪽 화살표는 목록 페이지 이동뿐이다.
- 제거된 링크의 공백이나 미사용 코드가 남지 않는다.
- 린트와 Next.js 빌드가 통과하며 기존 조회 검사도 통과한다.
- 공개 과정 상세에서 복귀 링크가 없고 공통 메뉴로 교육과정 목록에 이동할 수 있다.
- main·preview 원격 브랜치와 운영·스테이징 배포의 커밋이 일치한다.
