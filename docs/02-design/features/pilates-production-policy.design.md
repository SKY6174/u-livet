  `산과 필라테스 자격증과정`.

- 새 정책: 같은 조직 ENROLLMENT `PILATES-2026-10-17-v1`.

- 대상이 있으면 행 잠금 후 조직·이름·기존 연결을 확인한다. 새 정책 연결은 재실행 시 무변경이다.
- 연결과 academic_revision만 갱신하고 POLICY_LINK_CORRECTED 감사 이벤트에
  이전/이후 ID, 버전과 본문 해시, migration 식별자를 기록한다.
- 다른 정책 본문, 기존 신청과 동의 이벤트, 원서 PDF와 처리 이력은 변경하지 않는다.

예기치 않은 연결·잘못된 문안·미승인 정책을 확인한다. 기존 신청/동의/정책과
다른 과정이 보존되는지도 비교한다. PR Preview 마이그레이션 검사 후
정확한 SQL과 migration ledger를 한 트랜잭션으로 운영에 적용한다.
PR 병합 후 운영 deployment SHA, health/version 및 공개 과정·직접 신청
화면의 새 문안 표시와 검증 문구 제거를 확인한다.
