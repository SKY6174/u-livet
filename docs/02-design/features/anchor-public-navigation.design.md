# 공개 메뉴 구성 설계

- Header의 공통 links 배열을 `/about` 앵커사업 소개, `/terms` 수강안내, `/courses` 교육과정 소개 순서로 정의한다.
- `나의 공간`은 로그인한 회원의 개인 메뉴로 표시하며 비로그인 공개 화면에서는 제외한다.
- 로그인 시작화면의 중복 로그인 버튼은 기존대로 숨기고, 공개 안내 페이지의 비로그인 방문자에게는 로그인 링크를 표시한다.
- 로그인 후 역할별 업무 메뉴·로그아웃과 각 경로의 권한 검증을 유지한다.
- 기존 links 배열을 공유하는 데스크톱·모바일 메뉴 모두 같은 변경이 적용된다. 공개 화면 3곳과 로그인 시작화면, 모바일 메뉴를 브라우저로 확인하고 lint/build를 검증한다.
- 2026-09-21: 데스크톱 헤더는 좌우 동일 폭의 로고·계정 열 사이 중앙 열에 주 메뉴를 가운데 배치한다. 업무 메뉴가 많으면 중앙 영역에서 줄바꿈하며, 모바일 메뉴는 기존 펼침 방식을 유지한다.
