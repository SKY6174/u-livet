# 공개 과정의 수강료·이수·장학 안내 — Design

2026-10-08 · [계획](../../01-plan/features/public-course-enrollment-info.plan.md)

## 데이터

`/courses/[id]`의 기존 `offering_id`와 공개 `life_course_introductions` 결과를 그대로 사용한다. `tuition`은 `null`, `0`, 양수를 구분한다. 연결된 개설 과정이 아직 공개되지 않았으면 `getCourseIntroduction`은 `null`이며 개설 준비 중으로 안내한다. 수료기준은 연결 과정의 `completion_policy_id`로 기존 `getPolicies("COMPLETION", id)`에서 승인·유효 버전만 조회한다. 제목이 `[검증용]`인 정책은 실제 기준으로 표시하지 않는다. 별도 정책 조회 실패도 기준 없음으로 표시한다.

장학금의 대상·금액·지급률은 현재 승인된 공개 데이터 모델에 없다. 이를 생성하지 않는다. 공통 읽기 전용 안내는 운영절차 설계의 검증된 순서(수료 처리 → 결과보고 승인 → 지급 수속)만 제시한다. 과정별 확정 기준의 부재를 명확히 알리고 수료만으로 지급을 보장하지 않는다.

## 화면

과정 소개의 `교육 안내`에 수강료와 접수기간을 넣고 오래된 ‘별도 모집 안내’ 일괄 문구를 제거한다. 본문에 `이수요건` 섹션을 추가하여 원문·버전 또는 확인 중 상태를 보여준다. 장학금 공통 안내를 별도 섹션에 배치한다. `/offerings/[id]`의 수료기준·수강료는 유지하고 같은 장학금 안내를 추가한다. 장학금 안내는 과정별 조건이 아니라 일반 운영 절차임을 제목과 본문에서 구분한다.

## 검증

정책과 금액의 null/0/양수 처리, 검증용 정책 제외, 공개·비공개 연결 과정, 양쪽 상세의 안내 일치, 접근성 제목 구조, lint·빌드·배포 health를 확인한다.
