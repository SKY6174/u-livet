# 관리 목록·주차권 신청·날짜 표시 설계

2026-10-11 · management-lists-parking-dates

## 목록

- 수강생: 순번, 수강생, 신청 건수, 수강 중 과정, 관리. 이름과 상세 보기 모두 기존 상세 경로를 사용한다. 삭제된 계정 표시와 40명 단위 검색·페이지 이동 유지.
- 수료 검토: 순번, 과정/아카데미, 사업연도, 교육기간, 정원, 상태, 검토/관리. DB 등록 과정은 기존 검토 링크, 미등록 과정은 권한에 따라 등록 링크 또는 안내를 제공한다. 요약 수치 유지.
- 두 목록 모두 caption, scope, 이름 있는 키보드 접근 가능 스크롤 영역과 단일 행 버튼을 제공한다.

## 주차권

기존 anchor-parking-vouchers와 readiness 설계를 확장한다. 신청자는 로그인한 본인, 수령자도 본인이다. 수강생의 기존 신청을 유지하며 배정된 교내·교외강사 모두 `/instructor`에서 `/parking`으로 진입한다.

DB의 `parking_applicant`는 기존 수강 확정 조건 또는 `teaches`와 승인된 INTERNAL/EXTERNAL 분류를 확인한다. INTERNAL_INSTRUCTOR를 신청자 종류 제약에 추가한다. 공개 RPC·RLS·함수 권한은 유지하며 SECURITY DEFINER의 빈 search_path를 유지한다. 미분류/미배정 강사는 신청할 수 없다.

흐름: 관리자 센터 지정·실물 재고 입고 → 본인 과정/사용일/연락처/매수 신청 → 관리자 승인 대기 → 지정 센터 승인자의 유효한 본인 로그인 확인 후 승인 또는 사유 반려 → 재고 차감·처리기록·신청자 상태 공개. 승인 중복·재고 부족·타인 취소 차단 유지. 화면에 이 흐름을 짧은 단계로 표시한다.

## 날짜

클라이언트에서도 안전하게 사용하는 `lib/date-format.ts`에 날짜/기간/한국시간 일시 공통 함수를 둔다. ISO date는 엄격히 검증하고 timestamp는 Asia/Seoul 기준 formatToParts를 사용한다. 결과는 0 패딩한 `yyyy.mm.dd.`. 날짜 범위는 양 끝 연도와 ` ~ `를 모두 표시한다.

공개 과정, 강사·수강생, 관리·수료·운영계획·주차권 등의 날짜/기간 표시를 공통 함수로 연결한다. 기존 guide parser는 유지하고 formatter만 교체한다. 미확정·불완전 일정은 원문을 보존하며 HTML date/datetime 입력 값과 DB ISO 값은 변경하지 않는다.

## 검증

기존 실제 로컬 PostgREST 주차권 검증에 교내 신청 성공·본인 context·관리자 접수·승인 및 교내 미배정 거부를 추가한다. 표의 링크/상태/빈 결과/페이지 이동과 1440/360px 스크롤을 확인한다. 날짜 단위검증과 기존 guide 날짜 검증을 갱신한다. 운영 DB에서 함수/제약과 설정 준비 상태를 확인하고 병합 후 운영 배포를 검증한다.

## 현재 로그인 정책 확인

운영 DB의 20260929050415 정책에서 TOTP 요구는 중지되어 있다. 함수명 mfa_recent/mfa_verified는 유지되지만 현재 유효한 실제 세션·계정·암호 정책·동의를 확인한다. 기존 주차권 안내의 추가 인증 문구를 본인 로그인·관리자 권한으로 수정하며 인증 정책 자체는 변경하지 않는다.
