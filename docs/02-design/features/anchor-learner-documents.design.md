# 수강생 원본 서식 작성 — 설계

작성일: 2026-09-22 · 계획: anchor-learner-documents.plan.md

## 구조
- `/mypage/documents/application`, `/mypage/documents/scholarship`: 인증된 사용자의 이름·이메일과 공개 과정 목록을 전달한다. 검색 매개변수에는 과정 식별자만 넣고 인적사항은 넣지 않는다.
- `DocumentPopup`을 확장해 서식별 독립 창 이름을 지원한다. 나의 학습 상단에 두 작성 버튼을 둔다.
- `learner-documents/editor.tsx`: 왼쪽 입력 / 오른쪽 실제 PDF.js 미리보기. 작은 화면은 세로 배치. 기존 서명 컴포넌트 재사용. 입력은 React 메모리에서만 보관한다.
- `lib/learner-documents/model.ts`: 서식 종류, 필드, 한국시간 날짜, 다운로드 시 필수 항목 검증.
- `lib/learner-documents/pdf.ts`: 원본 페이지 복사 + 입력값·체크·PNG 서명 배치. 최신 bytes만 다운로드한다.

## 원본 유지
원본은 595 × 842 pt, 2페이지, PDF 1.3이다. 페이지별 템플릿을 보관하고 예시 과정명과 예시 날짜 텍스트만 제거한다. 원본 표·선·색·폰트·여백·문구는 보존한다. 날짜 연월일은 원래 자리에서 새로 표시한다. 생년월일은 원본 6칸에 YYMMDD로 출력한다. 장학금 주민번호는 원본 하이픈 좌우에 6자리 / 7자리로 표시한다. 계좌 안내 문구는 그대로 보존하고 그 위쪽에 입력값을 배치한다.

## 데이터 및 동의
공통: 과정명, 성명, 휴대전화, 성별, 작성일, 서명.
신청: 생년월일, 이메일, 주소, 신청목적(복수 선택), 개인정보·홍보·초상권 동의(각 미선택/동의/비동의).
장학: 주민번호 앞/뒤, 은행명, 계좌번호, 예금주, 개인정보 동의.
자동 동의 금지. 비동의도 문서에 그대로 반영하고 다운로드 허용한다. 주민번호는 입력폼 뒷자리 기본 마스킹; 실제 PDF에는 원본 요구대로 표시됨을 안내한다. 서명은 두 서식 사이 자동 공유하지 않는다. 서버 접수나 장학금 지급 상태를 변경하지 않는다.

## 렌더링과 오류
pdf-lib가 생성한 새 1.7 문서에 템플릿 페이지를 복사하고 한글폰트를 내장한다. 새 PDF의 헤더와 Catalog 버전은 1.7이다. 원본 텍스트는 재조판하지 않는다. 값은 해당 칸 중앙에 글리프 실제 경계를 기준으로 배치한다. 긴 문자열은 적정 최소 크기까지만 줄이며 넘치면 오류를 표시한다. 미리보기는 300ms debounce, 오래된 작업 결과 무시, 갱신 중 다운로드 비활성화, 자산 오류 재시도 제공. 내려받기 직전 필수값·날짜·숫자형식·서명을 검사한다.

## 검증
두 페이지의 원본과 템플릿을 이미지 비교(과정명·날짜 제거 영역 제외). 입력 PDF의 제목·내용·선택·페이지 크기·헤더·폰트 확인. 잘못된 날짜·숫자·빈 동의·긴 값 검사. 브라우저에서 팝업, 실시간 입력, 서명 지우기, PDF 다운로드, 모바일 가로 넘침 및 인증 보호 확인. 프로덕션 빌드 후 push.
