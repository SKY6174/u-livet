# Issue 172: 운영계획서 편집 및 제출 설계

2026-10-13 · 계획: `docs/01-plan/features/issue-172-course-plan.plan.md`

## 강의 기본정보

`DocumentEditor`에 계획서 강의 기본정보 상태를 둔다. 첫 저장 회차의 공통 항목으로 초기화하고, 원하는 기존 회차에서 명시적으로 불러올 수 있게 한다. 공통 항목은 시작/종료시간, 주제, 주/보조강사, 주/보조 시수, 장소, 수업방식이다. 기본정보 변경은 기존 회차를 덮어쓰지 않는다. 회차 추가 시 기존 schema의 빈 행과 공통 항목을 합쳐 독립 행을 만들며 날짜와 공휴일/보강은 비운다. 60회차 제한과 결과보고서의 기존 행 추가는 유지한다.

기본정보는 편집 중 새 회차에 적용하는 입력 보조값이다. 저장 형식을 늘리지 않고 생성된 각 회차의 기존 필드에 저장한다. 다시 열면 첫 저장 회차에서 복원하고 다른 회차를 불러올 수도 있다.

## 주요대상

필수 항목 안내와 함께 성인학습자/지역주민 checkbox를 제공한다. 둘 다 선택할 수 있으며 저장값은 기존 문자열 필드에 `성인학습자 / 지역주민`으로 직렬화한다. 기존 값은 읽을 때 선택 상태만 해석하고 사용자 변경 전까지 원문을 유지한다. 모두 해제하면 빈 문자열로 저장하고 검토 필수 항목으로 안내한다.

## 서명과 출력

계획 `missingContent`에 담당교수 서명을 추가하고 표지 입력에 검토 요청·최종 제출 필수라고 표시한다. DB에 내부 trigger를 추가하여 plan이 REVIEW/SUBMITTED로 저장되는 모든 경로에서 빈 서명을 거부한다. DRAFT 임시저장과 기존 제출본 읽기는 유지한다. 기존 transition의 접근 권한·역할·버전·예산 검증은 그대로 두며 API에 계획서 서명 오류 메시지를 추가한다. 함수는 고정 search_path의 invoker이며 외부 실행 권한을 회수한다.

표지 서명을 일반 flex 흐름의 50mm × 24mm 영역에 표시하여 이름/라벨과 겹치지 않게 한다. 기존 결과 서명 CSS는 유지한다. 실제 PDF 1.7 다운로드를 렌더링해 크기와 배치를 확인한다.

## 예산

계획 산출내역을 모든 항목에서 3줄 textarea로 제공한다. 기존 1,000자 제한 및 문자열 JSON 형식을 유지하고 출력 CSS의 pre-wrap으로 줄바꿈을 보존한다.

순수 parser는 `*`, `×`, `x`, `+`, 원/천원/만원/억원 및 통상 수량 단위를 처리한다. BigInt 유리수로 계산하고 최종 정수 0~999,999,999,999원만 반환한다. 여러 줄은 합산하며 번호/글자 접두 설명과 명시적 `=금액`을 지원한다. 등호 양쪽이 금액식이면 불일치는 거부한다. 단위만 있는 수량 계산은 가격으로 추정하지 않는다. eval/동적 실행, 나눗셈, 불명확한 수식은 사용하지 않는다.

산출내역 변경 시 확정 가능한 결과만 같은 행의 planned에 반영한다. 금액은 직접 조정할 수 있으며 계산 불가능한 내역은 직접 확인 안내를 표시한다. 기존 저장본 금액은 자동 재계산하지 않는다. 결과보고서의 예산 잠금/입력 방식도 유지한다.

## 검증과 릴리스

모델의 경계값·악성 수식·명시 금액·다중 줄·회차 독립성·이전 값 복원을 검사한다. 실제 편집 컴포넌트에서 대상/기본정보/예산 입력을 확인하고 생성 PDF를 렌더링한다. 로컬 SQL 트랜잭션에서 unsigned 검토/최종 거부 및 signed 통과, DRAFT 허용, 권한 회귀·제출 스냅샷 보존을 확인한다. 운영 DDL 적용 뒤 PR 검사·병합·READY 및 버전/health를 확인한다.
