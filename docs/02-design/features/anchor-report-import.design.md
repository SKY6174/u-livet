# 기존 운영 결과보고서 연결 - 설계

2026-09-19 · anchor-report-import

## 데이터

life_offerings에 ARCHIVED 상태를 추가한다. 이 상태에서만 접수기간·수강료·선발방식 null을 허용한다. 기존 DRAFT/PUBLISHED/CLOSED는 필수값을 유지한다. 기존 read_offering은 ARCHIVED를 공개 상태로 취급하지 않으므로 운영자만 조회한다. 공개·신청 RPC의 기존 DRAFT/PUBLISHED 검사도 유지한다.

ReportPayload에 선택적인 sourceReport를 추가한다. 파일명/SHA-256, 모집인원, 수료인원, 총시수, 회차수, 장학금 집계, 확인사항을 보관한다. 숫자 범위와 문자열을 양쪽 검증기로 검사한다. 기존 보고서와 미리보기는 sourceReport가 없어도 동작한다.

ARCHIVED 보고서의 인원·시수는 원문 집계로 표시하고 개인별 전산 승인 수와 구분한다. 실제 출결·강의실적 기록은 0개로 유지한다. 원본 PDF를 상단에서 바로 열 수 있으며 날짜·시간 불일치는 확인사항으로 노출한다. 원본 사진은 PDF 안에 보존한다.

## 등록

원본 파일은 Git 제외 경로에서 읽는다. 로컬 private manifest와 준비한 SQL에만 원본 경로·자료를 저장하고, 코드에는 개인 자료나 PDF 본문을 넣지 않는다. 원본 SHA-256과 등록 감사기록을 기준으로 중복을 방지한다. 명시한 운영 기관·사업연도·담당 운영자·기존 PDF 크기/매직 바이트를 확인한다. 과정·버전·기수·보고서·PDF·관리 작업 감사기록을 한 트랜잭션으로 저장한다. 사용자 세션을 위조하지 않고 실제 관리 API 실행과 업무 담당자를 구분한다.

교육기간은 각 결과보고서 표지 기준이다. 반려동물은 8/5~8/21, 파크골프는 7/14~7/21, 쿠키는 7/20~7/31이다. 교육시간은 원문 합계 30/35/30시간이다. 시간표의 세부 충돌을 임의 정정해 차시나 출석으로 입력하지 않는다.

## 검증

로컬 합성자료로 보관 상태 제약, 정상 모집 필수값, 보고 집계 검증, 익명 비공개·운영자 조회, 보고서 저장/재조회, 기존 학습 회귀를 검사한다. 원본의 표지·성과·강의표·예산 페이지를 시각 대조한다. 운영 등록 후 3개 연결·원본 지문·예산 합계·집계·기관/역할 경계와 운영 화면을 확인한다.
