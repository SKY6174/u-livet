# 강의 일정 출력 표 조정 설계

2026-09-23 · anchor-schedule-print-layout

## 출력 구조

일정 입력 데이터는 변경하지 않고 `document-preview.tsx`에서 출력 전용 표현으로 변환한다.

### 날짜·시간 셀

- 날짜: 기존 `date()` 결과를 공백 없는 `YYYY. MM. DD.` 형식으로 출력한다.
- 시간: 시작 또는 종료시간이 있으면 `(HH:mm ~ HH:mm)` 형식으로 다음 줄에 출력한다.
- 헤더는 `일자`와 `(시간)`을 두 줄로 표시한다.

### 주제 셀

- 원문의 공백과 괄호는 보존한다.
- CSS `word-break: keep-all`, `overflow-wrap: break-word`를 사용하여 한국어 어절 중간의 불필요한 분리를 줄인다.
- 주제 열 폭을 가장 넓게 배정한다.

### 강사 셀

- 주강사·보조강사 이름 열은 네 글자 이름이 한 줄에 들어가도록 고정 폭을 배정한다.
- 이름에는 `white-space: nowrap`을 적용한다.
- 머리글 `교육시간`은 `교육`과 `시간` 두 줄로 강제 분리한다.

### 장소 셀

- 문자열 마지막의 괄호 묶음을 호실로 간주한다. 예: `스포츠재활 실습실 (G-110)` → `스포츠재활 실습실` + `(G-110)`.
- 마지막 괄호 앞의 장소명은 한 줄을 우선하고, 호실은 다음 줄에서 줄바꿈하지 않는다.
- 괄호가 없으면 전체 장소명을 그대로 출력한다.

## 열 배치

- 결과보고서: `4 / 16 / 30 / 8 / 7 / 8 / 7 / 20`.
- 운영계획서: 결과보고서의 8열 뒤에 수업방식과 공휴일 열을 유지하되 전체 폭을 계획서용 비율로 축소한다.
- 합계 행의 병합 범위는 일자·시간 통합에 맞춰 4칸에서 3칸으로 줄인다.

## 검증

- 렌더링 보조 함수의 날짜·시간·장소 분리 사례를 회귀 스크립트에서 검사한다.
- 결과/계획 출력 DOM 구조와 헤더 줄바꿈을 정적 검사한다.
- 린트와 production build를 실행한다.
- 가능하면 실제 과정의 미리보기 또는 PDF 렌더링에서 표를 육안 확인한다.
