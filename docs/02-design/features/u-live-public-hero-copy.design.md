# 공개 첫 화면 문구와 제목 줄바꿈 설계

2026-09-28 · [계획](../../01-plan/features/u-live-public-hero-copy.plan.md)

## 표시 규칙

- 비로그인 홈 히어로의 작은 영문 제목을 `U-LiVE · Lifelong Vocational Education & Training`으로 바꾼다. 기존 브랜드의 가운데점 구분 기호와 글자 간격은 유지한다.
- 한글 제목의 글자는 `새로운 배움을, 여기에서 시작하세요.`로 유지한다. 사용자가 첨부 화면의 문구 유지를 선택했다.
- 제목의 `max-w-3xl` 제한을 없애고 기존 `md:text-6xl` 크기를 유지한다. 1024px·1280px 실측에서 제목이 영역 안에 들어가므로 `lg` 이상에서 한 줄을 유지한다.
- 좁은 화면은 한 줄 강제를 적용하지 않고 기존처럼 줄바꿈한다. 소제목도 필요하면 자연스럽게 줄바꿈한다.

## 변경 지점과 확인

- `src/app/page.tsx`의 비로그인 분기 2개 문자열/클래스만 수정한다.
- DOM 너비와 실제 줄 수를 390px, 1024px, 1280px 이상에서 확인한다.
- 인증·DB·메타데이터·링크·다른 페이지는 수정하지 않는다. lint·TypeScript·빌드가 통과해야 한다.
