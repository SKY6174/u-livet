## 화면 구조

`/completion/[id]`의 `수강생별 판정과 승인` 영역만 바꾼다. 기존 `CompletionRow[]`와 서버 액션, 권한 검사는 그대로 둔다. 카드 반복을 단일 의미론적 `<table>`로 바꾸고 수강생 한 명을 한 행으로 배치한다. 열은 순번, 수강생, 출석률, 수강·환불 상태, 판정 결과, 산출 시각, 근거·처리로 구성한다. 큰 화면에서도 개별 카드 테두리를 쓰지 않고 행 구분선과 옅은 hover 배경을 사용한다.

출석률과 충족 여부, 환불 문서·실제 환불 상태, 최신 판정의 오래됨·승인 여부, 산출 시각을 행에서 직접 읽을 수 있다. 판정 사유와 회차·과제·시험 근거는 근거 열의 `<details>`로 펼쳐 본다. 재산출 버튼은 처리 열에 바로 표시하고, 승인 대상자의 확인란·승인 버튼은 같은 열의 `수료 확정` 펼침 영역에 둔다. 기본 상태에서 행 높이를 다른 학습자와 비슷하게 유지한다. 자기 승인 방지 조건과 예시 모드의 버튼 비활성화는 변경하지 않는다.

표의 고정 최소 너비를 제거하고, 큰 화면에서는 페이지 폭 안에서 열 너비를 배분한다. 수강생명·상태·버튼 문구는 열 안에서 줄바꿈한다. `xl`보다 좁은 화면에서는 각 학습자의 셀을 두 열의 세로 목록으로 배치하고 셀별 항목명을 함께 표시한다. 따라서 수평 스크롤이 필요하지 않다. 표에는 시각적 열 머리글과 스크린리더용 설명을 둔다.

## 변경 및 확인

- 변경 파일: `src/app/completion/[id]/page.tsx` 한 곳.
- 데이터베이스·API·판정 규칙 변경 없음.
- TypeScript, ESLint, Next build 실행. 검증용 두 기수에서 행 정렬, 근거 펼침, 처리 버튼 표시를 확인한다.
