## 화면 구조

`/completion/[id]`의 `수강생별 판정과 승인` 영역만 바꾼다. 기존 `CompletionRow[]`와 서버 액션, 권한 검사는 그대로 둔다. 카드 반복을 단일 의미론적 `<table>`로 바꾸고 수강생 한 명을 한 행으로 배치한다. 열은 순번, 수강생, 출석률, 수강·환불 상태, 판정 결과, 산출 시각, 근거·처리로 구성한다. 큰 화면에서도 개별 카드 테두리를 쓰지 않고 행 구분선과 옅은 hover 배경을 사용한다.

출석률과 충족 여부, 환불 문서·실제 환불 상태, 최신 판정의 오래됨·승인 여부, 산출 시각을 행에서 직접 읽을 수 있다. 판정 사유와 회차·과제·시험 근거는 마지막 열의 `<details>`로 펼쳐 본다. 재산출 및 승인 `ActionForm`은 해당 행에 둔다. 승인 체크박스와 자기 승인 방지 조건, 예시 모드의 버튼 비활성화는 변경하지 않는다.

좁은 화면에서는 `role="region"`, 제목 연결, 키보드 포커스가 가능한 가로 스크롤 컨테이너 안에 최소 너비를 둔 표를 표시한다. 화면 밖의 열은 스크롤로 접근한다. 표에는 시각적 열 머리글과 스크린리더용 설명을 둔다.

- 데이터베이스·API·판정 규칙 변경 없음.
