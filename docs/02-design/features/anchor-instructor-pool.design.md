# 강사 Pool 설계

## 화면
- `/admin/instructors`: 파란색 강조의 관리 헤더, 기관 선택, 전체/교내/교외/서류 준비/지급 대기 요약. `강사 마스터`, `강의·활동 이력`, `수당 지급`, `이력 심사` 탭.
- 마스터: 이름·교내외·소속/부서/직위·전문분야·참여 과정·서류 상태·누적 지급액·관리 링크. 검색과 20명 페이지네이션. 등록 전에도 기존 강사 역할/배정/제출 이력을 연결해 보인다. 빈 대장에서도 열 구조와 신규 등록 동선을 제공한다.
- 기본정보 등록/수정: 기존 강사는 person ID로 연결하고, 신규 강사는 로그인 없는 대장 인물로 등록한다. Pool 등록만으로 로그인·강사 역할·과정 배정을 생성하지 않는다. 교내외·소속·부서·직위·전문분야·연락처·이메일·비고·활동 상태를 기록한다.
- 기존 계정 이름은 공통 신원에서 읽으며 이 대장에서 임의 변경하지 않는다. 계좌·주민번호는 평문 대장/엑셀에 입력하지 않는다.
- 기존 비공개 서류 접근 범위에 같은 기관의 활성 Pool 인물을 추가한다. 교내 강사는 기본 서류 면제 표시, 교외는 신분증/통장/이력서 제출 상태 표시. 담당자가 서류 필요 여부를 변경할 수 있다.
- 활동: 실제 배정 과정과 확정 강의실적 자동조회. 별도 활동·수당은 과정 선택(같은 기관만) 또는 외부 활동명으로 등록. 자동연계 강의 자체를 지급완료로 간주하지 않는다.
- 수당: 날짜·종류·시간·단가·총액·공제액·실지급액·근거·준비/지급완료/취소 상태. 시간×단가/60을 원 단위 반올림한다. 세율을 추정하지 않는다. 지급완료에는 지급일·거래/결의번호·근거가 필수이며 이체는 외부에서 처리한 기록을 저장한다. 완료/취소 건은 수정 불가, 취소 사유와 원기록을 보존한다.
- 엑셀: 신규 강사 일괄등록은 미리보기·검증 후 명시 저장. xlsx 최대 2MB/200행. 목록/수당 다운로드는 현재 기관의 필터 결과, 민감 원문 제외. 동명이인을 이름만으로 연결/덮어쓰지 않는다.

## 데이터·권한
- `life_private.instructor_pool`: org/person 유일, 등록 요청 UUID, 기본정보, 서류 필요 여부, ACTIVE/INACTIVE, optimistic revision, 생성/수정자·시각.
- `life_private.instructor_allowances`: org/person, 선택 offering FK, 활동명·일자·종류·분·단가·공제·근거, PLANNED/PAID/CANCELLED, 지급일/참조, revision 및 감사 이력. 등록 요청 UUID로 재시도 중복 방지.
- RLS 활성화, 테이블 직접 접근 회수. public security invoker wrapper → private definer에서 유효 세션/MFA/person_id 및 기관 COURSE_MANAGER 검사. 입력·enum·금액·날짜·기관·revision을 DB에서도 검사한다.
- 기존 역할/배정/심사 union과 Pool을 조회하며 타 기관 인물 ID로 신규 연결을 허용하지 않는다. 새 인물의 로그인 계정은 만들지 않는다.
- 활동 기록은 인물별 지급 합계에만 반영하고 기존 결과보고서의 이름 기반 강사료를 자동 복제하지 않는다. 실제 배정/승인 강의와 지급 기록은 서로 출처를 표시한다.
- 부적합·미비 서류를 지급 준비로 표시하지 않는다. 지급완료 기록 시 필수 서류를 서버에서 다시 확인한다. 누적 지급은 PAID만 합산하며 취소는 제외한다.
- 자료는 실제값만 사용하며 운영에 예시 강사나 지급액을 심지 않는다.

## 검증
실제 로컬 Auth RPC로 다른 기관·일반 강사 접근 거부, 새 인물/기존 강사 연결, 수정 충돌, 일괄등록 원자성, 중복 요청, 과정 기관 불일치, 공제액 검증, 필수 서류/지급 근거, 완료 불변/취소 합계, 서류 접근, RLS 직접 접근을 검사한다. 합성 자료로 UI·모바일·엑셀을 검수하고 가상 운영 자료는 정리한다.

## 구현 보완
- 기본정보 저장마다 `instructor_pool_history`에 당시 구분·소속·부서·직위·활동 상태를 기록하고 최근 20건을 표시한다.
- 수당 등록 시 강사 소속 스냅샷을 별도로 보관한다. 이후 기본정보 변경이 과거 수당의 구분·소속에 영향을 주지 않으며 상세 및 엑셀에 당시 값을 출력한다.
- 지급 상세는 목록 페이지·필터와 독립된 권한 검사 RPC로 조회한다. 활동 저장 후 해당 상세로 이동하여 중복 제출을 줄인다.
- 운영에 이미 적용된 첫 마이그레이션은 유지하고 후속 마이그레이션으로 이력 기능을 추가한다.
- 강사 신규 등록은 등록 서식·엑셀 등록·엑셀 다운로드와 같은 도구 줄에서 엑셀 다운로드 바로 오른쪽에 배치한다. 좁은 화면에서는 줄바꿈을 허용하며 등록 링크와 접근 권한은 유지한다.
