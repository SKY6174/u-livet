강사 이력 심사 기준
버전: INSTRUCTOR-REVIEW-2026-09-20-v2

1. 적용 범위
이 기준은 U-LIFE에 본인이 제출한 전문분야와 학력·산업 경력·강의 경력·자격 이력의 사실 확인에 적용합니다. 이력 확인 승인만으로 강사 역할, 위촉·계약, 과정 배정, 강사료·등급을 부여하지 않습니다. 과정별 강사 선발 요건과 실제 위촉은 별도 기관 절차를 적용합니다.

2. 제출 및 확인 항목
신청자는 전문분야와 심사용 소개를 작성하고 하나 이상의 이력 근거를 제출합니다. 각 이력에는 종류·명칭·기관·증빙 참조를 기재하며 기간·유효기간을 기재한 경우 실제 자료와 일치해야 합니다.
담당자는 제출된 모든 이력에 대해 발급기관과 문서 참조, 해당하는 기간·자격 유효기간 및 확인 가능한 외부 증빙을 대조합니다. 이 시스템은 자격기관의 자동 진위조회 결과를 제공하지 않습니다. 확인하지 못한 항목을 확인 완료로 기록하지 않습니다.

3. 심사 결과
- 승인: 제출된 이력을 증빙과 대조했고 불일치가 해소된 경우, 확인 근거와 유효기간을 기록합니다.
- 보완 요청: 정보·증빙 참조 누락 또는 추가 확인이 필요한 경우, 보완할 항목과 사유를 안내합니다.
- 반려: 확인 결과의 불일치가 해소되지 않거나 제출 요건을 충족하지 못한 경우, 근거와 사유를 안내합니다.
등록된 과정 담당자만 심사하며 본인의 이력을 직접 승인·반려·보완 결정할 수 없습니다.

4. 유효기간과 변경
담당자는 확인 자료의 효력과 재확인 필요 시점을 근거로 승인 유효기간을 개별 지정합니다. 제출 자격의 만료일보다 길게 설정할 수 없습니다. 기본 승인기간·점수·등급·강사료를 자동 부여하지 않습니다.
제출 이후 수정은 새 버전으로 보완합니다. 새 버전 생성 시 기존 공개 소개가 숨겨지고 최신 버전을 다시 심사합니다. 만료·정책 효력 종료·계정 상태 변경 등으로 현재 승인이 유효하지 않을 수 있습니다.

5. 문의와 철회
신청자는 본인 작성·제출 버전을 철회할 수 있고, 심사 결과·정정·재검토 문의는 앵커사업단 이연향 연구원(052-230-0427, yhlee4@uc.ac.kr)에게 접수합니다. 이전 제출 내용과 결정은 변경 이력으로 남습니다. 개인정보 삭제는 강사 이력 개인정보 안내의 별도 요청 절차를 따릅니다.
