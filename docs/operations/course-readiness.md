# 관리자의 과정 준비 판단 기준

2026-10-07 운영 DB와 현재 구현 기준.

원서 승인은 제출한 서류의 처리 상태이다. 실제 개설 기수의 모집 공개, 수강 신청, 수강 등록은 별도로 완료해야 한다.

| 단계 | 관리자가 확인할 내용 | 완료 판단 |
|---|---|---|
| 실제 기수 | DB 개설 과정, 담당 조직, 교육·모집 일정, 정원, 수강료, 교육장소 | 원서에 유효한 실제 기수 연결. 종료된 기수로 신규 등록 불가 |
| 승인·공개 | 개설 과정 관리 → 모집 공개에서 승인된 ‘모집·수집이용 정책’과 ‘수료기준’ 선택. 개발 제안에 연결된 과정은 최신 승인 확인 | ‘과정 승인·모집 공개’ 성공, `DRAFT`에서 `PUBLISHED`로 변경 |
| 유료 과정 | 승인 환불 규정, 조항별 계산 기준, 납부 안내와 기한 | 공개 전에 유료 설정 저장; 수강생 유료 신청 동의 확보 |
| 실제 신청 | 수강생이 공개된 기수의 수강 신청과 최신 정책 동의 완료 | 실제 신청내역 존재. 서류 제출·원서 승인만으로 대체되지 않음 |
| 등록 확정 | 신청 심사 승인 또는 서류함의 ‘수강 등록 확정’. 정원·기수·원서·동의 확인 | 무료는 수강 등록 완료; 유료는 납부 대기 후 납부 처리 완료 |
| 나의 학습 | 실제 수강 등록 상태와 교육 종료일 | 등록 `ACTIVE`이고 종료일이 오늘 이후 또는 오늘. 시작일 전에도 표시 가능. 종료된 등록은 학습 기록으로 분류 |
| 수업 운영 | 담당 강사 배정, 수업 회차의 날짜·시간·장소, 출석 운영, 필요한 강의자료·콘텐츠 | 실제 수업 가능한 상태. 강사·회차 등록은 나의 학습 표시 자체의 필수 조건은 아니지만 운영 준비에는 필요 |

## 확인한 두 과정

- 산과 필라테스 자격증과정: 기수는 2026-10-10 ~ 2026-12-05, `DRAFT`, 신청·수료 정책 미연결, 강사 1명, 수업 회차 0건. 승인 정책 선택 후 모집 공개와 실제 신청·등록을 진행한다.
- 도수물리치료 전문인력양성과정: 카탈로그에 연결된 기수는 2026-07-01 ~ 2026-07-16 종료 기수, `DRAFT`, 신청·수료 정책 미연결, 강사 1명, 수업 회차 0건. 새 유효 기수를 만들거나 준비된 기수를 선택하고, 화면에서 ‘과정 연결 필요’인 승인 원서에 실제 기수를 연결한다.

## 구현 근거

- `life_private.publish`: 승인 모집·수료 정책, 유료 환불 기준, 개발 제안의 최신 승인 검사.
- `life_private.link_learner_document` / `admit_learner_document`: 기수 연결, 승인 원서, 실제 신청, 최신 정책 동의, 모집 상태·교육기간·정원 검사.
- `life_private.my_learning`: 실제 신청·수강 등록 기반 조회. 원서 상태만으로 학습 과정 생성 안 함.
- `src/lib/student-learning/model.ts`의 `courseStage`: `ACTIVE` 등록과 교육 종료일로 현재 학습/학습 기록 구분.

이 확인 작업에서는 운영 과정의 모집 공개, 신청 심사, 수강 등록 또는 삭제를 실행하지 않았다.
