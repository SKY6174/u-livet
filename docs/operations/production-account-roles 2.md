# 운영 계정 역할 등록 기록

2026-09-20 · 운영(`uc-life.org`) · 사용자 지정 계정 처리

## 교외 강사

- 운영에 이미 가입한 지정 계정의 이메일 확인·활성 상태와 연결된 회원을 확인했다.
- 사용자의 명시적 요청에 따라 앵커사업단의 `INSTRUCTOR` 역할을 부여하고 `EXTERNAL`로 분류했다.
- 적용 시각: 2026-09-20 13:31:29 UTC (22:31:29 KST).
- 운영 DB 재조회 결과 유효한 강사 역할은 1개이며, 역할 부여와 분류 변경 감사 기록이 각각 1개 존재한다.
- 사업단 역할·과정 배정·이력 심사 결과는 이번 등록에 포함하지 않았다.
- 홈페이지 역할 표시는 실제 역할과 강사 분류를 읽으므로 새로고침 후 `강사(교외)`로 표시된다.

## 수강생

- 요청받은 다른 이메일은 운영 Auth에 등록되어 있지 않았다.
- 사용자는 초대 메일 대신 운영에서 Google 로그인 후 직접 가입을 완료하는 방식을 선택했다.
- 운영의 `수강생 → Google 로그인`에서 해당 계정을 선택하고 이름·휴대폰 번호·개인정보 동의를 완료하면 기본 수강생으로 등록된다.
- 수강생은 별도 업무 역할 행을 추가하지 않는다. 가입 완료 전에는 등록 완료로 간주하지 않는다.
- 계정·개인정보 동의 대행 생성이나 초대 메일 발송은 수행하지 않았다.

이메일·회원 식별자 등 대상별 증거는 Git에서 제외한 비공개 운영 기록에 보관한다. 역할 원장은 운영 DB에 적용되며 Git push는 이 작업 기록을 동기화한다. 스테이징 계정의 권한은 변경하지 않았다.
