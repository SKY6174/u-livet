## 사용 방법

각 과정의 ‘원문 편성 정보’는 PDF 계획값이다. 현재 모집이나 실제 개강 여부를 뜻하지 않는다. ‘소개·교육내용 제안’은 과정명에 맞춰 새로 작성한 검토용 문안이며 담당 강사의 강의계획서 확인 후 확정한다.

검토 후 과정 소개는 관리자 등록 화면의 ‘과정 소개’에, 교육내용은 ‘교육내용·대상·준비사항’에 옮길 수 있다. 미정인 접수기간·신청 자격·수강료·선발 방식·수료 기준은 먼저 확정해야 한다. 현재 초안은 운영 DB에 저장하지 않았다.

### 소개·교육내용 제안

**과정 소개**

가구와 소품의 시공 과정을 이해하고, 측정과 작업 준비부터 조립·설치·마감 점검까지 단계별로 익히는 실습 중심 과정입니다. 작업 계획과 결과를 기록하며 시공 절차를 설명하는 능력을 기릅니다.

**학습목표**

- 작업 대상과 공간을 살펴 필요한 치수와 준비 항목을 정리한다.
- 강사의 지도 아래 조립·설치 과정을 연습하고 작업 순서를 설명한다.
- 완성 결과를 점검하고 보완할 내용을 기록한다.

**교육내용**

1. 가구·소품 시공의 흐름과 작업장 이용 안내
2. 도면·치수 읽기와 작업 대상 측정
3. 재료·부자재·도구의 이해와 작업 준비
4. 조립·설치 절차 실습
5. 마감 점검, 결과 기록 및 피드백

**활동 결과 예시**: 측정 기록지, 작업 순서표, 실습 결과 사진과 점검표. 실제 제작물과 사용 장비는 강사 확인 후 결정합니다.

### 확정할 내용

- 달력상 8회 × 3시간은 24시간이다. 원문 30시간과의 차이 6시간은 실제 차시표로 확인한다. 임의 보강일을 만들지 않는다.
- 실습할 가구·소품, 제공 재료, 개인 준비물 및 별도 재료비 여부.
- 모집 대상·선수 경험, 선발 방식, 접수기간, 수강료, 수료 기준.

### 소개·교육내용 제안

**과정 소개**

산과필라테스 분야의 교육 주제와 수업 구성 방법을 살펴보고, 지도안 작성과 모의 수업을 통해 설명·시연 역량을 기르는 과정입니다. 강사가 확정한 교육자료를 바탕으로 이론 학습과 실습을 연결합니다.

**학습목표**

- 강사가 제시한 교육자료의 주요 내용을 정리한다.
- 수업 목표·진행 순서·설명 내용을 담은 지도안을 작성한다.

**교육내용**

1. 과정 운영 안내와 산과필라테스 교육 영역 소개
2. 담당 전문가가 선정한 이론 자료 학습
3. 수업 설계와 설명·시연 방법
4. 강사 지도하의 실습 및 모의 수업
5. 지도안 발표, 피드백 및 학습 내용 정리

**활동 결과 예시**: 학습 정리 노트, 수업 지도안, 모의 수업 피드백 기록. 실습 대상과 참여 조건은 담당 전문가가 정합니다.

### 확정할 내용

- 달력상 9회 × 6시간은 54시간이다. 원문 50시간과의 차이 4시간은 휴게시간·휴강 등 실제 편성을 확인한다.
- 대상자의 선수 자격, 실습 범위·참여 조건, 장소별 수업 배정, 준비물.
- 원문에는 자격증 명칭만 있다. 발급기관·자격 정보·응시요건·평가 방식·응시 및 발급 비용·별도 신청 여부를 확인한 뒤 자격 안내를 작성한다. 과정 이수만으로 자격증 취득을 보장하는 문구를 사용하지 않는다.
- 접수기간, 수강료, 선발 방식, 수료 기준과 실제 수강신청·수료 규정.

## 공통 입력 및 인력 구분

| 항목 | 현재 초안 처리 |
| --- | --- |
| 아카데미 | 전체 체계는 스마트테크·라이프케어·로컬창업·팝업. 이 문서는 우선 후보 3개만 포함 |
| 개설 여부 | 후보 단계, 개설 대상 선택 필요 |
| 접수기간 | 미정. 한국시간 시작·마감 날짜와 시각 필요 |
| 신청 대상·자격 | 미정. 소개문의 학습목표를 신청 자격으로 사용하지 않음 |
| 수강료·선발 방식 | 미정. 사업 예산 또는 등록 폼 기본값으로 결정하지 않음 |
| 수료 기준 | 미정. 위 활동 결과 예시는 승인된 수료 평가 기준이 아님 |
| 강사 구분 | 각 강사를 교내·교외로 확인 후 표시. 확인 전에는 미확인 유지 |
| 보조강사 / 보조인력 | 서로 다른 항목으로 유지. 원문 ‘-’는 미기재이며 인력 불필요 확정이 아님 |
| 개인정보 공개 | 인력명은 내부 편성 대조용. 수강생 페이지 표시 여부는 실제 배정·공개 범위 확인 후 결정 |
| 운영 담당자 | 기존 관리자 시범 운영. 별도 담당자 권한 연결은 추후 진행 |

담당 강사의 교육내용 검토 → 모집 조건·실제 차시·규정 확정 → 기존 관리자 계정으로 과정 초안 등록 → 신청·수료 정책 연결 → 모집 공개 순서로 진행한다.
