## 계정과 시스템

운영 계정 1개는 이메일 인증과 TOTP 등록을 완료했다. 현재 활성 역할은 SYSTEM_ADMIN뿐이며 COURSE_MANAGER는 0개다. 시스템 관리 역할이 과정 운영 권한을 포함하지 않으므로 실제 과정 운영 담당자를 확인해야 한다.

현재 운영 과정·기수는 0개다. 2026 사업연도는 2026-03-01~2027-02-28로 등록돼 있다. 수강신청(ENROLLMENT)·수료(COMPLETION) 정책은 아직 없다. 이 두 정책은 현재 앱의 공개 처리에서 검사하는 필수 항목이다.

DB에서 MFA 등록 상태를 확인했으며, 실제 로그인 세션의 AAL2·관리자 화면 접근을 확인한 것은 아니다. 현재 컴퓨터 사용 도구는 Mac 잠금 상태를 반환했고, 연결된 앱 내 브라우저에는 운영 로그인 탭이 없었다. 계정 비밀번호·인증 코드는 이 문서나 채팅으로 수집하지 않는다.

## 반영 순서

1. 확정된 담당자에게 해당 조직의 과정 운영 역할을 연결하고 본인 MFA 로그인으로 접근을 확인한다.
2. 선택된 과정의 필수값을 확정하고 기존 초안 등록 경로로 저장한다.
3. 확정된 신청·수료 정책 및 필요한 유료 정책을 연결한다.
4. 공개 후 수강생 화면의 과정명·일정·정원·모집상태와 신청 조건을 대조한다.
5. 실제 운영 과정으로 보고서·첨부·출력을 인수한다. 수료 실적이나 출석을 시험 목적으로 만들지 않는다.

현재 완료: 원본 대조, 운영 상태 점검, 개설 후보·누락값·차시 확인표 준비. 현재 미완료: 담당자 확정, 역할 연결, 과정 초안 등록, 정책 확정 및 모집 공개.
