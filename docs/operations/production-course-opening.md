DB에서 MFA 등록 상태를 확인했으며, 실제 로그인 세션의 AAL2·관리자 화면 접근을 확인한 것은 아니다. 현재 컴퓨터 사용 도구는 Mac 잠금 상태를 반환했고, 연결된 앱 내 브라우저에는 운영 로그인 탭이 없었다. 계정 비밀번호·인증 코드는 이 문서나 채팅으로 수집하지 않는다.

- 2026-09-19 사용자에게 성명·업무용 로그인 이메일을 받아 지정했다. 계정 조회 결과 해당 이메일의 Auth 계정은 0개다.

- 성명·이메일은 운영 감사기록 및 Git 제외 `ops/evidence/production-opening/`에만 남긴다. 담당자 지정은 계정 생성이나 권한 부여 완료를 뜻하지 않는다.

- 초대 메일 발송, 동의 대행, 비밀번호 설정, 실제 담당자 역할 부여는 아직 수행하지 않았다.

## 반영 순서

1. 이미 과정 운영 역할이 연결된 기존 관리자의 시범 운영 계정으로 본인 MFA 로그인·접근을 확인한다.
2. 선택된 과정의 필수값을 확정하고 기존 초안 등록 경로로 저장한다.
3. 확정된 신청·수료 정책 및 필요한 유료 정책을 연결한다.
4. 공개 후 수강생 화면의 과정명·일정·정원·모집상태와 신청 조건을 대조한다.
5. 실제 운영 과정으로 보고서·첨부·출력을 인수한다. 수료 실적이나 출석을 시험 목적으로 만들지 않는다.
