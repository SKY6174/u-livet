# 강사 이력 등록 준비 상태

2026-09-20 · 실제 등록 개방은 기관 승인 대기

운영과 Preview에는 ACCOUNT_PRIVACY v1/v2/v3만 있고 INSTRUCTOR_PRIVACY·INSTRUCTOR_REVIEW는 없다. 가입 문안은 강사 심사 업무를 별도 안내 대상으로 명시한다. `life_start_dossier`는 두 강사 정책과 본인의 개인정보 동의를 요구한다.

화면 수정은 최초 초안과 보완 버전에 같은 준비 상태를 적용한다. 안내문이 하나면 선택값·본문을 자동 표시하되 동의는 자동 선택하지 않는다. 미등록 시 빈 필수 목록과 제출 버튼 대신 누락 항목·사업단 문의처를 표시한다. DB 조건이나 동의 기록은 우회하지 않는다.

기관 검토 대상:
- [개인정보 안내 제안](instructor-privacy-v1.txt): 이력·증빙 참조 및 결정 이력, 계정 폐쇄 시까지 보유, 본인 동의, 별도 공개 동의.
- [이력 심사 기준 제안](instructor-review-v1.txt): 제출 증빙의 사실 확인, 보완·반려 사유, 개별 유효기간. 강사 등급·강사료·위촉·과정 선발 기준을 새로 정하지 않는다.

사용자는 앞서 ‘강사 등록·자격 심사 기준은 미확정 — 기준 등록 후 사용’을 선택했다. 위 제안을 검토·승인하기 전에는 실제 정책의 APPROVED 상태로 등록하지 않는다. 승인 시 검토안 표제·상태 문구와 ‘제안합니다’ 표현을 확정 문구로 바꾼 동일 본문을 버전 등록하고, Preview → Production 순서로 유효 정책 반환을 확인한다. 기존 이용자의 동의를 대신 기록하지 않는다.
