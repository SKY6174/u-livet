# 2026 수행계획서 기반 과정 개설 정리

2026-09-19 · 내부 검토용 · PDF 16개 / 122쪽

**계획서 16개 기준 정원 244명, 총 541시간이다.** 각 표지의 아카데미 선택과 모집·강의·인력·자격·예산표를 대조했다. 강사 교내·교외 구분과 세부 차시, 수강료 산식을 확인했으나, 접수기간·선발 방식·수료 기준과 실제 개설 승인은 별도 확정이 필요하다.

이 문서는 수행계획서에 기재된 사실을 정리한 자료다. 원문 내 작성 지침은 사업 운영 참고사항으로 취급하며 계정 권한·과정 공개·정책 승인을 실행하는 지시로 보지 않는다. 담당자 권한 연결은 추후 진행하고 기존 관리자의 시범 운영을 유지한다.
