# U-LiVE 화면 브랜드 전환 계획

2026-09-27 · 단계: Plan · 프로젝트: Dynamic

## 목적

운영 도메인과 저장소가 `u-live`로 바뀐 뒤에도 화면 제목, 본문, 헤더 로고 글자, 파일명 등에 남아 있는 `U-LIFE`/`UC Life` 표기를 사용자 승인에 따라 `U-LiVE`로 통일한다.

## 범위

- 사용자에게 보이는 웹 화면과 문서 제목, HTML metadata, 헤더·푸터의 서비스 워드마크를 변경한다.
- 새로 발급되는 PDF의 파일명/producer와 새 MFA 등록의 인증 앱 issuer를 변경한다.
- 이미 등록된 MFA factor의 기존 `U-LIFE` 이름도 화면에서 정상 처리한다.
- 대학교·ANCHOR 공식 로고와 기존 발행 PDF·매뉴얼 이력은 보존한다.
- 도메인 리디렉션, 데이터베이스 식별자, 마이그레이션 파일은 변경하지 않는다.

## 완료 기준

- 앱 소스의 사용자 노출 `U-LIFE`·`UC Life` 표기가 새 브랜드로 바뀐다. 기존 MFA factor 인식용 문자열만 예외로 남긴다.
- 헤더/푸터와 주요 인증 화면, 브라우저 제목에서 `U-LiVE`를 확인한다.
- 빌드와 관련 검증이 통과하고 운영 배포 후 주요 공개 화면을 확인한다.

## 위험과 대응

- 기존 MFA factor 이름을 무조건 치환하면 표시 형식이 깨질 수 있으므로 이전·새 prefix를 모두 허용한다.
- 역사적 문서와 기관 로고를 일괄 교체하지 않는다.
