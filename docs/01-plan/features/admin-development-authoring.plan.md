# 관리자 과정 등록·수정 계획

2026-10-08

## 목표
- `/admin/development`에서 기관 과정담당자가 신규 과정 제안 초안을 만들고 작성한다.
- 기존 과정 수정은 같은 기관 과정을 대상으로 개편 제안을 작성하게 한다.
- 관리자 본인의 미제출 초안은 관리자 목록과 상세에서 다시 찾아 수정할 수 있다.

## 제약
- 다른 작성자의 미제출 초안은 공개하지 않는다.
- 제출·승인된 버전은 직접 변경하지 않고 후속 버전으로 수정한다.
- 작성자 자신의 제안을 스스로 승인할 수 없다.
- 관리자 권한은 DB에서 기관별로 재검증한다.
- 2026년 앵커사업단 과정 16개가 산학협력단 운영 목록에 섞이지 않게 기관 소속으로 조회·저장을 제한한다.
- 운영 관리 화면의 등록 진입을 `+ 과정 등록` 버튼으로 명확하게 표시한다.

## 검증
- 관리자·비관리자 및 다른 기관의 등록/수정 권한, 초안 가시성, 본인 승인 차단을 확인한다.
- UI와 마이그레이션, lint/build, 배포 후 버전을 확인한다.
