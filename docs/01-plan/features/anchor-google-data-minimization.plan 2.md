# Google 로그인 정보 최소화

- 사용자 요청(2026-09-20): 프로필 사진을 수집 항목에서 제외한다.
- 기존 이용자별 로그인 설계의 최소 권한 원칙에 따라 Google 요청을 계정 식별·이메일로 줄이고 이름은 가입 화면에서 받는다.
- Preview 로그인·이메일 계정 연결·강사 권한 보존을 검증한다. 기존에 저장된 사진 메타데이터와 새 인증 응답은 구분해서 확인한다.
- Google을 반영한 계정 안내 v3는 검토용으로 준비한다. 운영 개방은 실제 최소화 검증과 기관 문안 승인 후 진행한다.
- 완료 기준: 사진 권한 없는 요청, 기능 회귀 점검 통과, 실제 인증/잔존 데이터 검증 결과 기록, 검토 가능한 안내문과 적용 순서.
- 기존 상세 설계: `docs/02-design/features/anchor-login-audiences.design.md`의 Google 개인정보 최소화 절.
