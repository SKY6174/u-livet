# 화면 설명 말풍선·표 가독성 조정 계획

2026-10-10

## 목적

- 제목 아래 반복 노출되는 설명을 화면 진입 시 한 번 나타나는 말풍선으로 전환한다. 평상시에는 설명이 자리만 차지하지 않되 필요할 때 다시 열 수 있어야 한다.
- 표 안의 화면용 글자를 현재보다 1.5px 작게 조정하고, 표의 동작 버튼과 주요 공통 버튼을 가능한 한 한 줄로 표시한다.

## 범위

- 공통 `PageIntro` 제목 설명을 재사용 가능한 일시적 안내로 전환한다. 첨부 화면의 접수 문서 안내는 동일한 말풍선에 합쳐 중복 팝업을 피한다.
- 공통 화면 CSS의 표 글자 크기와 버튼 줄바꿈 기준을 조정한다. 표의 가로 스크롤은 유지한다.
- 업무·검색·신청 로직, 알림·오류 메시지, 중요 확인 문구, 인쇄 서식은 유지한다.

## 완료 조건

- 페이지에 들어오면 제목 옆 말풍선이 한 차례 나타났다가 사라지고, 정보 버튼·키보드로 다시 열 수 있다.
- 접수 문서 제목·목록의 두 설명이 평소 본문에 표시되지 않고 안내 내용은 보존된다.
- 표 안 `text-sm` 등 주요 크기가 기존보다 1.5px 작고 신청서/삭제 등 버튼이 한 줄로 표시된다.
- 360/720/1440px에서 수평 넘침이 없고 lint·타입 검사·빌드·운영 배포 검증이 통과한다.
