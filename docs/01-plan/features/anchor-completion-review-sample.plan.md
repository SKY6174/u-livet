# 수강생별 수료 판정 화면 검토용 예시

> Feature: anchor-completion-review-sample | 2026-09-25

## 목적

수강등록자가 없는 과정에서도 운영자가 수료 판정·승인 화면의 필드와 배치를 확인할 수 있게 한다. 실제 개인정보, 출석, 환불, 수료 승인 기록에는 테스트값을 섞지 않는다.

## 범위

- 운영 환경에서 요청받은 건강식생활지도사(`0e822298-e2c6-4bc2-a3f3-5f908370871a`)와 실버푸드전문가과정(`be13635d-2625-4f81-ab2d-7f30551289d3`)을 우선 확인한다.
- 수강등록자가 없는 수료 검토 화면에 `예시 데이터로 화면 보기` 링크를 제공한다.
- 수료 확정, 승인 대기, 기준 미달, 중도 환불, 출결 미완료, 자료 변경 사례를 합성 수강생으로 표시한다.
- 예시 모드에 명확한 표시를 두고 저장·산출·승인 동작을 비활성화한다.
- 실제 데이터 보기로 돌아가는 링크를 제공한다. 기존 역할 검사를 유지한다.

## 완료 조건

- 예시 화면에서 수료율 카드, 학습자별 출석률·환불 배지·판정 근거·승인 버튼의 배치를 확인할 수 있다.
- 실제 DB에는 어떠한 합성 학습자나 수료 기록도 저장되지 않는다.
- 테스트 데이터는 실제 업무 화면과 섞여 보이지 않는다.
