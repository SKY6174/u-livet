# 연결 과정의 기본 정보와 복수 교육장소 — Plan

2026-10-07 · linked-course-locations

## 현황과 목표

과정 안내(`life_course_guides`)와 실제 개설 과정(`life_offerings`)은 `offering_id`로 연결되지만 과정명·장소·방식·정원·교육기간은 별도로 저장·수정되어 불일치할 수 있다. 연결된 과정은 실제 개설 과정의 기본 정보를 기준으로 자동 반영하고, 두 화면에서 수정 경로를 명확히 구분한다.

- 연결된 과정의 공통 기본 정보는 개설 과정 화면 한 곳에서 수정한다. 안내 화면은 값을 보여주고 해당 수정 화면으로 이동시킨다.
- 개설 전 안내 과정의 기본 정보는 기존 안내 화면에서 수정한다.
- 교육장소를 여러 행으로 입력·표시할 수 있도록 한다. 기존 장소 문자열은 손실 없이 유지한다.
- 요일·시간 추가 버튼 문구와 크기를 요청대로 조정한다.

## 완료 기준

- 두 화면의 연결 여부와 각 필드의 저장 출처가 UI에서 드러난다.
- 연결된 과정의 기본 정보 수정이 DB 트랜잭션 안에서 공개 안내에 반영되고, 안내 화면의 독립 수정으로 다시 어긋날 수 없다.
- 장소 2~3곳을 추가·수정·삭제하고 재열기 및 공개 화면에서 확인할 수 있다.
- 기존 16개 과정의 장소 문자열을 보존한다.
- 정적 검사·빌드·DB 검증·운영 배포를 확인한다.
