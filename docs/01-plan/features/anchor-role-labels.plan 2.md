# 이름 앞 사용자 역할 표시

작성일: 2026-09-19. 사용자 요청: 헤더에서 이름 앞에 관리자·운영자·강사·수강생 구분을 표시하고 Git에 반영한다.

- 데스크톱 헤더와 모바일 메뉴에 동일한 역할 표시를 제공한다.
- 서버가 확인한 현재 유효 권한을 기준으로 한다. 동명이인 및 동일 이름의 역할별 테스트 계정을 구분한다.
- 사용자 지정 담당자 구분: 송경영 단장·현용환 센터장은 관리자, 이연향 연구원·이현섭 책임연구원은 운영자다.
- 담당자 이름을 권한 판정 조건으로 쓰지 않는다. 이 변경에서 신규 계정 생성이나 권한 부여는 하지 않는다.
- 기존 SYSTEM_ADMIN과 COURSE_MANAGER의 업무 접근 범위를 유지한다.
- 여러 역할의 표시 우선순위와 업무별 권한의 운영자 묶음을 상세설계에 기록한다.

완료 기준: 네 가지 표시, 복수 권한 우선순위, 비로그인, 모바일 화면을 실제 컴포넌트로 확인한다. lint·빌드 통과 후 main·preview에 같은 변경을 푸시하고 배포 버전을 확인한다.
기존 기준: [인증·권한 설계](../../02-design/features/anchor-core-flow.design.md).
