# 이용자별 로그인

- 로그인 진입을 사업단, 강사(교내), 강사(교외), 수강생의 네 가지로 구분한다.
- 사업단 직책은 단장·센터장·연구원이며 검증된 계정의 등록 직책을 표시한다. 버튼이나 본인 입력으로 업무 권한을 부여하지 않는다.
- 교내 강사는 학교 이메일(@uc.ac.kr)과 U-LIFE 전용 비밀번호로 로그인한다. 초대 후 비밀번호 설정·복구 방법을 안내한다.
- 승인된 교외 강사는 카카오 소셜 로그인으로 기존 강사 업무를 사용할 수 있다. 새 가입자는 기존 강사 심사를 거쳐야 한다.
- 사용자 결정: 네이버·구글 개발자 앱 미준비. 두 제공자는 준비 중 표시, 공통 로그인 연동 경로와 설정 안내를 준비하고 실제 연결·개방은 후속이다.
- 기존 MFA, 계정 정지·세션 폐기, 개인정보 동의, 휴대폰 필수 입력·미인증 저장 정책을 유지한다.
