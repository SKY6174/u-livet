# 승인된 수강신청원서의 나의 학습 표시 계획

2026-10-07 · Dynamic

## 문제

운영 DB에는 승인된 수강신청원서가 있지만 해당 문서는 `offering_id`가 없고, 같은 사람의 `life_applications` 및 `life_enrollments` 기록도 없다. `life_my_learning`은 실제 온라인 신청과 등록만 반환하므로 나의 학습은 모든 수치를 0으로 표시한다. 문서 승인과 수강 확정은 서로 다른 상태인데 화면에는 그 차이가 드러나지 않는다. 해당 소개 과정과 연결된 운영 기수도 DRAFT이며 모집 기간과 수업 기간이 끝났다.

## 목표

- 나의 학습에서 본인의 수강신청원서 접수·승인 상태와 담당자 안내를 확인할 수 있다.
- 승인된 원서의 건수를 실제 수강 등록 건수와 분리해 표시한다.
- 관리자 처리 화면에서 과정 연결이 없는 원서의 승인 의미를 명확히 안내한다.
- 이미 승인된 운영 문서도 별도 데이터 변경 없이 수정 배포 직후 표시한다.

## 범위와 제한

- 기존 본인 범위 RPC `life_my_learner_documents`와 학습 RPC `life_my_learning`을 함께 읽는다.
- 원서 승인만으로 수강신청·등록·납부·수료 기록을 만들지 않는다. 폐강·초안·만료 과정에 대한 허위 등록과 정책·정원 우회를 막는다.
- 문서의 자유 입력 과정명을 운영 기수 ID로 추정해 연결하지 않는다.

## 완료 기준

- 승인된 원서만 있고 수강 등록이 없는 본인은 원서 승인 1건과 나의 수업 0과정을 명확히 본다.
- 실제 등록 과정은 기존 강의실 집계에 그대로 표시되고, 서류 조회 실패를 0건 성공으로 위장하지 않는다.
- 본인 문서만 표시되며 관리자 화면은 승인과 수강 등록의 차이를 안내한다.
- 관련 UI 검사, lint, 타입 검사, 빌드가 통과한다.
