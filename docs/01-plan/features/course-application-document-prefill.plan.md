# 과정에서 수강신청원서 작성·가입정보 자동 입력 계획

2026-10-07 · 사용자 직접 요청 · `codex/course-application-document`

수강생은 과정을 먼저 검토하고 해당 과정의 수강신청원서를 바로 작성해야 한다. 기존 `/mypage/documents`의 원서·PDF·접수 흐름을 재사용하며, 과정 식별자만 URL에 전달하고 본인 가입정보는 서버의 인증 세션에서 읽는다.

1. 공개 과정 상세·운영 기수 상세·기존 신청 화면·나의 학습 신청 목록에 과정별 원서 팝업 진입점 제공.
2. 원서 신청과정명을 서버 카탈로그의 선택한 과정으로 자동 입력. 비로그인 팝업에서 로그인해도 과정 선택 유지.
3. 가입 때 수집한 성명·이메일·휴대전화 자동 입력. 관리 등록의 저장된 생년월일도 있을 때만 사용. 모든 값은 검토·수정 가능.
4. 가입에서 수집하지 않은 주소·성별·신청목적, 서명·원서 동의는 사용자 직접 입력. 가입 동의를 원서 동의로 복사하지 않는다.
5. 기존 원서 접수·PDF 및 실제 모집 신청/기간·권한 검사는 유지. 원서 작성 버튼 클릭이나 자동 입력만으로 신청을 접수하지 않는다.
6. 합성 계정·A/B 과정으로 실제 팝업·로그인·자동 입력·접수·DB 연결 및 기존 회귀 검사. lint/build 후 push·PR·merge·Vercel 운영 배포 확인.

새 DB 필드나 마이그레이션 없이 현재 가입 데이터와 서류 컴포넌트를 연결한다. 디자인 전용 브랜치는 보존하고 별도 기능 브랜치에서 작업한다. 기존 승인·수료 이후 장학/환불 자격을 변경하지 않는다.
