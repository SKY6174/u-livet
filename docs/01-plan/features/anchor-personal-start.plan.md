# 로그인 중심의 개인 시작화면

## 목표
- 첫 접속은 기존 사업단·강사(교내)·강사(교외)·수강생 로그인 선택 화면으로 안내한다.
- 가입과 필요한 인증을 마친 이용자는 기존 남색 메인 화면을 개인 시작화면으로 이용한다.
- 이름과 실제 역할에 맞는 업무 바로가기를 제공한다.

## 범위와 검증
- 기본 로그인·OAuth·가입 완료·MFA 도착지를 `/`로 통일한다.
- 명시적으로 요청한 업무/과정 링크는 유지하고, 로그아웃 후에는 로그인 선택 화면으로 돌아간다.
- 공개 과정 안내는 계속 비로그인 열람이 가능하다. 실제 권한·가입 동의·MFA 규칙은 유지한다.
- 역할별 렌더링, 로그인 목적지, 가입 대기·MFA·로그아웃을 회귀 검증하고 데스크톱/모바일 화면을 확인한다.
- main·preview에 같은 커밋을 push하고 두 배포의 시작 경로를 확인한다.
