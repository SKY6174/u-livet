# 간편 로그인 가입 여부 자동 분기 계획

2026-09-21 · 사용자 요청: 선택 화면 제거, 가입 여부 자동 판별, 검증 후 Git push.

카카오·Google·네이버 인증 후 기존 회원은 바로 로그인하고 미가입자는 신규 가입 양식을 표시한다. 별도의 회원가입/로그인 선택을 요구하지 않는다. 같은 인증 사용자에 연결된 기존 이메일 가입도 완료된 가입으로 인정한다.

## 범위와 완료 기준
- 서버의 가입 상태에 따라 COMPLETE는 원래 목적지, PENDING은 가입 양식으로 이동한다.
- 기존 이메일 가입자는 Auth가 안전하게 연결한 동일 사용자 ID의 가입 완료 기록으로 판단한다.
- 미가입자는 이름·휴대폰 번호·필수 동의를 제출하기 전까지 회원 권한이 없다.
- 정지 계정, 세션 검증, 사업단·교내 강사의 이메일 로그인 정책 및 MFA는 유지한다.
- 선택 화면과 전용 로그아웃 액션을 제거하고 관련 회귀 검사를 갱신한다.
- 서버·DB 회귀 검사와 lint/build 후 원격 Git 및 운영에 반영한다.

검증되지 않은 이름·전화번호로 다른 사용자 계정을 자동 병합하지 않는다. 실제 이용자의 개인정보·동의 기록을 테스트 데이터로 변경하지 않는다.

2026-09-21 후속 요청: 세 제공자 모두 공통 가입 판별을 적용하고 callback·DB 검사를 제공자별로 실행한다. 제공자 활성화와 실제 연결 자격 증명은 기존 설정을 따른다.
