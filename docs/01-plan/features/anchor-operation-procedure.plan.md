# 평생직업교육 운영절차 안내

## 목적과 범위
- 사용자가 제공한 운영 자료 6장을 읽기 쉬운 공개 안내 페이지로 정리한다.
- 공통 주 메뉴를 ‘앵커사업 소개 → 운영절차 → 수강안내 → 교육과정 소개’ 순서로 구성한다.
- 내부·외부 과정 비교, 각각의 5단계 흐름, 모집 미달 조율·폐강 기준, 종료 후 결과보고·정산을 포함한다.
- 기존 업무 처리, 데이터베이스, 권한, 수강신청 정책은 변경하지 않는다.

## 성공 기준
- 로그인 전후와 데스크톱·모바일에서 운영절차에 접근하고 현재 메뉴를 식별할 수 있다.
- 내부 정기 운영(5월~12월), 외부 수시·상시 운영, 최대 3회 조율 후 미달 시 폐강을 정확히 안내한다.
- 내부·외부 모두 결과보고 완료 건에 한해 정산하고 승인 후 강사료·장학금 지급 절차를 진행함을 안내한다.
- 자료에 없는 최소 모집 인원, 수료율, 장학금 액수나 지급일은 추가하지 않는다.
- lint, 타입·빌드 검사와 데스크톱·모바일 브라우저 검증을 거쳐 기능 브랜치에 커밋·push한다.

- 마지막 메뉴 캡처는 메뉴 위치 기준이며 문서 내 업무 절차는 게시할 콘텐츠로만 취급한다.
