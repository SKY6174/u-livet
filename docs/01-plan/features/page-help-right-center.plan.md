# 페이지 안내 말풍선 오른쪽 정렬 계획

2026-10-10 · 사용자 요청: i 클릭 시 안내문구를 i 오른쪽, 수직 중간에 표시.

## 현재 상태와 목표

공통 PageDescriptionHint는 제목 영역의 왼쪽 아래에 말풍선을 표시한다. 버튼을 기준으로 오른쪽에 배치하고 말풍선과 버튼의 수직 중심을 맞춘다. 화살표도 왼쪽에서 버튼을 가리킨다.

## 범위와 완료 기준

- 공통 컴포넌트의 위치·반응형 배치를 수정한다.
- 추가 요청에 따라 과정 운영 카드의 “우선 승인 교내 강사” 라벨과 해당 이름·인증 상태 표시 영역을 제거한다. 지정 책임강사 표시는 유지한다.
- 문서 카드의 기관·연도를 “앵커사업단∙2차년도”로 줄이고 프로그램 ID 오른쪽에 우측 정렬한다. 로컬창업 아카데미 배지는 “C1-LOCAL-BUSINESS-00”으로 표시한다.
- 자동 표시·자동 닫힘·버튼 토글·닫기·Escape·접근성 이름을 유지한다.
- 좁은 화면에서는 안내 버튼 그룹을 제목 다음 줄에 두어 오른쪽 말풍선의 읽을 공간을 확보한다. 말풍선은 뷰포트 안의 가용 폭을 사용한다.
- 실제 브라우저에서 좌우 위치·수직 중심·가로 넘침·클릭·닫기를 확인하고 lint·타입 검사·운영 빌드를 검증한다.
- PR 생성·push·병합·운영 배포 커밋 및 READY 상태를 확인한다.
