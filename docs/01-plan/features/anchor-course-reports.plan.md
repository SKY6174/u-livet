# 과정별 운영 결과보고서 계획

2026-09-19 · 사용자 요청: 6종 서식, 운영진 이연향 연구원, 강사 출결 입력, 운영진 강사료 입력, git push.

## 목표
- 기존 과정 관리에 보고서 관리 진입점을 추가하고 6종을 개별 또는 일괄 인쇄/PDF 저장한다.
- 원본 PDF의 항목을 재사용 가능한 서식으로 구성한다. 실제 개인정보·서명·계좌·기존 과정 수치는 저장소에 복사하지 않는다.
- 강사 입력 출결과 승인된 수료 데이터를 연결하고 운영진이 보고서, 장학금, 강사료를 저장한다.
- 현재 담당자 표시 기본값은 이연향 연구원이며 계정·권한은 기존 기관 역할 체계를 사용한다. 계정 생성은 후속 작업이다.
- 원본 PDF 6종 및 운영사진을 과정별 보관하고 열람한다.

## 검증
기관/강사 권한, 입력 검증, 동시 수정 충돌, 합계, 미입력과 결석 구분, 오래된 수료승인 제외, 첨부 권한을 로컬 DB와 브라우저에서 확인한다. lint/type/build 후 preview 브랜치에 커밋·푸시한다.
