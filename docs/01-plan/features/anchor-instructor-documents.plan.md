# 강사 장기보관 서류 제출

uc-anchor의 전문가 서류 제출 화면과 비공개 Supabase 저장 방식을 uc-life 강사에게 제공한다. 신분증·통장사본 최초 제출/변경, AI 영역 분리 및 정보 추출(OpenAI → Gemini), 이력서 암호화 임시저장/완료 저장, A4 PDF 미리보기/보관을 포함한다.

uc-life 로그인과 기관별 강사/담당자 권한을 사용한다. 서로 다른 사이트의 이름만으로 개인정보를 자동 연결하지 않는다. 기본 저장소는 uc-life 프로젝트이며 기존 anchor 서류 공유는 확인된 연결 근거가 있어야 한다.

검증: 타입 검사, 린트, 프로덕션 빌드, 비로그인/타인/권한회수/만료 접근 차단, 암호화 왕복, Storage 비공개 여부, 임시저장과 완료본 분리, 실제 브라우저 입력 및 PDF 생성. 작업 파일만 커밋하고 main에 push한다.
