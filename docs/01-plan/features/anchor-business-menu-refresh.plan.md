# 사업단 메뉴·업무 홈 개선 계획

> Date: 2026-09-21 | Status: Approved by user request

기존 완료된 `anchor-business-menu`의 사용자 피드백 반영을 별도 PDCA 주기로 기록한다.

- 상위 메뉴 클릭은 `/admin` 이동, 호버는 메뉴 열기.
- 서브메뉴명만 표시하고 오른쪽에 호버·포커스 설명 제공.
- 중복 가로 메뉴, 이름·역할 안내 문구 삭제.
- 업무 홈에 강조 카드, 아이콘, 반응형 그리드, 절제된 호버 효과 적용.
- 권한과 기존 URL 유지. 타입·린트·회귀·빌드·브라우저 검증 후 git push.

상세 범위와 설계는 `anchor-business-menu.design.md` 버전 2.0.0을 따른다.
