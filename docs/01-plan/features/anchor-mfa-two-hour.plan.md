# 관리자 추가 인증 유효시간 2시간 계획

2026-09-24 · `anchor-mfa-two-hour`

관리자 저장·승인에 적용되는 최근 TOTP 인증 유효시간을 15분에서 2시간으로 늘린다. 화면의 안내와 실제 DB 판정을 함께 바꿔 표시와 동작을 일치시킨다.

## 범위

- `life_private.mfa_recent()`의 DB 인증 이력과 JWT AMR 시각 모두 최근 2시간으로 검사한다.
- `life_security_status().fresh_minutes`를 120으로 돌려주고 인증 화면에 `2시간`으로 표시한다.
- 기존 AAL2·유효 세션·조직 권한·재인증 요구는 유지한다. 토큰 갱신만으로 실제 인증 시각을 연장하지 않는다.
- 초대·비밀번호 복구 메일 코드의 15분, 인증 앱의 6자리 TOTP 자체 주기, 별도 보안 잠금 시간은 변경하지 않는다.

## 완료 기준

- 119분 전 인증은 유효, 121분 전 인증은 만료되며 만료 시 관리자 저장을 거부한다.
- 새 인증 후 저장이 복구되고, 토큰 갱신이나 오래된 JWT로 우회되지 않는다.
- 화면에는 최근 `2시간`으로 표시된다. 기존 MFA·로그인 회귀와 빌드를 통과한다.
- Preview DB·앱 검증 후 운영 DB·앱을 배포하고 `main`·`preview`를 푸시한다.
