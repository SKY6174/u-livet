# 과정 운영계획서·운영결과보고서

## 목표
첨부한 2026년 앵커사업 공식 계획서(8쪽)와 결과보고서(5쪽)의 항목·표·표지 구성을 재현하고, 과정에 연결된 하나의 작성·검토·최종제출 흐름을 제공한다.

## 역할과 범위
- 기관 SYSTEM_ADMIN 및 COURSE_MANAGER: 소속 기관 모든 과정의 책임강사 지정, 전체 내용/예산 수정, 보완 요청, 최종 제출, 제출 후 수정 재개.
- 명시적으로 지정된 책임강사: 본인 과정의 예산 이외 모든 항목 작성과 담당자 검토 요청. 일반 배정 강사에게 책임강사 권한을 자동 부여하지 않는다.
- 예산계획, 예산집행, 장학금 지원 금액은 담당자 입력. 원본 메모보다 사용자의 역할 분담을 우선한다.
- uc-anchor 전문가 자문서의 항목별 편집, 저장 상태, A4 실시간 미리보기, 서명과 제출 전 검토 방식을 참고한다.
- 기존 3개 보관 과정과 원본 보고서는 보존하고 기본정보/기존 집계를 초안으로 연결한다. 수료 승인이나 실제 수납 자료를 생성하지 않는다.

## 완료 기준
전체 원본 양식 항목 입력/저장/복원/출력 가능, 책임강사·다른 강사·관리자·비로그인 권한 검증, DB 예산변조 및 최종제출 우회 차단, 동시수정 충돌 처리, 최종본 이력 보존. 모바일·A4 시각 확인, lint/type/build, Supabase 적용, git push.
