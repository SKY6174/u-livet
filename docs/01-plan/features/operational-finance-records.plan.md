# 수납·환불·장학금 운영 조회 정리 계획

요청: 검증 자료를 운영 화면과 통계에서 제외하되 금액·상태·원장·기존 이력은 보존한다.

운영 전수 조사: 신규 청구/입금/환불/송금, 구형 payments, scholarship_disbursements 모두 0건. scholarships 3건은 지급 기록이 아닌 제도 정의다. 공식 문서 8개 및 구형 보고서 3개의 장학금 개별 지급 행도 0건이며 검증 문구가 없다. 과거 보고서의 확정 인원/금액과 제도 정의는 유지한다.

기존 운영 과정/인물 분류를 읽기 모델에 적용한다. 회계는 과정 필터만 있고 계정 필터가 없으며, 입금은 과정 연결 없이 조회되고 있었다. 학습자 장학금과 업무 현황 집계에도 같은 제외 기준을 적용한다. 이름/메모/거래 증빙을 새 정규식으로 추측 분류하지 않는다.

혼합 입금은 원입금과 미배분 잔액을 보존하며 운영 반영액만 검증 과정 배분액을 제외한다. 전액 검증 배분된 입금과 검증 계정 입금은 숨긴다. 정상 미배분액은 숨기거나 새 잔액으로 만들지 않는다. 쓰기/잔액 계산/권한/제출 문서/은행 거래를 변경하지 않는다.

검증: 로컬 혼합 자료·100건 제한 전 필터·집계·본인/기관 권한·원장 보존 테스트, Preview 마이그레이션/빌드, 운영 전후 원본 hash 및 함수 hash·보안 advisor, 실제 읽기 화면. PR 생성·push·병합·배포까지 수행한다.
