# 사이트 운영 문구 정리

- 요청: 사이트 전체의 검증용 문구·작성 요령을 점검하고 실제 운영 안내로 정리한 뒤 PR, 병합, 운영 배포.
- 범위: 전체 `src`/공개 매뉴얼 문자열, 공개 경로, 운영 DB의 과정 소개·교육내용·승인 정책, 로그인한 관리자의 수료·결과보고 화면.
- 확인: 수료의 `sample=1` 가상 수강생과 결과보고서 양식 검토의 가상 인원·일정·금액이 운영 화면에서 접근 가능하다. 학습자료·수업 일정의 빈 상태 및 인증 실패 안내가 일반적인 ‘준비 중’ 문구로 표시된다.
- 운영 안내로 바꿀 대상: 가상 예시 진입을 실제 자료 조회/작성 절차로 대체하고, 빈 상태와 사용 불가 상태를 구체적으로 설명한다. 수강안내의 증명·배지 안내는 발급 가능 여부·내역 확인 절차를 설명한다.
- 유지 대상: 검증 전용 과정/정책/증명/배지의 출처 경고, 과거 제출 문서·원본 PDF, 관리자 작성 필드 도움말, 미연결 문자 발송 경고, 실제 미승인·미등록 상태. 합성 기록을 실제 교육 실적으로 이름만 바꾸지 않는다.
- DB 감사: 공개 과정 안내에서 추가 검증/작성 요령 문구 0건. 잔여 검증 정책 4개와 합성 교육내용 3개는 명시적 검증 기록이다. 수정 없이 보존한다.
- 검증: 소스 검토, lint/타입/매뉴얼 검증, Preview 빌드, 운영 공개 페이지 및 관리자 실제 화면, `sample=1` 우회 조회 확인, 데이터 스냅샷 비교.
- 완료: 푸시·PR 체크·병합·운영 READY와 버전/health 확인, 운영 화면 증거와 범위/예외를 보고한다.
