# DB 연동 및 조회 최적화 계획

- 운영·스테이징 DB 연결, 마이그레이션 일치, 기관별 권한과 주요 읽기를 점검한다.
- 강사 관리·서류 목록의 기관 선택에 전체 정책 본문과 제안 자격까지 계산하는 RPC가 사용된다. 승인된 Identity의 COURSE_MANAGER 기관 ID로 이름만 읽어 불필요한 연산과 전송을 줄인다.
- 심사 상세에서만 필요한 정책을 읽고 대장 조회와 병렬 실행한다. 업무 RPC의 기관 권한 검사는 유지한다.
- 성능 점검 도구가 정상적인 `/` → `/auth/login` 이동을 실패로 처리하는 문제를 수정한다.
- 기존 DB 인덱스는 실제 실행계획에 따라 판단한다. 현재 소량 데이터에서 근거 없는 인덱스 추가나 정책 변경은 하지 않는다.
- 관련 쿼리 회귀, 권한·오류 처리, lint/빌드, 실제 환경 읽기를 검증하고 main/preview에 push한다.
