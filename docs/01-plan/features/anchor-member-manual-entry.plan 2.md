# 구성원 수동 등록 계획
2026-09-21 · anchor-member-manual-entry

- 사업단/강사/수강생 명부 수동 등록, 서버 검증 후 DB transaction 저장.
- 등록 권한은 송경영·현용환·이연향 전용으로 제한. 최고 관리자는 확인된 kysong@uc.ac.kr 사업단 계정. 동명이인 계정에 이름으로 권한을 부여하지 않는다.
- 이연향의 yhlee4@uc.ac.kr은 사용자 확인을 받았다. 현용환의 로그인 이메일은 사용자에게 확인 중이다. 미확인 계정에 임의 권한을 주지 않는다.
- 수강생 표에서 생년월일 다음, 수강이력 앞에 올해 수강과목을 표시. 전체 이력은 모든 연도 유지.
- 성공 기준: 비허용 계정의 직접 RPC 거부, 세 분류 등록/중복 방지/새로고침 후 유지, 연도 경계와 이력 보존, 기존 회귀/빌드/화면 확인, Preview/운영 migration 적용 및 git push.
