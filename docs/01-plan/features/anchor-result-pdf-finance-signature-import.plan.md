# 결과보고서 PDF 예산·장학금·원본 서명 가져오기

2026-09-22 · anchor-result-pdf-finance-signature-import

## 목표
- 완료된 원본 PDF의 예산집행표와 장학금 수치를 근거와 함께 제안하고 담당자가 선택해 저장한다.
- 원본에 실제 서명이 있으면 이미지와 쪽수를 보존해 출력한다. 원본 서명은 현재 책임강사의 최종 제출 서명과 구분한다.
- 이미 이관한 3개 과정의 검증된 예산·장학금 수치를 기존 초안에 채운다.
- AI 키가 없어도 정형 양식의 숫자 추출은 작동한다.

## 성공 기준
- 잘못된 금액과 불명확한 서명은 자동 반영하지 않는다.
- 담당자 예산 확정 → 책임강사 작성·서명 → 제출 권한은 유지한다.
- 원본 PDF와 가져온 값의 출처를 담당자가 대조할 수 있다.
