# 담당 기관 추가 계획

- 요청: 담당 기관에서 울산과학대학교 산학협력단, 울산과학대학교 앵커사업단을 선택할 수 있도록 한다.
- 현재: 운영·스테이징 모두 `uc-anchor` 기관 하나만 등록되어 있다. 현재 송경영 관리자는 이 기관의 SYSTEM_ADMIN과 COURSE_MANAGER를 보유한다.
- 범위: 산학협력단 기관 등록, 현재 총괄 관리자의 강사 관리 권한 연결, 기관명 정렬, 운영·스테이징 적용 및 main/preview push.
- 기존 강사·과정·서류·지급 기록의 기관은 변경하지 않는다. 일반 강사나 수강생에게 관리 권한을 부여하지 않는다.
- 확인: 두 기관의 중복 없는 등록, 관리자 옵션/대장 조회, 일반 회원 접근 거부, 재실행 중복 방지.
