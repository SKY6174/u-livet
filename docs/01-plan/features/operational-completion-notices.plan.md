# 전체 과정 수료 안내 운영 문안 점검

2026-10-17 · Feature `operational-completion-notices`

## 요구와 조사

전체 22개 과정과 모든 COMPLETION 정책을 확인하고 검증 문구·작성 요령을 운영 안내로 교정한다.
산과 필라테스 자격증과정만 실제 과정에 Issue124 검증 정책이 연결되어 있다.
실버푸드의 승인 정책 `2026-1`은 실제 안내인 ‘전체 과정 80% 이상 출석시 수료가능’이다.
작성 요령만 저장된 수료 정책은 없다. 나머지 검증 정책은 명시적 합성 과정에만 사용된다.
미공개·보관 과정의 미등록 기준을 임의로 만들어 공개하지 않는다.

## 작업과 완료 기준

- 산과 필라테스에 같은 사업단의 기존 승인된 80% 수료 정책을 연결한다.
- 과거 정책·과정 버전·신청·동의·수료 산출·확정 증빙은 보존한다.
- 공개 화면·관리자 선택지와 DB 연결 단계에서 검증 정책과 작성 요령을 차단한다.
- 수료 계산·두 사람의 계산 기준 승인·최종 확정 절차는 변경하지 않는다.
- 로컬 롤백 검증, lint·형 검사·Preview, 운영 DB 감사 및 전체 공개 안내 화면을 확인한다.
- PR 생성·push·병합·운영 배포와 실제 버전·health 확인을 완료한다.
