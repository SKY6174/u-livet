# 관리자 출석부 준비 상태 연결

2026-09-21 · 사용자의 연속 진행 요청에 따른 후속 보완.

## 문제와 목표
- 과정 운영 개요는 이미 출결 집계를 제공하지만, 수강 확정자·수업 일정이 없는 과정도 다음 작업이 결과보고서 작성으로 넘어갈 수 있다.
- 관리자가 강사 배정·수강 확정·수업 일정의 연결 상태와 담당 작업을 구별하도록 기존 운영 개요를 보완한다.
- 확정 시간표·명단이 없으므로 실제 개설·배정·수강 확정·출석 자료는 생성하지 않는다. 기존 보관 3개와 공개 소개 카드 정책을 유지한다.

## 범위와 완료 기준
- 기존 workspace 집계를 이용한 준비 상태 표시와 다음 작업 우선순위 수정. 추가 DB 요청·마이그레이션·권한 확대 없음.
- 관리자에게 담당 강사 화면으로 연결되는 권한 없는 링크를 주지 않는다. 관리자는 강사 배정·신청 심사를, 강사는 수업 일정·출결을 입력한다.
- 종료 수업 미입력, 수업 진행 중, 수료 검토, 보고서 작성을 구별한다. 개설 준비·보관 과정의 기존 우선 동작은 유지한다.
- 강사 일정 등록 양식에 실제 교육 구간 및 휴게시간 제외 안내를 보완한다.
- 준비 상태 조합, 보관 원본 집계와 개인 자료 분리, 다음 작업, 오류 화면·조회 수 회귀, 모바일/웹 화면·빌드 확인 후 main/preview push.
