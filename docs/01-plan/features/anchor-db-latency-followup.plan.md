# DB 지연 후속 개선 계획

2026-09-23 · anchor-db-latency-followup · Dynamic

## 목표와 범위

운영 DB 연결을 읽기 전용으로 점검하고, 최근 코드에서 남아 있는 조회 대기와 불필요한 전송을 줄인다. 이전 강의실 최적화는 유지한다.

- 공개 과정 목록: 실제 목록·검색에 필요한 필드만 조회한다. 과정 상세 데이터는 유지한다.
- 운영문서 편집: 인증·UUID 검사 후 서로 독립적인 context/list RPC를 병렬 실행한다. DB 권한 검사와 오류 처리를 유지한다.
- 실제 공개 REST 응답의 결과 동일성·크기와 교차 측정 시간을 비교한다. 보호된 편집기는 실행 회귀로 동시 시작과 접근 차단을 확인한다.
- lint, 빌드, 기존 관련 회귀 후 main에 통합하고 push·운영 배포 상태를 확인한다.

## 완료 기준과 위험

검색·정렬·과정 연결·상세 화면이 동일해야 한다. 비로그인·잘못된 ID는 DB 요청 전에 차단하고 FORBIDDEN은 404를 유지한다. DB 실패를 성공 빈 화면으로 바꾸지 않는다. 운영 자료·스키마·RLS·계정 설정은 변경하지 않는다. HTTP 측정 변동과 합성 시험을 실제 로그인 사용자 개선율과 구분한다. 기존 미추적 파일은 보존한다.
