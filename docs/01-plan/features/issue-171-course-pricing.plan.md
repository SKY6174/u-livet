# Issue 171: 과정 등록 아카데미 선택 및 수강료 계획

2026-10-13 · [이슈 #171](https://github.com/SKY6174/u-livet/issues/171)

## 목표

새 과정·기수 초안 등록에서 아카데미를 선택하고 유료/무료 및 1인 수강료를 설정한다. 폼 입력뿐 아니라 직접 등록·원문 연결 등록·임시저장과 복원까지 같은 값을 보존한다.

## 범위와 기존 계약

- 과정 안내 수정에 이미 사용하는 네 아카데미를 재사용하고 기존 임시저장/원문 아카데미 값도 복원한다.
- 무료는 0원, 유료는 기존 재무 설정과 같은 1~100,000,000원 정수 범위로 검증한다.
- 기존 등록 RPC를 유지하면서 수강료와 과정 초안을 한 트랜잭션으로 저장하는 새 RPC를 추가한다.
- 생성 상태는 DRAFT이며 유료 모집 공개의 기존 환불 규정·납부 안내 검증은 유지한다. 계획서 산식은 최종 수강료로 자동 확정하지 않는다.
- 13개 항목의 기존 임시저장본도 계속 읽고 새 가격 항목을 저장한다.

## 검증과 릴리스

모델·서버 액션·기존 개설 준비 회귀, 실제 DB의 무료/유료 저장·원문 연결·역할/기관·잘못된 가격·원자성·유료 공개 보호를 검증한다. 브라우저에서 선택 변경과 폼 유효성, 임시저장 복원, 모바일 배치를 확인한다. lint·타입·빌드 및 설계 대조 후 검증된 DB migration을 적용하고 PR·push·병합·운영 READY/revision/health를 확인한다.
