# U-LiVE 파비콘 교체 계획

2026-09-27

## 목표

- 사용자가 제공한 PNG 심볼을 사이트 파비콘으로 사용한다.
- 메타데이터의 아이콘 링크와 기존 `/favicon.ico` 호환 경로가 같은 심볼을 제공한다.

## 범위와 검증

- 원본 이미지를 색상·모양 변경 없이 정적 자산으로 추가한다.
- 루트 메타데이터와 Next.js rewrite를 새 자산으로 변경한다.
- 빌드 후 아이콘 링크와 `/favicon.ico` 응답을 확인하고, 운영 배포에서 다시 확인한다.
- 화면의 기관 로고와 기존 사용자 데이터를 변경하지 않는다.

## 위험

- 브라우저 캐시가 이전 파비콘을 잠시 유지할 수 있으므로 새 이미지 경로를 사용한다.
