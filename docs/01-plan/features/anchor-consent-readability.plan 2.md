# 가입 준비 안내와 동의 가독성 개선

2026-09-19 · anchor-consent-readability

성인학습자의 가입 화면에서 두 가지 혼란을 줄인다. 현재 승인 문안이 없는데도 개인정보 입력란이 표시되며, 승인 문안이 있을 때 본문은 접힌 14px 텍스트로 제공된다.

## 범위

- 가입에 필요한 승인 문안·인증 메일 준비가 없으면 입력 폼보다 준비 안내를 먼저 제공한다.
- 공개 과정 조회와 기존 계정 로그인 이동은 계속 제공한다.
- 승인 문안이 있을 때 개인정보 수집·이용 본문을 기본 펼침, 16px 이상으로 표시한다.
- 동의 체크는 기본 미선택이고 필수 입력이며, 서버 검증은 유지한다.
- 기관 보유기간·국외이전 판단·동의 자체를 대신하지 않는다. 새 정책/사용자/메일을 만들지 않는다.

## 완료 조건

가입 불가 상태에 개인정보 입력란·가입 제출 버튼이 없고 그 이유와 가능한 다음 행동이 보인다. 가입 가능한 화면은 승인 문안과 버전을 바로 읽고 직접 동의를 선택하도록 한다. 로그인은 기존대로 동작한다. 변경 파일 lint, 격리 빌드, 두 화면 상태 렌더링 확인, 배포된 준비 안내를 검증한다.
