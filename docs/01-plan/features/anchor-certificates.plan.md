# 이수증·강사 경력증명 계획

2026-09-19 · anchor-certificates · 전체 플랫폼 세 번째 구현 범위

수료 확정과 실제 강의실적을 기반으로 본인 발급 신청, 별도 발급권자의 승인, PDF 생성·보관·재다운로드, 최소정보 진위조회, 취소·정정 대체를 연결한다. 실제 기관의 D05 발급권/직인/서식은 미확정이므로 임의 명의나 직인을 운영 설정에 넣지 않는다. 로컬 가상 발급권은 검증 전용으로 명확히 표시한다.

경력증명은 강사가 제출하고 과정담당이 승인한 회차별 실제 강의분만 합산한다. 이수증은 최신 입력 revision에 맞는 별도 승인 수료만 인정한다. 수료 시간은 확인된 출결 근거가 있을 때에만 표시한다.
