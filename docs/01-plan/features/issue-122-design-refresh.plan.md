# Issue #122 디자인 개선 계획

2026-10-07 · https://github.com/SKY6174/u-livet/issues/122 · 브랜치 `codex/design-refresh`

일반인·재직자가 교육과정을 찾고 신청·신청 현황을 읽기 쉽게 공통 글자, 두 줄 헤더, 공개 홈, 과정 카드와 신청 화면을 개선한다. 기능·DB·권한 변경은 범위에서 제외한다. 기존 검색·신청·권한 메뉴·서버 검사를 유지하고 이미 읽고 있는 데이터를 화면에 명확히 표시한다.

1. 실제 파일과 참고 사이트의 데스크톱·모바일 전체메뉴 확인 및 변경 전 캡처.
2. 구현 기준 `u-livet-design-guide.md` 작성.
3. 공통 토큰·헤더 → 홈 → 과정 목록·상세·신청 → 나의 학습·관리자 명단 가독성 적용.
4. 360/768/1440px, 200% 확대, 키보드·역할별 메뉴·오류·빈 상태 확인.
5. #121의 실제 DB·관리자 연결 검증 재실행, 기존 린트·빌드·관련 회귀 통과.
6. 가이드·파일 목록·참고 및 전후 화면·검수 기록을 PR로 제출하고 승인된 push·merge·deploy 수행.

완료 조건과 상세 수치는 [설계](../../02-design/features/u-livet-design-guide.md)를 기준으로 한다. 기존 사용자의 미커밋 작업은 변경하지 않는다.
