# 운영 계정 명부에서 검증 계정 제외

2026-10-17 · 요청: 검증용·dummy 계정을 확인하고 원본 계정과 이력을 보존하면서 운영 화면에서 숨긴다. PR, push, merge, deploy까지 진행한다.

구성원 관리의 사업단·강사·수강생 목록, 인원수, 검색, 연도·구분 필터, 정렬·페이지 처리, 엑셀 내보내기와 기존 상세/이력 주소에 동일한 제외 기준을 적용한다.

실제 DB의 이름/이메일과 생성 자료를 조사해 검증 계정으로 확실한 기존 ID만 비공개 분류표에 기록한다. 실제 계정이 검증 과정에 참여했다는 이유만으로 계정을 숨기지 않는다. 원본 사람·Auth·역할·회원 상태·수강/강의/신청·감사 이력과 비밀번호를 수정하거나 삭제하지 않는다.

구현 전에 조회 경로와 권한 helper를 구분하는 설계를 작성한다. 기존 기관 범위, 인증, 페이지 크기와 내보내기 제한을 보존한다. 로컬 실제 SQL로 정상/검증 혼합 목록·페이지·총수·검색·필터·내보내기·직접 조회·권한을 검증하고, 운영 적용 전후 기존 데이터 count/hash와 보안 advisor를 비교한다. 배포 후 로그인한 운영 화면에서 재확인한다.
