# 운영대상별 매뉴얼 제작·버전관리 계획

작성일: 2026-09-22 · 기능: anchor-operation-manuals

## 목표와 사용자 요청
운영대상별 업무 매뉴얼을 웹과 배포용 문서로 함께 제공한다. 사용자가 두 형식 모두를 선택했다. 웹과 PDF는 동일한 원문을 사용하며 개정 전 문서도 보존한다.

## 범위
- 수강생, 교내 강사, 교외·보조강사, 과정 운영 담당자, 수료·증명 담당자, 수납·환불 담당자, 성과 담당자, 사업단·시스템 관리자 8종.
- 각 문서에 대상·권한 전제, 시작 경로, 업무별 절차·완료 확인, 일상 점검, 문제 대응을 제공한다.
- 웹 목록·검색·버전 선택·목차·PDF 다운로드·인쇄, 버전별 변경 이력.
- 버전별 원문·개별 PDF·전체 합본 PDF·Markdown 및 무결성 검증 도구, 개정 절차 안내.
- 현재 소스와 설계 문서가 근거다. 실제 운영 환경 검수와 기관의 정책 승인은 별도로 표시한다.

## 완료 기준
- 모든 대상의 문서를 실제 구현의 메뉴/권한과 대조한다.
- 웹과 배포본의 제목·내용·버전이 일치한다.
- 확정한 버전의 원문·배포파일 수정은 검사에서 거부하고 새 버전으로 개정한다.
- 존재하지 않는 대상/버전은 404, 검색 결과 없음은 명시적으로 안내한다.
- 모바일·인쇄 및 한글 PDF 렌더링, 타입·린트·관련 검증을 통과한다.

## 제외
원격 배포, 실제 업무 데이터 변경, 계정 권한 부여, 기관 정책 제정은 이번 제작 범위에 포함하지 않는다.
