# 수강생 내 정보 - 계획

## 목적
수강생이 헤더의 본인 이름에서 연락처와 선택 프로필 정보를 확인·수정한다. 현재 수강 신청·서류의 본인 정보와 같은 연락처 원본을 사용한다.

## 범위와 성공 기준
- 필수 휴대전화와 인증 이메일을 보여주고 변경할 수 있다. 휴대전화는 미인증 연락처이며 형식을 검증한다. 이메일 변경은 Supabase Auth 확인 완료 전까지 기존 주소를 유지한다.
- 선택 별명, 기본 캐릭터, 개인 사진을 설정하거나 지울 수 있다. 사진은 비공개 저장소에 보관하며 본인에게만 보인다.
- 헤더의 수강생 이름과 모바일 메뉴에서 내 정보로 이동한다. 본인 외의 계정은 수정할 수 없다.
- 수강생 서류 작성에 표시되는 전화번호가 변경된 연락처를 반영한다.
- 린트, 타입 검사, 빌드 및 권한·입력 검증을 통과하고 운영 배포를 확인한다.

## 제약
- 이름·역할, 계정 소유권과 승인된 정책은 수정하지 않는다.
- 사진과 별명은 수강 신청의 법적 이름을 대체하지 않는다.
- 인증되지 않은 새 이메일을 즉시 저장된 이메일로 표시하지 않는다.
