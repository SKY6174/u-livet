# 개설 준비 임시저장

2026-09-21 · 후속 진행: 모집기간·최종 일정이 미정이어도 16개 계획서의 입력 준비를 이어갈 수 있도록 한다.

- 현재 실제 기수 초안 저장은 모든 모집·교육 날짜가 필수여서 미정 상태의 편집 내용을 보관할 수 없다.
- 계획서별 개설 준비 입력을 DB에 임시저장하고 다음 방문에 복원한다. 기존 실제 기수 생성·모집 공개의 필수값과 승인 정책은 유지한다.
- 작성자 본인·관리 조직·계획서 ID별로 분리한다. 다른 관리자나 강사·학생에게 임시저장 내용을 공개하지 않는다.
- 빈 값은 미정으로 저장한다. 임의 날짜·수강료·강사 계정·실제 등록자를 만들지 않는다.
- 동시 편집 충돌 및 연결 실패 시 입력을 유지하고 저장본 다시 불러오기 경로를 제공한다.
- 로컬 실제 DB 권한/충돌/미정 값 검증과 UI·기존 개설 경로 회귀, 빌드·모바일 확인 후 Preview→Production migration 및 main/preview push.
