# 수강생 원본 서식 작성 — 계획

작성일: 2026-09-22 · 기능: anchor-learner-documents

## 목적과 범위
첨부 PDF 1페이지 수강신청원서, 2페이지 학습활동 우수 장학금 지급신청서를 각각 작성한다. 나의 학습에서 별도 창을 열어 왼쪽 입력과 오른쪽 실제 PDF 미리보기를 제공한다. 원본의 A4 크기, 여백, 글자, 색상, 표, 동의 문구를 보존한다.

## 완료 기준
- 원본 페이지를 벡터 템플릿으로 사용하고 예시 과정명·날짜만 제거한다.
- 각 서식의 인적사항, 동의 선택, 날짜, 자필 서명이 해당 칸에 반영된다.
- 두 서식의 작성 상태는 독립적이며 동의는 미선택으로 시작한다.
- 현재 PDF를 내려받으며 결과는 실제 PDF 1.7, 각 1페이지 A4이다.
- 다운로드는 서버 접수를 의미하지 않는다. 주민번호·계좌·서명은 브라우저 메모리에서만 처리하며 자동 저장·서버 전송하지 않는다.
- 실제 PDF 렌더링, 필드 검증, 모바일, 빌드 검증 후 git push한다.

## 위험과 대응
원본 재조판에 따른 차이는 원본 PDF 복사로 방지한다. 긴 값은 칸 안에서 축소하되 읽을 수 없을 정도인 값은 오류로 안내한다. 미리보기 갱신 중 이전 PDF를 다운로드하지 못하게 한다. 입력을 잃을 수 있는 창 닫기는 브라우저 이탈 경고로 보호한다.
