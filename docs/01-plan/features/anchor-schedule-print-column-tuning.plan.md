# 강의 일정 출력 열 미세조정 계획

2026-09-23 · anchor-schedule-print-column-tuning

## 목적

강의 일정 표에서 `회차` 머리글과 강의주제의 가독성을 높이고, 일자·교육장소 열의 여유 폭을 주제 열로 재배분한다.

## 범위

- 회차 열을 넓혀 머리글을 한 줄로 고정한다.
- 강의주제 열을 한글 한 글자 정도 넓힌다.
- 공백 뒤 마지막 괄호 설명을 다음 줄로 분리하고 한 줄 표시를 우선한다.
- 일자와 교육장소 열은 기존보다 소폭 줄인다.
- 결과보고서와 운영계획서에 동일한 원칙을 적용한다.

## 성공 기준

- `회차`가 한 줄로 표시된다.
- 대표 주제의 마지막 괄호 설명이 다음 줄에 배치된다.
- 표 전체 너비가 100%를 유지하고 셀 넘침이 없다.
- 회귀 검사, 린트, production build와 A4 브라우저 검증이 통과한다.
