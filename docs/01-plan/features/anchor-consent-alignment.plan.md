# 동의서 입력 정렬 및 서명 가독성

- 성범죄 동의서의 성명·국내/외국인 식별정보·연락처를 칸의 세로 중앙에 배치한다.
- 원본 동의자 라벨과 입력한 이름을 같은 기준선에 배치한다.
- 기존 및 새 서명은 PDF에서 굵고 선명하게 표시한다.
- 첨부 용지 설정: 좌우 10mm, 위 25mm, 아래 10mm, 머리말 10mm, 꼬리말/제본 0mm. 세 동의서에 공통 적용한다.
- 브라우저와 서버가 동일한 PDF를 생성하고 PDF 1.7·기존 제출 이력을 유지한다.
- 실제 PDF 렌더링, 글자/표 좌표 검사, 서버 타입 검사, production build 후 main push 및 배포 확인.
