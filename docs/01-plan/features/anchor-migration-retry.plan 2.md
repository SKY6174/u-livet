# anchor-migration-retry 계획

작성: 2026-09-19. 대상: ANCHOR / uc-life의 배포 마이그레이션 실패 진단 및 로컬 수정.

## 확인된 문제

- 원격 이력은 001~008인데 009·010에서 만드는 정책 이름이 이미 존재한다.
- 실제 branch action 로그에서 009의 `본인 및 관리자 프로필 조회 허용` 생성이 SQLSTATE 42710으로 중단됐다.
- 원격 Auth는 최소 6자, 문자 조합 미설정이다. 사용자가 정한 12자 이상 + 영문·숫자·특수문자(대소문자 동시 요구 없음)와 다르다.

## 범위

1. 009·010이 만드는 동명 정책을 재생성하기 전에 정확한 이름/테이블로 제거한다. 정책 조건·역할·권한은 바꾸지 않는다.
2. 별도의 로컬 임시 DB에서 원본 오류를 재현하고 신규 적용·재실행·일부 객체 존재 상태를 검증한다.
3. 기존 데이터, 정책 의미, 무관한 정책이 보존되는지 비교한다.
4. 실패 근거, 재시도 절차, Auth 배포 선택지를 운영 문서에 기록한다.

## 제외 및 완료 기준

- 원격 SQL/이력 보정, Auth 변경, Git push, 유료 리소스 생성, 외부 문의 발송은 이번 범위에 없다.
- .env.local을 읽거나 수정하지 않는다. 실제 회원정보를 로컬로 복사하지 않는다.
- 009·010의 기존 보안 설계 전체를 승인하는 작업이 아니다. 최신 life_ 스키마 및 기존 API 차단까지 별도로 검증해야 배포 가능하다.
- 로컬 회귀 검사 통과와 확인 가능한 보고서 작성으로 완료한다. 운영 출시 가능 여부와 분리한다.
