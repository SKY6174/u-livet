# 운영 증명·배지 발급 조회 정리

2026-10-17 · 요청: 수료증·배지 발급의 검증 자료를 확인하고 원본 이력을 보존하면서 운영 화면·통계에서 제외한다. PR/push/merge/deploy.

조사 결과 운영 DB의 수료증 신청/발급, 배지 정의/신청/발급, 구형 certificates/badge_assertions는 모두 0건이다. 삭제·취소할 발급 자료가 없음을 정확하게 보고한다. 기존 과정 제외만으로는 정상 과정에 연결된 검증 인물, test_only 발급권·발급 snapshot을 제외하지 못하는 조회 경로가 있어 공통 운영 읽기 모델을 보강한다.

범위: 증명 목록·상세·발급권 선택, 배지 정의/신청/발급 원장·본인 지갑·상세·선택지. 운영 집계는 동일한 필터가 적용된 관계를 사용한다. 별도 발급 통계 화면은 현재 없으므로 임의의 지표나 화면을 추가하지 않는다.

원본 요청/발급/정정·취소 이력, PDF/JSON 바이트와 해시, 토큰·공유 설정·증명 번호 카운터·감사 이벤트, 공개 QR 진위확인·상태 판정·기존 다운로드 권한/발급 helper는 보존한다. 기존 인증·기관/발급 위임·본인 권한 검사도 유지한다.

설계 후 로컬 정상/검증 혼합 자료로 목록과 count 집계, 직접 상세 차단, 권한, 원본 hash 보존을 검증한다. 운영 원본 aggregate count/hash·보안 advisor 비교, Preview/운영 체크와 실제 관리자 화면 확인까지 완료한다.
