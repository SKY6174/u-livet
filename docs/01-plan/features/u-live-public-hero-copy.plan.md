# 공개 첫 화면 문구와 제목 배치

2026-09-28 · u-live-public-hero-copy

## 요청

공개 첫 화면의 영문 소제목을 `U-LiVE · Lifelong Vocational Education & Training`으로 바꾼다. 큰 한글 제목은 첨부 화면의 기존 문구 `새로운 배움을, 여기에서 시작하세요.`를 유지하고, 충분히 넓은 화면에서 한 줄로 표시한다. 사용자가 첨부 화면 문구 유지를 확인했다.

## 범위

`src/app/page.tsx`의 비로그인 공개 히어로만 변경한다. 로그인 후 역할별 히어로, 다른 페이지의 문구·경로·인증·데이터 동작은 유지한다. 좁은 화면에서는 읽기 가능하도록 자연스러운 줄바꿈을 허용한다.

## 성공 기준

데스크톱에서 제목이 한 줄로 보이고 넘치지 않는다. 모바일에서는 가로 스크롤이나 메뉴 침범이 없다. lint·TypeScript·빌드와 로컬 브라우저 화면을 확인한 뒤 `main`으로 push한다.
