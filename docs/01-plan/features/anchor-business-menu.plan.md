# anchor-business-menu - Plan Document

> Version: 1.0.0 | Date: 2026-09-21 | Status: Approved
> Level: Starter

## Purpose

사업단 관리자 화면에서 현재 선택된 상위 메뉴와 하위 업무 메뉴의 관계를 명확하게 보여 준다.

## Goals

- 사업단 관리 상위 메뉴가 활성 상태일 때 배경, 글자, 포커스 상태로 쉽게 식별된다.
- 데스크톱에서 호버·포커스로 하위 메뉴를 열고, 클릭으로 고정해서 업무 메뉴를 선택할 수 있다.
- 모바일에서는 사업단 관리 항목을 눌러 하위 메뉴를 펼칠 수 있다.
- 기존 권한별 메뉴와 서버 권한 검사를 변경하지 않는다.

## Scope

- 공통 헤더의 사업단 관리 메뉴와 `officeSections` 기반 하위 메뉴 표시
- 키보드 포커스, Escape, 바깥 영역 포커스 이동 처리
- 데스크톱·모바일 반응형 스타일

## Non-goals

- 사업단 하위 메뉴의 권한 규칙이나 URL 변경
- 새로운 업무 메뉴 추가

## Success criteria

- `/admin` 및 사업단 하위 경로에서 상위 메뉴가 일관되게 활성 표시된다.
- 하위 메뉴에서 기존 권한별 경로를 바로 열 수 있다.
- 모바일 메뉴에서 가로 넘침 없이 같은 하위 메뉴를 사용할 수 있다.
