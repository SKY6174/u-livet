# 앵커사업 소개 개편 계획

- 목적: 공식 앵커사업단 자료를 바탕으로 4대 프로젝트와 RCC센터의 역할을 방문자가 쉽게 이해하도록 구성한다.
- 범위: `/about`의 소개 문안, 프로젝트별 사진·색상, RCC 역할, U-LIFE 교육과정 연결, 출처 표기.
- 원본: https://anchor.uc.ac.kr/rise/Main.do 및 여기서 연결되는 RCC 공식 사이트의 센터 소개.
- 프로젝트 순서: Dynamic TALENT → Dynamic BRIDGE → Dynamic JUMP → Dynamic CARE.
- 완료 기준: 공식 명칭·사진·색상 대응 확인, 모바일/데스크톱 가독성·이미지 로딩·링크 확인, lint/build 통과, main/preview push 및 배포 확인.
- 공개 소개만 변경하며 인증, 권한, 개인정보·심사 정책은 변경하지 않는다.
