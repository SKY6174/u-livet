# 결과보고서 커버 레이아웃 조정 계획

2026-09-23 · anchor-result-cover-layout

## 목적

결과보고서 커버의 페이지 번호, 기본정보 표, 책임강사 소속·성명·서명을 공식 제출본에 맞게 정돈한다.

## 범위

- 커버에는 페이지 번호를 표시하지 않고 두 번째 출력면부터 1쪽으로 번호를 매긴다.
- 기본정보 표를 `영역 → 세부프로그램명 → 교육기간 → 책임강사` 순서로 바꾼다.
- 표 행 높이를 현재보다 약 20% 키우고 글자 크기는 1.5px 확대하며 장평 100%를 유지한다.
- 승인된 책임강사의 소속을 운영문서 컨텍스트에서 함께 조회한다.
- 책임강사 행 안에 `소속 · 성명 · (서명)`을 배치하고 표 아래 중복 서명 영역을 제거한다.

## 제외 범위

- 운영계획서 커버의 담당교수 서명 방식은 변경하지 않는다.
- 책임강사 지정·승인 절차 자체는 변경하지 않는다.
- 기존 제출본의 본문·첨부 양식은 변경하지 않는다.

## 성공 기준

- 결과보고서 커버 중앙 페이지 번호가 비어 있고 두 번째 출력면이 `- 1 -`로 표시된다.
- 기본정보 표의 행 순서와 명칭이 요청과 일치한다.
- 책임강사의 승인 소속, 성명, 서명이 한 행 안에 표시되고 별도 서명 줄이 없다.
- 소속이 강사 풀에 없을 때 과정 운영기관 명칭을 안전한 대체값으로 사용한다.
- DB 회귀 검사, 린트, production build, A4 PDF 1.7 출력 검증이 통과한다.

## 위험과 대응

- 과거 책임강사에게 강사 풀 소속이 없을 수 있으므로 과정 운영기관 명칭으로 대체한다.
- 서명 이미지가 행을 넘지 않도록 전용 컨테이너에서 크기와 위치를 제한한다.
- 커버 번호 제거가 이후 쪽 번호에 영향을 주지 않도록 출력면 인덱스를 별도로 계산한다.
