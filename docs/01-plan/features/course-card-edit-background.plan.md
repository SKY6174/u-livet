# 과정 카드 편집·배경 이미지 계획

2026-10-01 · 사용자 요청

- 사업단의 유효한 `COURSE_MANAGER` 또는 `SYSTEM_ADMIN` 역할 계정이 공개 과정 안내의 내용을 수정한다.
- 공개 카드에서 수정 진입점을 표시하고, 일반 방문자에게는 표시하지 않는다.
- 과정별 카드 배경 이미지를 업로드하거나 HTTPS 주소로 지정·삭제하고 미리볼 수 있게 한다. 이미지가 없으면 현재 카드 디자인을 유지한다.
- 저장 권한과 입력 범위는 DB에서 검사하며 변경은 감사 기록에 남긴다.
- 16개 공개 과정, 카드·리스트 보기, 공개 상세의 기존 조회와 링크를 보존한다.

검증: 권한별 표시 및 저장 거부, 입력 검증, 카드 이미지 유무, 반응형 화면, lint·build, Preview 후 Production 배포.
