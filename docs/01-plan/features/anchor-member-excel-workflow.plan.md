# 구성원 엑셀 등록·관리 계획

2026-09-24 · anchor-member-excel-workflow · Dynamic

## 목적
구성원 관리의 사업단·강사·수강생 명부를 엑셀 서식으로 일괄 등록하거나 수정하고, 현재 검색 결과 전체를 내려받을 수 있게 한다.

## 범위
- 분류별 `.xlsx` 등록 서식과 검색 결과 전체 다운로드(최대 1,000명).
- 업로드 파일의 형식·행수·필수값·중복 검증, 등록/수정 건수 미리보기, 사용자 확정 후 DB 저장.
- 신규 행은 기존 수동 등록 권한과 이메일 중복·최근 MFA 검사를 재사용한다. 기존 행 수정은 SYSTEM_ADMIN과 revision 검사를 재사용한다.
- 한 파일의 저장은 단일 DB 트랜잭션으로 처리해 일부만 반영되지 않게 한다. 로그인·이메일 인증·업무 권한 부여는 기존 절차 그대로 둔다.

## 완료 기준
- 세 분류의 서식 다운로드, 유효한 파일 업로드·미리보기·확정, 필터를 적용한 전체 명부 다운로드가 동작한다.
- 권한 없음, MFA 만료, 중복 이메일, 수정 충돌, 잘못된 파일·행을 명확히 안내한다.
- 실패한 파일은 DB에 일부 행도 남지 않는다.
- 기존 단건 등록/수정, 목록, 수강·강의 이력, 권한 경계를 유지한다.
