# 로그인 인증 코드 자동 확인 계획

2026-09-22 · 사용자 요청: 이메일 로그인 후 인증 앱 코드 입력 활성화, 올바른 6자리 입력 시 확인 클릭 없이 다음 화면 이동, Git push.

## 목표와 범위
- 로그인 중 추가 인증 페이지가 열리면 코드 입력칸에 자동 포커스한다.
- 등록된 인증 앱의 숫자 6자리 입력·붙여넣기·자동완성이 끝나면 자동 검증한다.
- 서버가 실제 MFA 성공을 확인한 경우에만 기존 목적지로 이동한다.
- 중복 검증을 막고 잘못되거나 만료된 코드·연결 실패는 재입력할 수 있게 한다.
- 새 인증 앱 연결 및 직접 연 관리 화면은 명시적 확인을 유지한다.
- 기존 서버 인증·MFA·세션·요청 제한 정책을 유지한다.

## 완료 기준
자동 포커스, 1~5자리 비제출, 6자리 단일 제출, 성공 이동, 실패 복구, 수동 제출, 등록/관리 경로의 회귀 검사를 통과한다. 실제 React 브라우저 입력·붙여넣기 및 lint/build를 확인한 후 push·배포한다.
