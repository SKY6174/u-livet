# 출결·시험·수료판정 연결 계획

2026-09-19 · anchor-learning-evaluation · 전체 플랫폼의 두 번째 구현 범위

기준: anchor-lifelong-education-platform의 승인된 설계와 홈페이지 내 기본 LMS 결정.

강사는 담당 기수의 공식 수업일정·인정 출석시간·정정 사유와 객관식 시험을 관리한다. 수강생은 본인 출결과 시험 응시·결과를 확인한다. 과정담당은 수료 기준안을 작성하고 운영자료를 마감하여 수료 후보를 산출한다. 별도 CERTIFIER 역할의 승인자는 기준과 수료 결과를 검토한다.

기관의 실제 출석률·점수 기준은 미확정이다. 운영 기본값을 만들지 않고 별도 승인 기록을 가진 계산 규칙을 등록한다. 테스트 기준은 로컬 검증에서만 사용한다.

인수 기준: 담당 외 수정 및 타인 응시 차단, 정답 비공개, 서버 마감·중복 제출 보장, 출결 누락·미채점 시 검토 필요, 자료 변경 시 과거 산출 확정 금지, 자기승인 금지, 본인 수료이력 조회, 기존 접수 흐름 회귀 검증.

이번 구현은 강사 수기 출결과 객관식 단일 선택 시험을 제공한다. QR·영상 진도·서술형 시험·설문·증명서/배지 발급은 후속 범위다. 로컬에서 검증하고 원격 DB에는 적용하지 않는다.
