# 결과보고서 첨부·장학금 상세·사진 날짜 반영

2026-09-23 · anchor-result-attachments-scholarships

## 목적

공식 운영결과보고서가 본문과 5개 증빙 첨부를 하나의 제출 묶음으로 보여 주도록 정리하고, 장학금 합계의 근거가 되는 수강생별 지급내역을 공식 문서에 저장·출력한다. 기존 결과보고서 PDF를 가져올 때 사진 캡션에 적힌 날짜도 함께 반영한다.

## 범위

- 결과보고서 아래에 첨부 1 출석부, 첨부 2 수료자명단, 첨부 3 장학금 지급현황, 첨부 4 강사 강의날인부, 첨부 5 강사료 지급현황을 표시한다.
- `6종 출력`은 결과보고서 본문과 첨부 1~5를 동일한 순서로 합본 출력한다.
- 공식 결과보고서 예산에 수강생별 장학금 지급내역을 추가하고 학습자 선택, 장학유형, 지급률, 금액, 은행, 계좌, 예금주, 지급일, 비고를 입력한다.
- 장학금 인원수·합계는 상세행에서 자동 계산하고 기존 합계만 있는 문서는 그대로 읽을 수 있게 이관한다.
- 원문 PDF의 `개강식(날짜)`, `수료식(날짜)`, `운영사진N(날짜)` 텍스트를 ISO 날짜로 변환해 추출 사진에 연결한다.

## 완료 기준

- 관리자 화면에서 첨부 관계와 순서가 명확히 보인다.
- 결과보고서의 장학금 상세행을 추가·수정·삭제할 수 있고 저장/검증/최종 제출 스냅샷에 포함된다.
- 출력 본문 8번 장학금 지원과 첨부 3 장학금 지급현황에 동일한 상세내역이 반영된다.
- 원문 PDF에 날짜가 적힌 개강식·수료식·운영사진은 가져오기 후 날짜가 자동 입력된다.
- 기존 운영문서와 불변 제출본은 손실 없이 호환된다.
- 회귀 검증, 린트, production build, Preview·운영 DB 검증을 통과한다.

## 위험과 대응

- 계좌정보 노출: 기존 첨부 출력과 동일하게 기본 마스킹하고 명시적 `reveal=1`에서만 표시한다.
- PDF 이미지와 캡션 순서 불일치: 같은 쪽에서 추출된 캡션 순서와 이미지 그리기 순서를 연결하고, 개수가 다르면 확인 가능한 범위만 날짜를 채운다.
- 기존 합계 자료: 상세행이 없으면 기존 인원·금액·비고를 유지해 과거 보고서가 무효가 되지 않게 한다.
