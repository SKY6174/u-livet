# 운영계획서·결과보고서 메뉴 분리 계획

> 2026-09-22 · Dynamic

## 목적

사업단 관리의 묶인 ‘운영계획서·결과보고서’와 별도의 ‘결과 보고’를 하나의 작업 흐름으로 정리한다. 계획서 메뉴는 계획 문서에 집중하고, 결과보고서 메뉴는 공식 결과 문서와 기존 결과 보고의 과정별 집계·6종 증빙을 함께 찾을 수 있게 한다.

## 범위와 기준

- 관리자 메뉴에서 운영계획서와 결과보고서를 각각 표시한다. 기존 결과 보고를 제3의 중복 메뉴로 두지 않는다.
- 강사와 담당자에게 허용된 과정만 공식 문서 목록에 표시하고, 기존 결과 보고 자료는 기존 COURSE_MANAGER 권한을 유지한다.
- 과정별 기존 보고서·6종 자료 화면과 출력 기능을 새 결과보고서 메뉴에서 바로 찾게 한다.
- 기존 북마크 주소는 새 목록으로 안내하되, 과정별 세부 문서/증빙 경로는 유지한다.
- 메뉴 선택 상태와 모바일 탐색, 빈 데이터·오류 상태를 검사한다. DB와 제출 데이터는 변경하지 않는다.

## 성공 기준

관리자 업무 홈과 하위 메뉴에 ‘운영계획서’, ‘결과보고서’가 각각 보이고 각 메뉴를 누르면 다른 목록이 열린다. 결과보고서 목록에서 공식 양식 작성뿐 아니라 기존 결과 보고의 작성·검토·6종 출력까지 이동할 수 있다. 기존 보고서 접근 권한이 확대되지 않는다.
