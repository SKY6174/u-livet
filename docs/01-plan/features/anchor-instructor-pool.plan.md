# 평생직업교육 강사 Pool 및 수당 관리

요청: uc-anchor 전문가 Pool을 참고하여 사업단 전용 전문가 관리 화면을 강사(교내/교외)의 기본정보·서류·활동·수당 관리 시스템으로 개편하고 git push.

현재 `/admin/instructors`는 제출 이력 심사만 제공하여 등록된 강사와 지급 준비 상태를 보여 주지 못한다. 기존 강사 및 수동 등록 강사를 함께 조회하는 대장, 강의 자동연계 이력, 수당의 산출·지급 기록, 기존 비공개 서류함과 심사를 연결한다.

마스터 검색·교내외 필터·실데이터 요약·신규 등록/수정·엑셀 서식/일괄등록/다운로드, 활동 추가와 수당 지급완료 기록을 제공한다. 지급단가·공제액은 담당자가 근거에 따라 입력하며 실제 송금은 수행하지 않는다. 주민번호·계좌 원문은 기존 암호화 서류함에서만 관리한다. 원본 및 지급 기록은 삭제 대신 이력을 보존한다.

기존 권한·MFA·기관 경계를 유지하고 실제 Auth/RPC 검증, 데스크톱·모바일 시각 검수, 빌드 후 운영 DB와 main 배포를 확인한다.
