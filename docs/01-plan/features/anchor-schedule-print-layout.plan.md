# 강의 일정 출력 표 조정 계획

2026-09-23 · anchor-schedule-print-layout

## 목적

운영계획서와 운영결과보고서 PDF의 강의 일정 표를 실제 자료 길이에 맞게 재배치하여 날짜, 시간, 강사, 장소를 빠르게 읽을 수 있게 한다.

## 범위

- 일자와 시간을 한 셀에 `YYYY. MM. DD.`와 `(HH:mm ~ HH:mm)` 두 줄로 출력한다.
- 일자는 줄바꿈 없이 표시될 수 있도록 열 폭을 확보한다.
- 강의주제 및 내용은 단어와 괄호 경계를 활용해 자연스럽게 줄바꿈한다.
- 강사명 열은 한글 네 글자를 기준으로 고정하고, `교육시간` 머리글은 두 줄로 표시한다.
- 교육장소는 장소명과 마지막 괄호 안 호실을 각각 한 줄로 출력한다.
- 운영계획서의 수업방식·공휴일 열과 기존 일정 데이터는 유지한다.

## 성공 기준

- 결과보고서 일정 표가 8개 실제 열로 렌더링된다.
- 계획서 일정 표가 10개 실제 열로 렌더링된다.
- 날짜가 한 줄, 시간과 호실이 각자 다음 줄에 표시된다.
- 빈 값, 괄호가 없는 장소, 여러 괄호가 포함된 주제도 깨지지 않는다.
- 운영문서 회귀 검사, 린트, production build가 통과한다.
