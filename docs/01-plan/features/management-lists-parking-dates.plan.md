# 관리 목록·주차권 신청·날짜 표시 개선

2026-10-11 · management-lists-parking-dates

## 요청 및 확인

- 수강생 관리와 수료 검토·승인 과정 목록을 카드에서 리스트로 바꾼다.
- 기존 주차권 신청은 수강생·교외강사만 가능하다. 담당 과정에 배정된 교내강사까지 확장하고 관리자 접수·승인 경로를 명확하게 보여 준다.
- 홈페이지와 운영계획 카드의 날짜 표시를 `yyyy.mm.dd. ~ yyyy.mm.dd.`로 통일한다.
- PR, push, merge 및 운영 배포를 수행한다.

## 범위 및 검증

기존 조직별 조회 권한, 검색·페이지 이동, 수료 검토 링크와 미등록 과정 안내를 유지한다. 주차권의 지정 센터 승인자, 유효한 본인 로그인, 재고 차감과 감사기록을 유지한다. 날짜는 표시만 변경하며 날짜 입력과 미확정 원문은 보존한다.

실제 Auth/RPC의 교내·교외강사 신청, 타인·미배정 신청 차단, 승인·반려·취소·재고 처리와 목록 표시를 로컬에서 검증한다. 날짜 윤년·연도 넘김·한국시간 경계와 표시 호환성을 확인한다. lint, typecheck, build 및 운영 revision/health를 확인한다.
