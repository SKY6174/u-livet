# 사업단 등록 계정 활성화 및 MFA 중단 계획

## 목표
- 관리자가 사업단 구성원을 수동 등록하면 Supabase Auth 계정이 자동 생성되고 해당 구성원에 연결된다.
- 구성원은 로그인 화면의 신규 비밀번호 설정 버튼에서 등록 이메일로 받은 링크를 확인한 뒤 비밀번호를 설정한다.
- 당분간 MFA를 요구하거나 안내하지 않는다.
- 사업단 로그인 화면 아래에 활성화 순서를 쉽게 설명한다.

## 범위
- 기존 `manual_members` 등록 및 역할 범위를 재사용한다. 관리자 등록 서버 액션이 Auth 사용자를 안전하게 프로비저닝한다.
- 공개 가입 옵션은 수강생과 교외 강사에게만 제공한다. 사업단 구성원과 교내 강사는 대학 이메일(@uc.ac.kr) 수동 등록만 허용한다.
- Supabase DB의 MFA 게이트와 앱의 MFA 이동을 중단한다.
- 기존 계정의 역할, 기관 권한, 활성 상태, 비밀번호 정책은 유지한다.

## 완료 기준
- 미등록 이메일은 사업단 계정을 얻지 못하고 신규 비밀번호 메일 요청도 계정 생성으로 이어지지 않는다.
- 재시도 시 Auth 중복을 만들지 않으며 등록과 Auth 생성 사이 실패를 복구할 수 있다.
- 등록 이메일의 복구 링크 증명과 최초 비밀번호 설정 전에는 업무 접근이 불가능하다.
- 활성화 후 비밀번호 로그인은 MFA 없이 사업단 화면으로 이동한다.
- 기존 MFA 게이트가 사업단 조회·저장을 차단하지 않는다.
- 관련 정적 검사와 빌드가 통과하고 변경만 Git에 푸시된다.
