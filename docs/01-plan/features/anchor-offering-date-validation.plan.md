# 과정 등록 날짜 검증 계획

2026-09-24 · anchor-offering-date-validation · Dynamic

## 배경
운영 `life_create_source_offering` 요청이 `life_offerings_check`(접수 마감 > 접수 시작) 위반으로 거절되었으나, 화면에는 일반 오류만 나타났다. 요청자는 시스템 최고관리자이며 활성 권한은 확인되었다.

## 목표
- 실제 기수 초안 등록 전에 접수 및 교육 날짜 순서를 검사하고 해당 입력 항목을 안내한다.
- 서버 액션도 동일하게 검사해 수동 등록과 클라이언트 우회를 보호한다.
- 불완전한 날짜를 허용하는 개인 개설 준비 임시저장은 기존대로 유지한다.
- 기존 등록 권한과 DB 제약은 유지한다.

## 완료 기준
- 마감이 시작보다 같거나 이르면 명확한 오류가 나오며 등록 RPC를 호출하지 않는다.
- 교육 종료일이 시작일보다 이르면 명확한 오류가 나온다.
- 올바른 입력은 기존 등록 경로로 진행된다.
- 회귀 검증 후 preview와 main에 배포한다.
