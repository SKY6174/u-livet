# 1차 구현 작업단위: 인증·신청·기본 강의실

작성일 2026-09-19 (KST). 전체 플랫폼 기획의 첫 구현 작업단위를 별도 추적한다. 전체 기능 완료를 의미하지 않는다.

기준: [전체 기획](anchor-lifelong-education-platform.plan.md), [구현 순서와 상세설계](../../02-design/features/anchor-lifelong-education-platform.design.md).

목표는 기존 시연 코드를 실제 DB에 연결하고, 수강생·강사·과정담당의 최소 업무 흐름을 검증하는 것이다. 앞서 승인된 설계의 순서 1~5에서 필요한 기능을 묶었다. 사용자 선택인 홈페이지 내부 LMS를 따른다.

포함: 서버 신원검증, 유효기간·기관별 역할, 최소 가입정보와 동의 버전, 과정/버전/기수, 무료 신청과 심사·대기·취소, 자료 열람, 텍스트 과제 제출·재제출·채점, 운영 초안·공개·승인 강사 배정, 실제 자료 없는 상태와 오류 표시, 기존 가상 증명·실적 제거.

후속: 영상 출결, 시험, 파일 제출, Q&A, 수료 산출·확정, 증명·배지, 강사 이력·경력증명, 수납·환불, 문자, 지원·상담, 연차 평가·성과, 정책 승인/권한부여 관리 UI, MFA, 배포 운영체계.

인수 기준: TypeScript 빌드와 린트 통과, 별도 로컬 Supabase에서 마이그레이션 전체 재생 성공, 실제 Auth/Data API/RPC를 통한 역할·기관 경계/중복 신청/좌석 경쟁/과제 권한 검증, 브라우저 로그인·강의실·제출·모바일 확인. 원격 DB 적용이나 외부 발송을 완료 범위로 계산하지 않는다.
