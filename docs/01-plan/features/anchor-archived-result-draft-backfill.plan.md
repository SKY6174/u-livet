# 보관된 결과보고서의 검토용 초안 반영 계획

2026-09-22 · `anchor-archived-result-draft-backfill`

## 목표

운영 DB에 보관된 3개 과정의 결과보고서 PDF와 기존 구조화 집계가 새 운영결과보고서 화면에도 실제 저장된 초안으로 보이게 한다. 세 원본의 사진을 검토해 운영사진을 포함시키고, 관리자가 예산을 입력하고 책임강사가 검토·서명하는 현행 제출 절차는 유지한다.

## 범위와 검증

- 원본 PDF SHA-256과 기존 보관 파일·집계 기록의 SHA-256이 동일한 과정만 처리한다.
- 기존 결과보고서 문서가 없는 과정에만 초안을 생성한다. 기존 저장본·제출본은 변경하지 않는다.
- 본문 값은 기존 집계에 있는 값만 사용하고, 날짜·교육시간 충돌이 기록된 강의표는 자동 확정하지 않는다.
- PDF 이미지 후보에서 공백·마스크·슬라이드 그림을 제외하고 운영사진만 선별한다. 사진은 화면 제한에 맞게 축소·압축하고 원본 순서를 보존한다.
- 예산 입력란과 서명은 비워 두고 상태는 `DRAFT`로 둔다. 수료·출석의 개인별 승인값은 생성하지 않는다.
- 초안의 필드·사진 수·원본 해시를 삽입 전 검증하고, 삽입 후 재조회한다. 감사기록에 출처와 작성 경위를 남긴다.

## 완료 기준

3개 과정의 결과보고서 화면에 기존 본문 및 운영사진이 저장된 초안으로 표시되고, 나머지 과정은 그대로 유지된다. 원본 PDF 보관과 기존 집계는 변경하지 않는다. 운영진이 실제 보고서를 확인해 예산과 강의표를 보완할 수 있다.
