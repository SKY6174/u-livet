# 수강생 학습 허브 개편 계획

2026-09-21 · anchor-student-learning · Dynamic

## 목적과 범위
로그인 후 /mypage를 평생학습자의 학습 여정 중심으로 개편한다. 제목은 `OOO님의 학습`으로 간결하게 고치고, 기존 나열형 계정 버튼을 학습·성과·지원 서비스로 분류한다.

- 신청 상태, 강사·장소·일정, 주차/회차별 학습과 공식 출석, 이수 기준을 한곳에서 확인한다.
- 기존 강의실, 수강 신청, 만족도 조사, 이력·수료증·배지, 납부 기능을 연결한다.
- 본인 장학금 기록을 운영 보고서에서 안전하게 투영하고, 과목 이력의 분야를 활용해 후속 탐색 과정을 추천한다.
- 희망 과목 제안은 인증된 본인과 소속 기관을 연결해 저장하고, 제출 이력을 제공한다.
- 비수강생 역할의 기존 내 정보 화면은 유지한다.

## 성공 기준
실제 DB 상태를 표시하며 예시 수업·가짜 금액·출석률을 만들지 않는다. 조회 실패와 빈 상태를 구분한다. 개인정보는 본인만 읽고 장학 계좌·다른 수강생·보고서 원문은 노출하지 않는다. 모바일·데스크톱 레이아웃과 키보드 조작, lint/build, 데이터/권한 검증을 통과하고 Git push한다.

## 위험과 대응
장학 보고서는 승인 송금 원장이 아니므로 `지급 기록`으로 안내한다. 추천은 동일 분야 기반임을 명시하며 필수 선수과정처럼 주장하지 않는다. 신규 DB 기능은 migration과 재현 가능한 로컬 검증을 제공하고 조회 실패 시 데이터 없음으로 숨기지 않는다.

## 일정
계획 → 설계 → 구현 → 로컬 DB/브라우저 검증 → 보고 및 push (이번 작업).
