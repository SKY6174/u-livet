# 강사 My Room 통합 계획

2026-09-22 · anchor-instructor-my-room

## 목적과 범위
- 기존 청록색 메뉴·카드·입력 양식을 유지하고 강사 공간과 내 정보를 My Room으로 통합한다.
- 과정 개발, RCC센터의 교외 강사 연간 자격 점검, 강사진 배정, 운영 준비, 공동 홍보, 모집 인원에 따른 개설 확인, 수강생 관리, QR 입실 확인, 이수 검토, 만족도 조사, 강의이력·경력증명 경로를 연결한다.
- 기존 구현의 잘못된 QR 출결 테이블·수강 상태·검증 없는 토큰·GET 쓰기·저장 실패에도 성공하는 처리를 교체한다.
- 기존 사업단의 강의실적 검토·증명 발급 기능과 승인 권한을 유지한다.

## 성공 기준
- 교내·교외·복수 권한 강사 모두 My Room에서 본인 정보와 담당 업무에 접근한다.
- 강좌는 실제 모집 상태와 교육 기간을 표시하며 모든 강좌를 운영 중으로 표시하지 않는다.
- 담당 강사만 진행 중인 차시의 짧은 유효기간 QR을 발급한다. 로그인한 실제 수강생만 입실 확인을 기록한다.
- QR 링크 열기만으로 저장하지 않으며 확인 버튼 제출 후 DB 성공을 확인한다. 위조·만료·다른 강좌·휴강·배정 만료를 거부하고 중복 스캔은 최초 시각을 유지한다.
- QR은 입실 증빙이다. 수업 전체 이수시간은 종료 후 강사가 기존 출석부에서 확인하여 확정한다.
- 연간 심사와 개설 확정은 담당기관의 검토 절차로 안내한다. 자격 기준·최소 개설 인원·수료 기준을 임의로 만들지 않는다.
- 관련 권한/출석 회귀, DB 검증, lint/build와 브라우저 화면 검증 후 git push한다.

## 위험과 대응
- 외부 확장 프로그램 chext 콘솔 오류는 서비스 코드와 분리한다. 오류를 숨기는 전역 핸들러를 넣지 않는다.
- QR 공유만으로 실제 현장 재실을 보장할 수 없으므로 최종 인정시간은 강사가 확인한다.
- 신규 DB 기능이 없는 환경에서는 준비 안내를 표시하며 출석 성공을 허위 표시하지 않는다.
- 기존 사용자 변경과 자동 생성된 중복 파일은 이번 커밋에 포함하지 않는다.
