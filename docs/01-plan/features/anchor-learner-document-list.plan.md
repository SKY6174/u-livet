# 접수 문서 리스트 전환

## 목적과 범위
- 사용자 요청에 따라 `/admin/learner-documents`의 큰 접수 카드들을 한 건당 한 행의 표로 전환한다.
- 열 순서는 순번, 과정, 신청자(성명·전화번호), 신청시각, 다음 처리 단계, 수강생 안내 내용, 첨부문서, 비고다.
- 서류 종류 드롭다운을 ‘전체, 수강신청, 장학금신청, 환불신청’의 버튼형 단일 선택으로 바꾼다.
- 과정별 서류 종류, 기존 상태, 안내, 환불액, 원본 PDF와 처리 이력을 보존한다.
- 기존 조회 필터, 상태 변경 액션, 권한·MFA·revision 검증과 전화번호 마스킹을 유지한다.
- 새로운 비고 입력 저장소나 데이터베이스 변경은 추가하지 않는다.

## 완료 기준
- 각 행에서 해당 문서만 선택한 다음 상태·안내와 함께 저장된다.
- 선택한 서류 종류는 명확히 강조되고 처리 상태·검색어와 함께 기존 조회 버튼으로 제출된다.
- 종결 문서는 편집할 수 없고 원본·이력·최신 안내는 계속 볼 수 있다.
- 좁은 화면에서 전체 페이지 대신 목록 영역만 가로 스크롤되며 키보드로 접근할 수 있다.
- 합성 접수 데이터의 여러 행으로 폼 연결과 화면을 검증하고 production build 후 git push한다.
- 참고: `anchor-learner-document-workflow.design.md`, `anchor-admin-workflow-inbox.design.md` 및 사용자 접수 문서 캡처.
