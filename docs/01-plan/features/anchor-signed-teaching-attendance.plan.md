# 강사 강의날인부·QR 확정 출석부 계획

2026-09-22 · Dynamic · 기존 과정 운영/결과보고서와 출결·강의실적을 연결한다.

## 목표
- 강사가 자신의 종료 수업에 실제 강의 구간과 전자서명을 남긴다. 관리자만 전 과정의 확정 강의날인부를 취합·출력한다.
- 결과보고서의 강사별 교육시간과 강의날인부는 같은 강의실적 기록을 사용한다. 오전·오후·점심 구간을 강의 순서대로 표시한다.
- 출석부는 QR 입실 확인과 강사의 최종 출결 확정값을 분리해 표시한다. 담당 강사는 열람하고 관리자는 최종본을 출력한다.
- 출석부는 전체 회차 4회 이하면 A4 세로, 5회 이상이면 A4 가로다. 두 양식 모두 20mm 사방 여백, 왼쪽 하단 앵커사업단 로고를 쓴다.

## 범위와 판단
- 기존 `life_teaching_logs`, `life_attendance`, QR check-in 및 과정 운영문서 데이터 흐름을 확장한다. 이미 승인된 실적은 재승인 없이 보존한다.
- QR은 입실 확인이고 수업 종료 출결은 별도 확정이다. QR만으로 인정시간·수료를 자동 부여하지 않는다.
- 과거 강의실적의 세부 시간·전자서명은 추측해 채우지 않고 미등록으로 표시한다.
- 원본 PDF 양식의 표 구조를 참고하되, 사용자 지시의 여백/로고 위치/전자기록 요구를 우선한다.

## 완료 기준
- 타 강사의 서명 변경·열람과 비관리자 최종 취합은 DB 권한으로 거부된다.
- 자신의 강의 구간 합계가 입력한 실제 강의분과 같고 수업 시각 안에 있을 때만 저장된다. 실적 정정 시 기존 서명은 무효화된다.
- 관리자 인쇄 화면의 강의날인부에는 승인된 기록의 유효한 서명만 들어간다.
- 출석부의 QR 시각과 최종 출결이 다르게 보이며 미확정 행을 확정으로 오인하지 않는다.
- 4/5회차 경계, 다중 강사, 점심 구간, A4 20mm 여백 및 하단 로고를 확인한다.
