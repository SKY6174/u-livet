# 책임강사 지정과 운영 문서 연결 — 계획

> 2026-09-22 · Dynamic · `anchor-responsible-instructor-management`

## 목적

과정 운영관리에서 강사를 기수에 배정한 뒤 그중 한 명을 책임강사로 지정하고, 같은 지정값을 운영계획서·운영결과보고서의 작성 권한, 현황, 인쇄용 강사명에 연결한다. 현재 지정 입력은 문서 편집 화면에만 있고 보관 과정의 운영 설정은 조기 종료된다.

## 범위

- 과정 운영 목록에서 현재 책임강사를 표시하고 운영 설정·문서로 이동한다.
- 신규·진행·보관 과정의 운영 설정에서 강사 배정과 책임강사 지정을 제공한다.
- 기존 `life_operation_responsibilities`와 역할·MFA·버전 검사 RPC를 사용한다. 기수에 배정되고 활성 INSTRUCTOR 역할이 있는 강사만 지정한다.
- 변경 시 미제출 문서는 작성 중으로 되돌리고 표지의 책임강사명을 갱신한다. 제출 이력은 보존한다. 현재 책임강사의 기수 배정 해제를 막는다.
- 기존 강사 명단의 단순 텍스트를 권한으로 취급하거나 없는 계정·역할을 임의 생성하지 않는다.

## 완료 기준

- 운영 설정에서 책임강사를 지정하면 두 문서 목록/편집과 과정 목록에 같은 이름이 표시된다.
- 보관 과정도 강사를 배정·지정할 수 있다.
- 동시 지정 충돌, 미배정 강사, 현재 책임강사 배정 해제, 무권한 요청이 거부된다.
- 린트·빌드 및 로컬 DB의 실제 RPC 검증이 통과하고 Preview/Production 적용 후 Git에 푸시한다.
