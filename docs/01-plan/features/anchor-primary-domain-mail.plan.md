# uc-life.org 메인 주소 및 인증 메일 계획

2026-09-19 · 사용자 요청: `uc-life.org`를 메인으로 사용하고 준비 가능한 메일 설정 진행.

- 운영 canonical origin과 인증·증명 링크 기준을 `https://uc-life.org`로 변경한다.
- 기존 www·vercel.app 주소는 경로와 query를 보존하여 메인 주소로 이동시킨다. Preview 주소 및 DB 분리를 유지한다.
- 메일 서비스·발신 주소 확인과 SMTP/DNS 검증을 진행한다. 비밀값은 채팅·Git에 수집하지 않는다.
- SMTP가 아직 원격에 없으므로 공급자 정보를 기다리는 동안 독립적인 도메인 변경을 완료한다. 준비되지 않은 메일 기능을 활성화했다고 표시하지 않는다.
- 관리 파일만 수정/커밋하며 작업 전 존재하던 ` 2` 이름 미추적 복사본은 배포에 포함하지 않는다.
- 같은 소스를 main/preview에 push하고 HTTPS, 리다이렉트, health, 버전 및 Supabase URL 설정을 배포 후 재확인한다.
