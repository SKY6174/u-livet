# 하단 ANCHOR 브랜드 배치

- 첨부 ANCHOR 로고를 공통 Footer 왼쪽에 배치한다.
- 로고 이미지의 상단 기관명은 분리해 오른쪽 윗줄에 `울산과학대학교 앵커사업단`으로 표시한다.
- 오른쪽 아랫줄에는 `U-LIFE | 함께 성장하는 평생직업교육`을 표시한다.
- 청록색 배경에 밝은 로고·문구를 사용하며 기존 안내 링크를 유지한다.
- 사용자 추가 요청: 조타륜·닻 심벌은 흰색 글자와 약 10% 차이가 나는 옅은 색상으로 구분한다.
- 사용자 최종 문구 수정: 로고 아래 슬로건은 `지역과 함께하는 든든한 전문대학`으로 변경하고 글자 크기를 유지한다.
- PC·모바일 확인 후 main·preview에 Git 푸시한다.
