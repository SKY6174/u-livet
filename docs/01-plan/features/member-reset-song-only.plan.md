# 재설정 메일 발송 권한 제한 계획

2026-09-30 · member-reset-song-only · Dynamic

## 목표
- 구성원 관리의 비밀번호 재설정 메일은 송경영의 지정 계정만 발송할 수 있다.
- 버튼 문구를 `재설정 메일 발송`으로 명확히 표시한다.
- 화면 표시와 서버 동작 모두 같은 권한 조건을 사용한다.

## 수용 기준
- 송경영 계정은 연결된 구성원 행에서 버튼을 보고 사용할 수 있다.
- 다른 SYSTEM_ADMIN 및 구성원은 버튼을 볼 수 없고, 서버 액션을 직접 호출해도 발송할 수 없다.
- 기존 대상별 관리 범위, Auth 이메일 확인, 최근 발송 제한은 유지한다.
- lint·타입 검사·빌드, PR·병합·운영 배포를 확인한다.

## 근거와 위험
- 운영과 Preview의 송경영 Auth user ID는 다르므로 ID를 환경 공통 상수로 고정하지 않는다.
- 기존 `member_entry_operators`의 `SUPER_ADMIN` 지정 여부와 서버에서 검증한 현재 Auth 이메일 `kysong@uc.ac.kr`를 함께 확인한다. 이름 문자열이나 사용자가 수정할 수 있는 메타데이터로 권한을 주지 않는다.
