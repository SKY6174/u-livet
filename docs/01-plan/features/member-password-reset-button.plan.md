# 구성원 비밀번호 재설정 메일 버튼 계획

2026-09-30 · member-password-reset-button · Dynamic

## 목표
- 구성원 관리 목록에서 Auth 계정이 연결된 각 구성원에게 비밀번호 재설정 메일을 요청할 수 있다.
- 활성화가 끝난 계정도 재설정할 수 있으며, 대상 선택 오류·권한 부족·발송 실패를 화면에 명확히 표시한다.
- 기존 수동 등록 시 최초 설정 메일과 초대 흐름은 유지한다.

## 범위와 수용 기준
- 사업단·교내외 강사·수강생 목록의 관리 권한이 있는 연결 계정에 버튼을 표시한다. Auth 미연결 명부와 강사 풀 계정에는 표시하지 않는다.
- 서버에서 관리자 권한과 대상에 대한 관리 범위를 다시 확인한다. 브라우저가 보낸 이메일은 사용하지 않고, 서버에서 조회한 Auth 계정의 주소로만 보낸다.
- 짧은 시간 내 중복 요청은 안내하고, 발송 API 오류는 성공으로 표시하지 않는다. 처리 중 중복 클릭을 막고 결과를 해당 행에 표시한다.
- 정적 검사, 빌드, 대상 권한·발송 결과의 집중 검증을 통과한 뒤 PR 병합 및 운영 배포를 확인한다.

## 위험과 대응
- 권한 없는 대상에게 발송되는 문제: 서버에서 대상별 관리 범위를 재검증한다.
- 메일 반복 발송: 기존 복구 메일 시각 검사와 Auth 발송 제한을 적용한다.
- API 성공과 실제 수신의 차이: 화면에는 발송 요청 수락으로 표현하고 운영 메일 로그로 검증한다.
