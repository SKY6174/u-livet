# 접수 문서 필터와 표시 문구 개선 계획

## 목적
- 서류 종류를 누르는 즉시 해당 종류의 접수 목록이 보이게 한다.
- 관리자 표의 ‘다음 처리 단계’를 ‘처리 결과’로, PDF 링크를 ‘신청서’로 표시한다.
- 수강생 안내 내용 열을 기존 22%의 약 80%인 18%로 줄인다.

## 범위
- `/admin/learner-documents`의 필터 이동과 표의 문구·열 너비를 수정한다.
- 기존 상태·검색어 조건은 종류 전환 시 유지한다.
- 각 문서의 기존 인증 PDF 경로가 새 창에서 PDF로 표시되는지 확인한다.
- 조회 버튼·검색창 Enter와 상태 변경 폼은 계속 동작해야 한다.

## 완료 기준
- 네 종류 버튼 각각 클릭하면 URL의 종류 조건과 목록이 바로 바뀐다.
- 선택 종류가 시각적·접근성 상태에 반영된다.
- 8개 열과 각 행의 PDF·저장·이력 동작을 보존하며 모바일에서 표 내부만 스크롤된다.
- 빌드·관련 기능 검증 후 기능 브랜치를 push한다.
