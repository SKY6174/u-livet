# 과정 개발·심의 연차·주관 구분 계획

2026-09-24 · Dynamic

## 목적
- 관리자 과정 개발·심의 화면을 2025~2029년(1~5차년도)별로 탐색한다.
- 앵커사업단의 RCC, AID-X, ECC와 산학협력단의 재직자 과정을 명확히 구분한다.
- 새 제안의 주관 구분을 원장에 보존하여 심의·개설 이력에도 일관되게 표시한다.

## 범위
- 기관별 사업연도 원장에 빠진 2025~2029 공식 연차를 추가한다. 기존 앵커 2026 행은 보존하며 다른 연차 시험용 행과 혼동하지 않는다.
- 제안 root에 주관 구분을 저장하고, 생성 및 조회 RPC에서 기관·권한·허용값을 검증한다.
- 관리자/강사 목록에 연차 및 주관 필터와 명확한 빈 상태를 제공한다.
- 기존 제안은 근거 없는 자동 분류를 하지 않고 `미분류`로 둔다.

## 성공 조건
- 모든 연차를 선택할 수 있고 2025=1차년도, …, 2029=5차년도다.
- 앵커에서는 RCC/AID-X/ECC만, 산학에서는 재직자 과정만 새 제안에 지정할 수 있다.
- 목록과 승인 개발·개편 수가 선택 연차/주관을 따른다. 다른 기관 기록은 노출되지 않는다.
- 로컬 DB 검증, 타입/린트/빌드와 Preview→Production 배포 및 Git push를 확인한다.
