# 서비스 생성 PDF 1.7 통일

사용자 요청: 모든 PDF에 PDF 1.7 적용 후 git push.

서비스가 새로 생성하는 강사 신분증·통장/이력서, 이수증·강의경력증명서, 결과보고서 6종 및 강사 출석부 PDF를 대상으로 한다. 사용자 추가 답변에 따라 기존 보관 PDF도 원본 무결성·증명 해시를 보존하면서 별도 PDF 1.7 변환본을 제공한다.

브라우저 인쇄 대화상자는 PDF 버전을 강제할 수 없으므로 직접 인쇄와 PDF 1.7 파일 다운로드를 구분한다. 생성기의 버전 설정, 서버 저장 검증, 파일 헤더/카탈로그/페이지 파싱 및 시각 검증을 수행한다. 기존 원본 PDF는 입력·분석 자료로 계속 허용한다.

성공 기준: 모든 서비스 생성 경로가 1.7 출력, PDF 2.0 헤더 덮어쓰기를 통한 위장 변환 금지, 기존 문서 내용·권한·원본 해시 보존, 검사 후 main push와 배포 확인.
