# 환불 PDF 체크박스 및 서류 DB 최적화 계획

> Version: 1.0.0 | Date: 2026-09-23 | Status: Approved
> Level: Dynamic

## 1. 목적

환불신청서의 반환 사유 발생일 행에서 체크박스와 문구 사이에 일정한 간격을 만들고, 선택 표시를 사각형 중앙에 맞춘다. 동시에 수강생 서류 민원 기능의 과정·조직·사용자·파일·이력 연결과 관리자 조회 경로를 점검해 대량 조회 시 불필요한 반복 권한 판정과 과도한 JSON 생성을 줄인다.

## 2. 범위

- 원본 환불 PDF의 발생일 선택 행만 흰색으로 정리한 뒤 체크박스·문구를 다시 그린다.
- 체크박스 뒤 3pt 간격을 보장하고 체크 선을 사각형 안쪽 여백에 맞춘다.
- 기존 요청·이벤트·파일 FK, 조직 범위, RLS/RPC, PDF 무결성 연결을 검증한다.
- 관리자 목록의 권한 조직 계산을 요청마다 반복하지 않도록 한 번만 계산한다.
- 상태·종류 동시 필터를 지원하는 복합 인덱스를 추가한다.
- 관리자 한 번 조회량을 운영 가능한 상한으로 제한하고 선택된 요청에 대해서만 이력을 집계한다.

## 3. 제외 범위

- 기존 환불 금액 공식과 민원 상태 전환 규칙은 변경하지 않는다.
- 서류 민원을 실제 회계 환불 지급 레코드로 자동 변환하지 않는다.
- 원본 PDF의 다른 표·문안·여백은 변경하지 않는다.

## 4. 완료 기준

- [ ] 다섯 체크박스와 문구 사이에 육안으로 구분되는 동일 간격이 있다.
- [ ] 선택 표시는 네모 경계를 벗어나지 않고 중앙에 놓인다.
- [ ] 수강생·관리자·파일 RPC의 소유권 및 조직 격리가 유지된다.
- [ ] 관리자 종류+상태 필터가 새 복합 인덱스를 사용할 수 있다.
- [ ] PDF 1.7, DB 통합, 타입, 린트, 빌드 검사가 통과한다.
- [ ] 운영 DB·웹 배포와 Git main 반영을 확인한다.

## 5. 위험과 대응

| 위험 | 대응 |
|---|---|
| 마스킹 영역이 표 선을 덮음 | 원본 텍스트 bbox 안쪽만 마스킹하고 렌더 PNG로 확인 |
| 인덱스가 기존 조회를 방해함 | additive migration으로 추가하고 기존 인덱스는 유지 |
| 조회 함수 교체 시 권한 범위 확대 | 허용 조직 CTE를 역할·유효기간·MFA 조건으로 한정하고 격리 회귀 검사 |
| 이벤트 누락 | 제한된 요청 집합과 이벤트를 request_id로 다시 결합하고 순서 검증 |
