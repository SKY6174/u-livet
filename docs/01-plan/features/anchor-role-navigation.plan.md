# 로그인 역할별 메뉴 재구성

작성일: 2026-09-21

## 목적
관리자·강사·수강생의 업무가 섞인 개인 화면과 상단 메뉴를 역할별로 구분한다. 관리자의 직책은 단장·센터장·연구원으로 표시하며 실제 업무 권한은 기존 서버 권한 원장을 따른다.

## 범위
- 상단 공통 안내 메뉴를 유지하고 로그인 유형별 업무 메뉴와 개인 정보 메뉴를 구분한다.
- 사업단 관리에 과정 운영, 결과 보고, 수료 검토, 증명 관리와 권한별 지원 업무를 통합한다.
- 관리자 개인 화면에는 본인 정보·보안, 강사에게는 강사 정보, 수강생에게는 신청·학습 정보를 제공한다.
- 기존 과정 및 보고서 경로, 개설 계획 불러오기, MFA와 조직별 권한 검사를 유지한다.
- 역할별 합성 렌더링·접근 거부·모바일/웹 표시와 빌드를 검증하고 main/preview에 푸시한다.

## 완료 기준
권한 없는 메뉴가 표시되지 않고 직책만으로 권한이 늘어나지 않는다. 과정 운영과 결과 보고에 별도 진입점이 있으며 수료/증명 화면에서도 사업단 메뉴를 사용할 수 있다. 관리자 화면에서 수강생 신청 현황을 자동 조회하지 않는다.
