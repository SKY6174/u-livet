# 구성원 연도별 명부 계획

2026-09-24 · anchor-member-year-filters

- 기존 person_id와 로그인 계정은 재사용한다. 연도별 명부는 별도 회원가입이나 회원 복제를 하지 않는다.
- 수강생은 전체 또는 2025~2029 사업연도별 실제 수강 확정 기록으로 조회한다. 강사는 전체 또는 사업연도별 실제 강의 배정 기록으로 조회하고, 교내·교외 구분을 추가한다.
- 검색, 집계, 페이지, 정렬, 엑셀 내려받기에 같은 조건을 적용한다. 사업단 명부의 기존 직책순 기본값을 유지한다.
- 기존 상세·이력·등록·권한 기능을 보존하고, 연도 조건 없는 전체 명부에는 이력 없는 구성원도 표시한다.
