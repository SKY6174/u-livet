# 수강안내 구성 개선

## 목표
- 긴 단일 본문을 실제 수강 흐름에 맞춰 빠르게 읽고 행동할 수 있는 안내로 바꾼다.
- 과정 찾기 → 수강신청 → 수강 확정 → 강의실의 네 단계와 관련 화면 바로가기를 제공한다.
- 심사·대기, 취소·환불, 수료·증명 설명은 질문별로 펼쳐 확인하게 한다.

## 범위
- `/terms`의 화면·문구 구성을 개선한다. 기존 선발·취소·환불·수료 정책과 발급 준비 중 상태는 유지한다.
- 교육과정, 나의 공간, 수강이력으로 연결하고 사업단 문의를 안내한다.
- 모바일 가독성, 키보드로 열 수 있는 안내, 링크와 lint/build를 확인한 뒤 main·preview에 push한다.
