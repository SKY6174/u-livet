# 교외·보조강사 필요서류

교외 강사 대장에 보조강사를 포함하고 두 유형의 이력서 제출을 필수화한다. 첨부 동의서 3종을 로그인·PIN 서류 창에 추가한다. 성범죄 경력 조회 동의서는 원본 PDF 바탕에 입력값을 표시하고, 개인정보동의서는 uc-anchor의 안내/선택/서명 구성을 참고하며, 청렴서약서는 첨부 구조를 KoPub Dotum으로 재현한다.

실제 PDF 미리보기(우측), 입력·직접 서명(좌측), 암호화 초안, 버전별 비공개 PDF 보관, 제출 상태와 관리 대장 연결, PDF 1.7을 유지한다. 교내 강사 필수 적용 여부는 사용자 응답을 반영하되 기본은 교외/보조 필수다. 기존 다른 작업을 보존하고 독립 작업공간에서 검증한 변경만 main에 push한다.
