# 주차권 운영 준비 안내 — 계획

> 2026-09-22 · Dynamic · `anchor-parking-readiness`

## 목적

주차권 신청·승인 기능은 배포되었지만 실제 운영에는 과정별 센터, 실물 재고, 지정 승인자의 로그인·역할·MFA가 필요하다. 관리자가 `/admin/parking`에서 준비해야 할 일을 현재 DB 자료와 함께 확인하고 곧바로 해당 입력 위치로 이동하게 한다.

## 범위

- 조회 연도의 센터 미지정 과정과 센터별 주차권 잔여 매수를 기존 관리자 RPC 결과에서 계산한다.
- 센터 지정·재고 입고 입력 위치로 이동할 수 있는 안내를 추가한다.
- RCC 이연향, ECC 이은주, AID-X 임은애의 승인 조건과 구성원 관리 경로를 설명한다.
- 자료에 근거가 없는 과정 센터를 임의 배정하거나, 실물 확인 없이 재고를 등록하거나, 로그인 계정을 대신 만들지 않는다.

## 완료 기준

- 관리자가 미지정 과정 명칭과 총수를 볼 수 있다.
- 재고가 없으면 첫 승인 전에 입고가 필요함을 확인할 수 있다.
- 승인자 설정 안내가 수동 명부 등록과 실제 로그인 계정의 차이를 정확히 설명한다.
- 기존 신청·승인·인쇄 흐름과 권한은 유지되고 린트·빌드가 통과한다.
