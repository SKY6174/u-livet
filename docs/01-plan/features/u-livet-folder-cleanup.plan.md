## 목표와 범위

- 기본 checkout은 `~/Documents/u-livet`으로 유지한다.
- 백업은 `.local/backups`, 진행 중인 워크트리는 `.local/worktrees`로 모은다.
- 완료된 워크트리는 커밋·변경·환경 파일·검증 자료를 보존한 뒤 제거한다.
- `u-live`, `uc-life`, `uc-life 2` 호환 링크는 보관 폴더로 이동한다.
- 오래된 기본 checkout의 로컬 변경과 고유 커밋을 보존하고 최신 `main`으로 갱신한다.
- Git에는 정리 기준, 설계와 결과만 기록한다.

## 성공 기준

1. Documents에는 U-LiVET 관련 최상위 항목으로 `u-livet`만 남는다.
2. 열린 PR #204·#205 워크트리는 Git 등록과 작업 상태를 유지한다.
3. 제거하는 워크트리와 기존 기본 checkout은 검증된 복구 자료가 있다.
4. 백업·환경 파일은 Git 추적 및 배포 업로드 대상에서 제외한다.
5. PR 검사 통과, 병합, 최신 기본 checkout, 운영 배포 상태를 확인한다.

## 위험과 대응

미병합 커밋은 로컬 브랜치와 Git bundle로, 미커밋·무시된 파일은 비공개 압축본으로 보존한다. 의존성과 빌드 캐시는 재생성 가능한 항목으로 분류한다. 다른 활성 채팅의 경로는 이동하지 않는다. 데이터베이스·컨테이너·도메인 변경은 이 작업에 포함하지 않는다.
