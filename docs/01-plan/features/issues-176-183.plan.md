## 검증·릴리스

순수 입력 경계·계산 사례, 실제 로컬 DB의 기간·중복·권한·목록 일치·수강료 변경 제한, 실제 편집 UI와 PDF, lint·타입·빌드를 검증한다. 설계 대비 갭 분석 후 PR 검사·병합·운영 READY와 version·health를 확인한다.
