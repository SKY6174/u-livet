# anchor-operation-photo-crop - Plan Document

> Version: 1.0.0 | Date: 2026-09-23 | Status: Approved

## 1. Purpose

결과보고서에 직접 첨부하거나 원문 PDF에서 가져오는 운영사진을 중앙 기준 16:9로 잘라, 세로사진이나 비율이 다른 사진도 동일한 크기로 저장·출력한다.

## 2. Goals

- [ ] 직접 업로드한 JPG·PNG를 16:9 중앙 크롭 후 저장한다.
- [ ] PDF에서 추출한 사진에도 같은 16:9 크롭을 적용한다.
- [ ] 미리보기와 인쇄 영역을 16:9로 고정하고 이미지가 영역을 꽉 채우게 한다.
- [ ] 기존 저장 사진은 재저장하지 않아도 출력에서 16:9로 보이게 한다.

## 3. Scope

- 운영계획서가 아닌 운영결과보고서의 개강식·수료식·운영사진
- 브라우저 Canvas 기반 중앙 크롭과 JPEG 압축
- A4 미리보기와 PDF 인쇄 CSS

## 4. Success Criteria

- [ ] 가로·세로·정사각형 원본이 모두 정확한 16:9 데이터 이미지로 저장된다.
- [ ] 한 페이지 사진 셀의 크기와 비율이 모두 동일하다.
- [ ] 얼굴이나 피사체 위치 수동 조정 기능 없이 중앙을 기준으로 불필요한 상하 또는 좌우를 제거한다.
- [ ] ESLint와 프로덕션 빌드가 통과한다.

## 5. Risks

중앙 크롭으로 가장자리 피사체가 잘릴 수 있다. 이번 요구에서는 자동 중앙 크롭을 기본으로 하고, 원본 전체 보존용 별도 파일은 기존 결과보고서 PDF 및 업로드 원본으로 유지한다.
