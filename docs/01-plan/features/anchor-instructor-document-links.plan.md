# 강사 서류 직접 입력·개별 제출 링크

2026-09-22 / Dynamic

사용자 요청: 서류 확인·입력에서 중간 인증 시작 화면을 제거하고 별도 창에 직접 입력 화면을 연다. 신분증·통장사본 및 이력서별 입력 버튼, 관리 열 링크·수정·삭제, 전달용 입력 링크와 PIN 별도 안내를 제공하고 push한다.

범위: 기존 로그인/MFA를 이용한 자동 문서 세션, 팝업/새 창, 개별 무작위 링크+6자리 PIN 인증, 링크·PIN 개별 복사/재발급, 대장 삭제(기존 지급·서류 보존). 기존 PDF 1.7 및 AI 문서 처리 흐름은 유지한다.

성공 조건: 중간 클릭 없이 입력 표시, 요청 탭 선택, 로그인 없는 강사 PIN 입장, 틀린 PIN 잠금·만료·재발급·삭제 시 접근 차단, 다른 기관 관리 금지, 기존 로그인 문서 흐름 회귀 검증, 브라우저/빌드 확인 후 운영 배포.
