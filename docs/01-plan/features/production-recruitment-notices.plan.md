# 공개 과정 모집 안내 점검 및 운영 문안 교정

2026-10-17 · Feature `production-recruitment-notices`

## 요구와 점검 결과

다른 과정의 검증용 모집 안내를 찾아 운영 안내로 교체하고 PR·push·병합·배포한다.
운영 DB 전체 22개 과정과 ENROLLMENT 정책을 점검했다. 공개 안내 16개 중
운영 모집 공개 2개, 작성 중인 과정 11개, 운영 완료 소개 3개다.
실제 과정에 추가로 연결된 검증용 정책은 없다. 실버푸드전문가과정은 승인된
`2026-1` 정책의 작성 항목 목록을 표시하므로 운영용 안내로 교체한다.
나머지 검증 정책 연결 3건은 이름에 검증용을 명시한 합성 검증 과정이다.

## 범위

- 실버푸드전문가과정의 실제 일정·정원·무료·선착순 모집 안내와 기존 원서의 개인정보 안내를 새 버전으로 작성한다.
- 기존 관리자 작성·승인 경로에서 승인자와 감사 이력을 기록한다.
- 해당 과정의 정책 연결과 revision만 교정한다. 승인된 기존 정책과 신청·동의·원서 증빙을 보존한다.
- 실제 과정에 검증용 모집 정책 연결을 막는 DB 검사와 관리자 선택지 필터·오류 안내를 보완한다.
- 작성 중인 과정을 임의 공개하거나 운영 완료 과정의 모집을 재개하지 않는다.

## 완료 기준

- 로컬 롤백 테스트: 미승인/본문/대상/기존 연결 검사, 재실행, 기존 증빙 보존,
  검증 정책 insert·update·과정명 변경 우회 차단 및 실제 운영 정책 허용.
- 공개 안내 16개와 접근 가능한 운영 과정 상세에서 검증 문구가 없는지 확인한다.
- Preview 검사와 운영 DB 교정, PR 병합 및 운영 배포 SHA·health·실제 화면 확인.
