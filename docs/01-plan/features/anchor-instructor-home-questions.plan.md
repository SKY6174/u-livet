# 강사 수업 현황과 수강생 질문 계획

2026-09-23 · anchor-instructor-home-questions

## 목적
강사 첫 화면은 공개 과정 홍보보다 본인 담당 수업의 운영 상태를 먼저 보여준다. 수강생은 해당 강의실에서 담당 강사에게 질문하고 답변을 확인한다.

## 범위
- 강사 `/`와 My Room에 현재 배정된 수업별 수강생 수, 종료 수업 수, 출결 기록 수, 미답변 질문 수를 표시하고 명단·출석부·질문으로 이동한다.
- 수강생 강의실에 질문 작성과 답변 조회를 제공한다. 질문마다 작성자가 1:1 비공개 또는 같은 수업 공개를 선택한다.
- 강사 강의 운영 화면에서 질문을 읽고 답변한다. 같은 수업 공개 질문은 활성 수강생에게, 1:1 질문은 작성자와 현재 담당 강사에게만 보인다.
- 본인 인증, 활성 수강, 현재 강사 배정·기관 역할을 DB에서 확인한다. 강좌·사용자 ID를 클라이언트가 주장한 값만으로 신뢰하지 않는다.
- 운영 Preview에 DB 변경을 먼저 적용하고 실제 운영 DB와 배포를 검증한 뒤 main/preview를 동기화한다.

## 완료 기준
- 강사 첫 화면에서 공개 과정 카드가 아닌 담당 수업 현황을 확인한다. 담당 수업이 없거나 조회에 실패한 경우를 구분한다.
- 질문 공개 범위, 권한 만료, 타 강좌 접근, 잘못된 입력과 답변 권한을 DB 회귀 테스트로 검증한다.
- 수강생 질문·강사 답변이 페이지 새로고침 후에도 보이고, 공개 범위가 다른 수강생에게 정확히 적용된다.
- 기존 관리자·수강생 홈과 강사 업무/출석 동작이 유지되고 린트·타입·빌드·브라우저 확인을 통과한다.

## 위험과 대응
- 질문에는 개인정보가 들어갈 수 있으므로 비공개를 기본 선택하고 본문을 공개 목록·로그·감사 정보에 섞지 않는다.
- 강사 배정과 수강 상태는 조회와 변경 시마다 확인한다. 조회 실패를 0건으로 표시하지 않는다.
- 요약은 배정 수업 전체를 한 번의 DB 조회로 집계해 첫 화면의 호출 수를 제한한다.
