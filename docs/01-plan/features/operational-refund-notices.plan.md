# 전체 과정 환불 안내 운영 점검

2026-10-17 · Feature `operational-refund-notices`

전체 22개 offering, REFUND 정책·계산 조항·수납 설정과 운영 문서의 환불 항목을 조사했다.
REFUND 정책·계산 조항·수납 설정·청구·입금·회계 환불은 모두 0건이다.
19개 과정은 수강료 0원, 보관 과정 3개는 원본 수강료 미기재다.
실버푸드 제출 계획서의 자격시험·발급비 환불은 실제 원문이며 수강료 환불과 구분한다.
검증용 환불 정책이나 작성 요령 본문을 교체할 실제 데이터는 없다.

## 구현 범위

- 공개 과정 소개·상세에 실제 수강료 상태에 맞는 취소·환불 안내를 제공한다.
- 무료와 수강료 미기재를 구분하고, 유료 과정은 유효한 운영용 승인 규정만 표시한다.
- 관리자 환불 규정 선택지 및 DB 연결 경로에서 검증 문구·작성 요령을 차단한다.
- 유료 신청 화면도 검증 규정으로 신청을 진행하지 못하게 한다.
- 기존 수강료·정책·제출본·청구·입금·환불 이력을 보존한다. 환불 비율은 새로 정하지 않는다.
- 합성 로컬 검증, 전체 공개 안내 확인, PR·push·병합·운영 배포와 health 확인을 완료한다.
