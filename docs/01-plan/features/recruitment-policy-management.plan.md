# 모집 공개 정책 준비 · 계획

2026-10-07 · `recruitment-policy-management`

## 목적

모집 공개 화면은 승인된 모집·수집이용 정책과 수료기준을 요구하지만, 관리자가 이 정책을 직접 작성·승인할 수 없어 검증용 정책만 선택 가능한 상태다. 실제 정책 문안을 임의로 확정하지 않으면서, 초안 작성부터 승인·공개까지 연결한다.

## 범위와 성공 기준

- 과정 담당자는 조직별 ENROLLMENT·COMPLETION 정책을 초안으로 등록하고 승인할 수 있다. 승인된 버전은 기존 불변 규칙대로 보존한다.
- 모집 공개 화면에서 정책 준비 방법과 각 문안의 필수 검토 항목을 확인하고 관리 화면으로 이동할 수 있다.
- 검증용 정책을 실제 모집용 정책으로 오인하지 않도록 표시한다.
- 공개 API는 기존 `life_publish`의 유효 정책 검사와 신청 동의 기록을 그대로 사용한다.
- 기관의 보유기간·제공처·수료 점수는 코드에서 추정하거나 자동 승인하지 않는다.

## 위험과 확인

- 개인정보 동의의 적법한 근거와 문안은 기관 검토가 필요하다. 법령상 고지 항목만 안내한다.
- 수료기준 공개 정책과 수료 계산 규칙은 별개다. 승인 정책을 만든 후 실제 계산 임계값을 별도 검토·승인해야 한다.
- 데이터베이스 RPC는 조직 권한과 입력 길이를 확인한다. 공개 페이지는 승인된 정책만 표시한다.
