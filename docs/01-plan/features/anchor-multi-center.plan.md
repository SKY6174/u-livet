- 로그인 사업단 카드와 강사 운영 안내를 센터 공통 표현으로 바꾸고, 사업 소개에 재직자 교육을 포함한 공동 활용 방향을 반영한다.

- 승인된 개인정보·심사 원문과 과거 동의는 보존하고 현재 문의 UI를 센터별로 제공한다.
