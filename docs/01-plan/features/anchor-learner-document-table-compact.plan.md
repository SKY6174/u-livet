# 접수 문서 표 밀도 조정 계획

## 목적
- 수강생 안내의 현재 문구와 새 입력칸을 각각 한 줄로 간결하게 표시한다.
- 신청시각을 날짜와 시각 두 줄로 나누어 읽기 쉽게 한다.
- 현재 상태와 상태 저장을 한 행에 나란히 놓고 저장 버튼 폭을 기존의 절반 수준으로 줄인다.

## 범위와 기준
- 관리자 접수 목록의 셀 표현만 조정한다.
- 날짜와 시각은 기존 서울 시간대, 한국어 형식을 유지한다.
- 안내 필수 입력·1,000자 제한, 행별 저장 폼과 처리 이력은 유지한다.
- 좁은 표와 모바일 가로 스크롤에서 버튼·문구가 겹치지 않아야 한다.
- 합성 자료 화면과 빌드 검증 후 기능 브랜치를 push한다.
