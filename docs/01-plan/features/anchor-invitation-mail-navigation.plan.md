# 초대 메일 새 창 열기 계획

2026-09-19

사용자가 초대 링크에서 `uc-life.org refused to connect` 화면을 보고했다. 운영 초대 페이지는 HTTP 200이며 `X-Frame-Options: DENY`를 반환한다. 메일 내 iframe 이동으로 차단됐을 가능성이 있으나 사용한 메일 클라이언트는 확인되지 않았다.

초대 메일 버튼을 새 창으로 열고, 클라이언트가 이를 지원하지 않을 때 새 탭으로 여는 방법을 안내한다. 페이지의 프레임 차단과 fragment 토큰, 15분 만료·1회 사용, 공개 가입 차단은 유지한다.

운영과 Preview에 템플릿을 적용하고 읽어 확인한다. 기존 본인 동의와 발송 요청 범위에서, 아직 미인증 상태이며 이전 초대가 만료됐을 때 같은 운영 계정에 수정된 초대를 한 번 재발송한다. 비밀번호·MFA는 본인이 설정한다.
