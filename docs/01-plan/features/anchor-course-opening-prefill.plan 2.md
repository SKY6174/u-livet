# 운영계획서에서 과정 등록 양식 연결

> 2026-09-19 · Feature: anchor-course-opening-prefill

## 목적

사용자가 개설 준비 대상을 **운영계획서 16개 전체**로 선택했다.
기존 개설 준비 화면의 내용을 관리자 등록 양식으로 불러와 중복 입력을 줄인다.
이는 16개 과정의 모집 공고·최종 일정·수강료 승인 또는 실제 기수 저장 지시를 대신하지 않는다.

## 범위

- 각 계획서에 등록 양식으로 이동하는 링크를 제공한다.
- 과정명·아카데미·정원·계획 장소·소개·교육내용을 편집 가능한 기본값으로 불러온다.
- 원문 일정·대상·수강료·불일치와 미확정 항목을 등록 양식 가까이에 안내한다.
- 모집기간·최종 교육기간·운영방식·선발방식·사업연도는 관리자가 직접 선택한다.
- 기존 권한·MFA와 createOffering 저장 경로를 유지하며 페이지 조회로 DB를 변경하지 않는다.
- 사용자 선택을 운영 준비 문서에 기록하고 변경을 preview에 push한다.

## 완료 기준

16개 링크, 기본값 일치, 잘못된 원문 ID 처리, 날짜·운영방식·선발방식의 미확정 유지, 폼 이동·재사용, 검사·빌드가 검증된다.
실제 모집 개설은 최종 모집 조건·정책 확정 후 진행한다. 별도 담당자 권한 연결은 연기된 상태를 유지한다.
