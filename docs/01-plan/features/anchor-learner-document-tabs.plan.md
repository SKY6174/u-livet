# 수강생 서식 단일 창 전환

2026-09-22 · anchor-learner-document-tabs

사용자 변경 요청에 따라 수강신청원서와 장학금 지급신청서를 하나의 작성 창에서 두 버튼으로 전환한다. 기존 원본 PDF 및 좌우 편집·미리보기 구조를 유지한다.

완료 기준:
- 나의 학습에서 하나의 통합 작성 창을 연다.
- 창 안의 두 버튼은 새 창이나 페이지 이동 없이 서식을 전환한다.
- 전환해도 각 서식의 입력값·동의·서명은 유지된다.
- 현재 서식에 맞는 PDF만 미리보고 다운로드한다.
- 이전 서식 경로는 통합 창으로 연결한다.
- 브라우저 전환·입력 유지·다운로드·모바일 및 빌드 검사 후 push한다.
