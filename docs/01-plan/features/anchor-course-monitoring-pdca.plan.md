# 16개 과정 연간 일정·PDCA 신호등 계획

> Date: 2026-09-25 | Level: Dynamic | Status: Approved by user request

## 목표

과정 담당자가 2026년 평생직업교육 16개 과정의 연간 일정을 한 화면에서 비교하고, 계획 대비 지연·애로를 신호등으로 확인하며 P(계획)·D(운영)·C(점검)·A(개선) 기록을 관리한다.

## 범위

- 기존 `/admin/monitoring`에 연도별 12개월 일정표, 정상·지연·애로·계획전 신호등, 과정별 PDCA 상세를 제공한다.
- 16개 기준 목록은 `life_course_guides`의 해당 연도 과정으로 만들고 등록된 `offering_id`를 실제 운영 집계와 연결한다. 안내 과정이 아직 개설되지 않아도 목록에서 빠지지 않는다.
- 안내의 구체적인 기간은 참고자료로만 표시하고, 실제 개설 기간은 실적 데이터로 표시한다. 기간이 ‘12월 예정’처럼 불명확하면 임의 날짜를 만들지 않는다.
- 담당자는 과정별 P/D/C/A 목표일과 완료일, 애로·조치 내용을 저장한다. 목표일 미입력과 미확정 상태를 숨기지 않는다.
- 신호등은 저장된 목표일 대비 완료일·오늘 날짜와 명시적인 애로 표시를 기준으로 일관되게 계산한다. 기존 출결·신청 미처리는 별도 운영 지표로 제공한다.
- 조직 권한·최근 MFA를 서버와 DB에서 검사한다.

## 완료 기준

- 2026년 과정 16개가 월별 일정표에 모두 표시되며 월·분야·신호등 필터가 연동된다.
- 계획을 저장하면 다른 기기와 새로고침 뒤에도 P/D/C/A 일정 및 기록이 유지된다.
- 정상, 지연, 애로, 계획전의 판정 근거와 다음 조치가 과정별로 확인된다.
- 권한이 없는 사용자는 계획을 읽거나 저장하지 못한다.
- 타입 검사·린트·빌드와 관련 검증을 통과한다.

## 주의

- 원본 계획서와 공개 안내에 차이가 있어 구버전 날짜를 확정 일정으로 사용하지 않는다.
- 자동 신호등은 사실에 근거한 일정 지연만 판단한다. 애로는 담당자가 직접 등록한다.
- 실제 DB 마이그레이션 적용·운영 배포는 별도 릴리스 흐름을 따른다.
