# 과정 모니터링 계획

> Version: 1.0.0 | Date: 2026-09-24 | Status: Approved by user request
> Level: Dynamic

## 목적

`접수·운영`의 첫 메뉴에서 과정 담당자가 모집·수업·출결·수료 현황을 과정별로 한눈에 파악하고 해당 업무로 이동한다.

## 범위

- `COURSE_MANAGER`에게 `과정 모니터링`을 `접수·운영` 첫 메뉴로 제공한다.
- 기존 조직 범위·최근 MFA를 검사하는 `life_course_workspace` 집계를 재사용한다.
- 조직·사업연도·운영 상태·과정명 필터와 전체 요약을 제공한다.
- 과정마다 신청 대기, 수강 확정/정원, 수업 회차, 종료 수업 출결 입력/미입력, 수료 검토·승인을 표시한다.
- 관련 운영, 신청, 출결, 수료 화면으로 연결한다.
- 기존 원본 보고서의 인원은 전산 수강 확정 인원과 별도로 표시한다.

## 제외

- 출결 미입력을 결석으로 해석하거나 수료를 자동 승인하지 않는다.
- 새 권한·DB 테이블·RPC 또는 원본 보고서 이관 로직을 만들지 않는다.

## 완료 기준

- 관리자 업무 홈과 공통 업무 메뉴에서 `접수·운영`의 첫 항목으로 표시된다.
- 조직 권한이 없는 이용자는 화면·데이터에 접근하지 못한다.
- 빈 목록·조회 실패·원본 이관 과정에서도 수치가 오해 없이 표시된다.
- 린트, 빌드, 관련 회귀 검사를 통과하고 `main`·`preview`에 push한다.

## 위험과 대응

- RPC는 `COURSE_MANAGER`와 최근 MFA에 한정된다. 화면도 동일 역할로 제한한다.
- `application_pending`은 전체 신청 수가 아니므로 `신청 대기·대기`로 명시한다.
- `attendance_recorded/expected`는 출석률이 아닌 출결 **입력률**로 명시한다.
