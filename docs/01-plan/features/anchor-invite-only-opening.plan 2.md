# 최초 관리자 초대와 공개 가입 개방 분리

2026-09-19 · anchor-invite-only-opening

사용자는 초기 담당자를 SYSTEM_ADMIN만으로 지정하고 회원정보 보유기간을 탈퇴·계정 폐쇄 시까지로 확인했으며 해외 처리 기관 검토도 완료됐다고 답했다. 최종 개인정보 문안을 제시하고 본인의 동의·초대 메일 발송 요청을 받기 위한 준비를 진행한다.

승인 ACCOUNT_PRIVACY가 생기면 현재 UI에 가입 폼이 나타나므로, 초기 초대용 정책 등록이 일반 가입 개방으로 오인되지 않도록 명시적인 공개 가입 설정을 추가한다.

## 범위와 완료 조건

- 관리형 운영에서 공개 가입은 별도 opt-in 설정이 있어야 UI·서버 액션 모두 허용한다.
- 로그인·복구·이미 발급된 초대 수락은 이 설정과 독립적으로 유지한다.
- 운영·Preview는 계속 공개 가입 미개방으로 배포한다.
- 기관 결정·대상·최소 권한·수집 문안과 실제 해외 처리 사실을 비공개 검토본에 기록한다.
- 실제 계정 생성·본인 동의·최종 문안 승인·초대 메일 발송은 해당 요청을 받기 전 수행하지 않는다.
- 공개 가입 차단의 서버 동작, UI 상태, 배포 버전과 상태를 검증한다.
