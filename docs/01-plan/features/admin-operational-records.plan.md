# 관리자 운영 기록에서 검증 자료 제외

2026-10-17 · 요청: 관리자 화면의 검증 과정·신청내역을 숨기고 PR/푸시/병합/운영 배포.

확인된 대상: 검증/테스트 과정 4개, 연결 신청 22개, 검증 환불 서류 2개. 실제 신청서 5개(미연결 1개 포함)는 유지한다.

운영 조회에서 공통 분류를 적용한다. 과정 목록, 검색·필터 옵션, 신청/수강생 목록의 페이지 처리 전 제외, 총건수, 서류 접수 알림, 수료·운영문서·보고·모니터링·성과 집계에 반영한다. 기존 주소를 통한 관리자 상세 진입도 차단한다.

검증 기록은 삭제·취소·상태 변경하지 않는다. 비공개 별도 분류표에 기존 대상 ID와 사유를 보관하여 이름을 바꾸더라도 다시 표시되지 않도록 한다. 실제 운영 자료와 승인·증명·감사 이력은 보존한다.

권한·기관 범위·추가 인증을 그대로 유지한다. DB 조회 단계에서 제외하므로 프런트엔드에서 한 페이지만 지우는 방식으로 처리하지 않는다.

검증: 로컬 실제 RPC/페이지네이션·검색·권한 테스트, 마이그레이션 및 기존 데이터 hash 보존, 보안 advisor 전후 비교, PR 체크/운영 READY, 로그인 관리자 실제 화면과 공개 화면 회귀 확인.
