# 운영결과보고서 원본 PDF·AI 가져오기 계획

2026-09-22 · anchor-operation-result-pdf-ai-import

완료된 과정의 제출 PDF를 운영결과보고서 편집 화면에서 올리고, 원본을 과정의 기존 `result` 보관 파일로 저장한다. PDF 본문과 사진을 추출해 기존 양식의 초안에 반영한다. 원본을 사실 근거로 삼고 `gpt-5.6-terra`가 주요 내용·성과·개선점 등의 문장을 제안한다. 담당자는 제안을 검토해 선택적으로 반영·저장하며 기존 예산 확정 → 책임강사 작성·서명 → 최종 제출 절차를 유지한다.

범위: 관리자가 PDF 4MB 이하 업로드, PDF 텍스트/운영사진 추출, AI 제안, 원본과 대조할 수 있는 확인사항, 기존 입력란·미리보기·인쇄 연동. 개인정보 명단·계좌·서명, 예산·장학금, 확정 출석/수료 기록은 AI가 생성하거나 자동 확정하지 않는다. 제출 상태의 문서는 덮어쓰지 않는다.

검증: 실제 보관 보고서 세 종류에서 본문과 사진 추출, 유효성 제한, 미리보기·저장, 권한 경계, 빌드·린트·Preview 환경 동작을 확인한다.
