# 접수 문서 안내·처리이력 개선 계획

2026-10-08

## 목표
- 관리자 접수 문서 표의 수강생 안내에 접수 안내와 현재 수강 신청 상태를 함께 표시한다.
- 과정명이 이미 있는 행의 중복된 연결 과정명·기간을 제거한다. 연결 자체와 실제 등록 상태는 유지한다.
- 비고·관리 열이 일반 데스크톱 폭에서 보이도록 표를 압축하고 삭제 동작은 아이콘과 텍스트를 한 줄로 유지한다.
- 처리 이력을 별도 열로 보여 접수 시각과 승인 시각·승인자를 빠르게 확인하게 한다.

## 제약과 검증
- 현재 DB의 원본 안내·이벤트·과정 연결을 수정하지 않는다. 등록 상태에서 계산한 안내는 동적으로 보여 상태 변경 시 정확하게 갱신한다.
- 기존 상태 변경, 과정 연결, 수강 등록 확정, 삭제 기능 및 접근권한을 유지한다.
- 코드 검사와 production build, 처리이력·안내 표시 확인을 수행한다.
