# 카카오 로그인·공개 가입 준비

2026-09-19. 수강생 카카오 로그인 및 공개 가입, Git push 요청.
최신 결정: 휴대폰 인증 서비스 연결은 보류한다. 번호 입력만 필수로 가입을 허용하며 미인증 상태로 저장한다.

## 구현 범위

- 운영·스테이징의 등록된 Kakao provider를 사용하는 로그인 버튼과 PKCE callback.
- 신규 사용자는 이름·휴대폰 번호와 승인된 개인정보 문안 동의를 제출한 뒤 수강생으로 활성화한다.
- OAuth 성공과 휴대폰 본인확인을 구별한다. 전화번호는 미인증으로 저장하고 이름·전화번호 일치로 학습기록을 병합하지 않는다.
- 강사·운영자·관리자의 기존 이메일·비밀번호와 MFA 접근 조건을 유지한다.
- 기존 수강생과 같은 이메일로 Supabase가 자동 연결하더라도 카카오 가입 정보·동의 완료가 필요하다. 업무 역할 계정의 OAuth 접근은 DB에서 거부한다.
- 가입 문안을 개정하고 OAuth·DB 접근 통제 검증 후 운영·스테이징에 공개 가입을 개방한다.

## 외부 선행조건

PASS·SMS 공급자 연결·계약은 이번 범위에서 제외한다. 임의 phone_confirmed_at, 인증 완료 표시 또는 CI·DI 수집을 만들지 않는다. 미인증 번호를 계정 복구나 동일인 판정 근거로 사용하지 않는다.

검증: OAuth 오류/PKCE 실패/외부 redirect 차단, 가입 미완료 세션의 DB 접근 거부, 기존 비밀번호·MFA 회귀, 데스크톱·모바일 버튼과 안내, lint/build, main·preview push 및 배포 확인.
