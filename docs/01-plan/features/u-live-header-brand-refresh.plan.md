# U-LiVE 헤더 브랜드 교체 계획

2026-09-27

## 목적과 범위

- 공개·로그인·개인 화면에 공통으로 표시되는 헤더에서 기존 `uc` 그림을 사용자가 제공한 U-LiVE 심볼로 교체한다.
- 심볼 오른쪽에 `U-LiVE`를 표시하고, 아래 문구를 `열린 배움, 더 넓은 내일`로 바꾼다.
- 상단의 `개방형 평생직업교육` 표기와 메뉴, 로그인 동작은 유지한다.
- 사용자가 제공한 그림과 동일한 기존 투명 심볼 자산을 재사용해 로고 아래에 중복 워드마크가 생기지 않게 한다.

## 완료 기준

- 데스크톱과 모바일 헤더에서 심볼·워드마크·문구가 자연스럽게 배치된다.
- 화면 낭독기용 홈 링크 이름에 서비스명과 새 문구가 반영된다.
- lint, TypeScript, 빌드 및 실제 화면 확인을 통과한다.
- 최종 변경을 원격 Git에 push한다.

## 위험과 대응

- 작은 화면의 로고와 메뉴 간 충돌: 기존 헤더 높이를 크게 늘리지 않고 모바일 배치를 확인한다.
- 기존 브랜드 문서와 충돌: 이 문서와 후속 설계가 이전 `u-live-brand-transition`의 헤더 로고 결정을 대체한다.
