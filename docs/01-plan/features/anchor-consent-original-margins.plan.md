# 동의서 원본 여백 보존

- 요청: 첨부한 세 PDF의 원본 여백 유지, 성범죄 조회동의서의 ‘울산동부경찰서장’ 밑줄 삭제, git push.
- 기존 공유 renderer를 수정하여 브라우저 미리보기와 서버 보관본에 동일하게 적용한다.
- 개인정보동의서의 본문 폭 및 상하 여백, 청렴서약서 외곽선의 위치를 원본에서 측정해 적용한다.
- 성범죄 양식은 해당 밑줄 벡터만 제거하고 나머지 내용과 페이지 위치를 보존한다.
- PDF 1.7, KoPub Dotum, A4 단일 페이지, 입력·서명 보존을 검사하고 실제 PDF를 렌더링해 확인한다.
- 기존 제출본은 불변 이력으로 보관하며 새 서식 버전을 발행한다.
