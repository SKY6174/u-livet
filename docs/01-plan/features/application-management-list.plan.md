# 신청내역 관리 리스트 계획

2026-10-10 · 사용자 요청: 신청내역을 리스트로 표시하고 PR·push·병합·운영 배포한다.

## 목적과 범위

- `/admin/applications`의 큰 신청 카드들을 한 신청이 한 행을 차지하는 표 목록으로 바꾼다.
- 신청자, 과정, 신청 상태, 신청일시, 수강 상태를 같은 행에서 비교한다.
- 상세 이동, 삭제된 계정 표시, 검색 조건, 결과 수, 페이지 이동과 빈 목록 안내를 유지한다.
- 기존 관리 기능 설계 `issue-124-management.design.md`의 담당 기관 접근 권한과 조회 경계를 그대로 사용한다.

## 완료 기준

1. 여러 신청이 머리글이 있는 하나의 표에 행으로 표시된다.
2. 각 행은 원래 신청의 정보와 상세 링크를 보존한다.
3. 360px 화면에서는 표 내부에만 가로 스크롤이 생긴다.
4. 검색 및 페이지 링크가 기존 조건을 유지하고, 신청이 없는 경우 기존 안내가 나온다.
5. lint·타입 검사·빌드와 실제 컴포넌트 렌더링 및 브라우저 검증을 수행한다.
6. PR을 병합하고 정확한 운영 revision 및 상태 API를 확인한다.
