# 수강생 로그인·후속 서류 자격 - Plan

> Version: 1.0.0 | Date: 2026-09-23 | Status: Approved | Level: Dynamic

## 목적

- 수강생 로그인 화면에서 카카오·네이버·구글을 기본 수단으로 유지하고 이메일 로그인을 하단 보조 동선으로 이동한다.
- 수강신청원서 승인 전에는 장학금 지급신청서와 수강료 환불신청서를 사용할 수 없게 한다.
- 장학금 지급신청서는 해당 과정의 유효한 수료 승인이 확인된 뒤에만 사용할 수 있게 한다.
- 화면 조작이나 직접 RPC 호출로 자격 조건을 우회할 수 없도록 DB에서 최종 검증한다.

## 범위

- 로그인 카드 하단의 개인정보 안내와 이메일 로그인 배치
- 과정별 후속 서류 자격 조회 RPC
- 제출 RPC의 수강신청원서 승인·수료 승인 검증
- 서류 탭 비활성 상태와 사유 안내
- 대상 과정 선택 목록 제한 및 서버 오류 안내
- DB 통합 검증, 정적 검사, 빌드, 배포

## 자격 규칙

| 서류 | 활성 조건 |
|---|---|
| 수강신청원서 | 항상 활성 |
| 수강료 환불신청서 | 같은 수강생·과정의 수강신청원서가 `APPROVED` 또는 `COMPLETED` |
| 장학금 지급신청서 | 위 승인 조건 + 현재 학사 revision에 유효한 `READY` 수료 결과가 승인됨 |

`REJECTED`, `CANCELLED`, 검토 중인 원서는 자격을 만들지 않는다. 과거 수료 승인이 현재 학사 revision 또는 승인된 수료 정책과 맞지 않으면 장학금 자격으로 인정하지 않는다.

## 성공 기준

- 이메일 로그인은 개인정보 안내의 반대편인 로그인 카드 오른쪽 하단에 표시된다.
- 자격이 없는 후속 서류 탭은 비활성화되고 필요한 선행 조건이 보인다.
- 자격이 생기면 새로 고침 후 해당 탭과 과정이 활성화된다.
- 직접 RPC 호출도 같은 규칙으로 거부된다.
- 기존 멱등 제출, 환불 자동 계산, PDF 1.7 생성과 관리자 처리 흐름이 유지된다.
