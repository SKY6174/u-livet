# 강사 이력·과정 개발 계획

2026-09-19 · `anchor-instructor-development`. 전체 기획의 강사 이력/강사풀/과정 개발 항목과 승인된 운영 설계를 구체화한다.

## 목적과 범위

강사의 자기신고 이력과 사업단 확인을 구분하고, 신규·개편 제안을 승인된 과정 버전과 실제 기수 초안에 연결한다. 이미 구현한 강사 배정·출결·실적·경력증명은 유지한다.

- 모든 로그인 사용자가 승인된 모집 기관의 강사 이력 초안을 작성하고 심사를 신청한다. 학력·자격·산업/강의 경력의 명칭·기관·기간·증빙 참조를 구조화한다. 증빙 원본 파일 업로드와 지급 계좌/신분증 수집은 이번 범위에 포함하지 않는다.
- 본인 작성 → 제출 → 사업단 보완/반려/승인. 제출 자료와 심사 근거를 버전으로 보존한다. 승인에는 유효기간과 증빙 확인을 요구하며 자기 승인을 금지한다.
- 공개 소개는 별도 선택동의 후 승인된 최소 소개만 실제 배정 과정에 노출한다. 심사용 경력·증빙과 연락처는 공개하지 않는다.
- 현재 강사 역할 또는 유효 이력 승인을 가진 사람이 신규/개편 과정 제안을 작성한다. 수요 근거, 대상, 역량, 교육시간·차시, 준비물, 평가안, 예산 근거를 제출하고 별도 과정담당자가 심의한다.
- 개발 승인 시 승인 과정 버전을 생성한다. 승인본으로 여러 기수를 개설할 수 있지만 개발·개편 건수는 기수 수와 분리한다. 기존 공개/수료 정책 절차를 그대로 거친다.

## 기관 결정과 제한

사용자는 강사 등록·자격 심사 기준이 아직 미확정이며 기준 등록 후 사용한다고 답변했다. 승인된 개인정보 안내·심사 기준·공개 안내·과정개발 기준을 등록해야 해당 작업이 가능하다. 로컬 스킬의 등급·단가·세율 예시는 운영값으로 사용하지 않는다. 이력 승인은 위촉/계약이나 강의 배정 권한을 자동 부여하지 않는다. 별도 위촉 확인 후 기존 신뢰된 역할 등록과 배정 절차를 사용한다.

강사료·세무·전자계약·파일 저장/악성파일 검사·위원회 다단계 심의·공식 성과지표 자동 변경·대외 공개 강사 디렉터리는 후속이다. 외부 자격 진위 자동 조회를 구현한 것으로 표시하지 않는다.

## 완료 기준

기관/본인/역할 범위, 보완 후 새 버전, 제출 자료 불변, 자기 승인 차단, 기간·입력 검증, 정책·계정·배정 유효성, 선택 공개·철회, 개발 승인과 중복 개설 방지, 과거 기수/증명 영향 분리를 실제 로컬 Auth/RPC로 검증한다. 기존 237개 회귀, 전체 migration 재생, 보안 advisor, lint/build, 역할별 브라우저·모바일을 확인한다. 설계 대비 검사와 결과 보고를 남긴다.

모든 변경은 로컬 전용 환경이며 실제 운영 기준 등록·원격 migration·배포는 별도다.
