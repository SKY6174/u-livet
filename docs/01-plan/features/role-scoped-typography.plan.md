# 역할별 화면 글자 크기 조정 계획

2026-10-10 · 기존 설계: `adult-learner-typography-icons.design.md`

## 목표

- 사업단 구성원과 교내·교외 강사는 2px 확대 이전의 화면 글자 크기로 돌아간다.
- 수강생과 비로그인 방문자가 이용하는 화면은 같은 이전 기준보다 1.25px 크게 보인다.
- 기존 아이콘, 표의 1.5px 축소, 인쇄 양식과 기능은 유지한다.

## 검증

- 역할별 본문·Tailwind 글자 토큰·제목·표·문의처의 계산 크기를 확인한다.
- 공개 모바일/데스크톱 화면의 가로 넘침을 확인하고 lint·타입 검사·빌드를 통과한다.
- PR 병합 후 운영 버전과 상태를 확인한다.
