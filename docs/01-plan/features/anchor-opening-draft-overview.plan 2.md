# 개설 준비 임시저장 현황

2026-09-21 · anchor-opening-draft-overview

16개 계획서의 등록 양식을 개별로 열어야 본인 임시저장 여부를 알 수 있다. 기존 개설 준비 목록에서 저장 개수·최근 저장 시각·이어서 편집 링크를 제공하고 본인 저장 과정만 모아 볼 수 있게 한다.

- 작성자와 관리 조직별 비공개 원칙 유지. 목록에는 원문 계획서 정보와 저장 메타데이터만 사용한다.
- 목록용 단일 RPC로 저장 요약만 조회한다. 16번 개별 조회나 전체 편집 payload 다운로드는 하지 않는다.
- 조회 실패를 미저장/0개로 표시하지 않는다. 원문 계획서는 계속 열람할 수 있다.
- 실제 기수 등록·모집 공개·운영 일정 확정과 임시저장 상태를 구분한다.
- 저장 후 목록 갱신, 필터 결합, 권한 격리·DB 성능, 모바일 확인 후 main/preview push와 배포 확인.
