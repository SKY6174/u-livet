# 기존 운영 결과보고서 연결 - 계획

2026-09-19 · anchor-report-import

사용자가 제공한 반려동물수제간식 만들기, 파크골프지도사 양성(자격증), 달콤한 도약 로컬 쿠키 창업 마스터클래스 결과보고서를 근거로 실제 운영 과정 3건과 원본 PDF를 연결한다. 송경영 관리자는 기존 임시 운영 권한으로 검토한다.

종료 과정의 교육기간·정원·교수·내용·보고서 집계·예산·총평을 옮긴다. 원문에 없는 접수기간·수강료·선발방식은 null로 남긴다. 개인별 출결·수료 승인·강사 제출·지급내역은 만들지 않는다. 기존 전체 집계를 개인별 전산 실적과 구분하고 원문 불일치 사항을 명시한다.

완료 기준: 비공개 보관 과정 3건, PDF 원본 지문 일치, 관리자 페이지에서 직접 접근·내용 검토, 중복 실행 방지, 모집·신청 경로 차단, 회귀 검증, git push 및 운영 반영.
