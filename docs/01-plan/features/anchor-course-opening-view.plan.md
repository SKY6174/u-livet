# 운영계획서 기반 개설 준비 화면

> Feature: anchor-course-opening-view · 2026-09-19

## 목적과 근거

사용자가 제공한 16개 운영계획서의 정리 결과를 기존 관리자가 사이트에서 검토할 수 있게 한다.
[검증된 정리 자료](../../operations/2026-course-opening-plans.md)와 JSON을 단일 원천으로 사용한다.
기존 14개 현황표와 운영계획서는 서로 다른 자료이므로 각각 조회하고 연결한다.

## 범위

- 관리자 메뉴에 2026 개설 준비 화면을 추가한다.
- 아카데미·교내/교외 강사 구분·검색 및 기존 현황표와의 대응을 제공한다.
- 교육 소개·내용·대상·일정·강사·보조강사·보조인력·수강료 산식·확인 사항·원문 쪽수를 표시한다.
- 16개/244명/541시간과 기존 대응 13개·추가 3개·계획서 미제공 1개를 명확히 구별한다.
- 모집 조건 미확정과 원문 불일치를 숨기지 않는다.

## 완료 기준

1. 기존 COURSE_MANAGER 및 MFA 접근 경계를 유지한다.
2. 원천 JSON이 공개 API나 클라이언트 정적 번들에 포함되지 않는다.
3. 필터·자료 대조·예외 수치 보존·권한·서버 렌더링 검증과 앱 빌드를 통과한다.
4. 변경을 preview에 커밋·push한다.

## 범위 밖과 후속 단계

실제 과정/기수 생성, 모집·정책 승인, Production 배포, 담당자 권한 연결은 이번 화면 연결에 포함하지 않는다.
원문 계획값은 실제 실적이나 승인된 수강료로 변환하지 않는다. 실제 개설은 모집 조건 확정 후 기존 개설 절차로 진행한다.
