# 과정 안내 날짜·요일·시간 입력 개선

2026-10-07 · course-guide-date-time-fields

- 과정 안내 수정 화면의 교육기간을 시작일/종료일 date 입력으로 분리한다.
- 요일별 시작/종료 시간을 개별 입력하고 여러 행을 추가/삭제한다.
- 공개 표시는 `2026. 10. 10. - 12. 5.`, `토 14:00 - 18:00` 형식으로 맞춘다.
- 기존 DB/RPC의 period_label/time_label 계약과 revision·권한 검사를 유지하여 저장한다. 실제 개설 기수의 일정이나 기존 안내 내용을 임의 변경하지 않는다.
- 파싱 가능한 기존 값은 자동 채움, 미확정/해석 불가 안내는 원문 보존 후 사용자가 날짜/시간을 입력하면 교체한다.
- 기간/시간 역전, 잘못된 날짜, 시간 누락을 차단한다. 공개 과정의 종료일 필터가 새 표기에서도 유지되어야 한다.
- 실제 로컬 브라우저와 저장 RPC 재조회, 모바일 화면, 카탈로그 회귀, lint/build를 검증하고 PR push/merge 및 운영 배포를 완료한다.

참고: 기존 `course-card-edit-background.design.md`, `anchor-schedule-time-fields.design.md`.
