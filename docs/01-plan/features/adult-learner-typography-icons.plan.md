# 성인학습자 화면 글자·아이콘 개선 계획

2026-10-10 · 참고: https://anchor.hj.ac.kr/rcc/main.do

## 목표

- 현재 화면용 본문·보조 글씨 기준을 각각 약 2px 키워 과정 탐색과 업무 화면의 읽기 부담을 낮춘다.
- 공개 홈의 과정 검색, 신청 안내, 신청 확인, 사업 소개와 과정 카드의 핵심 행동을 의미 있는 아이콘으로 구별한다.
- 360px 모바일과 데스크톱에서 글자 잘림, 가로 넘침, 버튼 접근성 저하 없이 표시한다.

## 범위와 기준

- 기존 디자인 가이드 `docs/02-design/features/u-livet-design-guide.md`의 16px 루트와 18px 본문 체계를 유지하며 화면용 글자 토큰만 조정한다. 인쇄 양식, 로고 내부 문자, 데이터·권한 동작은 그대로 둔다.
- 아이콘은 기존 `lucide-react`를 재사용하고 텍스트 레이블을 유지한다. 장식 아이콘은 보조 기술에서 숨긴다.
- 공통 토큰 및 공개 홈·과정 카드에서 우선 개선하고 필요하면 주요 탐색 UI를 조정한다.

## 완료 조건

- 화면용 `text-xs`, `text-sm`, `text-base`와 기본 본문의 계산된 크기가 기존보다 2px 커진다.
- 핵심 진입점의 아이콘 의미가 명확하고 모바일 줄바꿈·키보드 포커스가 정상이다.
- lint, 타입 검사, 빌드 및 공개 홈·과정 화면의 시각 검증을 마친다.
- PR 병합·push 후 운영 배포 상태와 공개 경로를 확인한다.
