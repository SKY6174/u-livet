# 과정 운영과 결과보고서 통합 관리

2026-09-20 · anchor-course-workspace · Dynamic

## 목표
과정 목록 → 운영 개요 → 담당 업무 → 결과보고서·출력으로 이어지는 일관된 작업 공간을 만든다. 운영진이 과정별 상태, 누락 자료, 입력 담당자와 다음 행동을 실제 저장 자료 기준으로 파악하도록 한다.

## 범위
- 검색·상태 필터와 과정별 운영/보고서 요약을 갖춘 관리자 목록.
- 공통 과정 헤더 및 운영 개요/신청·강사/결과보고서 메뉴. 기존 관리 폼은 신청·강사 화면으로 이동.
- Supabase의 과정·보고서·출결·수료·강의실적·첨부를 집계하는 기관 범위 읽기 RPC. 목록에서 파일 본문·계좌·참여자 명단은 가져오지 않는다.
- 보고서 6종별 자료 상태, 입력 담당 및 보완/출력 링크. 긴 원본 설명은 펼쳐보기로 정리한다.
- 기존 보관 과정은 원본 집계와 개인별 전산 기록을 구분한다. 데이터 없는 문서는 완료로 오인시키지 않는다.
- 강사 출결 입력, 운영진 지급 입력, MFA/기관 권한, 보고서 저장 충돌 검사는 유지한다.

## 완료 기준
3개 보관 과정과 신규/운영 과정 모두 자연스러운 이동이 가능하다. 수정·첨부·승인 후 DB 재조회로 상태가 갱신된다. 일반 사용자·타기관 접근 차단, 오래된 수료 승인 제외, 오류/빈 상태와 모바일 화면을 검증하고 Git에 반영한다.
