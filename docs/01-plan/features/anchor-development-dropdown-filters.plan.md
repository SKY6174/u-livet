# 과정 개발·심의 분류 필터 계획

2026-09-24

## 목표
- 연차, 주관기관, 기관별 센터·팀, 아카데미를 한 줄의 드롭다운으로 선택한다.
- 선택한 분류가 제안 목록과 승인 개발·개편 건수에 정확히 반영된다.
- 앵커사업단에는 ECC·ICC·RCC·AID-X, 산학협력단에는 산학기획팀·산학지원팀을 제공한다.

## 범위
- 관리자와 강사가 공유하는 과정 개발·심의 목록 화면 및 제안 생성 분류.
- 기존 분류와 제안은 보존하고, 기존 산학협력단 `WORKER` 자료는 전체에서 계속 조회한다.
- 아카데미 분류는 제안 버전의 교육 분야 값으로 판단한다.

## 완료 기준
- 선택 순서: 사업연도 → 주관기관 → 센터·팀 → 아카데미. 각 선택 후 나머지 유효한 선택은 유지한다.
- 아카데미 네 영역과 전체 선택이 가능하며, 필터가 100건 제한과 집계 전에 적용된다.
- 잘못된 URL 값과 기관별 잘못된 분류가 다른 기관의 자료를 노출하지 않는다.
- lint, build, DB 함수 검증, Preview와 운영 배포를 완료한다.
