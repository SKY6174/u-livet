# 구성원 관리 계획

2026-09-21 · 사용자 요청 승인 · Dynamic

기존 계정 직책/강사 구분 화면을 사업단·강사·수강생 구분 버튼이 있는 구성원 관리로 확장한다. 사업단은 직책/성명/이메일/사무실 전화/핸드폰/비고, 강사는 교내외/성명/이메일/문의용 연락처/강의이력/비고, 수강생은 성명/이메일/핸드폰/생년월일/수강이력/비고를 순번과 함께 제공한다. 모든 분류에서 수정·삭제가 가능하다.

DB 권한과 이력 보존, 조직 간 개인정보 분리, 추가 인증 및 입력 검증을 유지한다. 목록은 서버 검색/페이지 처리, 이력은 필요할 때만 조회한다. 로컬 SQL·권한 회귀·브라우저·production build 검증 후 Preview/운영 DB에 검증된 추가 migration을 적용하고 main을 git push한다.
