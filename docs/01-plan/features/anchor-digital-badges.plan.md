승인된 배지 정의와 최신 확정 수료 근거를 바탕으로 홈페이지 내부 배지를 신청·발급·보관·검증한다. 이름/업적/기준/발급기관/근거/버전/상태가 있는 실제 발급 원장을 만들며 예시 배지를 실제 발급으로 표시하지 않는다. 기본 비공개이며 본인이 승인된 공유 안내문을 확인해 별도 선택해야 외부 검증을 허용한다.

범위: 기수별 배지 정의 초안/별도 승인, 발급 위임, 본인 신청/철회 및 담당자 반려, 원장·JSON 원본, 정정 대체/취소/만료·원자료 변경, 수강이력 연결, 공유 링크 생성·교체·철회, 최소정보 공개검증. 기존 증명 발급권에 BADGE 종류 위임을 추가한다. 실제 정책·권한은 기관 확인 전 생성하지 않는다.

외부 업체나 표준 연동 계획은 선택 질문을 보냈다. 답변 전 기본은 홈페이지 내부 발급이며 외부 연결을 추가할 수 있는 명시적 포맷 버전이다. Open Badges 3.0 서명·지갑 API·적합성 검증, 외부 전송, 일괄 발급, 마이크로디그리 복합 조합, 디자인 파일 업로드는 후속 범위다.
