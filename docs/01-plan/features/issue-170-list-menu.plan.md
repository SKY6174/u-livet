# Issue 170: 과정 리스트 관리 메뉴 표시 계획

2026-10-13 · [이슈 #170](https://github.com/SKY6174/u-livet/issues/170)

## 문제와 목표

`/admin/courses`의 리스트형 표가 스크롤 영역보다 넓어서 오른쪽 상태/관리 버튼이 잘린다. 모든 관리 메뉴를 화면 안에서 확인할 수 있게 한다.

- 상태/관리 머리글과 셀을 스크롤 영역 오른쪽에 고정한다.
- 작은 화면에도 관리 열과 버튼이 들어가게 하고, 나머지 과정 정보는 기존 가로 스크롤로 확인한다.
- 기존 카드형, 관리 권한별 메뉴 및 링크, 검색과 필터를 유지한다.

## 완료 기준

수정 전 클리핑을 브라우저에서 재현하고, 360/768/1440px에서 스크롤 전후 모든 관리 링크의 영역과 글자가 셀 및 화면 안에 들어가는지 확인한다. 카드/리스트 및 관리자/조회 사용자 메뉴 구성을 대조한다. lint·타입 검사·빌드 후 PR·push·병합·운영 READY 및 정확한 revision을 확인한다.
