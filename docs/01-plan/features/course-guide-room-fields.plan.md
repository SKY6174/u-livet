# 교육장소 호실·호실명 입력 분리

2026-10-07 · course-guide-room-fields

과정 안내 수정의 교육장소 입력을 호실과 호실명 두 칸으로 나눈다. 기존 `2-418, 비앤비네오필라테스센터`는 각각 자동으로 채운다. 여러 호실만 있는 기존 안내와 외부 장소명만 있는 안내도 보존한다. 한쪽만 입력할 수 있고 둘 다 비어 있거나 합친 장소가 기존 160자 제한을 넘으면 저장을 차단한다.

기존 location 저장 계약·권한·revision 및 공개 교육장소 표시를 유지하며 schema 변경은 없다. 실제 저장·DB 재조회·재열기, 기존 16개 안내 보존, 모바일을 확인하고 lint/build 및 PR push/merge·운영 배포를 진행한다.
