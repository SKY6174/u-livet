# 과정 운영 목록과 예산 관리

2026-09-21 · anchor-course-budget

2026년 공개 안내에 등록된 16개 과정을 과정 운영 화면에도 표시하고, 연결된 세 개 운영·보고 자료는 중복 없이 유지한다. 카드/리스트 선택, 프로그램 ID, 인력·일정 정보를 제공한다.

첨부 예산표의 여섯 항목을 초기 예산으로 저장하고 관리자와 과정 담당자가 기관 범위에서 수정할 수 있게 한다. 예산 집행은 양식 미확정 상태이므로 XLSX의 시트·제목 행을 선택하여 확인하고 기관별 조회용 스냅샷을 저장한다. 실제 지출 원장이나 지급 승인으로 처리하지 않는다.

성공 기준: 16개 목록, 합계와 개별 예산 저장, 권한·MFA·동시 수정 보호, 엑셀 오류 및 파일 크기 제한, 기존 과정 이동, 빌드·브라우저 검증, main/preview push 및 DB 배포.
