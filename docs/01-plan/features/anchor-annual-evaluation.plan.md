# 연차별 과정 평가·성과 관리 계획

2026-09-19 · anchor-annual-evaluation · Dynamic

## 목적

전체 설계 A12/API25/T25~T26에 따라 운영 현황, 과정 품질 환류, 승인 지표 보고를 연결한다. C1 PDF 인쇄 168~169쪽(파일 12~13쪽)을 다시 확인했다. 2차년도 목표 110명/52명/108.2%/6건/10%/16%/111.7%/77%/52%/64.5%는 사업계획 참고값으로만 표시한다. 목표는 실적이 아니다. 지원지수 산식 불일치 D06은 유지한다.

## 범위

1. 기관·사업연도·아카데미별 현재 원장 집계: 신청, 등록 실인원/수강건수, 중도취소, 최신 확정 수료, 미확인 자료. 기수 귀속 사업연도를 사용하고 달력연도와 구분한다.
2. 승인된 설문 정책/문항/공개 임계값을 사용하는 종료 과정의 선택 만족도 조사. 참여확인과 응답 내용 분리, 마감 전 또는 소수 응답의 점수 공개 차단.
3. 강사 의견, 사업단의 유지/개편/통합/폐지 검토, 담당·기한·다음 기수 반영·별도 확인 이력.
4. 공식 지표 정의 초안/별도 승인, 자료원·분자·분모·미확인·증빙 참조, 등록 지표 보고 초안/별도 확정/새 버전 정정.
5. 이전 166개 회귀 및 신규 DB/Auth 검증, 빌드·보안 검사·브라우저 역할별 흐름 확인.

## 운영 경계

기관의 공식 산식·중복·분모 기준은 아직 별도 확인되지 않았다. 승인 정의 없으면 공식 보고 확정을 막는다. 사업계획에 없는 산식을 임의 승인하지 않는다. 학사/취업/장학 원자료가 없으면 0이나 미취업으로 대체하지 않는다. 외부 지표는 승인 정의와 확인된 비식별 수치·증빙 참조를 등록하는 경로까지만 제공한다. 학사시스템 자동 연계, 실제 공식 보고 제출, 과거 시점 상태 복원, 사전·사후 역량 분석은 후속이다.

선택 설문을 수료/발급 요건으로 강제하지 않는다. 기존 상세설계가 로컬 도메인 스킬의 예시 기본 요건보다 우선한다. DB 명명은 이미 채택한 Supabase CLI timestamp migration을 유지한다.

## 성공 기준

중복수강 실인원 분리, 사업연도 경계 및 미확인 표시, 무자료 분모의 null, 설문 중복/타인 응답 차단과 공개 임계값, 미승인 정의·누락 증빙·자기승인·원자료 변경 보고 차단, 확정본 불변/정정 버전, 역할·기관 격리를 검증한다. 실제 기관 정책/실적을 가상 seed로 채우지 않는다.
