# 2026 운영계획서 강사 pool 및 책임강사 반영

2026-09-24 · Dynamic

## 목적

사용자가 제공한 16개 운영계획서의 이름이 확인된 강사와 보조강사를 강사 pool 및 구성원 관리 강사 목록에서 조회할 수 있게 한다. 각 과정의 첫 교내 강사를 책임강사로 지정하고, 교외 강사만 있는 여섯 과정에는 현용환 센터장을 지정한다.

## 범위

- 원본 MD 16개와 기존 추출본 `docs/operations/2026-course-opening-plans.json`의 강사 순서·교내/교외 구분·소속을 대조한다. 미정 인원과 보조인력은 강사 pool에 인물로 등록하지 않는다.
- 같은 이름이어도 소속이 다르면 신원을 자동 합치지 않는다. 기존 실명·교내/교외가 일치하는 pool 기록은 재사용하고, 관리자가 이미 수정한 비어 있지 않은 정보는 유지한다.
- 계정 이메일·연락처는 추정하지 않는다. 새 인물은 로그인 미연결 상태로 등록한다. 교외 강사는 강사 pool에 등록하되 필요서류와 계정 확인 전에는 새 강사 역할을 자동 승인하지 않는다.
- 기존 교내 강사 9명·10개 과정의 초기 지정은 검증·유지한다. 16개 과정의 계획상 책임강사를 지정하고, 실제 기수가 개설된 과정에만 운영 책임을 연결한다. 센터장은 운영 DB에서 실제 등록된 `CENTER_HEAD` 구성원과 안전하게 연결하고, 없을 때는 기존 초기 인물을 사용한다. 기존 제출본은 변경하지 않는다.
- 구성원 관리의 강사 목록에도 pool 강사를 읽기 전용으로 표시해, 화면에서 기존 1명만 보이는 현상을 해결한다. pool 전용 인물의 상세 관리는 강사 마스터로 이동한다.
- Preview와 Production에 동일한 이관을 적용하고 원본 대비 인원·과정·책임강사, 권한 및 배포를 검증한다. main과 preview에 git push한다.

## 위험 관리

이름만으로 동일인이라고 판단하면 다른 강사를 합칠 수 있다. 소속까지 확인한다. 로그인 이메일을 임의 생성하지 않는다. 운영계획서 등록만으로 교외 강사 문서 작성 권한을 열지 않는다. DRAFT/ARCHIVED 문서 상태와 제출 이력은 보존한다.
