# anchor-learner-refund-document - Plan Document

> Version: 1.0.0 | Date: 2026-09-23 | Status: Approved
> Level: Dynamic

## 1. Overview

### 1.1 Purpose

수강생 작성 서류 화면에 `수강료환불신청서`를 세 번째 문서로 추가한다. 수강생은 기존 두 양식과 같은 창에서 환불 신청 정보를 입력하고 원본 서식에 반영된 PDF 1.7 파일을 미리보기 및 다운로드할 수 있다.

### 1.2 Background

현재 작성기는 수강신청원서와 장학금 지급신청서만 제공한다. 새 환불 신청서도 기존 문서 전환·미리보기·서명·다운로드 흐름을 재사용하되, 첨부 PDF의 A4 크기, 여백, 표, 문구, 반환기준을 그대로 보존해야 한다.

## 2. Goals

### 2.1 Primary Goals

- [x] 동일 창의 문서 선택 영역에 수강료환불신청서 버튼을 추가한다.
- [x] 환불 신청에 필요한 인적사항, 입금계좌, 발생시점, 반환내역, 신청일, 서명을 입력할 수 있게 한다. 원본에 고정된 반환사유 `개인사유`는 그대로 표시한다.
- [x] 원본 PDF 페이지 위에 입력값만 합성하고 결과를 PDF 1.7로 출력한다.
- [x] 세 문서의 입력 상태를 독립적으로 유지한다.

### 2.2 Non-Goals

- 서버 저장, 온라인 제출, 승인, 환불금 자동 계산은 포함하지 않는다.
- 원본의 반환기준이나 법률 문구를 편집하지 않는다.

## 3. Scope

### 3.1 In Scope

- 환불 신청서 템플릿 등록 및 출처 문서 갱신
- 환불 문서 타입·필드·검증 규칙 추가
- 환불 입력 화면과 PDF 좌표 매핑 추가
- 다운로드 문서의 A4 1페이지 및 PDF 1.7 검증
- 기존 두 문서 회귀 검증과 데스크톱·모바일 화면 검증

### 3.2 Out of Scope

- 학사·결제 시스템 연동
- 반환기준에 따른 환불액 자동 산정
- 전자문서 서버 보관 및 담당자 알림

## 4. Success Criteria

- [ ] 세 번째 버튼으로 환불 신청서를 선택할 수 있고 다른 문서와 전환해도 입력값이 유지된다.
- [ ] 필수값과 전화번호·주민등록번호·계좌·금액·날짜 형식을 검증한다.
- [ ] 원본 페이지의 크기, 여백, 표, 고정 문구가 픽셀 수준으로 유지된다.
- [ ] 입력값과 서명이 각 원본 칸 안에 겹침이나 잘림 없이 표시된다.
- [ ] 다운로드 결과가 A4 1페이지이며 헤더와 Catalog가 PDF 1.7이다.
- [ ] TypeScript, lint, build, PDF 자동 검증, 브라우저 QA가 통과한다.
- [ ] 검증된 변경을 `main`에 커밋하고 원격 저장소에 push한다.

## 6. Risks & Mitigations

| Risk | Impact | Probability | Mitigation |
|------|--------|-------------|------------|
| 좌표 오차로 입력값이 원본 칸을 벗어남 | High | Medium | 원본 좌표를 pt 단위로 측정하고 PNG 렌더링으로 확인한다. |
| 환불 입력값이 다른 문서 상태와 섞임 | High | Low | 문서 타입별 폼 객체와 저장 기준을 독립 관리한다. |
| 민감정보가 브라우저 밖에 저장됨 | High | Low | 기존 정책대로 클라이언트 메모리에서만 처리하고 서버 저장을 추가하지 않는다. |
| 원본 서식이 재조판 과정에서 변형됨 | High | Low | 원본 1페이지를 그대로 복사한 템플릿을 사용하고 입력값만 오버레이한다. |
