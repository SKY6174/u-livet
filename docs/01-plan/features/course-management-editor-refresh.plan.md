# 과정 관리 입력 화면 개선 — Plan

2026-10-07 · course-management-editor-refresh

## 목적

과정 관리에서 장소별 차시 메모를 한 칸에 섞어 쓰고, 교육내용·대상·준비사항도 한 칸에 섞여 있어 입력과 공개 안내가 모호하다. 공통 기본 정보와 강사 배정의 용어·배치를 실제 업무 순서에 맞춘다.

## 범위와 완료 기준

- 교육장소를 최대 3행으로 편집한다. 넓은 화면에서 `장소 번호 | 교내/교외 | 강의실·장소명 | 비고 | 삭제` 한 줄로 표시하고 좁은 화면에서 세로 배치한다. 기존 장소 문구는 수정 전 원문을 유지한다.
- 교육내용, 교육대상, 준비사항을 별도 박스로 입력하고 공개 과정 안내에서도 각각 구분해 표시한다. 기존 본문은 손실 없이 읽는다.
- 과정명·정원 / 모집 상태·선발방식 / 운영방식 / 접수 시작·마감 / 교육 시작·종료 순으로 배치하고 과정 소개의 수강생 대상 용도를 설명한다.
- 강사 배정에서 ‘기수’는 ‘이번 개설 과정’으로 풀어 쓰고, 동일 교육과정의 실제 개설 이력이 2건 이상일 때만 운영 순서를 표시한다. 주요 저장·배정 버튼을 오른쪽에 배치한다.
- 기존 권한·revision·정원/일정 검증과 가이드 동기화는 유지한다. lint·타입 검사·빌드·Preview·운영 배포를 검증한다.
