# 결과보고서 관리자 검토 - 계획

2026-09-19 · anchor-report-review

송경영 관리자가 임시 과정 운영진으로 결과보고서 구성을 검토한다. 운영 DB 조회 결과 동일 계정에 SYSTEM_ADMIN과 기존 시범 COURSE_MANAGER가 유효하며 이메일 인증·TOTP 등록을 완료했다. 중복 역할을 만들지 않는다. 임시 역할의 종료일은 지정되지 않았으며 담당자 인계 시 회수한다.

운영 과정이 0개여서 현재 보고서 경로에 진입할 수 없다. 과정 등록 없이 관리자 화면에서 여섯 실제 출력 양식을 검토하는 전용 페이지를 제공한다. 가상 예시를 사용하며 운영 DB에 과정·출석·수료·지급 내역을 저장하지 않는다.

완료 기준: 운영자 권한 확인, 관리 메뉴에서 검토 화면 연결, 여섯 양식별 입력 담당 안내·선택·인쇄, 모든 예시 용지의 검토용 표시, 익명·비운영자 접근 차단, 빌드·화면 확인 및 Git 푸시.
