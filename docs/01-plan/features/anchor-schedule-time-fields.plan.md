# 강의 일정 입력 구조 조정

2026-09-23 · anchor-schedule-time-fields

## 목적

운영계획서와 운영결과보고서의 회차별 일정에서 날짜와 시작·종료 시간을 각각 입력하고, 주강사와 보조강사의 이름·교육시간 관계를 명확하게 표시한다.

## 범위

- `일자`, `시작시간`, `종료시간`을 별도 입력 필드로 제공한다.
- 강의주제 및 내용과 교육장소는 각각 한 칸으로 유지한다.
- 주강사는 강사명·교육시간, 보조강사는 강사명·교육시간의 두 칸으로 묶어 표시한다.
- 입력 화면, 저장 검증, AI PDF 가져오기, A4 미리보기·PDF 출력에 같은 구조를 적용한다.
- 기존 `일시` 문자열 데이터는 날짜·시작시간·종료시간으로 변환하되 파싱할 수 없는 원문은 날짜 칸에 보존한다.

## 완료 기준

- 날짜 입력기는 날짜형, 시작·종료 시간 입력기는 시간형으로 동작한다.
- 저장 데이터의 일정 행은 `date/startTime/endTime/topic/instructor/hours/assistant/assistantHours/location` 구조다.
- 출력 표는 `일자 | 시작시간-종료시간 | 강의주제 및 내용 | 주강사 2칸 | 보조강사 2칸 | 교육장소` 구조다.
- 기존 계획서·결과보고서 일정과 최종 제출본이 유실되지 않는다.
- 회귀 검증, 린트, 빌드와 실제 출력 확인을 통과한다.
