# 기존 과정 소개 카드 복구 계획

2026-09-21 · anchor-public-course-cards

교육과정 찾기에서 기존 보관 과정 3개가 익명 RLS 조회에서 제외되어 0개로 표시된다. 데이터는 Production과 Preview에 그대로 존재한다. 사용자는 누구나 과정 소개 카드를 보고 보고서는 관리자만 접근하는 범위를 선택했다.

- 기존 3개 과정의 소개 카드와 상세 소개를 공개한다.
- 다른 비공개 보관 과정과 준비 중 과정은 공개하지 않는다.
- 과정 상태와 모집 가능 여부, 관리자 업무·보고서·첨부의 접근 제한을 유지한다.
- 공개 조회/직접 상세 접근과 비공개 자료 차단을 검증하고 Preview·Production DB 적용 및 Git push를 수행한다.
