# 2026~2027 과정별 연간 PDCA 확장 계획

> 2026-09-25 | Dynamic | 사용자 요청

## 목표

2026년 16개 과정의 일정표를 2026년 1월부터 2027년 2월까지 표시한다. P(과정준비 → 운영계획서 제출 → 수강생모집), D(과정운영), C(과정별 성과평가), A(성과평가 기반 차년도 운영 여부 반영)를 과정별로 계획하고 기록한다.

## 범위와 원칙

- 기존 신호등·실제 운영 비교·권한 제한을 유지한다.
- P의 세 업무 각각 목표일과 완료일을 저장한다. 기존 P 목표/완료 값은 수강생모집 일정의 이전 입력값으로 보존한다.
- A에 차년도 운영 판단(미정·계속·개편·중단)과 근거/반영 내용을 남긴다.
- 14개월 표에 한 달에 겹치는 단계들을 모두 표시하며, 공개 안내 기간은 확정 계획과 구분한다.
- 원본에 없는 P/C/A 날짜나 차년도 결정을 임의로 만들지 않는다.
- 실제 증빙에 따른 P·D·C·A 완성도를 과정별로 표시한다. P는 운영계획서 최종 제출과 모집 종료, D는 전체 예정 회차 대비 출결 입력, C는 결과보고서와 1~2회 자체평가회, A는 사업단 평가 또는 자체평가회 수행을 사용한다.
- 평가회 수행일과 자체평가 목표 횟수를 권한·MFA·수정 충돌 검사를 유지한 저장 경로에 기록한다. 일정 신호등도 제출·출결·평가 증빙을 반영한다.

## 완료 기준

- 모든 과정 행에 ’26.1월~’27.2월 14개 월이 순서대로 표시된다.
- P 3개 업무와 D/C/A 흐름을 표·상세 편집·저장값에서 확인할 수 있다.
- 단계별 완료 지연, 미계획, 애로 신호가 일관되게 계산된다.
- 단계별 완성도 P 0/50/100%, D 0~100%, C 0/75/100%, A 0/100%가 실제 운영 문서·출석부·평가회 기록에 따라 표시된다.
- 입력 범위·날짜 순서·권한·수정 충돌을 검증하고 빌드·린트·타입 검사를 통과한다.
