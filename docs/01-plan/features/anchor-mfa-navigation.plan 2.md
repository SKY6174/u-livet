# 인증 완료 후 화면 이동 계획

2026-09-19 · anchor-mfa-navigation · Dynamic

## 문제와 목표

인증 앱으로 확인을 마친 계정에도 코드 입력 폼이 계속 표시되고, 인증을 요청한 작업 화면으로 수동 복귀해야 한다. 인증된 세션으로 인증 URL을 다시 방문해도 동일 폼을 보게 된다.

- 유효한 추가 인증을 유지하면서 화면을 이동한다.
- 인증을 요청한 화면이 있으면 성공 후 자동 복귀한다.
- 최근 인증이 완료된 상태에서는 코드 입력 폼을 숨긴다.
- 직접 연 계정 보안 화면에서는 인증 앱 추가·해제 기능을 계속 제공한다.

## 범위와 완료 기준

현재 Supabase SSR 쿠키·서버 검증과 기존 관리자 MFA 설계를 재사용한다. DB 권한, 인증 만료와 최근 15분 저장·승인 조건은 유지한다. 추가 인증이 필요한 상태·잘못된 코드·등록 중에는 입력 흐름이 정상 작동해야 한다. 새 창 인증 후 원래 화면의 입력과 사용자 저장 확인도 유지한다.

UI/서버 회귀 검증, 린트·빌드 후 수정만 Git push한다. 다른 작업의 미완료 변경은 별도 작업 디렉터리로 보존한다.
