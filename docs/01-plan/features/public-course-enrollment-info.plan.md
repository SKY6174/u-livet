# 공개 과정의 수강료·이수·장학 안내 — Plan

2026-10-08 · public-course-enrollment-info

## 목적

수강생이 과정 소개에서 신청 전에 필요한 수강료, 이수요건, 장학금 안내를 함께 확인할 수 있도록 한다. 현재 과정 소개에는 수강료를 별도 모집 안내로 돌리는 문구만 있고 승인된 수료기준은 연결하지 않는다.

## 범위

- 연결된 개설 과정의 수강료와 접수기간을 과정 소개에 표시한다. 미연결·미확정 정보는 금액을 추정하지 않는다.
- 승인되어 유효한 해당 과정의 수료기준 제목·버전·원문을 이수요건으로 표시한다.
- 기존 운영절차에서 확인된 장학금 지급 흐름을 소개하고, 과정별 대상·금액·신청방법이 공개되지 않았다는 상태를 명시한다. 수료만으로 지급이 보장된다고 표현하지 않는다.
- 이미 수강료·수료기준을 보여주는 개설 과정 상세에도 동일한 장학금 안내를 표시한다.

## 제외

장학금 지급률·금액·대상 조건을 새로 정하거나, 승인되지 않은 문안을 정책으로 게시하지 않는다. 장학금 지급·신청 자격 로직과 DB 스키마는 변경하지 않는다.

## 완료 기준

연결/미연결 과정 및 무료/유료/미확정 수강료에 사실과 다른 정보가 나타나지 않는다. 승인된 수료기준만 공개하고 미등록 상태를 분명히 표시한다. 두 공개 상세 화면에 장학금 안내가 일치한다. lint·빌드와 PR Preview를 통과하고 운영 배포 버전을 검증한다.
