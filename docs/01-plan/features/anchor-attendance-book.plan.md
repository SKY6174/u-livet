# 강사 출석부와 개인 출석 확인

2026-09-21

## 목표
기존 공식 출결 DB를 활용해 강사는 담당 과정의 출석부를 생성·기록·인쇄하고, 수강생은 본인 출석 현황을 확인한다. 과정별 요청 횟수와 전송량, 반복 검색 비용을 줄이고 DB 연결과 실제 응답시간을 측정한다.

## 범위
- 담당 강사용 과정별 출석부: 수업 일정 등록, 활성 수강생 명단 자동 구성, 회차별 출결 일괄 저장, 정정 사유, 인쇄.
- 본인 출석 확인: 수업별 인정시간/휴강/예정/미입력 구분, 종료된 수업 기준 집계.
- DB 읽기는 역할·담당 과정 또는 본인 등록 범위로 제한하며 새 RPC는 기존 공식 출결·감사·정정 버전을 재사용한다.
- 실제 운영·Preview는 연결·배포 검증, 테스트 쓰기와 성능 비교는 별도 로컬 합성 데이터에서 수행한다.

## 완료 기준
명단 생성 자체가 출석 처리하지 않는다. 미입력은 결석과 구별한다. 권한·만료 배정·타인 정보·정정 경합·부분 실패·휴강/보강/미래 수업을 검증한다. 관련 회귀·빌드 통과, 필요한 migration 적용, main/preview push와 배포 확인.
