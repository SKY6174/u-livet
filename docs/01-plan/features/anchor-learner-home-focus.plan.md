# 수강생 홈의 내 수업 중심 개편 계획

2026-09-23 · Dynamic

## 목표
- 수강생 `/`에서 본인이 활성 수강 중인 수업과 다음 일정, 출석 상태, 강의실·질문·출석 바로가기를 첫 화면의 중심으로 둔다.
- 다른 과정은 본인의 신청·수강 이력과 중복되지 않는 추천을 작은 가로 이동형 카드로 그 아래에 둔다.
- 관리자·강사 홈과 수강생 `/mypage`의 기존 경로·권한을 유지한다.

## 범위와 판단
- 기존 `life_my_learning()` 권한 검증 RPC와 `getCourseCatalog()`를 재사용한다. 새 테이블·마이그레이션 없이 홈에 필요한 데이터만 조회한다.
- 모집 가능 여부를 추측하지 않고 과정 소개 링크로 보낸다. 추천은 동일 교육분야를 우선하며, 신청·수강했던 과정은 제외한다.
- 수업이 없으면 신청 현황 또는 과정 탐색 안내를, 조회 실패는 오류로 구분한다.
- 가로 이동은 터치 스와이프·트랙패드 스크롤·이전/다음 버튼으로 가능하게 한다. 작은 화면에서 페이지 전체가 가로로 넘치지 않게 한다.

## 완료 기준
- 활성 수강생은 자기 수업 이름·다음 수업·출석 상태와 강의실·질문·출석 링크를 본다.
- 신청만 했거나 수업이 없을 때 잘못된 수강 현황을 표시하지 않는다.
- 추천에 본인 과정이 없고, 실패 상태와 빈 상태를 구분한다.
- 역할별 홈 회귀, 추천 정렬·중복 제외, 가로 카드 렌더링, lint·type·build를 통과하고 Preview와 운영에 순서대로 반영한다.
