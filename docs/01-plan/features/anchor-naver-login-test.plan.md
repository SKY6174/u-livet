# 네이버 로그인 검수 테스트 및 개인정보 안내

작성일: 2026-09-22. 사용자 요청: 준비 중인 네이버 로그인을 실제 연결하고 개인정보 안내에 네이버 내용을 추가한 뒤 git push.

## 목표와 범위

- 기존 로그인 디자인과 수강생·교외 강사 흐름에서 네이버 인증을 시작할 수 있게 한다.
- Supabase `custom:naver`가 네이버의 중첩 사용자 정보 응답을 읽을 수 있도록 최소 정보 변환 경로를 제공한다.
- 이메일 확인이 필요한 경우 취소 오류와 구분해 안내한다. 확인되지 않은 이메일을 임의로 인증하거나 계정을 병합하지 않는다.
- 네이버 제공 항목과 이용 목적, 선택권, 연결 해제 안내를 개인정보 v5에 기록하고 운영 가입 정책을 새 버전으로 연결한다.
- 운영에서 실제 네이버 인증 화면 도달 및 개인정보 안내 반영을 확인한다. 개인 계정 인증·동의는 이용자가 수행한다.

## 완료 기준

- 네이버 버튼이 활성화되고 실제 네이버 로그인 화면에 도달한다.
- 변환 경로는 유효한 네이버 토큰을 검증하고 회원 식별자·이메일만 반환하며 응답과 토큰을 저장·캐시·로그에 기록하지 않는다.
- 가입 완료 및 QR 복귀, 교내·사업단 제한, 기존 동의 기록이 보존된다.
- 관련 회귀 검사, lint, 빌드와 운영 배포 확인을 완료한다.
