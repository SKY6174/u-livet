# 공개 가입 준비 점검 계획

2026-09-19 · anchor-signup-readiness · Dynamic

## 목적

메일 연결 이후 공개 가입에 필요한 기관 결정, 최초 관리자 설정, 기술 검증의 간격을 확인한다. 이번 작업의 완료 대상은 검토 자료와 읽기 전용 점검이며, 실제 가입 개방은 별도 실행 단계다.

## 범위

- 운영·Preview의 승인 개인정보 문안, 계정·관리자·MFA 등록 상태를 개인정보 원문 없이 조회한다.
- 현재 가입·개인정보 화면, 동의 저장, 최초 계정 생성 트리거, 업무 역할을 설계와 비교한다.
- 가입에 필요한 수집·이용 동의 초안과 전체 처리방침 검토안을 작성한다.
- 국내 담당자가 확정해야 할 보유기간, 연락처, 처리 위탁·국외이전 정보를 명시한다.
- 최초 정책 승인과 계정 생성의 순서, 본인 동의·이메일 확인·MFA·권한 지정 절차를 문서화한다.
- 반복 실행 가능한 읽기 전용 SQL 점검을 준비한다.

기관의 법적 판단, 승인자·관리자 임의 지정, 동의 대행, 운영 데이터 생성 및 공개 가입 활성화는 이번 점검의 완료 조건에 포함하지 않는다. 실제 담당자가 정해지면 구체적 문안과 역할을 확인받고 후속 실행한다.

## 완료 기준

1. 운영·Preview 상태를 각각 확인하고 관찰 시각을 남긴다.
2. 기술 구현과 운영 미확정 사항을 구분한 갭 표가 있다.
3. 초안의 모든 미확정 내용은 명시적으로 표시하며 승인본으로 게시하지 않는다.
4. 최초 관리자 절차는 가입 트리거·동의 이력·이메일 검증을 우회하지 않는다.
5. 점검 SQL은 읽기 전용으로 실행되며 이름·이메일·비밀번호·키·토큰을 출력하지 않는다.
