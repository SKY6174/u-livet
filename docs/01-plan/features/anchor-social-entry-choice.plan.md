# 간편 인증 후 회원가입·로그인 선택 계획

2026-09-21 · 사용자 요청: 카카오 로그인 뒤 곧바로 가입 양식이 나타나는 흐름 개선.

## 목적과 범위
- 간편 인증을 통과했지만 U-LIFE 간편가입을 완료하지 않은 이용자에게 새 회원가입과 기존 계정 로그인 선택을 제공한다.
- 가입을 완료한 간편 로그인 회원은 기존처럼 원래 화면으로 이동한다.
- 기존 계정 로그인을 선택하면 현재 브라우저의 U-LIFE 인증 세션을 종료하고 로그인 방법 선택으로 돌아간다.
- 카카오와 Google이 공유하는 가입 화면에 동일하게 적용한다. DB 구조·계정 병합·제공자 연결·동의 문안은 변경하지 않는다.

## 완료 기준
- 선택 전 이름·휴대폰·동의 입력을 요구하지 않는다.
- 새 회원가입 선택 후에만 기존 가입 양식을 표시한다.
- 기존 계정 로그인 경로에서 다른 기기 세션을 종료하지 않고 안전한 복귀 주소를 유지한다.
- 로그아웃 실패를 안내하고, 실패 시 성공한 것처럼 이동하지 않는다.
- 기존 회원 자동 이동, 미인증 접근 차단, 입력 및 동의 검증을 유지한다.
- 회귀 검사, lint/build, 선택·가입 화면의 브라우저 확인 결과를 기록한다.

## 위험과 대응
- 가입 대기 상태에는 기존 이메일 회원도 포함될 수 있으므로 미가입자로 단정하지 않는다.
- 카카오 인증과 U-LIFE 로그인 완료를 구분하여 문구를 수정한다.
- 운영 계정으로 테스트 가입을 완료하지 않고 합성 테스트로 상태별 동작을 확인한다.
