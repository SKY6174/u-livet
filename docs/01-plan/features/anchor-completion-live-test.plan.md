# 운영 환경 수료 판정·승인 검증 기수 계획

> Feature: anchor-completion-live-test | 2026-09-25

## 목적

건강식생활지도사와 실버푸드전문가과정의 수강생별 판정 화면에서 실제 저장·재조회·승인 동작을 점검한다. 두 원 과정은 개설 준비 상태이며 정책·회차·등록자가 없어 원 기록에 검증 데이터를 섞지 않는다.

## 범위

- 운영 DB에 `[검증용]` 조직과 두 별도 기수를 만들고, 합성 수강생·출결·판정 근거를 저장한다.
- 현재 관리자에게 검증 조직에 한정된 과정 관리·수료 승인 역할을 부여한다.
- 승인 가능, 기준 미달, 철회, 미산출 사례를 제공하고 실제 화면에서 재산출·승인 동작을 점검한다.
- 원 과정 ID, 정책, 출석부, 운영 통계는 변경하지 않는다. 공개 모집·실제 결제·문자 발송은 하지 않는다.

## 성공 기준

1. 운영 환경의 검증 기수 두 곳에서 저장된 수강생과 출석률이 보인다.
2. 실제 수료 후보 산출과 별도 작성자가 산출한 후보의 승인을 UI에서 확인한다.
3. 검증 대상이 일반 공개 과정 목록에 나타나지 않고 원 두 과정은 등록자 0명을 유지한다.
4. 생성된 레코드를 정확히 식별하고 제거할 수 있는 명령을 남긴다.

## 주의점

검증용 정책·승인은 실제 교육 결과를 증명하지 않는다. 데이터와 역할은 별도 조직에 묶고 모든 명칭에 `[검증용]`을 표시한다. 운영 DB 변경 전 대상·기존 상태를 확인하고 트랜잭션으로 입력한다.
