# 전체 회차 출석부와 QR 종료 기록 계획

2026-09-25

## 목적
출석부에 모든 정규 회차를 가로축으로 펼쳐 각 수강생의 시작·종료 QR 확인 시각을 표시한다. 결과보고서 첨부 1~5의 번호는 제목에서 분리해 문서 좌상단에 작게 표시한다.

## 범위와 완료 기준
- 강사는 시작/종료 목적의 QR을 구분해 발급하며 수강생은 같은 회차에 순서대로 확인한다.
- 서버는 본인 수강 자격, 담당 강사, 유효 회차·토큰·시간을 검증하고 최초 시작·종료 시각을 보존한다.
- 출석부는 모든 회차를 한 표의 가로축에 표시하고, 각 시작/종료 칸에 QR 기록 날짜·시각을 작게 적는다. 확정 인정시간·출석률은 별도 열로 유지한다.
- 첨부 1~5의 제목에는 번호가 없고 문서 시작 좌상단에 `[첨부 #n]`이 표시된다.
- 기존 시작 QR 기록과 보고서 PDF 1.7 출력이 유지되고 빌드·검증 후 Git push 한다.

## 위험
회차가 많으면 A4 가로에서 글씨가 작아지므로 화면에서는 가로 스크롤을 허용하고 PDF는 가로 용지에 폭을 맞춘다. 종료 QR은 시작 기록이 없으면 거부하며 QR 자체를 출석 확정으로 사용하지 않는다.
