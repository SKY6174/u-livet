# 구성원 수동 등록 설계 대조
2026-09-21 · anchor-member-manual-entry

| 요구/경계 | 결과 |
|---|---|
| 사업단·강사·수강생 등록 폼 및 DB 저장 | 구현, 실 DB 재조회 검증 |
| 지정 세 명 외 수동 등록 차단 | 구현, 다른 SYSTEM_ADMIN/수강생/타 조직/익명 거절 검증 |
| 송경영 최고 관리자 | 확인된 사업단 인증 계정 연결, 표시 및 타인 삭제 보호 |
| 이연향 권한 | 사용자 확인 이메일 yhlee4@uc.ac.kr로 인증 가입 시 연결하도록 예약; 현재 미가입 |
| 현용환 권한 | 기능 슬롯 준비, 사용자 이메일 답변 대기; 이름으로 자동 부여하지 않음 |
| 범위가 좁은 운영자 권한 | 조회/등록만, 기존 수정·삭제 권한 확장 없음; 사업단 로그인/MFA 지원 |
| 올해 수강과목 열 위치/조회 | 생년월일과 수강이력 사이. 서울 현재 연도에 걸친 ACTIVE 수강만 표시 |
| 과거 수강이력 | 과거·미래·철회 포함 기존 전체 이력 유지 |
| 중복/재시도/입력 검증 | email UNIQUE와 DB 검사, request lock/fingerprint, MFA 및 감사 로그 |
| 성능 | 목록 1 RPC, scope materialized, 페이지 최대 20명 과목만 indexed 조회 |

## 검증
- 신규 DB 38개 + 기존 DB 37개, 모두 transaction rollback.
- 신규 모델/action/화면 18개 + 기존 구성원 23개 + 역할 메뉴 18개 + 로그인 46개 = 합계 180개 통과.
- TypeScript, ESLint, production build 통과.
- 실제 React 화면을 합성 데이터로 렌더링한 브라우저 fixture: 올해 과목 열, 등록 폼, 중복 안내 후 입력 유지, 390px 모바일 문서 넘침 없음(표 영역만 1050px), 브라우저 오류 없음.
- DB 저장과 권한은 위 실 SQL 검사로 확인. 브라우저의 등록 action은 합성 응답이며 실제 사용자/운영 DB에 테스트 구성원을 생성하지 않았다.

남은 사용자 의존 항목: 현용환 로그인 이메일. 구현 검증과 확인된 계정 반영을 진행하고, 이 슬롯은 미확인 상태로 유지한다.
