# 수강생 내 정보 - 설계 대비 확인

## 일치율: 100% (기능 항목 12/12)

- 헤더의 이름 링크, 읽기 전용 법적 이름, 필수 번호·이메일 및 선택 별명·캐릭터·사진 화면을 구현했다.
- 번호의 DB 원본과 수강생 서류 자동입력을 연결하고, 이메일 변경은 Auth 확인 절차로 분리했다.
- 별도 비공개 프로필 테이블과 사진 버킷, 본인 폴더 RLS, 세션 검증 RPC 및 이미지 형식·용량 검사를 구현했다.
- 사진 교체/삭제 시 기존 경로를 정리하고 오류 발생 시 저장된 경로를 유지한다.

## 검증 결과
- ESLint, TypeScript, Next.js 프로덕션 빌드 통과.
- 운영 DB에 마이그레이션 한 건 적용 후 추가 대기 마이그레이션 없음 확인.
- 운영 anon 키로 프로필 읽기·저장·사진 경로 변경 RPC를 호출했을 때 모두 `42501`로 거부됨을 확인.
- 로컬 `test:core`는 로컬 Supabase 프로젝트의 마이그레이션 이력 불일치로 시작하지 못했다. 기존 로컬 데이터를 초기화하지 않았으며 실제 수강생 세션으로 저장·이메일 확인·사진 업로드를 실행하는 검증은 배포 후 계정 테스트가 필요하다.
