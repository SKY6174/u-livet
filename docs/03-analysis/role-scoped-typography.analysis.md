# 역할별 글자 크기 설계 검증

2026-10-10 · 설계 항목 5/5 일치

- 기존 `workspaceKind`로 사업단·강사·수강생을 구분하고 비로그인 화면은 수강생 기준을 사용한다.
- 사업단·강사는 확대 이전 본문 18px, 작은 글씨 16px, 제목 30/40px이다.
- 수강생은 각 크기가 1.25px 크다. 표는 역할별 토큰에서 1.5px 작다.
- 문의처는 기존 12.5/14.5px 기준에서 수강생만 1.25px 확대한다.
- 인쇄 양식 및 로고 내부 글씨는 변경하지 않았다.

검증: lint, TypeScript, 빌드 통과. 브라우저 계산값으로 360/1440px 두 크기와 가로 넘침 없음을 확인했다.
