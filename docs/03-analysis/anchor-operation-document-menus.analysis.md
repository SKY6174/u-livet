# 운영계획서·결과보고서 메뉴 분리 — 설계 대비 점검

> 2026-09-22 · [설계](../02-design/features/anchor-operation-document-menus.design.md)

## 일치율: 100% (9/9)

1. 관리자 메뉴의 계획서·결과보고서 분리: 구현.
2. 두 종류의 별도 문서 목록과 원본 양식 링크: 구현.
3. 결과 메뉴 내부의 공식 문서/기존 결과 보고·6종 증빙 탭: 구현.
4. 미선택 탭 DB 조회 생략과 독립적인 실패 표시: 구현.
5. COURSE_MANAGER 전용 증빙 탭, 강사·SYSTEM_ADMIN 공식 문서 권한 유지: 구현.
6. 기존 목록 주소의 적절한 새 탭 리다이렉트: 구현.
7. 문서 편집·과정 운영·관리자 업무 홈의 링크 및 중첩 활성 상태: 구현.
8. 기존 개별 결과 보고·6종 인쇄·문서 작성 URL과 DB 데이터 유지: 확인.
9. 역할 검사, 로컬 RPC 회귀, lint/build, 관리자·강사 브라우저 및 모바일 폭 검사: 완료.

역할 탐색 20개 검사가 통과했다. 로컬 관리자 화면에서 공식 결과 목록과 기존 결과 보고의 검색·필터·출력 링크가 탭별로 표시됐다. 강사 화면에서 증빙 탭 직접 접근은 404이며 모바일 가로 넘침은 없었다. `verify-operation-documents` 통합 검사는 기존 문서 권한·저장·제출 동작을 확인했다.
