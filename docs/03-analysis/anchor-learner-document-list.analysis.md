| 권한·실패 상태 | 기존 허용 역할, 조회 실패·빈 결과 메시지 보존. 권한 없는 사용자는 데이터 조회 전 거부 |

## 수정 및 검증 범위
- `npm run build`: 최종 수정 후 통과. 타입 검사·린트·운영 매뉴얼 검사 포함.
- `git diff --check`: 통과.
- 모바일에서 absolute 위치의 sr-only 라벨이 스크롤 영역을 벗어나던 현상을 발견해 스크롤 컨테이너에 relative 위치 기준을 추가했다.
- `node scripts/verify-learner-document-list.mjs`: 통과. 실제 페이지 모듈에 합성 데이터·인증/액션 mock을 주입한다.
- 브라우저는 `--preview`로 생성한 실제 서버 컴포넌트 HTML과 빌드 CSS를 사용한다. 데스크톱 1680px, 모바일 390px를 확인했다.
- 실제 사용자나 접수 문서는 사용하지 않았고 제출은 로컬 이벤트로 차단해 폼 데이터만 검사했다. 변경하지 않은 DB 상태 전환·MFA·PDF 바이트는 이번 검증 대상이 아니다.
