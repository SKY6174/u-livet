# 구성원 엑셀 등록·관리 구현 점검

2026-09-24 · 설계: `docs/02-design/features/anchor-member-excel-workflow.design.md`

## 설계 일치율: 100% (10/10)

1. 구성원 목록의 사업단·강사·수강생별 엑셀 서식·업로드·다운로드: 구현.
2. 기존 명부의 구성원 ID·수정 버전과 그룹별 편집 필드: 구현.
3. 신규/기존 행 구분과 기존 이메일 조회 전용: 구현.
4. `.xlsx` 2MB·100행, 서식·값·중복 검증, 미리보기 후 확정: 구현.
5. 서버에서 단건 등록·수정 검증 재사용: 구현.
6. 신규 사업단 권한과 수정 SYSTEM_ADMIN 권한 분리: 구현.
7. 최근 MFA·조직·중복·버전 검사 및 파일 단위 원자성: 구현 및 로컬 DB 검증.
8. 명부 내보내기의 기존 조회 범위, 그룹·검색 조건과 1,000명 상한: 구현.
9. invoker wrapper·private definer·명시적 함수 권한: 구현.
10. 파서·액션·회귀 검증, 로컬 DB 격리 테스트: 통과. Preview/운영 반영은 릴리스 검증 단계에서 진행.

설계상의 RPC 가칭 `life_member_import`/`life_member_export`는 기능을 분명히 하는 `life_member_excel_import`/`life_member_excel_export`로 구현했다. 업로드 원본 파일은 서버나 스토리지에 저장하지 않는다.

검증: Next.js 프로덕션 빌드, 구성원 엑셀 스크립트 9건, 기존 구성원 관리·수동 등록 회귀 스크립트, 격리 DB에서 신규·수정·혼합 파일·실패 시 전체 롤백·권한·MFA·버전·조회 범위 확인.
