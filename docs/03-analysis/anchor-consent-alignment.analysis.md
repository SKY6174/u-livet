# 입력 정렬·서명·용지 여백 검증

설계 대비 6/6 항목 충족.

- 성범죄 서식 가상 입력의 실제 검은 픽셀 경계로 칸 중앙과의 차이를 측정: 성명 0.030pt, 식별번호 0.050pt, 연락처 0.055pt. 이름 크기가 자동 조절되어도 글자 윤곽을 기준으로 정렬한다.
- 국내/외국인 두 경우 동의자 라벨과 이름 기준선 차이 < 0.01pt. 외국인 이름/영문과 국내·외국인 식별정보를 분리한 기존 입력 방식 유지.
- 기존 얇은 가상 서명 PNG에 대해 PDF 출력의 어두운 픽셀 수 1,226 → 2,102 증가 확인. 이미지를 변조해 저장하지 않으며 PDF 합성으로 보강한다. 새 서명 패드는 동의서에서만 4.8px 적용.
- 3종 × 국내/외국인 × 초안/최종 = 12개 PDF 1.7, 595×842pt 생성. 좌우/아래 10mm, 위 25mm+머리말 10mm 인쇄 영역 내 텍스트 확인. 성범죄 템플릿은 내부 표 들여쓰기를 유지하고 쪽번호를 아래 여백 안으로 이동.
- Poppler PDF 렌더링으로 세 서식의 글자/표/서명/여백을 확인. 브라우저용 Node renderer와 Deno/Edge renderer의 성범죄 PDF 렌더 픽셀 동일.
- Deno 타입 검사·실제 PDF 생성, Next.js production build(ESLint/TypeScript 포함) 통과. React 변경은 숫자형 선 두께 옵션과 해당 effect 의존성만 추가하며 기존 다른 서명 패드 기본값 유지.

DB/권한 변경 없음. 새 서식 버전 2026-09-22.3이며 기존 제출본은 변경하지 않는다.
