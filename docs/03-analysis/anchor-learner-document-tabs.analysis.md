- 나의 학습에서 통합 작성 창 1개가 열림.
- 두 서식을 왕복해도 페이지 URL과 창 개수가 바뀌지 않음.
- 서로 다른 과정명·성명·계좌 정보, 동의 선택 및 서명이 각각 유지됨.
- 두 서식을 전환한 뒤 다운로드한 PDF의 제목·내용이 선택한 서식과 일치하고 헤더가 PDF 1.7임.
- 두 파일을 내려받으면 이탈 경고가 해제됨. 현재 숨겨진 서식에 변경 내용이 남으면 이탈 경고 유지.
- 390px 모바일에서 가로 넘침 없음. 키보드 Enter로 전환 가능. 미처리 브라우저 오류 없음.
- 기존 장학금 서식 URL은 통합 경로로 이동하고 장학금 버튼이 선택됨.
- 기존 PDF 생성 검증 스크립트 통과. PDF 원본·생성 코드 변경 없음.
