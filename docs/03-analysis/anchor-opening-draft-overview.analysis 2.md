# 개설 준비 임시저장 현황 검증

2026-09-21 · anchor-opening-draft-overview

| 설계 항목 | 결과 |
| --- | --- |
| 내 저장 현황·최근 저장 | 0개/일부/16개 상태, 한국시간 시각 및 이어서 준비하기 링크 확인 |
| 기존 검색과 결합 | drafts=saved만 허용, 검색·아카데미·강사·자료대조 조건과 AND 적용. 전체 계획서 집계는 유지 |
| 오류 구분 | 저장 조회 실패를 0개/미저장으로 표시하지 않음. 원문 계획서 표시 유지와 재시도 안내, 적용하지 못한 저장 필터 명시 |
| 개인·조직 범위 | 기존 등록 폼과 같은 첫 COURSE_MANAGER 조직을 사용. 실제 로컬 JWT로 다른 작성자·역할·조직·익명·권한 회수 검증 |
| 최소 데이터 | 단일 RPC가 source_id/revision/updated_at만 반환. 전체 payload 및 사람 식별자 미노출 |
| 저장 후 갱신 | 성공 후 개설 준비 목록 revalidatePath 호출, 실패 시 호출 없음 |
| 반응형 | 실제 컴포넌트로 390px 화면 확인, 상단 현황 및 카드 표시 정상, 가로 넘침 없음 |

자동 검증 59개 통과: 새 현황9 + 기존 계획서9 + 불러오기7 + 임시저장 앱8 + 실제 로컬 DB8 + 역할별 메뉴18. Next.js production build 통과.

로컬 합성 계정에 16개 임시저장을 생성해 단일 요약 RPC를 측정했다. 첫 요청 8.6ms, 이후 5회 중앙값 5.8ms(6.3/6.4/4.3/5.8/5.8), JSON 1,295bytes. 서버 위치·네트워크가 다른 실제 서비스 페이지 응답시간을 의미하지 않는다.

브라우저 검증은 실제 CourseOpeningView + 합성 요약 데이터로 수행했다. 저장만 보기 2건→아카데미 결합 1건, 0건 안내, 조회 오류에서 전체16건 유지, 한국시간 시각과 편집 링크를 확인했다. DB 권한·집계는 별도 실제 로컬 JWT 테스트로 검증했다. Hosted 계정/임시저장 데이터를 테스트로 생성하지 않았다.

설계 대비 미해결 누락 없음. 기존 실제 기수 개설·모집 공개와 개인 임시저장을 연결하거나 공개하지 않는다.
