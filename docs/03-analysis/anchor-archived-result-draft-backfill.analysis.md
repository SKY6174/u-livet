# Gap Analysis: anchor-archived-result-draft-backfill

2026-09-22 · 설계: `docs/02-design/features/anchor-archived-result-draft-backfill.design.md`

## Match Rate: 93%

비공개 manifest와 로컬 PDF의 SHA-256을 기존 집계·보관 PDF 해시와 대조했다. contact sheet에서 빈 마스크를 제외하고 반려동물 10장, 파크골프 26장, 로컬 쿠키 8장을 선별했다. 과정별 초안의 모든 필드 키는 운영 DB 결과보고서 스키마에서 만들고, 기존 구조화 집계 본문·성과·검토 메모를 복사했다. 예산·서명·강의표는 비웠다. 초안 JSON은 적용 전 DB 검증 함수를 통과했다.

운영 DB에 세 `DRAFT`를 새로 삽입했다. 재조회에서 사진 수 10/26/8, 기존 본문 일치, 원본 PDF 해시 일치, 빈 예산·서명·강의표, revision 1을 확인했다. 기존 원본 PDF는 3건 그대로이고 최종 제출 스냅샷은 0건이다. 각 삽입에 감사기록이 남았다. 기존 결과 초안이 있으면 스크립트는 덮어쓰지 않는다.

미확인 1건: 실제 담당자 로그인 화면의 시각적 표시 및 인쇄 결과는 해당 사용자 세션이 없어 이번 작업에서 직접 열지 못했다. 기존 편집·출력 경로는 이전 브라우저 검증에서 통과했으며, 이번에는 저장 모델과 데이터 정합성을 DB에서 확인했다. 담당자는 원본 PDF와 초안의 사진 순서·강의표·예산을 검토해야 한다. 실제 Terra 제안은 유효한 `OPENAI_API_KEY` 설정 후 별도 확인이 필요하다.
