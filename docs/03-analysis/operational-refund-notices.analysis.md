# 환불 안내 운영 점검 설계 대조

2026-10-17 · Feature `operational-refund-notices`
Design: `docs/02-design/features/operational-refund-notices.design.md`

## 구현 일치율: 7/7 (100%)

1. 운영 22개 과정과 환불 정책·조항·수납 설정 조사 완료: 정책·설정·회계 거래 모두 0건.
2. 무료 수강료와 미기재 구분, 자격시험·발급비 등 별도 비용 구분을 공통 안내로 구현.
3. 공개 과정 소개·상세·신청 화면에 취소·환불 안내와 기존 신청 현황·연락처 링크 제공.
4. 정상 승인 유료 규정만 표시하고 만료·검증·작성 요령 규정은 안내에서 제외.
5. 관리자 환불 규정 선택지 필터와 구체적인 설정/공개 오류 안내 구현.
6. private INVOKER 트리거로 finance INSERT/UPDATE와 offering 이름·상태 변경 보호.
7. 기존 정책·조항·회계 원장 불변 및 명시적 합성 과정 예외, 실제 이름 변경 차단.

## 검증

- `verify-operational-refund-notices.mjs`: 공통 서버 컴포넌트의 무료·미기재·유료·만료·
  제목/버전/본문 검증 문구·CRLF 작성 요령, 별도 자격 비용과 링크 검증 통과.
- 실제 합성 PostgreSQL에서 MFA 수강료 설정 RPC의 거부/허용·실패 원자성, 직접 정책
  update·합성 과정명 변경·private 함수 권한, 기존 정책/조항·회계 원장 보존 확인 후 ROLLBACK.
- 기존 모집 안내·수료 안내 DB 회귀, ESLint·TypeScript·diff 검증 통과.
- React 검토: 서버 컴포넌트, 의미 있는 heading/link, 추가 클라이언트 상태·효과 없음.
  소개 화면의 환불 RPC는 공개된 유료 과정에서만 실행하고 수료 조회와 병렬 처리한다.

검증 전용·[테스트] 표기도 환불 문안 검사에 포함하여 기존 fixture 표기 관례를 보호한다.
운영 원문·수강료·자격발급비 조건·서류 제출본은 변경하지 않는다. 새 환불 비율을 만들지 않는다.
Preview 및 운영 DB/배포/화면 검증은 릴리스 단계에서 수행하고 최종 PR에 기록한다.
