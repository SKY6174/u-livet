UI 검증은 실제 DocumentEditor→로컬 HTTP→인증된 PostgreSQL RPC→DB 저장→응답→새로 열기의 경로를 사용했다. 테스트 전체를 열린 트랜잭션에 두고 서버 종료 시 ROLLBACK했으며 운영 데이터는 변경하지 않았다. 임시 HTTP 테스트 경로는 실제 Next.js의 세션·same-origin 경계를 대체하므로 실제 route/action의 입력 검사와 호출 인수도 별도 확인했다.

PDF 1.7의 대상 비율·주요목적 체크·기관 정보·시간·합계 렌더링을 확인했다. 입력/산술 회귀, 실제 로컬 RPC, 기존 서명 필수 흐름, 사전 입력 16개 과정·7개 보고서, 타입·lint·build 통과. React hook 순서·권한 prop·클라이언트에 비밀키 미포함을 확인했다.

기존 데이터의 문서 승인과 수강 확정은 별도 근거이므로 자동 등록·동의 생성은 하지 않는다. 일반 신청과 원서는 각각의 근거를 보존하며 목록에서 연결한다. 변경된 수강료·환불 규정은 이미 접수된 신청에 소급하지 않는다. 운영 migration·배포 commit·READY·version·health의 최종 근거는 PR 본문에 기록한다.
