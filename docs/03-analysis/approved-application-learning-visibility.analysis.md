# 승인 원서의 나의 학습 표시 갭 분석

2026-10-07 · [설계](../02-design/features/approved-application-learning-visibility.design.md)

## 일치율: 100%

설계 항목 7개 중 7개를 구현했다.

1. 기존 본인 범위 원서 RPC를 학습 데이터와 병렬 조회한다.
2. 원서 조회 오류는 `null`로 유지해 빈 목록과 구분한다.
3. 승인·처리 완료 원서만 별도 지표에 센다.
4. 처리 현황에 과정명, 상태, 접수 시각, 담당자 안내를 표시한다.
5. 등록 상태와 현재·종료 과정 상태에 맞는 설명을 표시한다.
6. 관리자 문서함에서 원서 승인과 수강 등록이 별도임을 안내한다.
7. 승인 원서만 있는 상태와 원서 RPC 오류를 학습 검증에 포함한다.

운영 DB의 읽기 전용 점검에서 승인된 원서 1건은 과정 연결값이 비어 있고, 해당 수강신청·수강 등록은 0건이었다. 동일 명칭의 공개 과정 안내는 존재하지만 연결된 운영 기수는 DRAFT이고 모집·수업 기간이 종료되어 자동 등록 대상으로 사용할 수 없다. 운영 데이터를 변경하거나 이름만으로 문서를 기수에 연결하지 않았다.

검증: `node scripts/verify-student-learning.mjs` 6건 통과, `npm run lint` 통과, `tsc --noEmit` 통과, `npm run build` 통과.
