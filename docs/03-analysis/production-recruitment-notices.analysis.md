## 설계 대조

구현 항목 9/9 확인: 대상 한정 교정, 승인·효력·정확한 원문 해시,
기존 연결 검사, 재실행 무변경, revision/감사 이벤트, 증빙 불변,
관리자 필터, DB 경로 검사, 사용자 오류 안내.

- `node scripts/verify-operational-recruitment-notices.mjs`: 통과.
- 대상 없는 Preview, 미승인/미래 효력/다른 원문/과정명/연결을 검증했다.
- 기존 정책·신청·동의·다른 과정 보존을 양방향 EXCEPT로 비교했다.
- 제목·버전·본문의 검증 문구, CRLF/주변 공백이 있는 작성 요령에 대해 TS 필터와 실제 DB 거부가 일치했다.
- 실제 INSERT/UPDATE/과정명 변경/상태 변경 검사와 명시적 검증 과정 허용을 확인했다.
- MFA 확인된 합성 관리자의 실제 `life_publish` RPC에서 잘못된 정책은 전체 롤백되고 운영 정책은 공개됐다.
- 트리거 함수의 anon/authenticated/service_role 실행 권한이 없고 security invoker임을 확인했다.
- 서버 액션이 실제 운영 안내 작성·승인 경로를 사용자에게 안내함을 확인했다.
- `npm run lint`, `npx tsc --noEmit`, `git diff --check`: 통과.

전체 SQL 검증은 로컬 합성 DB에서 ROLLBACK했다. 운영 승인 및 교정,
공개 안내 16개 HTTP 검사와 실제 화면, Preview/운영 배포 및 advisor
비교 결과는 완료 후 PR에 기록한다.
