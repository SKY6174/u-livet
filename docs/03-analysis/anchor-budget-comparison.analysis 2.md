# 예산 및 집행현황 통합 검증

2026-09-21 · 설계: `docs/02-design/features/anchor-budget-comparison.design.md`

설계 항목 7/7 구현 확인. 누락 없음.

- 예산/집행 탭을 ‘예산 및 집행현황’으로 통합하고 상단 설명을 제거했다. ‘단위: 원’은 제목 오른쪽에 표시된다.
- 16개 과정마다 예산/집행 두 행을 표시한다. 프로그램 ID·과정명·수정 버튼은 두 행에 걸쳐 병합된다.
- 아카데미 소계와 총계도 예산/집행을 함께 표시한다. 집행 연결 과정 수를 명시하며 미등록 금액과 실제 0원을 구별한다.
- 기존 예산 수정 폼과 서버 권한·저장 경로를 유지했다.
- 접힌 엑셀 자료 영역에서 최근 저장 자료를 자동 조회한다. 파일·시트·제목행 선택은 비교 표에 반영된다. 저장 전/후 상태를 표시한다.
- 정확한 과정명/과정 ID와 선택적인 프로그램 ID 확인으로 연결한다. 공유 프로그램 ID 단독 연결, 중복 행/열, 잘못된 금액, 알 수 없는 과정은 집행 합계에 포함하지 않고 안내한다.
- 원본 엑셀 조회와 저장 기능을 유지하며 DB 스키마·RPC·접근 권한 변경은 없다.

## 검증 결과

- `node scripts/verify-budget-comparison.mjs`: 14건 통과(16개 과정의 32행 렌더링 포함).
- `node scripts/verify-course-budget.mjs`: 기존 예산 모델 12건 통과.
- `npm run lint`, `npm run build`, `npx tsc --noEmit`, `git diff --check`: 통과.
- 개발용 실제 컴포넌트 렌더링에서 1600px 데스크톱 배치, 390px 모바일 편집/표 스크롤 확인. 모바일 body 390px, 표 1400px로 표 내부에만 가로 스크롤된다.
- 합성 XLSX 업로드 후 제목행 변경 시 쿠키 과정의 집행액 5,831,000원과 현수막 66,000원이 표시됨. 이름이 다른 행은 연결되지 않음을 확인.
- 서버 액션 응답을 모사해 저장 전/후 표시와 접힌 상태의 최근 저장 자료 자동 조회(67,234원)를 확인했다. 브라우저 오류 없음.

## 검증 범위

브라우저 검증은 서버 액션을 모사한 로컬 컴포넌트 환경이다. 실제 관리자 계정의 재인증/DB 쓰기 작업은 수행하지 않았다. 해당 권한·RPC 코드는 변경하지 않았다. 집행 비교는 선택한 한 시트를 기준으로 하며 확정 전 양식을 임의 추정하지 않는다.
