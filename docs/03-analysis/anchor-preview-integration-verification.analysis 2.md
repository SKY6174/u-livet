## 이전 계정 준비 차단의 해소

최초 `b973116` 배포 검증에서는 Preview DB에 `20260919053031_anchor_kakao_signup`이 먼저 적용된 상태였다.
시험 도구가 사용한 별도 정책 ID와 누락된 휴대전화 입력이 현재 가입 규칙과 맞지 않아
Auth Admin 생성과 메일 없는 초대 링크 생성이 `PUBLIC_SIGNUP_CLOSED_OR_POLICY_CHANGED`로 거부됐다.

후속 카카오 가입 변경이 `fb8a27a`/`3670705`로 Preview에 반영된 것을 확인하고,
시험 도구가 현재 `life_signup_policy()`와 합성 휴대전화 값을 사용하도록 수정했다.
동일한 메일 없는 초대 링크 준비가 성공했고 웹 비밀번호 로그인과 TOTP도 통과했다.
앱의 가입 정책을 완화하거나 DB migration을 롤백하지 않았다. 이번 검증을 위해 제품 코드를 추가 변경하지 않았다.
실제 이메일 초대 발송이나 외부 카카오 계정의 OAuth 인증 전체를 검증한 것으로 확대 해석하지 않는다.
