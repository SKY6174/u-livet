## 검증 결과와 한계
- `npm run build`: 매뉴얼 검사, lint, 타입 검사와 production build 통과.
- 브라우저: 1440×1000, 390×844에서 화면 확인. `aria-current="page"`, 모바일 메뉴 순서, 5/5/3/3 단계 수 확인. JavaScript 오류 없음.
- `git diff --check`: 통과.
- `node scripts/verify-role-navigation.mjs`: 21개 항목 통과 후 기존 운영 문서 목록 fixture에서 실패. 기존 공개 메뉴 개수 3개 단언은 새 순서 4개 검증으로 갱신함.
- 변경 전 HEAD의 스크립트와 소스를 `git show`로 읽어 재실행해 동일한 `/operation-documents/course-1/plan` 단언 실패를 재현했다. 문서 목록 mock의 조직 조회 `.in()` 누락 등 기존 fixture 불일치는 이번 공개 안내 변경 범위에 포함하지 않았다.
- 실제 로그인 계정은 사용하지 않았으며 역할별 메뉴는 기존 합성 계정 검사로 검증했다. 운영 데이터 변경 없음.
