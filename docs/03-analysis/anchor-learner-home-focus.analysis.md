# 수강생 홈 설계 대조

2026-09-23 · [설계](../02-design/features/anchor-learner-home-focus.design.md)

| 설계 항목 | 구현·검증 | 결과 |
| --- | --- | --- |
| 수강생에게만 내 학습 RPC 조회 | `workspaceKind` 분기, 역할별 홈 16건 | 일치 |
| 활성 수강 과정 우선 표시 | `courseStage`와 내 수업 카드, 신청만/빈/실패 렌더링 | 일치 |
| 다음 수업·출석·강의실·질문 링크 | 기존 학습 모델 재사용, 합성 화면 검사 | 일치 |
| 이력 과정 제외·같은 분야 우선 추천 | `recommendCourses` 최대 8개, 기본 3개 유지 | 일치 |
| 작은 가로 이동형 카드 | 스크롤 스냅·터치/트랙패드·이전/다음 버튼·키보드 초점 | 일치 |
| 추천 오류·빈 상태 구분 | 독립된 렌더링 검사 | 일치 |
| 관리자·강사·기존 `/mypage` 경로 유지 | 기존 역할/학생 허브 회귀 21건 | 일치 |

설계 7개 중 구현 7개로 일치율 100%다. 로컬 ESLint, TypeScript, production build가 통과했다. 새로운 DB 스키마는 없으며 개인 수업 조회는 기존 `life_my_learning()` 권한 검사를 따른다. 실제 계정으로 화면을 여는 검증은 배포 후 별도로 수행한다.
