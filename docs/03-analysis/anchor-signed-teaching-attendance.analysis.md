# 강사 강의날인부·QR 출석부 설계 대조

2026-09-22 · [설계](../02-design/features/anchor-signed-teaching-attendance.design.md)

## 구현 일치: 10/10 (100%)
1. 강의실적 구간·서명·revision을 DB에 저장하고, 정정 시 이전 서명을 무효화한다.
2. 강사 본인·담당 과정·종료 수업 검증과 PNG/JPEG 입력 검증을 RPC에서 수행한다.
3. 관리자와 강사의 출석/QR 읽기 범위를 DB에서 분리하고 전체 명단은 담당자에게만 허용한다.
4. 강사의 실제 구간 입력/서명 화면과 관리자 승인 상태가 연결된다.
5. 강의날인부는 실제 순서, 오전/오후 분할, 점심 공백, 유효 승인·서명 이미지를 표시한다.
6. QR 입실과 강사 확정 출결·인정시간을 분리한다.
7. 전체 4회차 이하는 A4 세로, 5회차 이상은 A4 가로다.
8. 브라우저 인쇄와 PDF 1.7 다운로드에서 두 양식의 사방 20mm 여백·왼쪽 하단 로고를 적용한다.
9. 관리자 과정 보고서·현재 공식 결과보고서 인쇄에 강의날인부를 연결한다. 과거 제출본에는 현재 기록을 섞지 않는다.
10. 기존 기록에서 없는 강의 구간/서명은 추정하지 않고 미등록으로 표시한다.

## 검증
- Preview·운영 DB에 migration 1건 적용, 열/함수 권한 확인, 보안 Advisor 경고 0건.
- 로컬 DB에서 유효/무효 구간, 본인 제출·서명 RPC 및 관리자 QR/출결 조회를 거래 rollback으로 확인했다.
- A4 세로·가로와 로고/여백을 PDF 렌더링으로 확인했다. PDF 1.7 다운로드에서 발생한 1px 빈 페이지를 수정한 뒤 총 3페이지로 확인했다.
- 최종 빌드·린트·diff 검사 통과. 전체 `test:core`는 기존 로컬 MFA fixture secret 부재로 계정 준비 단계에서 중단됐다.

## 의도된 경계
- 공식 결과보고서 본문의 회차별 서술 표는 담당자가 계속 수정한다. 강의날인부는 동일한 승인 강의실적에서 자동 생성되는 현재 보고서 부록이다.
- QR 확인은 입실 증거이며, 최종 인정시간은 강사가 수업 종료 후 확정한다.
