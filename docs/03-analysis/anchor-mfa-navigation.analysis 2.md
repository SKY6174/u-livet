# 인증 완료 후 화면 이동 검증

2026-09-19 · anchor-mfa-navigation

| 설계 항목 | 확인 결과 |
|---|---|
| 인증 후 명시적 작업 주소 복귀 | 서버 페이지·클라이언트 핸들러·Chromium에서 확인 |
| 유효한 최근 인증의 중복 폼 제거 | 실제 React 렌더와 Chromium에서 확인 |
| 직접 연 계정 보안 관리 유지 | 앱 관리·추가 등록 폼 확인 |
| 외부 주소 및 인증 경로 복귀 제한 | 실제 safeReturnTo 사용 회귀 통과 |
| 만료·미인증·재설정 필요 상태 보호 | 서버 액션/페이지 경계 회귀 통과 |
| 다른 창의 입력과 저장 확인 유지 | 원래 창/업무 폼 변경 없음, 자동 저장 없음 |
| 세션·DB·최근 인증 조건 유지 | native 검증·SSR 쿠키·DB 정책 변경 없음 |

설계 7개 항목을 모두 확인했다(7/7). 새 MFA 회귀 23개와 계정 설정/복구 회귀 21개 통과. main의 기존 DB 성능 회귀 13개도 통과했다. Chromium에서는 실제 React 컴포넌트를 사용하고 인증 경계만 합성 응답으로 대체했다. 실제 계정의 비밀번호·인증 앱 코드를 조회하거나 사용하지 않았다.

최초 빌드에서 저장소의 과거 복사본 `page 2.tsx`가 추가된 prop 없이 컴포넌트를 호출하는 호환성 문제를 확인했다. 복귀 플래그를 선택 prop으로 바꾸고 기본값 false를 지정하여 정상 화면과 과거 호출부를 함께 지원한다. 보완 후 전체 main 빌드·린트 통과.

Preview 원래 브랜치에도 동일 수정만 cherry-pick하여 MFA 회귀 23개와 전체 Next.js 빌드를 다시 통과했다.
