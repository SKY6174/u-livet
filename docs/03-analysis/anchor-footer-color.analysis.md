- 흰색 본문·링크 대비 7.59:1, teal-50 보조 문구 대비 7.28:1.
- 1440px 데스크톱·390px 모바일에서 가로 넘침 없이 문구와 링크가 표시된다.

- 브라우저 콘솔 오류 없음. DB 미연결 로컬 빌드에서 공통 하단을 확인했다.
