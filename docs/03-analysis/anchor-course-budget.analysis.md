# 과정 운영·예산 검증

2026-09-21 · anchor-course-budget

- 16개 guide를 운영 화면에 표시하고 권한 범위 workspace를 연결한다. 기존 3개가 중복되지 않으며 추가 개설 자료도 별도 표시한다.
- 카드/리스트, 검색, 아카데미/상태 선택, 프로그램 ID의 위치, 예산 6항목 편집/소계/총계, 엑셀 시트·제목행·검색·미리보기·저장 및 저장 자료 조회 구현.
- XLSX 양식은 미정이다. 파일의 셀 값과 열 구성을 조회용 스냅샷으로 보존하며, 자동 회계 항목 매핑/집행 합계 산출은 양식 확정 후 범위다. 원본 바이너리 첨부가 아닌 선택한 시트의 값이 저장된다.
- 기관 COURSE_MANAGER 또는 SYSTEM_ADMIN만 예산에 접근한다. 원장 직접 권한 없음, RLS 활성화, private 구현 함수와 invoker RPC, 최근 MFA, revision 충돌 및 감사 기록 확인.

## 근거

- 모델 검증 12개 통과: 금액 범위, 0/null, ID, 역할/기관, 워크북 크기/내용/제목 행, 16/3 연결.
- 격리한 로컬 Postgres DB의 SQL 검증 21개 통과, fixture 및 변경 rollback. 관리자/담당자 쓰기, 교차기관/강사/익명 차단, 직접 쓰기 차단, revision, MFA 만료, workbook 재시도/재조회, 감사.
- 기존 역할 메뉴 18개, 공개 카탈로그 14개 회귀 통과.
- lint, TypeScript, Next production build 통과. 과정 화면 첫 로드 JS 120kB, 엑셀 컴포넌트와 파서는 지연 로딩.
- 실제 React 컴포넌트의 격리 브라우저 fixture에서 16개 카드와 3개 운영 링크, 리스트16행, ID 검색6행, 예산 편집 폼, 모바일390px 페이지 넘침 없음 확인. 서버 액션은 fixture에서 모의 처리했고 실제 저장/권한은 위 SQL로 별도 검증.
- 합성 XLSX 2시트로 파서, 제목행 선택, 검색, 시트 전환, 저장 상태 확인. 브라우저 런타임 오류 없음.

## 자료 차이

건강식생활지도사의 첨부 항목 보조인력 1,023,300원을 보존해 전체 합계는 115,036,420원이다. 원문 총계115,036,320원과 100원 차이를 화면에 명시했다. 임의로 보정하지 않았다.

프로그램 ID는 자료의 라이프케어/팝업 및 강조된 로컬창업 행을 초기값으로 사용하며 담당자가 수정할 수 있다. 운영계획 인력과 실제 계정 배정은 구분한다.

## DB 적용

동일 additive migration을 Preview/Production에 적용했다. 기존 강의·보고서·모집 상태를 변경하지 않는다. 신규 테이블은 API 직접 접근을 회수한 RPC 전용 구조이며 advisors의 RLS-no-policy INFO는 이 구조에 해당한다.
