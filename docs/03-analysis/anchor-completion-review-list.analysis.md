## 설계 일치율: 100% (7/7)

1. 단일 의미론적 표와 수강생별 한 행: 구현.
2. 순번·수강생·출석률·수강/환불·판정·산출시각·근거·처리 열: 구현.
3. 출석 기준 충족, 실제 환불과 환불 문서, 오래된 판정 표시: 구현.
4. 판정 사유·회차·과제·시험 근거 펼침: 구현.
5. 기존 재산출·승인 액션 및 승인 체크박스와 권한 조건: 유지.
6. 가로 스크롤, 키보드 포커스, 표 머리글과 스크린리더 설명: 구현.
7. 데이터/API/판정 규칙 변경 없음: 확인.

ESLint, TypeScript, Next build가 통과했다.

운영 배포 후 실버푸드 검증 기수에서 표 구조를 확인했다. 승인 대기 행은 확인란이 기본으로 노출되어 높이가 커지고 처리 열이 화면 밖으로 밀렸다. 승인 폼을 같은 행의 펼침 영역으로 옮겨 기본 목록 높이를 줄이고, 빌드를 다시 통과했다.
