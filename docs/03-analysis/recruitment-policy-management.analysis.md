# 모집 공개 정책 준비 · 구현 대조

2026-10-07 · [설계](../02-design/features/recruitment-policy-management.design.md)

## 설계 대조: 8/8 (100%)

1. 기존 버전·상태·승인 후 불변 모델 사용: 마이그레이션이 기존 `life_policy_versions`를 사용한다.
2. COURSE_MANAGER의 조직별 초안 등록·수정·승인: 세 RPC에서 역할과 대상 조직을 검증한다.
3. 입력 검증 및 동시 수정 방지: 길이·종류·상태, 제출 당시 제목·본문 비교를 적용한다.
4. 승인·초안 변경 감사기록: 각 RPC에서 기록한다.
5. 정책 구성 안내 및 새 버전 관리: `/admin/policies`에 두 유형별 체크리스트·작성·수정·승인을 제공한다.
6. 공개 화면 연결: 과정 관리에서 검증용 항목을 제외하고 정책 관리로 안내한다.
7. 공개 과정에 원문 표시: 모집 안내와 수료기준을 방문자에게 표시한다.
8. 수료 계산 규칙 분리: 별도 수료 검토·승인 절차를 안내한다.

## 검증 상태

`npm run lint`, `npx tsc --noEmit`, `npm run build` 통과. 최초 Supabase dry-run에서 신규 기능 마이그레이션 1건만 확인했고, 이후 권한 보완 마이그레이션을 추가했다. 실제 DB 함수 권한·실행 확인은 배포 단계에서 수행한다. 기관의 실제 정책 문안·수료 숫자는 확정되지 않았으므로 등록하지 않았다.

Preview 사후 권한 조회에서 내부 함수의 PostgreSQL 기본 `PUBLIC` 실행 권한을 발견해 별도 보완 마이그레이션에서 회수했다. 공개 RPC의 익명 실행은 이미 차단되어 있었으며, 보완 적용 후 다시 확인한다.
