# 수강생 마이페이지 학습이력 흐름 점검

2026-09-27

## 설계 대비 결과

| 기준 | 결과 |
|---|---|
| 4단계 학습이력 안내와 외부 이동 | `/mypage`, `/mypage/history`에 공통 카드 제공 |
| UC Life 수강이력과 국가 포털 기능 구분 | 사업단 이수증을 별도 명칭으로 표시하고 자동 연계를 주장하지 않음 |
| 본인 수강·수료 요약 | 기존 `life_completion_history`의 확정 조건을 재사용 |
| 빈 결과와 조회 오류 구분 | 0건 및 재시도 안내를 각각 표시 |
| 모바일·키보드 접근성 | 반응형 카드, 44px 링크, 새 창 접근성 이름 적용 |

## 검증

- `git diff --check`: 통과
- `npm run lint`: 통과
- `tsc --noEmit`: 통과
- `npm run build`: 통과, 매뉴얼 v1.0.0~v1.3.0 검사 포함
- 빌드를 가로막던 기존 보고서 JSX 닫는 태그 오류 한 줄 수정

병합 후 로컬 전용 가상 수강생으로 실제 브라우저에 로그인해 `/mypage`와 `/mypage/history`를 확인했다. 4단계 카드와 내 수강이력 링크, 수강이력 요약 1·0·1건, 외부 링크의 새 창 안내가 표시됐다. 화면 간 재검토 상태 불일치와 위치 표현을 발견해 후속 수정했다. 운영 사이트의 인증된 수강생 화면은 운영 로그인 세션이 없어 확인하지 못했다. 국가 포털의 개인 기능은 로그인 영역이므로 공개 페이지에서 세부 경로를 검증할 수 없었고 공식 첫 화면으로 연결했다.
