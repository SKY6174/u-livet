## 검증

각 과정의 강사 담당시수·날짜별 교육시수 합계, source ID 고유성, 기존 과정 매핑, 페이지 범위, 파일 해시, 인력명 원문 포함 여부, Markdown 링크 및 미확정 필드를 확인했다. 산과필라테스 총액 오기와 스포츠테이핑42/48시간 차이를 그대로 유지했다. 담당교수 현용환은 로컬페스타·질문소통 두 문서 표지에서 시각 확인했다.

텍스트 추출이 깨진 한글을 OCR로 보완했다. 아카데미 체크 전체와 주요 시간표·금액 불일치를 렌더링으로 확인했다. 앱 코드·DB 변경이 없어 앱 빌드나 운영 로그인 시험은 이번 자료 검증에 포함하지 않았다.

## 남은 업무 조건

계획서 미제공 재활운동지도사 자료, 최종 개설 대상·자료 버전, 충돌 항목 정정, 실제 접수기간·선발·수료 기준·납부 및 환불 정책은 후속 `anchor-production-opening`에서 확인한다. 이 항목은 누락을 숨긴 것이 아니라 정리본에 명시한 미확정 값이다.
