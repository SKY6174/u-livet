# 운영 계정 및 교육과정 개방 설계 대비 검증

## 설계와 달라진 점

초기 설계는 확정 모집기간 없이 기수를 등록하지 않도록 했다. 이후 사용자가 **교육 시작 2개월 전 접수 시작·2일 전 마감**, **선착순·대면·2차년도**, **미등록 과정의 실제 기수 초안 등록**을 명시해 12개 비공개 초안을 생성했다. 이는 후속 지시를 반영한 범위 변경이며, 미확정 수료·접수 정책을 승인하거나 모집을 공개한 것은 아니다. P06은 원문의 7월 기간을 보존했으나 최신 현황의 12월 일정과 충돌하므로 공개 대상에서 제외해야 한다.

## 남은 조치

1. P06의 12월 시작·종료일과 차시를 확정한 뒤 교육·접수기간을 함께 수정한다.
2. 지원 자격·취소·대기 처리와 수료 출석·평가 기준, 최종 수강료 및 필요한 환불·납부 조건을 확정한다. 모집 정원 80% 목표를 수료 출석률로 전용하지 않는다.
3. 문안·승인자·시행일을 갖춘 정책을 등록하고 실제 관리자에게 승인받는다. 현재 관리 화면은 **승인된 정책 선택**만 제공하므로 정책 등록·승인 절차를 별도로 마련해야 한다.
4. 일정과 접수 마감이 유효한 기수만 `life_publish` 경로로 공개하고, 수강생 화면의 일정·정원·모집상태를 확인한다. 지난 일정의 초안을 실제 운영·수료 실적으로 바꾸지 않는다.

**판정:** 공개 조건이 미확정이므로 Act 단계의 DB 정책 승인·모집 공개는 진행하지 않는다. 이 문서는 검증 결과이며 기능 완료 보고서가 아니다.
