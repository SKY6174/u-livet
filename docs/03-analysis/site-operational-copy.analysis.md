# 사이트 운영 문구 정리 검토

2026-10-17 · 설계: `docs/02-design/features/site-operational-copy.design.md`

구현 일치: 8/8. 운영 배포 후 실제 화면 검증은 릴리스 완료 전에 추가 확인한다.

| 설계 | 구현/검증 |
| --- | --- |
| 실제 수료 명단만 표시 | 가상 행 생성, sample 쿼리 분기와 예시 링크 제거. DB 행과 기존 기관/역할/별도 승인 제약 유지 |
| 실제 결과보고 절차 안내 | 가상 번들/인원/금액/PDF를 제거. 기존 관리자 인증을 유지하고 실제 공식/증빙 목록 링크 제공 |
| 빈 상태·이용 불가 안내 | 자료/일정 없음, 승인 기준 없음, 인증/QR/수납 이용 불가의 구체적인 다음 행동 표시 |
| 수강안내 증명 절차 | 수료 확정과 증명/배지 발급을 구분. 나의 공간 내역 및 사업단 문의 안내 |
| 매뉴얼 개정 | 1.3.1 발행, 개정 수료 안내 PDF 3쪽 추출/렌더링 확인 |
| 기록 보존 | DB 변경/마이그레이션 없음. 검증 이력과 test_only 경고 유지 |
| 공개 검증 과정 제외 | 공개 카드/상세 쿼리에서 명시적 검증 이름/아카데미 제외. 모집 정책도 기존 운영용 검사 적용 |
| 버전 등록 | 원문 맵 등록 후 109개 매뉴얼 검사 통과. 1.0.0~1.3.0 발행 무결성 유지 |

감사 범위: 전체 `src` 및 공개 매뉴얼 문자열, 공개 페이지 28개(초기 크롤), DB 공개 스키마 107개 테이블 352개 텍스트/배열/JSON 필드의 일치 건수, 실제 로그인 관리자 수료/결과보고 목록.

발견 사항: 공개 목록과 상세에 Issue124 검증 과정이 노출되었고 현재 수정 대상에 포함했다. 16개 공개 과정 안내의 운영 문구에서는 추가 검증/작성 요령 문구가 발견되지 않았다. 명시적 합성 과정/정책/출결/신청/감사·수료 근거는 기록을 실제 이력으로 오인하지 않도록 보존한다. 구판 매뉴얼은 과거 버전 표시와 함께 보관한다. 관리자 작성 필드 안내·검증 전용 증명 경고·문자 업체 미연결 경고는 사실을 나타내므로 유지한다.

검사: eslint 경고 0, TypeScript 오류 0, 매뉴얼 109개 검사 및 발행본 무결성 통과, diff 공백 검사 통과. React 검토: 새 client 상태/effect 없음, 기존 병렬 조회·인증 유지, 안내는 제목/section/실제 링크로 구성.

남은 확인: Preview 빌드 및 공개 필터 실제 동작, 병합 후 Production READY/버전/health, 실제 관리자 `sample=1`과 결과보고 링크, 최신 매뉴얼/수강안내, 공개 페이지 재감사와 DB count/hash 비교.
