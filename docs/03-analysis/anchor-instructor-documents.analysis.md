# 강사 서류 제출 설계 대조

검증일: 2026-09-22. uc-anchor 원본의 문서 전용 제출 흐름을 uc-life 로그인·기관 권한에 연결했다.

| 요구사항 | 구현·검증 결과 |
| --- | --- |
| 사업단 전용 전문가 관리 | 사업단 홈/데스크톱/모바일 메뉴에 독립 항목. COURSE_MANAGER만 노출·접근. 과정 운영 메뉴에서 분리. |
| 강사 본인 제출 | My Room → 강사 서류 제출. 본인 또는 담당 기관 관리권한 RPC 검증. |
| 신분증·통장사본·이력서 | 원본 입력·AI 분석·분리·미리보기 구성 재사용. 문서 전용 모드에서 회의·의견·서명 작업은 비활성. |
| 동일한 비공개 저장 방식 | uc-life 전용 버킷, 원본·생성 PDF 메타데이터, AES-256-GCM 이력서/판독정보, 해시 세션 적용. |
| 초안과 완료본 | 별도 암호화 초안 테이블. 완료 저장 시 초안 제거. 제출 현황에서 구분. |
| 인증/다운로드 | JWT+현재 역할 매 요청 검증, 세션 30분·사용자 결합, 다운로드 URL 300초. |
| 표준 A4 PDF | 브라우저에서 생성 후 비공개 저장. 내려받은 PDF 실제 크기 595.28×841.89 pt 확인. |
| 관리 제출 현황 | 해당 기관 강사와 이력서 등록자, 이름·제출 상태만 목록 노출. 상세는 별도 인증. |
| 사이트 간 데이터 | 동일 구조를 별도 프로젝트에 적용. 기존 uc-anchor 개인정보 자동 공유/복사는 하지 않음. |

검증 결과:
- TypeScript, 변경 파일 ESLint, Deno 타입 검사, 프로덕션 빌드, git diff 공백 검사 통과.
- 로컬 Supabase 통합 검증 14개: 익명·타인·탈취 토큰·역할 회수·인증 해제·기간 만료 차단, 암호화 왕복, 초안/완료 분리, 이름/파일 검증, 직접 테이블 접근 차단, 비공개 버킷.
- 역할/내비게이션 회귀 검증 19개 통과. 사업단 담당자 전용 항목, 하위 페이지 활성 상태, 일반 강사·수강생 차단 포함.
- 운영 Supabase의 가상 계정으로 세션 발급, 업로드, 암호화 복원, 서명 URL 다운로드 및 공개 URL 차단 확인.
- 실제 브라우저에서 신분증·통장사본 PDF와 이력서 PDF 생성/저장, 저장 후 복원 및 보관 PDF 링크 확인. 데스크톱·390px 모바일 확인.
- 가상 TXT 이력서의 실제 AI 분석은 Gemini 대체 경로로 성공. OpenAI 우선 경로의 성공 응답은 확인되지 않았음. 실제 신분증을 사용한 OCR 정확도 평가는 수행하지 않음.
- Supabase 보안 진단: 새 테이블 5개의 `rls_enabled_no_policy` INFO는 서비스 역할 전용 설계에 따른 결과. 새 기능 관련 WARN/ERROR 없음.
- npm audit 취약점 0건. PDF.js는 보안 수정 버전 6.3.289 사용.

설계의 기능 누락은 발견하지 않았다. 실제 문서의 판독 결과는 저장 전에 담당자가 검토한다.
