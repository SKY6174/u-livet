# 접수 문서 안내·처리이력 검증

2026-10-08 · [설계](../02-design/features/learner-document-desk-clarity.design.md)

## 설계 일치
- 접수 안내와 현재 수강 신청 상태를 관리자 안내 칸 및 수강생 서류 현황의 한 영역에 표시함.
- 과정 열의 중복된 연결 과정명·기간을 제거하고 실제 연결 및 관리 링크를 유지함.
- 별도 처리 이력 열에 접수 시간, 실제 승인 이벤트의 시간·담당자 및 전체 이벤트를 표시함. 승인 이벤트가 없으면 승인 내역은 표시하지 않음.
- 표 최소 너비를 1,580px에서 1,320px로 줄이고, 관리 열 삭제 버튼의 아이콘·문구가 줄바꿈하지 않도록 조정함.
- 원본 안내, 상태 저장 폼, 연결, 등록 확정, PDF 및 삭제 서버 동작은 그대로 유지함.

설계 항목 5개 중 5개 구현(100%). ESLint, TypeScript, production build 통과. 운영 화면의 실제 사용자 데이터 확인은 배포 후 수행한다.
