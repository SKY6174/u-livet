## 검사
- `node scripts/verify-pdf-17.mjs`: 6개 검사 통과. 실제 jsPDF/pdf-lib 생성·파싱, 한국어 증명서 2종, 올바른 Edge decoder 수용 및 오류 거부, 페이지 픽셀 보존, 자산 API의 임의 파일 접근 거부.
- `node scripts/verify-instructor-documents.mjs`: 로컬 Supabase 15개 검사 통과. 기존 권한/암호화/세션 검증과 잘못된 생성 PDF 저장 거부 포함.
- 로컬 Storage 서비스가 없는 환경이므로 이번 회귀검사의 정상 PDF는 decoder까지 검증했다. Storage 업로드 성공까지 실행한 검증은 아니다. 기존 기능 도입 시 운영 가상 자료로 업로드·복원을 확인한 기록은 별도 보고서에 있다.
- 브라우저 실제 다운로드: PDF 1.4 두 페이지 → 1.7 두 페이지, 2.0 두 페이지 및 90도 회전 → 1.7 크기/방향 보존, 비임베디드 한글 CID 글꼴의 구형 PDF 변환 성공.
- 보고서 6종 10쪽, 긴 문단 150줄 포함 보고서 13쪽, 23명·7차시 출석부 4쪽을 다운로드하여 PDF 1.7 및 페이지 크기 확인. Poppler 렌더로 한글·표·표지·연속 문단 검수.
- 마지막 시각 검수에서 발견한 긴 문단의 경계 글자 잘림은 실제 Canvas 빈 줄로 분할 위치를 보정하여 해결. 연속 페이지의 074/075 등 문장 연결을 확인했다.
- `npx tsc --noEmit --incremental false`, 변경 TypeScript ESLint, Deno 타입 검사, `npm run build`, `git diff --check` 통과.
- 검증용 공개 라우트와 가상 PDF는 삭제했다. 로컬 생성 검증 자료는 git 제외 디렉터리에만 남긴다.

## 범위와 한계
- PDF 1.7 출력 규격이며 PDF/A 인증을 의미하지 않는다.
- 브라우저 인쇄 대화상자 자체의 PDF 버전은 제어하지 않는다. 버전이 필요한 파일은 `PDF 1.7 다운로드` 또는 `PDF 1.7 변환본`을 이용한다.
- 기존 보관본은 필요할 때 변환한다. 일괄 원본 덮어쓰기나 새 사본의 서버 영구 저장은 하지 않는다. 암호 잠금 PDF·30MiB 초과 원본은 안내 후 중단한다.
