# 전체 회차 출석부와 QR 종료 기록 검증

2026-09-25 · [설계](../02-design/features/anchor-qr-session-grid.design.md)

## 일치율: 90% (10개 항목 중 9개 확인)

- 시작·종료 토큰 분리, 최초 시각 보존, 시작 없는 종료 거부, 수강·강사·회차 권한 검사를 DB 함수에 적용했다.
- 종료 후 15분 허용을 강사 발급·수강생 스캔 양쪽에 적용했다. 운영 DB에서 마이그레이션과 익명 실행 차단을 확인했다.
- 출석부 전체 회차 가로축, 두 QR 시각, 별도 인정시간, A4~A0 가로 용지, PDF 1.7을 정적 렌더링·PDF 검증으로 확인했다.
- 첨부 1~5의 번호를 제목에서 분리해 출력물 좌상단에 표시했다.
- 빌드, 타입 검사, lint, QR 서버 액션과 출석부 테스트는 통과했다.

## 남은 검증

- QR DB 통합 테스트는 로컬 환경의 공개 가입 정책이 닫혀 있어 합성 계정 생성 단계에서 중단됐다. 정책을 약화하지 않고 별도의 사전 승인 테스트 계정이 마련되면 시작·종료 실스캔을 재검증할 수 있다.
