# 전체 회차 출석부와 QR 종료 기록 검증

2026-09-25 · [설계](../02-design/features/anchor-qr-session-grid.design.md)

## 일치율: 100% (설계 항목 10개 중 10개 구현·검증)

| # | 설계 항목 | 검증 결과 |
| --- | --- | --- |
| 1 | 기존 시작 시각 보존 및 종료 시각 별도 저장 | `checked_out_at` 추가, 최초 시작·종료 시각 보존 및 재스캔 멱등성 확인 |
| 2 | 시작·종료 토큰과 발급 RPC 분리 | `phase` 분기와 종료 전용 발급 RPC 확인 |
| 3 | 수업 시간 및 종료 후 15분 제한 | 시작·종료 발급과 스캔의 시간 제한 확인 |
| 4 | 강사·수강생·회차 권한과 비공개 테이블 보호 | 무권한·타 강좌·만료·위조 토큰 거부, 비공개 테이블 직접 접근 차단 확인 |
| 5 | 강사 화면의 시작·종료 QR 구분 | 선택·안내문·회차별 출력 확인 |
| 6 | 수강생 확인 화면의 결과와 일자·시각 | 시작·종료 결과와 최초 기록 표시 확인 |
| 7 | 전체 정규 회차를 한 표에 배치 | 전체 회차 가로축과 명단 세로 분할 확인 |
| 8 | QR 시각과 인정시간 분리 | 회차별 한국시간 시작·종료 칸과 별도 인정시간 확인 |
| 9 | A4~A0 가로 출력, PDF 1.7, 첨부 번호 | 용지 크기·PDF 버전·첨부 1~5 좌상단 번호 확인 |
| 10 | 시작·종료 흐름 통합검증 | 로컬 합성 계정 DB 검사 9개, QR 액션·화면 검사, 빌드·lint 통과 |

Preview와 Production DB에 두 QR 마이그레이션이 적용됐고, 종료 시각 컬럼과 종료 QR 발급 RPC가 양쪽에서 확인됐다. Production 앱은 배포 완료 상태이며 v1.3.0 매뉴얼의 웹·PDF 응답도 확인했다.

이 일치율은 설계 구현과 자동 검증 범위다. 실제 수업에서 휴대전화 카메라로 QR을 스캔하는 현장 확인은 포함하지 않는다.
