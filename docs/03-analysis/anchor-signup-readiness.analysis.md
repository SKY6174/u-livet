# 공개 가입 준비 점검 결과

2026-09-19 10:17 KST · anchor-signup-readiness

## 결론

읽기 전용 점검 및 검토 자료 작성 범위는 완료했다. 실제 공개 가입은 `REVIEW_REQUIRED`다. 담당자 정보 확보와 문안·동의·권한 승인을 구분한다. SMTP와 배포 성공이 기관 개인정보 승인 또는 관리자 생성을 대신하지 않는다.

## 공개 가입까지 남은 간격

| 항목 | 실제 상태 | 후속 조치 |
|---|---|---|
| 처리기관·문안·보유기간 | 초안, 기관 승인 없음 | 법적 처리자 명칭, 기간·근거·시행일·승인자 확정 |
| 위탁·국외이전 | 도쿄 운영 DB 확인, 계약상 근거·범위 미확정 | Supabase/Vercel/Resend 계약·지원·로그·백업 처리 범위 검토 |
| 처리방침/동의 구분 | `/privacy`와 가입 UI가 ACCOUNT_PRIVACY를 함께 사용 | 필수 동의 절과 전체 방침 분리 설명, 필요 시 UI/정책 종류 분리 |
| 최초 정책 승인 | `approved_by`는 life_people 참조 | 실재 기관 승인 근거로 승인자 식별 행·정책 등록; 자동 승인 금지 |
| 최초 관리자 | 사용자가 후보 이름·이메일·직위를 제공 | 정확한 문안에 대한 본인 동의·메일 발송 요청·초기 설정 방식 검증 후 생성 |
| 초기 설정 흐름 | 가입 전 동의를 처리하는 전용 웹 흐름 없음 | Preview 인수 검증 후 운영 적용; 공개 가입을 잠시 열어 우회하지 않음 |
| 업무 권한 | SYSTEM_ADMIN과 COURSE_MANAGER는 독립 | 담당 업무·유효기간 확인, MFA 후 필요한 역할만 부여 |
| 메일 검증 범위 | Resend 진단 Delivered·Preview 복구 완료 | 승인된 실제 담당자 수신함, 가입 인증·최초 설정 메일 검증 |
| 권리행사·파기 | 전체 탈퇴/자동 파기 완료로 볼 수 없음 | 담당 창구·요청 처리·예외 보존·공급자 삭제 절차 확정 |
| 성인학습자 안내 | 비밀번호 안내 및 버튼 제공; 동의 상세 본문은 text-sm | 최종 문안 적용 때 읽기 크기/요약 표시 검토, 가입 연령 범위 확정 |

승인된 정책은 동결되며 `getPolicies`는 현재 유효한 모든 버전을 읽는다. 정책 교체 시 이전 승인본을 직접 덮어쓰거나 트리거를 해제하는 방식은 적용하지 않는다. 이 문제는 현재 0건 상태의 가입 차단을 무너뜨리지는 않으나 첫 버전 이후 변경 절차가 필요하다.
