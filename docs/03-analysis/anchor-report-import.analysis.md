## 구현 대조

- ARCHIVED 상태에서만 접수기간·수강료·선발방식 미기재를 허용한다. 기존 모집 상태의 필수값과 공개 접근 경계는 유지한다.
- 원본 집계의 입력 범위는 TypeScript/Postgres에서 검증한다. 모집인원보다 큰 수료인원이나 숫자 대신 문자열을 거부한다.
- 로컬 합성 PDF와 운영자로 등록·저장·재조회 및 동일 원본 재실행을 확인했다. 재실행 후 감사기록·과정은 각 1건이다.
- 개인별 출결·수료 승인·강사 실적을 생성하지 않았다. 운영자 조회는 가능하며 익명 catalog 조회는 0건, 원본 다운로드는 404다.
- 인증된 원본 다운로드의 SHA-256이 원본과 일치한다. 출력 결과의 원본 집계 비율·총시수와 원본 표기를 확인했다.
- 실제 브라우저의 원본 연결 요약, 인원·시수·장학금, 확인사항과 다운로드 버튼을 시각 확인했다.
- 린트·타입·전체 Next.js 빌드 통과. 기존 학습/출결/수료 회귀 검사 33건 통과. 로컬·Preview 보안 Advisor WARN/ERROR 없음.
- `20260919132208_anchor_archived_reports.sql`만 양 원격 dry-run 목록에 나타났으며 Preview → 운영 순으로 적용했다.

저장소에 있던 사용하지 않는 `src/**/* 2.ts(x)` 사본 88개는 타입 검사 대상에서 제외했다. 사본을 가져오는 import는 없으며 실제 라우트·원본 코드의 타입 검사를 유지한다. 파일은 삭제하지 않았다. 별도 빌드 디렉터리와 검증 자료도 타입 검사에서 제외한다.
