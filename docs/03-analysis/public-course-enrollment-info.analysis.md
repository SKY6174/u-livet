# 공개 과정의 수강료·이수·장학 안내 — Gap Analysis

2026-10-08 · [설계](../02-design/features/public-course-enrollment-info.design.md)

## 설계 부합도: 100% (7/7)

1. 과정 소개는 연결된 공개 개설 과정의 수강료를 null/0/양수로 구분한다.
2. 연결되지 않았거나 아직 공개되지 않은 개설 과정은 모집 공고 준비 중으로 표시한다.
3. 과정 소개는 승인·유효한 수료기준의 원문·제목·버전을 표시한다.
4. 검증용 정책과 조회되지 않은 정책은 실제 이수요건으로 표시하지 않는다.
5. 장학금은 확정되지 않은 대상·금액·신청방법을 만들지 않고 지급 절차와 미게시 상태를 안내한다.
6. 같은 장학금 안내가 과정 소개와 개설 과정 상세에 표시된다.
7. `npm run lint`, `npm run build`, `git diff --check`가 통과했다.

## 남은 데이터 제한

과정별 장학금 지급 기준의 승인·공개 데이터가 아직 없으므로 구체적 대상과 금액은 표시할 수 없다. 기관이 실제 정책을 확정하면 별도 정책 관리·게시 흐름으로 연결해야 한다.
