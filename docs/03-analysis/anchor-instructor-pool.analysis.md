## 실행 결과

- `node scripts/verify-instructor-pool.mjs`: 18개 통과.
- `node scripts/verify-instructor-documents.mjs`: 기존 비공개 서류 15개 회귀 검증 통과.
- `node scripts/verify-instructor-pool-excel.mjs`: 실제 XLSX 왕복, 입력 한도·중복·열 순서·문자열 보존 통과.
- 브라우저: 활동 생성 → 150,000원 산출/5,000원 공제 → 145,000원 지급 완료 → 누적액 반영 확인. 엑셀 미리보기/등록/검색/필터 다운로드, 기본정보 수정, 서류함 진입 확인. 가상 자료와 인증 임시 파일 정리.
- TypeScript, 변경 파일 ESLint, `npm run build`, `git diff --check` 통과.
- React 검토: 데이터 조회/권한은 서버, 엑셀 라이브러리는 사용자 실행 시 지연 로드, 폼 label 및 처리 중 중복 제출 차단, 탭 aria-current.
- 운영 Supabase 후속 마이그레이션 적용 완료. 보안 경고/오류 없음. 새 비공개 테이블의 `RLS enabled no policy` 정보는 직접 조회를 허용하지 않고 권한 검사 RPC를 사용하는 의도된 구조이다. [Supabase 설명](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy)

## 범위

수당 기능은 실제 송금 내역을 확인하여 보관하는 지급 대장이다. 은행 송금 및 세율 자동 판단은 수행하지 않는다. 기존 이름 기반 결과보고서 수당을 자동으로 복사하지 않는다. 문서 AI 및 PDF 1.7 생성 경로는 변경하지 않았다. 신규 문서의 AI 분석 호출은 이번 검증 대상이 아니다.
