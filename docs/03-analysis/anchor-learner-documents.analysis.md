# 수강생 원본 서식 — 설계 대조 및 검증

2026-09-22 · 기능: anchor-learner-documents

## 설계 일치
완료 항목 12/12. 수강신청원서·장학금 신청서, 인증된 경로, 별도 창, 좌우 입력/미리보기, 원본 보존, 과정 선택/직접입력, 항목별 동의, 서명, PDF 1.7, 입력 검증, 메모리 전용 작성, 모바일 레이아웃을 구현했다.

## 확인한 결과
- 원본과 페이지별 템플릿을 2배 해상도(1190 × 1684)로 비교: 예시 과정명·날짜 제거 영역 외 변경 픽셀 **각 0개**.
- 빈 양식, 작성된 양식, 비동의 선택을 두 서식에서 생성: 각 595 × 842 pt 1페이지, 헤더 `%PDF-1.7`, Catalog `/1.7`.
- 원본의 Malgun Gothic, HCR Dotum, KoPub 글꼴은 그대로 보존. 새로 입력하는 한글은 프로젝트의 KoPub 글꼴을 내장한다.
- `node scripts/verify-learner-documents.mjs`: 날짜·연락처·계좌·주민번호 형식·필수값·서명·긴 내용·지원하지 않는 문자 검증 통과.
- 브라우저: 나의 학습 → 별도 작성 창, 입력 → 실제 PDF.js 렌더링 → 다운로드 확인. 원본 미리보기 캔버스가 정상 표시됨.
- 직접 그린 서명과 PNG 이미지 서명 모두 다운로드 PDF에 포함. 지우기 후에는 다시 서명하도록 검증. 서식 사이에 서명·동의를 공유하지 않음.
- 모바일 390 × 844와 데스크톱 1500 × 1100 확인. 가로 넘침 없음. 미리보기는 데스크톱에서 자체 스크롤하여 다운로드 버튼 유지.
- 브라우저 미처리 오류 없음. 생성된 두 PDF를 재렌더링하여 값·체크·서명 위치 확인.

## 범위
작성 및 PDF 다운로드 기능이다. 개인정보를 서버에 저장하거나 실제 수강신청·장학금 접수를 자동 처리하지 않으며, 화면에서 제출 방법을 안내한다. 신분·계좌의 진위 검증은 이 기능의 범위가 아니다.

## 보완
서명 업로드 실패를 명시적으로 안내하고, 지우기 후 이전 업로드 결과가 뒤늦게 적용되지 않도록 보호했다. PDF 입력란이 넘치거나 지원되지 않는 문자를 입력하면 오류를 표시한다.
