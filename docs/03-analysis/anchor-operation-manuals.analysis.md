## 수행한 검증
- `npm run test:manuals`: 25개 검사 통과. 해시 불일치·파일 삭제·구판 제거 검사는 임시 폴더에서만 실행.
- `npm run manuals:check`, `npm run prebuild`, `npm run prebuild:vercel`: 통과.
- `npm run lint`: 통과.
- `.env`를 복사하지 않은 별도 `tmp/manuals-build`에서 Next.js production build, 린트·타입 검사 통과. 인쇄·앵커 수정 후 재빌드 통과.
- agent-browser: 검색 입력/결과, 본문 이동, 목차, 버전 이력, 모바일 확인, 인쇄 PDF 생성.
- 실제 HTTP: 8종 웹 페이지 200, 개별 PDF 200 및 다운로드 해시 일치, 미등록 대상·버전 404, 최신판 307, 검색 결과 없음 확인.
- pypdf: 8종 개별 PDF 및 38쪽 합본에서 모든 번호 절차 포함 확인. 합본 표지 목차·쪽수, public/output 복사본 동일 확인.
- Poppler: 합본 38쪽 전체 렌더링과 축소판 검토, 표지·본문 확대 검토. 합본 표지 글꼴 누락을 전체 글꼴 임베딩으로 수정.

## 남은 적용 경계
초판은 확인한 저장소 구현 기준이며 실제 운영 계정으로 전체 업무를 수행한 검수본은 아니다. 원격 배포, 기관 정책·위임의 승인 확인은 포함하지 않았다. 후속 개정 시 운영 담당자의 검수와 변경된 화면 캡처를 반영할 수 있다.
