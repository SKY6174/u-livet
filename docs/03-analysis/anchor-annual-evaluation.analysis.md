## 점검 중 보완

- 미확인 판정과 과거 수료 재검토가 같은 등록 건일 때 공식 지표의 검토 건수를 두 번 더하던 것을 합집합으로 수정했다.
- 마감 직전 제출이 늦게 커밋되면서 공개 평균이 변할 수 있는 상황을 피하도록, 응답·결과 확정이 같은 조사행 잠금을 사용하게 했다. 응답은 잠금 획득 후 실제시각을 검사하고, 사업단이 마감 후 집계를 한 번 확정한다. 결과는 수정할 수 없다.
- 역할 부족 때문에만 거절되는 검사에 그치지 않도록 양쪽 권한을 가진 작성자·입력자·개선 담당자의 자기 승인 차단을 검사했다.
- 데스크톱 첫 dev 컴파일 직후 빈 CSS가 한 번 관찰되었다. 새로 탐색한 뒤 스타일·화면·콘솔 정상 확인. 운영 빌드도 별도로 성공했다.

## 검증 증거

DB/Auth 203개 = 기존 166 + 신규 37. `docs/04-report/features/evidence/annual-*.txt`에 결과를 저장했다. 17개 migration 재생, lint, production build, 로컬 security advisor(warn 이상 없음), `git diff --check` 통과.

브라우저는 실제 로컬 Auth 계정으로 사업단 설문 개설 → 수강생 3문항 제출·참여 영수증 → 강사 의견 → 사업단 개편 검토(v2) → 성과담당 보고 초안(v9) → 별도 승인자 확정 → 인증 JSON 200을 확인했다. 같은 다운로드의 익명 401, 수강생 404, 승인 전 409 및 no-store를 확인했다. 개선 과제의 보고·별도 확인과 공개 임계값/마감 확정은 DB/Auth 회귀로 검증했다. 모바일 설문과 성과 대시보드를 시각 확인했다.

## 운영 적용 전 범위

기관의 실제 공식 산식/분모/중복 규칙은 승인됐다고 간주하지 않는다. PDF D06 지원지수의 목표·제시 산식 불일치 확인, 조사 문안·보유기간·최소 응답수·권한 위임 확정이 필요하다. 시험용 기준은 운영 기준이 아니다. 대외 RISE 제출, 복합지수 자동 계산, 근거파일 업로드/검증, 대용량 부하, 개인정보 파기 작업, 개선 담당자 재배정·반려 UI는 이번 범위 밖이다.
