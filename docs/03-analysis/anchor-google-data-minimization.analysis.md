설계 항목 7/7 확인. 이 결과는 최소화 기능과 검토안 준비 범위이며 운영 Google 개방이나 기관 승인을 완료했다는 뜻은 아니다.
배포 직후 일시적 400은 새로고침 후 재현되지 않았다. 원인을 단정하지 않으며 지속 발생 시 별도 조사한다.
실계정 신규 가입·새 문안 동의는 기관 문안 승인 후 수행할 후속 검증이다. 기존 두 계정 재로그인은 실제 브라우저와 DB 조회로 확인했다.
