## 검증 실행

- `node scripts/verify-course-plan.mjs`: 14개 검사 통과.
- `npm run lint`: 통과.
- `npm run build`: Next.js production build와 TypeScript 검사 통과.
- 제공 PDF SHA-256과 데이터의 출처 지문 일치.
- 비로그인 GET: 로그인 이동, 과정명·인력·예산 내용 미노출.
- 실제 로컬 수강생 계정: 권한 확인 후 not-found, 원문 정보 미노출.
- 실제 로컬 과정담당 계정: 비밀번호·MFA 로그인 후 14개 과정 확인.
- 팝업 필터: 3개. 김두영+팝업+확인 필요: 가구소품 과정 1개.
- 교내 필터: 빈 결과와 원문 구분 미기재 안내. 초기화: 14개 복원.
- 390×844 모바일: 펼친 상세의 인력 구분 확인, 문서 폭 390px로 가로 넘침 없음.
- 홈 이동·새 화면에서 오류 오버레이 없음.

빌드와 브라우저 검증은 기존 결과보고서 작업과 분리한 작업 폴더에서 실행했다. 검증한 코드와 `preview`에 적용한 코드의 diff가 없음을 확인했다.

## 남은 원문 확인사항

교내·교외 명단, A/B의 인적사항, 스마트테크 세부 과정, 정원 소계 차이는 원문만으로 확정할 수 없다. 해당 값은 미확정 상태를 그대로 유지한다. 이번 범위는 읽기 전용 연간 계획이며 DB 기수 등록·모집 공개·강의자료 제작은 포함하지 않는다.
