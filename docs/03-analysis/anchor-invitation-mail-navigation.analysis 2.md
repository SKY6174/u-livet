# 초대 메일 새 창 열기 검증

2026-09-19

초대 페이지는 HTTP 200, `X-Frame-Options: DENY`였다. 브라우저 새 탭에서 실제 계정 설정 안내가 정상 표시됐다. 첨부 오류는 프레임 내부 이동 차단과 일치하지만 원래 메일 클라이언트에서의 재현은 확인하지 않았다.

기존 href와 fragment 토큰 구조를 유지한 채 `_blank` 및 `noopener noreferrer`, 새 탭 이용 안내를 추가했다. 운영·Preview Auth 설정을 각각 다시 읽어 저장된 HTML과 소스가 일치함을 확인했다. 제목·SMTP·SiteURL·15분 유효시간·공개 가입 차단 설정은 변경되지 않았다.

수정이 HTML 메일 템플릿에 한정되어 애플리케이션 빌드나 인증 처리 코드는 변경하지 않았다. 새 창 처리는 메일 클라이언트에 따라 제한될 수 있으므로 직접 새 탭에서 여는 안내도 제공한다. 비밀번호 입력·MFA 완료는 당사자가 수행해야 한다.

실제 계정의 재초대 요청 및 전달 결과는 비공개 `ops/evidence/signup-opening/initial-admin-execution.json`에 보관한다. 새 메일 발송만으로 본인 설정 완료를 판정하지 않는다.
