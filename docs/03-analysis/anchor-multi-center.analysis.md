# 센터 공통 안내 설계 대조

2026-09-22 · 설계: `docs/02-design/features/anchor-multi-center.design.md`

## 결과: 8/8 항목 충족
1. 로그인 사업단 표시에서 RCC 전용 명칭 제거, 학교 이메일 설명과 audience 유지.
2. RCC·AID-X·ECC 문의 담당자와 전화·이메일 및 tel/mailto 값 일치.
3. 공통 SupportContact를 사용하는 하단·인증·복구·개인정보·강사 안내 갱신.
4. 수강안내에서 같은 공통 연락처 사용.
5. 강사 연간 점검·배정 주체는 운영센터로 표시, 기존 승인 절차 유지.
6. 사업 소개에 네 센터와 재직자 교육을 포괄하는 공동 플랫폼 소개 반영.
7. 4개 프로젝트 사진·색상·설명 패널과 기존 인증·DB·개인 동의 기록 유지.
8. lint, production build, 기존 강사 등록 UI 8개 검사 통과. 브라우저에서 1440px 로그인, 390px 로그인/수강안내, 320px 수강안내/사업 소개 가로 넘침 없음. 문의 링크 높이 44px 확인.

React 점검: 서버 렌더링 유지, 추가 요청·상태·효과 없음, 목록 키와 접근성 이름 제공, 전화·메일은 명시적 링크로 연결.

미충족 항목 없음. ICC 담당자는 지정되지 않아 연락처를 추정하지 않았다. 후속 단계는 Git push와 운영·스테이징 배포 확인이다.
