# 로그인 인증 코드 자동 확인 검증

2026-09-22 · anchor-mfa-auto-submit

| 설계 항목 | 확인 결과 |
|---|---|
| 로그인 코드 입력 자동 포커스 | 실제 React StrictMode 브라우저에서 클릭 없이 입력 시작 |
| 1~5자리 비제출, 최신 6자리 자동 제출 | 컴포넌트 회귀 및 브라우저의 요청 횟수 확인 |
| 선행 0·붙여넣기 정규화 | `012345` 타이핑 및 공백 포함 붙여넣기로 성공 화면 도착 |
| 중복 제출 방지 | 입력·Enter·지연 응답 회귀에서 요청 1회 |
| 검증 성공 후 목적지 이동 | 기존 서버 검증 회귀와 브라우저 성공 화면 확인 |
| 잘못된 코드·연결 실패 복구 | 회귀 통과, 브라우저 오류 시 포커스 복구 및 재입력 성공 |
| 등록·직접 관리 수동 확인 유지 | 회귀 통과, 브라우저 관리 화면에서 버튼 클릭 전 요청 0회 |
| 서버 인증·세션 정책 유지 | 서버 액션 변경 없음, 기존 서버·리다이렉트 회귀 통과 |

설계 8개 항목 모두 충족했다. `node scripts/verify-mfa-navigation.mjs` 50개, `npm run lint`, `npm run build`, `git diff --check` 통과.

브라우저에서는 실제 컴포넌트와 합성 인증 응답을 사용했다. 실제 계정의 비밀번호·TOTP를 사용하지 않았으며, 실제 인증 서비스 연결은 이번 검증 범위에 포함하지 않는다. 기존 회귀 스크립트의 마이페이지 모킹은 현재 학생 대시보드 및 강사 리다이렉트에 맞춰 갱신했다.

재현: 빌드 후 `node scripts/preview-mfa-auto-submit.mjs`. 출력된 localhost 주소에서 합성 코드 `012345`를 사용한다. `?mode=manage`는 직접 관리, `?mode=enroll`은 신규 인증 앱 등록 흐름이다. 운영 서비스에 연결하지 않는다.
