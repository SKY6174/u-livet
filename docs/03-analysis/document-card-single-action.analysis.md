# 운영 문서 카드·안내 말풍선 검증

2026-10-10 · 설계 항목 4/4 일치

- 카드 상단 상태 배지는 유지하고 하단 문서 링크의 중복 상태 텍스트는 제거했다.
- 계획·결과 카드에 같은 단일 행동 링크와 방향 아이콘을 적용했다.
- 말풍선 설명은 `text-base`에서 `text-sm`으로 바뀌어 역할별로 2px 작다.
- 라우팅·권한·미등록 과정과 리스트형 보기는 변경하지 않았다.

검증: lint·TypeScript·프로덕션 빌드 통과. 360px 브라우저에서 말풍선 17.25px(수강생), 16px(사업단·강사), 가로 넘침 없음 확인.
