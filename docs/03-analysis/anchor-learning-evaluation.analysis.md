# 출결·시험·수료판정 설계 대조

2026-09-19 · anchor-learning-evaluation · 로컬 검증 완료

전체 플랫폼의 기능률이 아니라 이번 범위의 인수 기준을 비교했다.

| 기준 | 구현·검증 근거 | 결과 |
|---|---|---|
| 담당 강사의 공식 출결 | 담당기수+유효 역할, 종료 후 인정분, 낙관적 revision, 본인 기록 금지 | 통과 |
| 회차 전체 분모 | 누락 회차는 NEEDS_REVIEW, 취소 제외, 취소 원회차에 보강 연결 | 통과 |
| 출결 정정 추적 | before/after·사유·actor 감사원장, 입력 값 보존 | 통과 |
| 시험 정답 비공개 | private 정답표, public 문제/응시표 조회권한 회수, 안전한 응시 RPC | 통과 |
| 문항 고정·제한시간 | 응시 스냅샷, 서버 종료시각, 1회 응시, 종료 후 추가 채점 차단 | 통과 |
| 임시저장·재접속·최종제출 | DB 답안 저장, 동시 시작 고유키, 중복 최종제출 결과 고정 | 통과 |
| 점수 공개 시점 | 종료 전 수강생 응답의 score=null, 종료 후 서버 점수 공개 | 통과 |
| 승인된 수료 기준 | 기본값 없음, 정책버전 연결, 작성자/승인자 분리, 승인 후 불변 | 통과 |
| 누락·미채점 처리 | 명시적 NEEDS_REVIEW, 근거가 완전할 때만 READY/INELIGIBLE | 통과 |
| 확정 전 자료 변경 | 기수 행 잠금+입력 revision; 출결/성적/응시/제출/수강상태/평가항목 변경 추적 | 통과 |
| 별도 확정·이력 | CERTIFIER, 자기산출/본인수료/담당강사 승인 차단, 확정 재시도 고유키 | 통과 |
| 확정 후 정정 | 기존 승인 보존, 현재 조회는 재검토 표시, 동시 정정/승인 경합 검증 | 통과 |
| 회귀·화면 | core 33 + learning 33, 실제 브라우저 입력·응시·수료확정·본인 이력 | 통과 |

이번 범위에서 발견한 결함은 보완했다: 카탈로그 뷰의 새 컬럼 누락, 미승인 기준 읽기 조건의 컬럼 한정, 자기 과제 채점 금지, 승인된 동일 자료 재산출 시 기존 승인 유지, 오류 응답 시 공통 폼 초기화 문제.

범위 밖: 영상/QR 자동출결, 객관식 외 문항, 재응시·가중 배점·공결 환산, 설문, 이수증/배지/경력증명, 운영 MFA·대규모 목록 페이지 처리. 운영기관 기준·발급권 확정과 원격 적용은 별도다.
