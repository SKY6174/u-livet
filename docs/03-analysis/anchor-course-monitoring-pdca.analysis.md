## 검증 결과

- `npm run lint`, `npx tsc --noEmit`, `npm run build` 통과.
- 기존 과정 모니터링 5개 회귀 검사와 연간 기간·신호등 16개 검사, 16개 과정 일정표 렌더링 통과.
- 로컬 DB에서 최종 마이그레이션 적용, 권한 없는 RPC/테이블 조회 거부, 16개 안내 과정 조회, 쓰기·읽기·revision 충돌 방지 통과. 쓰기 검사는 트랜잭션을 롤백해 실제 기록을 남기지 않았다.
- 전체 `supabase db lint`에는 기존 `member_directory_filtered`, `course_budget_overview`의 누락 함수 참조 2건이 남는다. 이번 마이그레이션 함수의 오류는 보고되지 않았다.

## 운영 전제

- P/C/A 목표일은 출처에 없는 정보이므로 임의 생성하지 않았다. 담당자가 각 과정의 목표일을 확정할 때까지 ‘계획전’으로 표시된다.
- 로컬 DB 외 운영 DB에는 마이그레이션을 적용하지 않았다. 운영 배포 전 DB 변경을 먼저 적용해야 한다.
