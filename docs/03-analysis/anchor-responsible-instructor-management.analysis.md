### 검증 기록

`node scripts/verify-operation-documents.mjs`가 통과했다. 책임강사 변경 후 이전 강사의 문서 접근 거부, 새 강사의 접근, 두 문서 표지 갱신, 동일인 재지정 무변경, 제출 스냅샷 보존, 강사명 위조 교정, 책임강사 배정 해제를 검사했다. `npm run lint`와 `npm run build`가 통과했다. 브라우저로 일반/보관 과정의 관리 화면과 지정 폼 제출을 확인했다. Preview와 Production에 신규 마이그레이션 한 건씩 적용했으며 각각 Supabase 보안 진단에서 경고가 없었다.

실제 과정 책임강사는 승인된 계정과 기수 배정이 준비된 다음 운영자가 지정해야 한다. 원본 PDF의 강사명은 신원 식별자로 사용하지 않는다.
