## 검증 근거
- `node scripts/verify-role-navigation.mjs`: 18개. 모든 사업단 역할, 3개 직책, 복수 권한, 비로그인, 무권한 직책, 상위·하위 layout, 데이터 조회 전 거부, 보고서 필터/검색, 빈 결과·실패 구분.
- `node scripts/verify-personal-start.mjs`: 12개. 실제 역할 기반 첫 화면 및 로그인·MFA 복귀.
- `node scripts/verify-mfa-navigation.mjs`: 44개. 기존 인증 앱 입력·추가·해제 및 관리자 개인 페이지 노출.
- `node scripts/verify-course-opening-prefill.mjs`: 7개. 16개 운영계획서, 개설 양식, 조직별 연도·잘못된 ID.
- `npm run build`: 타입·lint 포함 빌드 통과.
- 실제 소스 컴포넌트를 합성 신원/과정으로 로컬 브라우저에서 렌더링. 모바일 메뉴 열기·닫기, 보고서 검색/보완 필터, 관리자·강사·수강생 개인 화면 확인. 390/1024px에서 scrollWidth가 뷰포트와 동일.

## 한계와 변경 범위
실제 계정 로그인이나 운영 DB 변경 없이 합성 신원으로 권한별 동작을 검사했다. DB 권한 원장·RLS·RPC·MFA 액션은 변경하지 않았다. 서버 layout은 기존 COURSE_MANAGER 경계를 개별 하위 경로에 보존한다. 직책별 일괄 권한 부여나 별도 운영 담당자 계정 연결은 수행하지 않았다.
