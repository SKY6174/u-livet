# 과정별 결과보고서 설계 대비 점검

## 2026-09-22 저장본 출력 경로 보완

추가 설계 3항목(공식 결과보고서 출력 연결, 카드의 공식 문서 상태, 나머지 5종 개별 출력)을 모두 구현했다(3/3, 100%). 결과보고서 카드와 기존 `document=result` 링크는 공식 문서의 저장본 출력으로 이동하며, 개별 증빙 출력은 선택한 서식만 렌더링한다. 일괄 출력은 공식 결과보고서 뒤에 5종을 순서대로 배치한다. 강의날인부는 결과보고서 저장본에 중복 첨부하지 않는다.

Next 프로덕션 빌드(타입·린트 포함), 5종 개별 출력과 일괄 출력의 서버 렌더링 검증, 카드의 공식 상태·링크 검증을 통과했다. 로컬 DB의 기존 보고서 9건·공식 결과 문서 6건을 읽기 전용으로 확인했다. 기존 전체 보고서 DB 검증 스크립트는 로컬 MFA 테스트 계정에 필요한 fixture secret이 없어 시작 단계에서 중단됐으며, 기존 인증 요소를 임의로 제거하지 않았다.

SQL 별칭 충돌, 인쇄 표지의 빈 페이지/가로 표 폭, Next 개발 서버 Origin 비교 문제를 검증 중 발견해 수정했다. 요청 Host와 Origin 비교 검증을 추가했으며 타출처 업로드는 403으로 차단된다.

로컬 DB의 기존 migration 이력과 중복 파일 때문에 `db pull` 자동 추출은 이력 충돌로 중단됐다. 기존 이력을 수정하지 않고, CLI가 만든 신규 migration을 빈 테이블 상태의 트랜잭션에서 재실행·롤백하여 검증했다. Preview에는 신규 migration만 적용하고 원격 버전 `20260919043637`에 파일명을 맞췄다.
