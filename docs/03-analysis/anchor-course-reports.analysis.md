|---|---|
| 과정별 운영진 관리 | 관리자 목록·과정 상세에서 보고서 관리 진입, 기관 COURSE_MANAGER 검사 |

SQL 별칭 충돌, 인쇄 표지의 빈 페이지/가로 표 폭, Next 개발 서버 Origin 비교 문제를 검증 중 발견해 수정했다. 요청 Host와 Origin 비교 검증을 추가했으며 타출처 업로드는 403으로 차단된다.

로컬 DB의 기존 migration 이력과 중복 파일 때문에 `db pull` 자동 추출은 이력 충돌로 중단됐다. 기존 이력을 수정하지 않고, CLI가 만든 신규 migration을 빈 테이블 상태의 트랜잭션에서 재실행·롤백하여 검증했다. Preview에는 신규 migration만 적용하고 원격 버전 `20260919043637`에 파일명을 맞췄다.

검증용 PDF·이미지·세션은 Git 제외 디렉터리에만 저장했다. 첨부 문서의 실제 학습자 개인정보, 주민등록번호, 계좌, 서명은 코드나 seed에 복사하지 않았다. 지급서식은 생년월일을 사용하며 계좌는 기본 마스킹, 운영진 선택 시 원문 출력이다.
