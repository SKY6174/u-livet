# 과정별 결과보고서 설계 대비 점검

## 2026-09-25 첨부 1~5 공통 양식·20mm 여백

추가 설계 6항목(A4만 사용, 모든 인쇄면의 상하좌우 20mm 여백, 첨부 2·3·5 상단 문구 배너 제거, 첨부 1~5 표제·요약·하단 왼쪽 이미지 로고 통일, 강사료 지급 건별 두 줄 표현, 지급 정보 보존)을 모두 반영했다(6/6, 100%). 첨부 2·3·5는 A4 가로, 첨부 4는 A4 세로로 출력하며 출석부는 기존 20mm 서식을 유지한다. 강사료 두 번째 줄에는 은행·계좌번호·예금주·지급일/비고를 남겼다.

검토용 가상 데이터 PDF에서 첨부 2~5의 로고·배치·지급 건 두 줄을 육안 확인했다. 전체 출력은 A4 10쪽으로 세로 6쪽·가로 4쪽이며, 표지 뒤에 꼬리말만 나오는 페이지를 발견해 표지 높이를 줄인 뒤 재검증했다. 빌드·린트·출석 UI 검증이 통과했다. 실제 과정의 긴 이름과 많은 지급 건에 대한 배포 후 인쇄 확인은 남아 있다.

## 2026-09-25 첨부 1·2 A4 인쇄 양식 보완

이번 변경의 설계 항목 5개(A4 고정, 출석부 요약 명칭·크기, 4회차별 QR 시작·종료 표, 인정시간·출석률 열 제거, 수료자명단의 동일한 표제·하단 로고)를 모두 반영했다(5/5, 100%). 출결 인정시간과 수료 판정 데이터 자체는 변경하지 않았다.

9개 출석 UI·권한 검증과 Next 프로덕션 빌드를 통과했다. 검토용 가상 데이터로 생성한 두 출력 PDF는 각각 A4 가로 1쪽이며, 수료자명단 로고가 왼쪽 하단에 놓이고 표가 잘리지 않는 것을 확인했다. 실제 과정의 긴 이름·다수 인원 데이터에 대한 브라우저 인쇄 확인은 배포 후 점검 항목이다.

## 2026-09-22 저장본 출력 경로 보완

추가 설계 3항목(공식 결과보고서 출력 연결, 카드의 공식 문서 상태, 나머지 5종 개별 출력)을 모두 구현했다(3/3, 100%). 결과보고서 카드와 기존 `document=result` 링크는 공식 문서의 저장본 출력으로 이동하며, 개별 증빙 출력은 선택한 서식만 렌더링한다. 일괄 출력은 공식 결과보고서 뒤에 5종을 순서대로 배치한다. 강의날인부는 결과보고서 저장본에 중복 첨부하지 않는다.

Next 프로덕션 빌드(타입·린트 포함), 5종 개별 출력과 일괄 출력의 서버 렌더링 검증, 카드의 공식 상태·링크 검증을 통과했다. 로컬 DB의 기존 보고서 9건·공식 결과 문서 6건을 읽기 전용으로 확인했다. 기존 전체 보고서 DB 검증 스크립트는 로컬 MFA 테스트 계정에 필요한 fixture secret이 없어 시작 단계에서 중단됐으며, 기존 인증 요소를 임의로 제거하지 않았다.
