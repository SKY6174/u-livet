# 첫 구현 단위 설계 대조

2026-09-19 KST · 대상: [anchor-core-flow](../02-design/features/anchor-core-flow.design.md)

전체 42화면·전체 DB 모델의 완성률을 이 결과로 대신하지 않는다. 아래 10개 항목은 첫 구현 단위의 범위이며 모두 구현했다(구현 항목 10/10). 검증 범위 밖의 운영 조건은 별도 표시한다.

| 항목 | 구현·검증 근거 |
|---|---|
| 서버 인증·역할 | getUser + DB 신원. 브라우저 저장값 ADMIN 변조 후 /admin 진입 거부, user_metadata ADMIN 가입에도 역할 없음 |
| 기관·기수 권한 | 기관 COURSE_MANAGER, INSTRUCTOR + 기수 배정. 다른 기관·미배정 기수 RPC 거부. 승인 강사 배정·해제, 배정 해제 즉시 접근 거부 검증 |
| 개인정보 동의 | 승인·유효한 버전 요구. 가입/신청 동의 이벤트. 다른 목적의 정책으로 신청·공개 거부 |
| 과정/버전/기수 | 새 구조로 분리. 사업단 초안 생성→정책 연결→공개 UI/DB 확인 |
| 무료 신청·등록 | 신청·등록 상태 분리. 동일 신청 재전송 시 동일 ID·동의 1건 |
| 정원·대기·취소 | 8개 동시 요청에서 1명 확정/7명 대기, 초과 승인 거부, 취소 후 대기자 승인 |
| 기본 자료·과제 | 등록 수강생만 자료 열람, 읽음 기록, 텍스트 제출. 열람을 출석·수료로 환산하지 않음 |
| 채점 분리 | 학습자 직접 점수 쓰기/RPC 거부. 담당 강사 채점. 재제출 점수 무효화와 이전 버전 채점 거부 |
| 원자료·가짜 화면 | 기존 SQL/데이터 보존, legacy 접근권한 회수. 임의 증명/배지 중지. 새 Auth 삭제 후 새 person·신청 유지 |
| 운영 기반 검증 | 전체 SQL 로컬 재생, DB security advisor, 빌드·린트, 패키지 감사, 데스크톱·모바일 브라우저 |

변경 사항: 기존 스키마와 공존하기 위해 `life_` 접두어를 사용한다. 노출 RPC는 invoker wrapper, 권한을 검사하는 본문은 private schema에 둔다. 기본 LMS 첫 단위는 텍스트 자료·과제다. 발견된 보안 취약점 때문에 Next 14에서 수정된 15.5.25로 업그레이드했다.

전체 설계에서 아직 남은 기능: 영상 학습·공식 출결·시험·Q&A·파일 제출, 수료 산출/확정, 증명/배지, 강사 프로필/경력증명, 유료 수납/환불/정산, 문자, 지원·상담·설문, 연차별 과정 평가/KPI, 대량 이관·운영관리.

운영 경계: 정책 관리/권한 승인 UI, 관리자 MFA, 보존·파기, 요청 속도제한, 운영 로그·백업/복구, 원격 적용은 이번 단위에서 끝내지 않았다. 기존 데이터의 학습·재무·증명 이관도 별도다. 로컬 보안 검사를 통과했다는 이유로 운영 적합성을 모두 확인했다고 해석하지 않는다.

다음 구현 권고: 공식 출결·과제 정책·시험과 수료판정을 먼저 연결하고, 발급권한이 확정되면 증명·배지로 이어간다. 유료 과정은 청구·입금배분·환불 원장과 동시성 검증을 갖춘 뒤 연다.
