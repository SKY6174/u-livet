# 수료 검토 예시 데이터 구현 점검

> 2026-09-25 · 설계: `docs/02-design/features/anchor-completion-review-sample.design.md`

## 설계 일치율: 100% (7/7)

1. 기존 과정 조회와 기관별 `COURSE_MANAGER`·`CERTIFIER` 권한 검사를 유지했다.
2. 수강등록자가 0명일 때만 예시 링크를 표시하며, `?sample=1`에서도 실제 등록자가 생기면 실제 보드를 사용한다.
3. 수료 확정, 승인 대기, 기준 미달, 중도 환불, 출결 미완료, 자료 변경의 여섯 사례를 `CompletionRow` 구조로 작성했다.
4. 예시 화면에 명확한 안내와 실제 화면 복귀 링크를 표시한다.
5. 정책·운영자료·수료 산출·승인 처리 폼을 예시 화면에서 비활성화한다.
6. 예시 데이터는 서버 메모리에서 생성하며 수강등록·출석·환불·승인 테이블에 저장하지 않는다.
7. 기존 수료율 카드, 출석률, 환불 배지, 판정 근거, 승인 버튼 UI를 그대로 재사용한다.

정적 검사, 타입 검사와 Next.js 빌드가 통과했다. 운영 환경의 두 대상 과정은 현재 전산 수강확정 0명으로 확인했다. 배포 후 로그인 상태에서 화면 표시와 버튼 비활성 상태를 확인할 예정이다.
