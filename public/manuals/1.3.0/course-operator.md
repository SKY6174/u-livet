# 과정 운영 담당자 매뉴얼

UL-M04 | v1.3.0 | 2026-09-25

대상: 과정 담당 연구원·운영센터 실무자
업무 문의: 담당 운영센터·사업단
검수 상태: 소스 기준 제작본 · 운영 검수 전

개설 준비부터 모집·강사·출결·결과보고·주차권까지 운영합니다.

2026-09-25 저장소의 화면·업무 흐름을 기준으로 제작했습니다. 수업 질문, QR 시작·종료 확인, 과정 등록·모니터링, 수료 출석·환불 검토, 구성원 엑셀 관리 등을 반영했습니다. 실제 운영 사이트의 배포 상태와 기관별 정책·위임은 담당자가 확인해야 합니다.

## 시작하기 전에

- 담당 기관의 과정 운영 권한과 추가 인증을 확인합니다.
- 모집·수료·유료 과정의 환불 규정 등 승인된 기준과 담당자를 준비합니다.

### 내 역할로 시작하기

로그인 화면에서 본인 구분을 선택합니다. 수강생은 나의 학습, 강사는 My Room, 사업단 담당자는 사업단 관리로 이동합니다. 실제 메뉴는 부여된 권한·담당 기관·배정·추가 인증 상태에 따라 달라집니다.

### 저장과 완료 확인

버튼을 누른 뒤 성공 안내와 상태·이력을 다시 확인합니다. 입력 중, 저장됨, 검토 요청, 승인, 최종 제출을 구별합니다. 오류가 나면 기존 이력을 먼저 확인하고 중복 신청·발급·송금을 피합니다.

### 도움이 필요할 때

사이트 하단 문의처 또는 해당 과정 운영 담당자에게 과정명·업무 경로·발생 시각·오류 문구를 전달합니다. 비밀번호·추가 인증 코드·개인정보 원문은 보내지 않습니다.

## 1. 개설 준비와 기수 생성

메뉴 경로: 사업단 관리 → 과정 운영 관리 → 개설 준비
시작 화면: /admin/courses

준비할 것: 연간 과정 현황, 계획서, 기관·운영센터·일정·정원

1. 연간 과정 현황과 원본 운영계획에서 과정 등록 여부·기존 개설 기수를 확인합니다.
2. DB 미등록 계획은 원본 계획에서 과정 초안 등록으로 이동해 연결된 계획의 기본값을 검토하고 기수 초안을 저장합니다.
3. 기관·운영센터·기간·정원과 유료 과정의 수강료·승인 환불 규정·납부 안내를 확인합니다.

완료 확인: 원본 계획과 연결된 기수 초안이 준비 상태로 표시됩니다.

확인하세요: 원본 계획에서 만드는 것은 초안입니다. 모집 공개와 강사 배정은 별도로 진행하며 이미 등록된 과정을 중복 생성하지 않습니다.

## 2. 전문가 심사·강사 배정

메뉴 경로: 사업단 관리 → 전문가 관리 / 과정 → 관리 → 담당 강사 배정
시작 화면: /admin/instructors

준비할 것: 이력·자격·필수 서류, 대상 기수

1. 원본 운영계획의 강사·보조강사 명단은 참고자료로 확인하고 실제 승인 강사 계정·배정 상태를 대조합니다.
2. 전문가 관리에서 교내·교외·보조강사 대장과 제출 서류를 확인하고 이력 심사를 처리합니다.
3. 과정 관리에서 승인된 강사를 해당 기수에 배정하고 유효기간을 확인합니다.
4. 과정 관리의 강사진 영역에서 책임강사를 별도 지정하고 저장 결과를 확인합니다. 초기 추천 강사 표시는 실제 책임강사 지정과 다릅니다.
5. 운영계획서와 운영결과보고서 목록에서 지정된 책임강사 이름과 문서 작성 가능 상태를 다시 확인합니다.

완료 확인: 담당 강사의 My Room에 과정이 표시되고 책임 문서의 작성자가 지정됩니다.

확인하세요: 명부 등록, 이력 심사, 기수 배정, 초기 추천 강사, 책임강사 지정은 서로 다른 단계입니다. 보관 과정은 현재 승인된 강사 연결 상태도 확인합니다.

## 3. 모집 공개와 수강생 선발

메뉴 경로: 과정 운영 관리 → 해당 과정 → 관리 → 모집 공개 / 신청 내역
시작 화면: /admin/courses

준비할 것: 확정 일정·정원·모집기간과 승인 기준

1. 기수의 교육정보·모집기간·수료 기준·유료 조건을 확인하고 모집 공개를 진행합니다.
2. 신청 내역에서 대상자와 자격·정원을 확인하고 선발 처리를 진행합니다.
3. 무료 과정은 등록 상태를, 유료 과정은 납부 대기 및 입금 확인 후 등록 상태를 확인합니다.

완료 확인: 공개 과정 안내와 신청·등록 인원이 일치하며 선발 결과가 저장됩니다.

확인하세요: 유료 선발은 납부 대기 상태일 수 있습니다. 입금 신고만으로 수강을 확정하지 않습니다.

## 4. 과정 모니터링과 수업 운영

메뉴 경로: 사업단 관리 → 과정 모니터링 / 과정 운영 관리
시작 화면: /admin/courses

준비할 것: 회차 일정, 강사 기록, 승인 안내 문안

1. 과정 모니터링에서 신청·수업·출결·수료 신호를 확인하고 지연 또는 누락 과정을 엽니다. 신호등은 일정 상태, PDCA 진행률은 기록된 근거를 나타냅니다.
2. 2026년 1월부터 2027년 2월까지 단계별 계획일·실제일과 P·D·C·A 진행률을 대조하고 누락된 계획·모집·출결·결과·평가 근거를 확인합니다.
3. 수업 일정과 강사 배정·수강 확정 인원을 점검하고 종료 회차의 QR 시작·종료 기록과 확정 출결을 대조합니다.
4. 안내문자에서는 승인 문안·대상 조건과 미리보기 제외 사유를 확인하고 처리 이력을 점검합니다.

완료 확인: 과정별 지연·누락 근거와 다음 조치, 문자 상태가 확인됩니다.

확인하세요: PDCA 비율은 근거 자료를 따라 변합니다. 문자 예약·테스트 처리 상태를 실제 발송 성공으로 안내하지 않습니다.

## 5. 수강생 서류 접수·검토

메뉴 경로: 사업단 관리 → 접수·운영 → 수강생 서류
시작 화면: /admin/learner-documents

준비할 것: 과정 운영·재정·시스템 관리자 역할, 담당 기관 범위와 최근 추가 인증

1. 사업단 관리 첫 화면의 업무 요청에서 수강신청·장학금·환불 미종결 건과 최근 요청을 확인합니다. 화면이 보이는 동안 30초마다 갱신되며 필요하면 새로고침을 누릅니다.
2. 수강생 서류함의 종류 버튼과 처리 상태, 이름·이메일·과정 검색을 조합해 대상을 찾습니다. 목록 표에서 과정·제출 시각·상태를 확인합니다.
3. 제출 원본과 처리 이력을 열어 입력 내용과 이전 안내를 확인합니다. 원본에 주민등록번호·계좌·서명이 포함될 수 있으므로 업무에 필요한 담당자만 엽니다.
4. 화면에 제시된 다음 처리 단계만 선택하고 검토 결과와 다음 절차를 수강생 안내에 구체적으로 입력한 뒤 상태 저장을 누릅니다.
5. 저장 후 새 상태와 이력을 확인합니다. 다른 담당자가 먼저 처리했다는 안내가 나오면 화면을 새로 열어 최신 상태를 기준으로 다시 판단합니다.

완료 확인: 수강생과 담당자 양쪽에 같은 처리 상태·안내·이력이 표시됩니다.

확인하세요: 안내 내용은 수강생에게 즉시 공개됩니다. 서류 승인은 수강 확정·수료 승인·장학금 지급·환불 산출·송금을 자동 처리하지 않으므로 해당 담당자에게 별도로 인계합니다.

## 6. 운영 문서 검토와 최종 제출

메뉴 경로: 사업단 관리 → 운영계획서 / 운영결과보고서
시작 화면: /operation-documents/plan

준비할 것: 책임강사 지정·작성 내용, 예산계획·집행 근거와 추가 인증

1. 분리된 운영계획서·운영결과보고서 목록에서 기관·사업연도·아카데미·상태를 필터링하고 카드형·리스트형 보기로 작성·검토 대상을 찾습니다.
2. DB 이관 대기·과정 DB 미등록 표시는 원문 계획의 상태입니다. 원본 계획에서 과정 초안 등록과 식별자 연결을 완료한 뒤 편집·제출합니다.
3. 결과보고서의 예산계획·집행현황과 장학금 집계를 먼저 입력·확정합니다. 예산이 확정되어야 책임강사가 결과 내용과 서명을 완료할 수 있습니다.
4. 책임강사의 검토 요청에서 내용·최신 서명·예산·일정·사진을 확인합니다. 수정이 필요하면 사유를 남겨 보완 요청합니다.
5. 필수 내용과 증빙을 확인한 뒤 최종 제출하고 제출 이력의 버전·시각과 저장본 출력을 확인합니다. 출력에서는 일정의 날짜·시간, 담당자 소속·이름·서명과 결과 표지의 중복 서명 여부를 점검합니다.
6. 최종본 수정이 필요하면 사유와 함께 다시 작성 상태로 전환하고 새 버전으로 제출합니다.

완료 확인: 최종 제출 이력에 스냅샷이 보관되고 이전 제출본을 열 수 있습니다.

확인하세요: 저장, 예산 확정, 책임강사 서명, 검토 요청, 최종 제출을 구별합니다. 제출 후 문서는 불변 스냅샷으로 보관됩니다.

## 7. 결과보고서 원본·사진·장학금·첨부 검토

메뉴 경로: 운영결과보고서 → 대상 문서 → 원본 PDF·AI 가져오기 / 미리보기·인쇄
시작 화면: /operation-documents/result

준비할 것: 권한이 확인된 원본 결과 PDF, 실제 일정·예산·장학금·사진·출결·강의 근거

1. 기존 또는 새 원본 결과 PDF를 선택해 보관 상태를 확인합니다. AI 제안은 쪽수·원문 근거가 확인된 항목만 선택하며 자동 저장·자동 제출되지 않습니다.
2. 가져온 일정은 일자·시작시간·종료시간으로 나뉘었는지 확인하고, 예산·장학금 숫자와 원본 PDF 서명 참고 이미지를 현재 입력값·책임강사 서명과 구분합니다.
3. 운영사진의 표제·날짜와 16:9 중앙 자르기 결과를 확인합니다. 본문 이후 사진 전용 페이지는 한 페이지에 최대 8장씩 배치됩니다.
4. 수강생별 장학유형·지급률·지급액·계좌·지급일을 입력하고 집계값을 확인합니다. 일반 화면과 출력에서 계좌번호 마스킹 여부를 점검합니다.
5. 통합 인쇄에서 본문 뒤 첨부 1 출석부, 첨부 2 수료자명단, 첨부 3 장학금 지급현황, 첨부 4 강사 강의날인부, 첨부 5 강사료 지급현황 순서와 내용을 대조합니다.

완료 확인: 선택해 반영한 원본 근거와 현재 입력값이 구분되고, 결과보고서 본문·사진·장학금·첨부 1~5를 검토했습니다.

확인하세요: PDF·AI 가져오기는 검토용 초안을 만드는 기능입니다. 원본 서명 참고 이미지는 현재 책임강사 서명이나 제출 권한을 대신하지 않으며 개인정보·계좌정보는 필요한 담당자만 열람합니다.

## 8. 센터별 주차권 재고·승인·대장

메뉴 경로: 사업단 관리 → 무료 주차권 관리
시작 화면: /admin/parking

준비할 것: 과정 담당 센터, 재고 입고 근거, 지정 확인 담당자

1. 연도·센터와 과정의 담당 센터를 확인하고 실제 수령한 매수·사유로 재고를 등록합니다.
2. 승인 대기에서 과정·교육일·수령자·매수·재고를 대조합니다. 지정된 확인 담당자의 본인 계정으로 승인·발급 또는 반려합니다.
3. 처리 기록의 발급 매수·잔여 재고·확인자를 점검하고 사용대장을 출력합니다.

완료 확인: 승인된 발급 기록과 재고 잔액이 함께 반영됩니다.

확인하세요: 과정 운영 권한만으로 모든 센터의 승인자가 되는 것은 아닙니다. 권한 안내가 보이면 지정 담당자에게 요청합니다.

## 9. 운영절차 안내 확인

메뉴 경로: 사이트 하단 → 운영절차
시작 화면: /operation-procedure

준비할 것: 과정의 현재 단계와 담당 업무

1. 운영절차에서 개설·모집·수업·마감·정산의 순서와 단계별 준비물을 확인합니다.
2. 현재 단계의 책임자·필요 문서와 시스템 상태를 대조하고 다음 담당자에게 누락 사항을 인계합니다.

완료 확인: 현재 단계와 다음 처리 담당자가 정리됩니다.

확인하세요: 안내 페이지는 공통 흐름입니다. 실제 승인·집행 기준은 해당 과정의 승인된 정책과 위임을 따릅니다.

## 업무 점검표

- 매일 신규 신청·납부 대기·수강생 서류·운영문서 검토 요청을 확인합니다.
- 개강 전 강사 배정·정원·수업 일정·자료 공개를 확인합니다.
- 종강 후 출결·강의날인·평가 마감, 수료 담당 인계와 최종 문서 제출을 확인합니다.
- 결과보고서의 원본 근거·사진·장학금 세부내역·첨부 1~5를 최종 제출 전에 대조합니다.

## 문제 해결

### 저장 충돌 안내가 나와요.

다른 담당자의 최신 저장 상태를 확인하고 화면을 새로 연 뒤 변경을 반영합니다. 오래된 화면으로 덮어쓰지 않습니다.

### 최종 제출을 할 수 없어요.

책임강사 지정, 예산 선확정, 필수 내용, 최신 책임강사 서명, 검토 요청 상태와 본인의 담당 권한·추가 인증을 확인합니다.

### PDF를 가져왔는데 바로 제출되지 않아요.

가져오기는 원본 보관과 검토 초안 생성 단계입니다. 근거가 확인된 제안만 선택해 반영하고 예산·개인정보·서명·첨부를 직접 검토한 뒤 저장·서명·검토 요청·최종 제출 절차를 진행합니다.
